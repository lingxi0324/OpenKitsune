## 📋 八字推演总纲（十五步流程）

### 第一步：排四柱八字

**万年历查定**：
- **年柱**：以立春为界。立春前为上一年，立春后为当年
- **月柱**：以节气分界。正月寅（立春）、二月卯（惊蛰）、三月辰（清明）、四月巳（立夏）、五月午（芒种）、六月未（小暑）、七月申（立秋）、八月酉（白露）、九月戌（寒露）、十月亥（立冬）、十一月子（大雪）、十二月丑（小寒）
- **月干推算法**：五虎遁法——甲己之年丙作首，乙庚之岁戊为头，丙辛之年寻庚上，丁壬壬寅顺水流，若问戊癸何处起，甲寅之上好追求
- **日柱**：查万年历，或按公式计算
- **时柱**：五鼠遁法——甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途

**确认四柱** → 导出八个天干地支字

### 第五步：判定日主强弱（量化法）

综合《八字强弱鉴定法》台湾何建忠量化法 + 传统经验法：

#### 方法一：传统经验法（八字实战讲义）

**A. 得令**（月令为最重）：
- 日干生于临官、帝旺月 → 得令，旺度最高
- 日干生于长生、冠带月 → 得气
- 日干生于衰、病、死月 → 失令
- 日干生于墓、绝月 → 失令最重

**B. 得地**（地支通根）：
- 地支有日干之禄、旺 → 强根
- 地支有日干长生 → 有根
- 地支有日干余气（库、墓）→ 微根
- 地支无根 → 无根（漂）

**C. 得势**（天干生助多少）：
- 同五行天干多 → 势强
- 印比生助多 → 势强
- 财官食伤多 → 消耗重

**D. 综合判断**：
| 状态 | 得令+得地+得势 | 含义 |
|:----|:--------------|:------|
| 身旺 | 三项皆备或二强一弱 | 可抗官杀、担财 |
| 身强 | 月令得气+地支有根 | 中强 |
| 中和 | 月令不强不弱+天干平衡 | 最宜 |
| 身弱 | 失令+根浅或无根 | 需印比帮扶 |
| 从格 | 失令+孤立无根 | 从势而变 |

#### 方法二：量化计分法（参考何建忠）

```
A = 天干生助日干的旺度之和（印+比劫的分数）
B = 日干对月令的当令度 N（0.0~1.0）
C = 平衡标准值 = 4.5 - 0.9×N

A > C → 日主偏强
A < C → 日主偏弱
A ≈ C → 中和
```

### 第九步：取用神（最核心步骤）

依《子平真诠评注》用神五法 + 《滴天命理新论》相对论 + 《命理正宗》口诀综合判断：

#### 法一：扶抑（最常用）
| 日主状态 | 用神取法 |
|:---------|:---------|
| **日主太旺** | 克（官杀）、泄（食伤）、耗（财星） |
| **日主太弱** | 生（印）、助（比劫） |
| **日主中和** | 看月令旺神，旺者抑之，弱者扶之 |

#### 法二：病药（张神峰心法）
> 八字有"病"（失衡处），能去病的是用神

常见病药：
| 病（失衡） | 药（用神） |
|:----------|:-----------|
| 比劫多（争财） | 官杀制比劫 / 食伤泄比劫生财 |
| 财多身弱 | 印生身 / 比劫帮身 |
| 官杀混杂 | 印化官杀 / 合去一神 |
| 食伤过旺 | 印制食伤 |
| 印星过旺 | 财破印 |
| 寒暖湿燥过偏 | 调候（见法三）|

#### 法三：调候（依气象）
根据日干生于寒暖之月，以调候为先：

| 情况 | 调候用神 |
|:-----|:---------|
| 生于冬月（亥子丑），命局寒湿 | **火**（暖局） |
| 生于夏月（巳午未），命局燥热 | **水**（润局） |
| 生于春秋，气候适中 | 以扶抑为先 |

**注意**：调候有时比扶抑更重要——"金寒水冷"必须用火，"火炎土燥"必须用水。

#### 法四：通关（化解冲突）
当两种五行对峙、势均力敌时，用通关之神：

| 对峙 | 通关之神 |
|:----|:---------|
| 金木相战 | **水**（泄金生木） |
| 水火相战 | **木**（泄水生火） |
| 火金相战 | **土**（泄火生金） |
| 土水相战 | **金**（泄土生水） |
| 木土相战 | **火**（泄木生土） |

#### 法五：专旺（特殊格局取用法）
从格/专旺格：**顺其势，不可逆**
- 从财格：行财运最佳，官杀次之
- 从杀格：行杀运最佳，财星次之
- 从旺格：行印比运最佳

### 第十三步：排大运

**起运岁数**：
- 阳年男命、阴年女命 → 顺行
- 阴年男命、阳年女命 → 逆行

**计算方法**：
1. 顺行：从生辰日到下一个节气，计天数 ÷ 3 = 起运岁数
2. 逆行：从生辰日逆数到上一个节气，计天数 ÷ 3 = 起运岁数
3. 余数处理：一天计4个月，一个时辰计10天

**大运干支**（《子平真诠评注》法）：
- 顺排：月柱干支的下一个干支
- 逆排：月柱干支的上一个干支
- 每十年一运，干支各管五年

**特殊提醒**（《八字实战讲义》）：
- **反对大运上下五年分看法**——赵知易认为大运十年看整体趋势，干支共同影响
- 应以原命的用神体系为准，结合大运干支与原命的生克制化综合判断

### 第十四步：论流年吉凶

**核心原则**（《滴天命理新论》法）：

1. **太岁为君**：流年为当年主宰，力大于大运
2. **岁运并临**：大运与流年干支相同 → 吉凶倍之（《八字实战讲义》有大量案例）
3. **冲合见吉凶**：
   - 流年冲用神 → 凶多吉少
   - 流年合忌神 → 转危为安
   - 流年合用神 → 或有阻滞
4. **岁伤日干**（天克地冲）：凶
5. **日犯岁君**（日干克流年天干）：凶，需要五行有救

**具体论法**：
```
流年干支 + 大运干支 + 原命局
→ 三者生克制化
→ 决定本年度吉凶
```

**重要提醒**（《命理正宗》）：
> "太岁乃众煞之王，入命未必为殃；若遇战斗之乡，必主刑于本命"

```
八字画像 = 
  ① 格局类型（正格/从格/专旺格）
  + ② 日主强弱（旺/强/中/弱/从）
  + ③ 用神取定（扶抑/病药/调候/通关/专旺）
  + ④ 忌神（最不利的五行/十神）
  + ⑤ 关键制化（合/冲/刑的重要影响）
  + ⑥ 大运趋势（每十年有不同主题）
  + ⑦ 流年焦点（本年度的主要变化）
```
