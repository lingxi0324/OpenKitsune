# 第二十三篇 · 杂疗方

## 一、三观分析

### 津液观
本篇核心不在津液，而在**气机**——救急之法，要在**通闭救逆**，使气机周转恢复。
- 自缢死 → 气道闭塞，需**通天气**
- 溺死 → 水闭肺窍，需**宣通肺气**
- 中恶客忤 → 气机逆乱，需**安神定气**

### 表里观
- 救卒死（突然昏仆）→ **里气暴脱，当急固之**
- 救自缢 → **表气闭塞，当徐徐通之**（不可骤然解绳）
- 凡卒死而张口、手撒、遗尿 → **里气已脱，难治**

### 正邪观
- 救自缢 → **邪闭气机，正气未绝**（可救之机）
- 中恶 → **邪气暴中，正气尚存**（当急驱邪）
- 救溺死 → **水邪闭窍，正阳被困**（温覆取汗）

## 二、四证定性

| 证类 | 条文 | 定性 |
|:-----|:-----|:-----|
| **气证** | 救自缢死："徐徐抱解，不得截绳，上下安被卧之。一人以脚踏其两肩，手少挽其发，常弦弦勿纵之。一人以手按据胸上，数动之。一人摩捋臂胫，屈伸之。" | 气道闭塞→通天气 |
| **血证** | "若已僵，但渐渐强屈之，并按其腹。如此一炊顷，气从口出，呼吸眼开。" | 血脉凝滞→通血络 |
| **水证** | 救溺死："取灶中灰两石余，以埋人，从头至足。水出七孔，即活。" | 水邪闭窍→灶灰吸水 |
| **火证** | "凡中暍死，不可使得冷，得冷便死。" — 暑热闭窍，忌用冷 | 暑邪闭窍→温通救逆 |

## 三、方阵归属

本篇无成方，皆为急救术法：

| 急救术 | 方阵归属 | 机理 |
|:-------|:---------|:-----|
| 救自缢法 | **太阳开表法**（类麻黄汤意） | 通天气以开闭 |
| 救溺死法 | **太阴温运法**（灶灰温覆） | 灶灰吸水+温复阳气 |
| 救冻死法 | **少阴回阳法** | "切勿以火炙"，缓以温热 |
| 救中恶法 | **少阳枢转法**（吹鼻取嚏） | 通窍醒神，枢转气机 |

## 四、天干化气·病机映射

| 急救 | 天干 | 病机 |
|:-----|:----|:-----|
| 救自缢 | **乙庚化金** → 庚金（大肠）闭→气道不通 | 庚金主天气，自缢闭庚金→通庚金（按胸） |
| 救溺死 | **丙辛化水** → 水邪太过，丙火被困 | 灶灰（火之余烬→扶丙火）+温覆 |
| 救冻死 | **戊癸化火** → 癸水寒凝，戊土失温 | 缓温勿急，待戊癸自化 |
| 救中恶 | **丁壬化木** → 木郁气乱，丁火失明 | 吹鼻取嚏→通丁火（心）以安神 |
| 救卒死 | **甲己化土** → 甲木（胆）气脱，己土（脾）失守 | 取嚏→甲木得通，己土自固 |

# 第二十四篇 · 禽兽鱼虫禁忌并治

## 一、三观分析

### 津液观
本篇重在**饮食入胃后的运化**——五脏各有所恶，所食不洁/不当则**伤津损液**。
- 肝病禁辛 → 辛散伤肝阴
- 心病禁咸 → 咸走血伤心液
- 脾病禁酸 → 酸收碍脾运
- 肺病禁苦 → 苦燥伤肺津
- 肾病禁甘 → 甘缓碍肾气

### 表里观
- 食禁之要在**里**——饮食入胃，直接影响**太阴阳明**运化
- 表证未解忌食肉 → 肉腻滞表，邪不得出

### 正邪观
- 有毒之物 → **邪气直中**，当吐下之
- 不洁之物 → **邪从口入**，脾胃先伤
- 五脏各有所禁 → **护正以避邪**

## 二、四证定性

| 证类 | 核心禁忌 | 致死机制 |
|:-----|:---------|:---------|
| **水证** | 食犬鼠余→生癥瘕 | 秽毒入血，水湿凝聚 |
| **火证** | 食诸肉过度→发黄 | 肉积化热，湿热熏蒸 |
| **气证** | 六畜自死→疫毒闭气 | 毒气入胃，气机闭绝 |
| **血证** | 生肉伤胃→瘀阻经络 | 肉毒入血，血脉瘀滞 |

## 三、方阵归属

本篇虽无完整方剂，但仲景给出了**解毒方阵**：

| 禁忌 | 解救 | 方阵归类 |
|:-----|:-----|:---------|
| 食诸肉中毒 | 煮大豆汁→饮之 | **阳明清解**（豆汁解毒） |
| 食牛肉中毒 | 煮甘草汁→饮之 | **太阴解毒**（甘草和中） |
| 食狗鼠余毒 | 韭汁灌之 | **厥阴温通**（韭温肝经） |
| 食马肉中毒 | 芦根汁→饮之 | **太阳清解**（芦根利尿） |
| 食自死六畜肉毒 | 黄柏屑→水服 | **少阴清解**（黄柏清肾热） |

# 第二十五篇 · 果实菜谷禁忌并治

## 一、三观分析

### 津液观
果菜多生冷，**过食伤脾阳、损津液**。谷类为常食，**误食不当则滞胃气**。

### 表里观
- 生冷果菜 → 直伤**太阴（脾）**
- 霉变谷食 → 直伤**阳明（胃）**

### 正邪观
- 果子落地经宿 → **虫蚁食之，人大忌**（邪从口入）
- 菌类辨识 → **春夏生者有毒，冬夏无毒**（择时以避邪）

## 二、四证定性

| 证类 | 核心禁忌 | 致死机制 |
|:-----|:---------|:---------|
| **水证** | 食诸果过甚→水渍于脾 | 果酸化水，脾湿不运 |
| **火证** | 食诸菜过甚→胃热上冲 | 菜辛助火，胃火上炎 |
| **气证** | 食诸菌中毒→气机闭绝 | 菌毒闭气，神昏欲死 |
| **血证** | 食枫菌（木耳类）→血痢 | 菌毒伤络，血不循经 |

## 三、解毒方阵

| 禁忌 | 解救 | 方阵归类 |
|:-----|:-----|:---------|
| 食诸果中毒 | 猪骨烧灰→水服 | **少阴固涩**（骨灰吸附毒素） |
| 食诸菜中毒 | 煮甘草、荠苨汁→饮 | **太阴解毒**（甘草和百药） |
| 食菌中毒 | 地浆水饮之 | **太阴解毒**（黄土制毒） |
| 食枫菌中毒 | 人粪汁饮之 | **阳明涌吐**（激吐排毒） |
| 食蜀椒闭口者 | 饮冷水 | **阳明清解**（冷水制热毒） |
| 食生枣多 | 令人腹胀→利即愈 | **太阴通利**（枣甘壅脾） |

## 四、五味过食·五脏受病

| 味 | 过食所伤 | 症状 | 河图数理解 |
|:--|:---------|:-----|:----------|

| **苦** | 伤肺 | 皮槁而毛拔 | 火(2)克金(4)→金体受伤 |
| **甘** | 伤肾 | 骨痛而发落 | 土(5)克水(1)→水体受伤 |

> **此即「五味过极则自伤其脏」之理——河图相克为害。**

# 📊 终篇总结 · 二十三至二十五篇整体评价

## 后三篇的学术价值

### 杂疗方第二十三
> **价值**：中医急救术的**最早系统记载**——救自缢、救溺死、救冻死、救中恶，奠定了中医急救学的雏形。其核心思想"徐徐救之，勿急勿骤"至今仍是急救铁律。

### 禽兽鱼虫禁忌第二十四
> **价值**：中医饮食禁忌学的**源头文献**——五脏各有所禁、五畜各有所忌，为后世"食疗""食禁"学科奠定基础。其"肝病禁辛，心病禁咸"的原则至今指导临床。

### 果实菜谷禁忌第二十五
> **价值**：中医果蔬禁忌+解毒学——"果子落地经宿，虫蚁食之，人大忌"，两千年前已认识到食品安全问题。
