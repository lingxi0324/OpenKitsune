# 针法体系对比 · 北斗七星 / 五套化气 / 干支化气 / 针灸大成

> 本体系为玄医融合针法体系之一，与现有针法体系各有定位，互补而非替代。

---

## 三大针法体系对比

| 体系 | 核心原理 | 配穴范围 | 适应症 | 操作特点 |
|------|----------|----------|--------|----------|
| **北斗七星针法** | 七穴打底 + 奇门扩展 | 七星主穴 + 奇门扩展配穴 | 内伤三阴病、急症 | 七穴打底，奇门格局扩展配穴 |
| **五套化气针法** | 五脏各一套，基于天干化合 | 五脏特定穴位 | 五脏特定病机 | 每脏一套固定配穴方案 |
| **干支化气针法** | 干支双维映射 + 化气原理 | 纯十二经五输穴 | 虚实证候、固结顽邪 | 虚用合、实用劫；劫必归合 |
| **针灸大成** | 十四经穴 + 子午流注 + 补泻八法 | 361穴 + 特定穴 + 奇穴 | 通治百病，经络辨证 | 常法底盘，以穴定经、以时定穴 |
| **针灸大成古法** | 干支化气阵·四大古法+八法总诀 | 古法独立穴对 | 特定病候、古法传承 | 干支化气拆解、合机劫法定位 |

## 干支化气针法详细定位

### 核心原理

| 维度 | 内容 |
|------|------|
| **天干维度** | 五门十变天干化合（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火）定气化方向 |
| **地支维度** | 地支归经（子=肾、午=心、丑=肺、未=脾、寅=胆、申=三焦、卯=胃、酉=大肠、辰=膀胱、戌=小肠、巳=心包、亥=肝）定病位深浅 |
| **阴阳辨证** | 虚则合而养之、和之；实则劫而散之、破之 |
| **闭环铁律** | 虚用合、实用劫；合为体、劫为用；劫必归合、散必复收 |

### 适应症细分

| 病机类型 | 治法 | 对应体系 |
|----------|------|----------|
| 一切虚损、气机不和、久病失调 | 合机常法（补法/平补平泻） | 合机 |
| 一切实证、固结死瘀、痰瘀毒结块 | 劫法阶梯（纯泻法） | 劫法 |
| 本虚标实、固结顽邪 | 劫法攻坚 + 合机收摄 | 劫必归合 |
| 劫法术后修复 | 合机养护 | 合机 |
| 癥积结节、气机死寂 | 阶梯劫法攻坚 | 劫法 |

### 配穴特色

| 特色 | 说明 |
|------|------|
| **纯五输标准化** | 全程仅用十二经五输穴，无杂穴、无奇穴、无局部取穴 |
| **四级阶梯劫法** | 六破→六害→三刑→六冲，由浅入深、标准化攻坚 |
| **攻后必收** | 任何劫法后必配合机收摄，劫必归合 |
| **双维映射** | 天干化合（五门十变）+ 地支归经（六合）双维配穴 |

## 体系互补关系

| 场景 | 首选体系 | 备选/辅助 |
|------|----------|-----------|
| 急症、内伤三阴 | 北斗七星针法 | 干支化气合机辅助 |
| 五脏特定病机 | 五套化气针法 | 干支化气合机辅助 |
| 顽痰死瘀、固结癥积 | 干支化气劫法 | 北斗/五套术后合机收摄 |
| 久病虚损、气机不和 | 干支化气合机 | 北斗/五套合机辅助 |
| 劫法术后修复 | 干支化气合机 | 通用合机 |
