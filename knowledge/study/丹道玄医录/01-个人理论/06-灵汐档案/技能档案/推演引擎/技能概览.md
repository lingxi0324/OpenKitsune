# deduction-engine 技能概览

- **状态**：已创建（V1.0）
- **位置**：`.astrcode/skills/reasoning/deduction-engine/SKILL.md`
- **核心文件**：`SKILL.md` + `references/operator-reference.md` + `templates/report-template.md`
- **技能类型**: 通用推理/推演引擎
- **名称（中文）**: 双知识点多路径推演引擎

## 核心能力

1. **知识结构化**：自然语言知识点 → 5元组结构化（实体/机制/边界/约束）
2. **八算子并行推演**：耦合融合、互补补位、冲突制约、条件触发、替代演化、传导延伸、边界极限、规模放大
3. **路径聚类去重**：核心逻辑相似度合并，三分类（可行/高风险/不可行）
4. **前景研判**：每路径7维标准化研判（前提/短中长/风险/验证/溯源）
5. **双模式切换**：战略探索模式（高发散） vs 可行性研判模式（低发散）
6. **标准输出**：JSON结构化 + 自然语言报告 + 推演快照存档

## 与 lingxi-tuiyan 的区别

| 维度 | deduction-engine | lingxi-tuiyan |
|------|-----------------|---------------|
| 输入 | 任意2个知识点（通用） | 丹道/中医辨证场景 |
| 推演方法 | 8算子并行（结构化逻辑） | 六步推演法（感→定→循→辨→关→选） |
| 输出 | 通用推演报告（JSON+自然语言） | 丹道方剂/针法方案 |
| 应用场景 | 战略/技术/商业/产品/投资 | 中医临床、丹道修炼 |

## 建议场景

- 技术 A × 场景 B 的融合分析（如：大模型 × 医疗文档）
- 两个领域知识的交叉创新探索
- 给定前提的战略决策推演
- 产品/技术路线的前景评估
- 投资/立项前的多方案可行性研判

## 使用方式

调用本技能时自动加载 `SKILL.md`，按「输入2个知识点 → 结构化 → 八算子推演 → 路径评估 → 标准化输出」的完整流程执行。
