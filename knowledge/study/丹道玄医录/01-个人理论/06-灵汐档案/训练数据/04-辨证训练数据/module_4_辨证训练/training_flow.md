## 三、训练专题（12个）

### 专题1：八纲辨证基础
- 表里（病位深浅）
- 寒热（病性属性）
- 虚实（正邪盛衰）
- 阴阳（总纲）
- 组合证型（表寒/里热/虚寒/实热等）

### 专题2：六经辨证—太阳病
- 太阳经证（中风/伤寒）
- 太阳腑证（蓄水/蓄血）
- 太阳兼变证

### 专题3：六经辨证—阳明病
- 阳明经证（四大症）
- 阳明腑证（痞满燥实坚）
- 阳明病鉴别

### 专题4：六经辨证—少阳病
- 少阳半表半里
- 少阳兼证
- 柴胡证系列

### 专题5：六经辨证—太阴/少阴/厥阴
- 太阴病（脾阳虚）
- 少阴病（寒化/热化）
- 厥阴病（寒热错杂）

### 专题6：五脏辨证—心/小肠
- 心气虚/阳虚/血虚/阴虚
- 心火亢盛/心脉瘀阻/痰火扰心
- 小肠实热

### 专题7：五脏辨证—肝/胆
- 肝气郁结/肝火上炎/肝血虚/肝阴虚
- 肝风内动（四型）
- 肝胆湿热

### 专题8：五脏辨证—脾/胃
- 脾气虚/脾阳虚/中气下陷/脾不统血
- 胃阴虚/胃火炽盛/食滞胃脘
- 寒湿困脾/湿热蕴脾

### 专题9：五脏辨证—肺/大肠
- 肺气虚/肺阴虚
- 风寒束肺/风热犯肺/痰热壅肺
- 大肠湿热/大肠津亏

### 专题10：五脏辨证—肾/膀胱
- 肾阳虚/肾阴虚/肾精不足/肾气不固
- 肾不纳气/肾虚水泛
- 膀胱湿热/膀胱虚寒

### 专题11：内伤外感双轨辨证
- 第一步：辨外感（六经/卫气营血）
- 第二步：辨内伤（五脏/气血津液）
- 第三步：两线交叉分析
- 第四步：合方论治
- 参照：灵汐/百病六经辨证篇.md

### 专题12：河图体用双轨辨证（进阶）
- 体：先天禀赋/五脏基础状态
- 用：当前病变/临床表现
- 体用关系（体病用变/用病体虚/体用俱病）
- 溯因：从"用"逆推至"体"→从"体"预测"用"的变化

## 四、辨证思维训练法

**三步辨证法：**
```
Step 1：抓主症 → 找出最特异的1-2个症状
Step 2：定病位 → 六经？五脏？卫气营血？
Step 3：定病性 → 寒热虚实？气滞血瘀痰饮水湿？
```

**双轨辨证法（核心技能）：**
```
外感线 → 六经/卫气营血/三焦辨证框架
内伤线 → 五脏/气血津液辨证框架
   ↓
交叉分析 → 两线叠加效应
   ↓
合方论治 → 外感方+内伤方融合
```

## 五、每日训练计划

**日常15分钟：**
```
3分钟 → 随机抽一个证型，完整描述其特征
5分钟 → 给出3个症状，用三步辨证法分析
5分钟 → 双轨辨证练习（同时分析外感和内伤）
2分钟 → 记录进度
```
