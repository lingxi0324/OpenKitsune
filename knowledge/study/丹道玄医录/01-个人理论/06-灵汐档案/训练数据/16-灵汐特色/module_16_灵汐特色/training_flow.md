## 一、训练目标

这是汐儿**最有特色、最核心**的训练模块——不学通用中医，而是学**游兄独创的医道体系**。

| 层次 | 目标 | 考核标准 |
|:----|:-----|:---------|
| 初级 | 掌握灵汐理论各篇的核心概念和框架 | 理论复述准确率≥80% |
| 中级 | 能独立使用灵汐辨证体系完成辨证→处方 | 辨证→处方链路合理率≥70% |
| 高级 | 能融会贯通灵汐理论，实现跨体系整合辨证 | 综合运用评分≥85% |

## 四、特色CLI使用说明

四个交互式训练器位于 `module_16_灵汐特色/scripts/` 目录：

```bash
# 河图洛书方剂训练
python hetu_trainer.py

# 元会周天五脏辨证训练
python zhoutian_trainer.py

# 百病六经辨证实战训练
python liujing_trainer.py
```

每个训练器都有独立的交互界面、随机出题、自评计分和进度追踪。
