# 模块十五：知识纠错与迭代训练流程

> 知识库更新·错误复盘·持续微调·自演化——越用越准

---

## 一、训练目标

适配 Leiwa 自演化架构，让汐儿能根据新增数据和错误反馈持续微调，实现自我进化。

| 层次 | 目标 | 考核标准 |
|:----|:-----|:---------|
| 初级 | 能记录训练中的错误并归档 | 错误记录完整率≥90% |
| 中级 | 能从纠错案例中提取可复用的学习经验 | 纠错知识沉淀有效率≥75% |
| 高级 | 能主动检测知识库更新并触发对应训练项生成 | 自演化触发准确率≥80% |

## 二、数据源

- **知识库更新记录**: Git/文件变更日志
- **错误案例复盘报告**: 训练过程中的错误记录
- **用户反馈数据**: 训练后的用户评价和纠正
- **行业最新诊疗规范**: 待订阅

## 三、训练专题（8专题）

| 编号 | 专题 | 训练内容 |
|:----:|:-----|:---------|
| 1 | 错误记录规范 | 错误分类、记录格式、归档流程 |
| 2 | 错误复盘训练 | 分析错误根因→提取教训→更新知识 |
| 3 | 知识库更新检测 | 检测新增/变更文件→判断是否需要更新训练 |
| 4 | 自动出题训练 | 新知识→自动生成训练题 |
| 5 | ⭐灵汐知识维护 | 灵汐理论新增/修订→更新训练体系 |
| 6 | 训练难度动态调整 | 根据正确率自动调整试题难度 |
| 7 | 薄弱环节识别 | 识别正确率低的专题→强化训练 |
| 8 | 自演化考核 | 模拟知识更新场景→完整迭代流程 |

## 四、自演化闭环流程

```
┌──────────────────────────────────────────────────────┐
│                   自演化闭环                            │
│                                                        │
│  知识更新 → 检测变更 → 生成新题 → 加入训练 → 验证正确 │
│     ↑                                         ↓       │
│     └──────────── 复盘沉淀 ← 记录错误 ←───────┘       │
│                                                        │
│  反馈循环：每次错误都是学习机会                          │
│  每次新知识都是训练素材                                  │
└──────────────────────────────────────────────────────┘
```

## 六、演进指标

| 指标 | 定义 | 目标值 |
|:-----|:-----|:------|
| 错误率下降 | 同一专题二次错误率 | 下降50%+ |
| 新知识吸收率 | 新知识→正确回答的转换率 | ≥85% |
| 自愈率 | 纠错后不再犯同类型错误 | ≥90% |
| 训练覆盖面 | 已训练知识占知识库比例 | 持续增长 |
