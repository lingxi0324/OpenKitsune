### 1.2 五行生克关系

```
        木（震·巽）
        ┃   ↑
        ┃   │相生
        ┃   │
   火（离）←←←→→→ 土（坤·艮·中）
        ┃               ┃
        ┃               ┃
        ↓               ↓
   金（乾·兑）→→→→→ 水（坎）
```

### 1.3 维度判定总则

任何事物或问题进入推演时，按以下顺序确定宫位归属：

1. **主属性判定**：问题最核心的领域归属（如"发热咳嗽"→二宫坤·中医）
2. **次维度标记**：涉及的其他辅助维度（如"发热咳嗽"同时涉及六宫乾·因果推演）
3. **跨宫联动**：主宫与次宫的生克关系决定推演优先级
4. **中宫统摄**：最终收敛时所有维度回归五宫中宫归一

## 三、维度间生克制衡关系

### 3.1 生克总表

| 关系 | 规则 | 示例 |
|:----|:-----|:-----|
| **相生（顺）** | 木→火→土→金→水→木 | 坎水→震木（智识生发推动行动） |
| **相克（逆）** | 木→土→水→火→金→木 | 乾金→震木（宏观规律约束行动方向） |
| **相乘（过克）** | 克的力量过强 | 兑金过旺→震木被伐（数理过度抑制生发） |
| **相侮（反克）** | 被克者反制克者 | 震木过旺→反侮乾金（行动过多忽略规律） |

### 3.2 九宫联动规则

```
坎宫（智识） ⇄ 震宫（行动） ⇄ 离宫（情志）
    ↕             ↕             ↕
坤宫（辨证） ⇄ 中宫（归一） ⇄ 兑宫（数理）
    ↕             ↕             ↕
巽宫（应变） ⇄ 艮宫（器用） ⇄ 乾宫（规律）
```

- **对角线互补**：坎（智识）↔离（心神），坤（辨证）↔艮（器用）
- **对应制衡**：震（行动）↔兑（数理），巽（应变）↔乾（规律）
- **中宫为纽**：所有维度最终经中宫归一

## 四、维度判定的操作流程

### 4.1 单问题维度标记

```
输入问题
    ↓
第一步：识别主宫（问题最核心领域）
    ↓
第二步：识别次宫（涉及的辅助维度，至多3个）
    ↓
第三步：标注生克关系（主宫与次宫的关系）
    ↓
第四步：中宫标记（是否涉及归一收敛）
```

### 4.2 示例

**问题**：「患者面色萎黄，大便稀溏三年，情绪易焦虑」

```
主宫：二宫坤·涵容（中医辨证）→ 坤2-1四诊、坤2-2辨证、坤2-7治则
次宫：九宫离·心神（情志人格）→ 离9-1识情、离9-5明心
生克：坤土（辨证）←火生土→离火（情志），情志郁结影响脾胃运化
收敛：中宫统摄 → 辨证肝郁脾虚，治以疏肝健脾
```

## 五、与四层推演范式的衔接

九宫81维度是「布阵层」的核心工具：

| 四层范式 | 九宫维度用法 |
|:---------|:-------------|
| **拆解** | 将问题按81维度逐项扫描，识别涉及的所有维度 |
| **布阵** | 将识别出的维度归入九宫对应位次，建立生克关联 |
| **运化** | 按维度间生克制衡交叉演算，排查矛盾，多分支推演 |
| **归真** | 回归中宫归一，对多分支结果收敛为统一核心结论 |
