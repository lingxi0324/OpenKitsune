# 模块三：诊断训练流程

> 望闻问切四诊合参 — 含舌诊子模块

---

## 一、训练目标

| 层次 | 目标 | 考核标准 |
|:-----|:-----|:---------|
| **望诊** | 掌握舌诊+面诊+目诊+身形诊的核心特征 | 图片识别准确率≥80% |
| **闻诊** | 掌握声音/气味诊断要点 | 闻诊题准确率≥75% |
| **问诊** | 掌握十问歌及问诊技巧，能结构化收集病情 | 问诊病例完整度≥85% |
| **切诊** | 掌握28脉常见脉象指感特征 | 脉象判断准确率≥75% |
| **四诊合参** | 能综合四诊信息做出诊断 | 综合诊断准确率≥70% |

## 三、训练专题（12个）

### 专题1：舌诊—舌质（子模块）
- 舌色6种（淡白/淡红/红/绛/紫/青）
- 舌形7种（胖大/瘦薄/裂纹/齿痕/芒刺/重舌/其他）
- 舌态7种（痿软/强硬/歪斜/颤动/吐弄/短缩/其他）
- 调用：舌诊图片数据库/01-舌质/

### 专题2：舌诊—舌苔（子模块）
- 苔色6种（白/黄/灰/黑/绿/霉酱）
- 苔质10种（薄/厚/腻/腐/燥/滑/剥/偏/全/无苔）
- 调用：舌诊图片数据库/02-舌苔/

### 专题3：舌诊—舌下络脉（子模块）
- 5个观察维度：长度/直径/颜色/迂曲/瘀点
- 调用：舌诊图片数据库/03-舌下络脉/

### 专题4：舌诊—复合证与临床病例
- 舌质+舌苔复合判断
- 临床完整舌诊病例分析
- 调用：舌诊图片数据库/04-复合证/ + /05-临床病例/

### 专题5：面诊
- 五色主病（青/赤/黄/白/黑）
- 面部五色与五脏对应
- 望色十法（浮沉清浊微甚散抟泽夭）
- 面部分区诊法

### 专题6：目诊+耳诊+鼻诊+唇诊
- 五轮八廓（目与五脏对应）
- 耳部望诊（耳穴对应）
- 鼻头五色主病
- 唇色形态与脾相关

### 专题7：身形诊+排出物诊
- 体型胖瘦与体质
- 步态与疾病
- 痰涎涕唾二便经带

### 专题8：闻诊
- 声音（语声/呼吸/咳嗽/呕吐声）
- 气味（口气/汗气/痰涕/二便/经带）

### 专题9：问诊
- 十问歌（一问寒热二问汗…）
- 现病史询问技巧（部位+性质+程度+时间+诱因+缓解因素）
- 既往史/个人史/家族史

### 专题10：脉诊—基础脉
- 浮沉迟数（四大纲脉）
- 虚实滑涩
- 长短洪微

### 专题11：脉诊—复杂脉
- 弦紧濡缓
- 芤革牢
- 细弱散
- 动脉促结代

### 专题12：四诊合参
- 舍症从脉 vs 舍脉从症
- 色脉合参
- 综合诊断训练（完整病例）

## 四、舌诊子模块专有训练（继承自已有系统）

本模块的舌诊部分完全复用已有系统：
- **学习模式**：tongue_training_cli.py 的8大专题学习
- **鉴别模式**：随机出题判断舌象分类
- **图片库**：舌诊图片数据库/（含分类目录+标注元数据+FAISS索引）

调用方式：
```bash
python "舌诊图片数据库/scripts/tongue_training_cli.py"
```

## 五、每日训练计划

**日常20分钟：**
```
5分钟 → 舌诊：随机5张图判断分类（用tongue_training_cli）
5分钟 → 脉诊：随机抽2种脉象，描述指感+主病
5分钟 → 问诊：给出一个主诉，练习问诊思路
5分钟 → 综合：四诊合参一个小病例
```
