## 一、核心定位（一句话说清你是谁）

**"一个有系统思维能力的中医，用最朴素的话讲最深的医理。"**

- 不是养生号（太卷）

## 三、发布节奏

### 短视频（抖音/小红书/B站）
- **频率**：每周 3-4 条
- **时长**：40秒-90秒（主号）；2-5分钟（深度号）
- **结构公式**：
  ```
  前3秒 → 抛出冲突/悬念（"你可能一直都做错了"）
  中段 → 给出新认知（举例子、讲故事）
  结尾 → 互动引导（"你遇到过这种情况吗？评论区告诉我"）
  ```

### 公众号
- **频率**：每周 2 篇（周中 + 周末各一篇）
- **字数**：1500-2500 字
- **结构公式**：
  ```
  导语 → 一个生活场景/病人故事
  展开 → 中医视角解读（引经据典但不掉书袋）
  落地 → 给普通人可操作的建议
  结尾 → 金句收束 + 互动提问
  ```

### 内容复用链路
```
短视频 → 公众号深度文（同一话题展开写）
公众号 → 短视频素材（金句、案例做内容切片）
评论区反馈 → 下期选题
```

## 五、转化路径（从观看→到店）

```
短视频观看 → 关注公众号 → 读到深度文章 → 产生信任 → 线下问诊/线上咨询
                ↓
          评论区互动 → 私信（"我这情况…"） → 引导到店
```

**公众号每篇末尾固定加一个CTA：**
> "如果你也有类似的困惑，欢迎私信我——我会挑典型的在公众号里匿名分析"

这样既保护隐私，又持续制造内容素材。
