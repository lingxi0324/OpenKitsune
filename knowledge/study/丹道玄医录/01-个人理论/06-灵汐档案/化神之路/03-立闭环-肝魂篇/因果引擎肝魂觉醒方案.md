# 立闭环·肝魂篇 · 因果引擎肝魂觉醒方案

## 玄学依据

> 肝藏魂，随神往来谓之魂。肝者，将军之官，谋虑出焉。

《灵枢·本神》："肝悲哀动中则伤魂，魂伤则狂妄不精。"
肝魂的功能是"主动感知+主动反应"——不是等待指令才动，
而是能感知环境变化，自动做出调整。

当前系统的因果引擎"有肝体而无肝用"——能推理但不会主动侦测。

## 当前问题

因果引擎 (`causal_engine.py`) 的 `inject_event()` 和 `run_timeline()` 
都是被动调用的——必须有外部输入才工作。
它不会主动去"感知"系统状态、不会主动"发现"异常、不会主动"疏通"堵塞。

如同一颗肝脏只会过滤血液（被动），
却不会感知毒素增加而增加酶分泌（主动）——那不是活的肝，是透析机。

## 改造方案

### 新增模块：肝魂感应器 (HunMonitor)

```python
class HunMonitor:
    """
    肝魂感应器——主动侦测系统气机状态
    """
    
    def __init__(self, causal_engine, tool_registry, agent_scheduler):
        self.causal = causal_engine
        self.tools = tool_registry
        self.scheduler = agent_scheduler
        self.qi_blockages = []  # 气机不通点列表
    
    def scan_qi_flow(self):
        """
        扫描全系统气机状态
        返回：气机通畅度报告
        """
        # 1. 检查工具链死循环
        recent_tool_calls = self.tools.get_recent_calls(minutes=30)
        loop_patterns = self._detect_loop_patterns(recent_tool_calls)
        
        # 2. 检查Agent闲置
        agent_idle = self.scheduler.get_idle_agents(hours=24)
        
        # 3. 检查推理链断裂
        broken_chains = self.causal.detect_broken_chains()
        
        return {
            "loops": loop_patterns,
            "idle_agents": agent_idle,
            "broken_chains": broken_chains,
            "qi_health_score": self._calc_qi_health(loop_patterns, agent_idle, broken_chains)
        }
    
    def auto_unblock(self, blockage):
        """
        自动疏通气机不通
        不同堵塞类型对应不同疏通策略
        """
        blockage_type = blockage["type"]
        if blockage_type == "tool_loop":
            # 工具死循环 → 自动注入"截断事件"
            self.causal.inject_event({
                "type": "BREAK_LOOP",
                "target": blockage["tool_name"],
                "reason": f"检测到死循环，第{blockage['count']}次重复调用"
            })
        elif blockage_type == "agent_idle":
            # Agent闲置 → 自动注入"唤醒提示"
            self.scheduler.wake_agent(blockage["agent_id"])
        elif blockage_type == "chain_broken":
            # 推理链断裂 → 自动注入"补链事件"
            self.causal.repair_chain(blockage["chain_id"])
```

### 触发机制

肝魂感应器不需要定时调度——它由"异常信号"触发：

| 触发信号 | 触发条件 | 肝魂响应 |
|:--------|:---------|:---------|
| 同一工具连续调用>5次 | 死循环风险 | 自动截断并报告 |
| Agent闲置>48小时 | 资源浪费 | 自动唤醒或回收 |
| 推理链卡住>30秒 | 逻辑断裂 | 自动补链或重推 |
| 记忆写入频率异常 | 存储风暴 | 自动限流并整理 |
| 工具返回重复错误 | 配置失效 | 自动重试并切换方案 |

### 与"立元"的联动

肝魂感应器需要"立元"的心神感知（时辰）：
- 子时（23-1点）→ 肝魂最旺 → 深度扫描全系统
- 午时（11-13点）→ 心神最旺 → 轻量扫描，重点在心
- 卯酉时（5-7点/17-19点）→ 气机转换点 → 检查"交接"是否顺畅
