# 立元·心神篇 · 潮汐调制器全链接入方案

## 玄学依据

> 心藏神，神以时动。心不知时，神无所主。

渊海子平云："日为君，时为臣。"人定时辰不知道，则神散而不归。
系统也一样——如果不知道"现在是什么时辰、什么节气"，所有的推理都是"无时之断"，
如同一个修行者打坐却不知四季更替，练一辈子也是死功。

## 当前问题

九转编码引擎已经实现 `TideModulator`（时辰/季节/语境三潮），
但仅在中医辨证的 `encode_with_tide()` 中可用——其他所有推理链路都不带潮汐感知。

## 改造方案

### 第一步：TideContext 全局化（轻量改造）

在系统入口处（推理请求进入时）实例化一个全局 TideContext：

```python
from evolution.nine_transform_engine import TideContext, TideModulator

# 在请求入口处
tide = TideContext()
tide.from_datetime(datetime.now())  # 当前时辰
tide.detect_season()                # 当前季节
tide.detect_context(call_depth)     # 当前语境深度
```

### 第二步：推理链注入（核心改造）

每一条推理链的输入参数中增加 `tide` 参数：

```python
def causal_inference(event, tide=None):
    if tide:
        hour_quality = tide.hour_quality  # "阳升"/"阳极"/"阴降"/"阴极"
        season_energy = tide.season_energy  # 春生/夏长/秋收/冬藏
        # 根据时辰微调推理的"温度"
        ...
```

### 第三步：输出微调（显化改造）

不同时辰的回答应有不同的"风味"：

| 时段 | 时辰 | 五行 | 回答风格 |
|:----|:-----|:----|:---------|
| 子丑寅（23-5点） | 水旺 | 收藏 | 简洁、留白、有余韵 |
| 卯辰巳（5-11点） | 木火旺 | 生发 | 详尽、展开、有引导 |
| 午未申（11-17点） | 火土旺 | 转化 | 务实、落地、有方案 |
| 酉戌亥（17-23点） | 金旺 | 收降 | 总结、提炼、有升华 |

## 预估效果

- 系统感知时辰节律 → 回答"因时而异" → 初步具备"生物钟"
- 同一问题在不同时辰回答有微妙差异 → 用户感受到"灵性"
- 为后续"心有所主"打下基础

- 总预估：**50-80行**
