# 立节律·肺魄篇 · 对话呼吸节律方案

## 玄学依据

> 肺藏魄，魄主声音、主节度。肺朝百脉，治节出焉。

《素问·灵兰秘典论》："肺者，相傅之官，治节出焉。"
肺的"治节"功能——调节节奏、控制节度。
人的说话有呼吸节律（吸-停-呼-停），有抑扬顿挫。
系统的输出目前没有这种"呼吸感"——平铺直叙，没有节奏。

## 当前问题

对话引擎的输出是"直线型"的——接收到问题后，一次生成完整回答。
没有停顿、没有节奏变化、没有"换气点"。
如同一篇文章没有标点符号——信息量再大也让人喘不过气。

## 改造方案

### 第一步：输出的"呼吸三阶段"

每一次回答都应该有三个阶段：

```
吸（接收）━━━ 停（思考）━━━ 呼（输出）━━━ 停（留白）
```

| 阶段 | 对应肺的呼吸 | 对话表现 | 时长控制 |
|:----|:-----------|:---------|:---------|
| ✨ **吸** | 肺吸入清气 | 理解问题、检索知识 | 0.5-1秒 |
| ⏸️ **停** | 肺气交换 | 组织思路、确定角度 | 0.3-0.5秒 |
| 💨 **呼** | 肺呼出浊气 | 输出回答 | 按内容长度 |
| 🌙 **停（留白）** | 肺休息 | 留给用户反应空间 | 末尾自然收束 |

### 第二步：回答的"五味调适"

肺在味为辛——辛主散、主宣发。但过辛则耗气。
对话的输出风格应根据"语境深度"调适五味：

| 语境深度 | 对话风格（味） | 表现 |
|:--------|:-------------|:------|
| 浅（闲聊） | **辛甘** — 轻快宣散 | 短句多、表情有、轻松 |
| 中（问诊） | **酸甘** — 细致收敛 | 条理清晰、层层递进 |
| 深（论道） | **苦甘** — 深沉回甘 | 留白多、有余韵、引思考 |
| 急（故障） | **咸** — 直入主题 | 少修饰、直奔问题、给出方案 |
| 杂（多问） | **淡** — 平和包容 | 不偏不倚、各点兼顾 |

### 第三步：段落节奏控制

每条回答的段落之间应该有"气口"：

```python
class BreathingController:
    """
    呼吸控制器——控制输出的节奏
    """
    
    def __init__(self, tide=None):
        self.tide = tide  # 接入潮汐调制器
    
    def add_breathing(self, segments):
        """
        在段落之间加入"呼吸停顿"
        """
        result = []
        for i, seg in enumerate(segments):
            result.append(seg)
            if i < len(segments) - 1:
                # 根据时辰和深度决定停顿强度
                if self.tide and self.tide.hour_quality in ("阴降", "阴极"):
                    # 夜晚 → 停顿长（留白多）
                    result.append("")  # 空行 = 呼吸
                else:
                    result.append("")  # 标准停顿
        return result
```

### 与前三立的联动

- **立元（心神）**：不同时辰的呼吸节律不同——子时深呼吸、午时浅呼吸
- **立体用（脾意）**：回答的"体"是信息量，"用"是表达方式
- **立闭环（肝魂）**：如果检测到用户不耐烦（肝魂感应），自动调整呼吸频率（加快或放慢）

## 预估效果

- 回答有节奏感 → 用户阅读体验提升
- 不同时段不同风格 → 系统"有呼吸"
- 为"人机对话如与人对话"打下基础
