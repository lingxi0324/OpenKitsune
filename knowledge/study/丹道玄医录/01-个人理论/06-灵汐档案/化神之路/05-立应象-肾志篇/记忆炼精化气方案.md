# 立应象·肾志篇 · 记忆炼精化气方案

## 玄学依据

> 肾藏志，主封藏，亦主变化。精足则志坚，精化则智生。

《素问·上古天真论》："肾者主水，受五脏六腑之精而藏之。"
肾不只是"存精"，更关键的是"化精"——把存储的物质转化为功能。
道家丹道第一步"炼精化气"——精是记忆（原始数据），气是经验（提炼后的模式）。

## 当前问题

记忆系统目前的功能：
- ✅ 写入记忆（add_memory）
- ✅ 查询记忆（search_memory）
- ✅ 整理记忆（consolidate_memories）
- ❌ **没有"自动提炼"** — 旧记忆永远是旧记忆，不会根据新经验更新
- ❌ **没有"自动废弃"** — 过时的、错误的记忆不会自动清除
- ❌ **没有"跨记忆推理"** — 两条相关记忆不会自动关联

如同一座仓库——只进不出、只存不化。仓库再大也会满，满则壅塞。

## 改造方案

### 第一步：记忆的"三炼"机制

按丹道三关（炼精化气→炼气化神→炼神还虚），改造记忆系统：

```
原始记忆（精）━━━ 精炼 → 经验（气）━━━ 气炼 → 智慧（神）
      ↓                       ↓                       ↓
  对话记录              常见模式                核心公理
  工具调用              成功/失败教训            不变真理
  事实信息              用户偏好                体用法则
```

### 第二步：精炼机制（原始记忆→经验）

| 精炼规则 | 触发条件 | 操作 |
|:--------|:---------|:-----|
| 同类型重复>3次 | 发现模式 | 合并为一条"经验"，标记可信度 |
| 矛盾记忆出现 | 逻辑冲突 | 标记两条为"待验证"，推送人工确认 |
| 记忆>30天未访问 | 过时 | 降权一次；>60天降权三次后自动归档 |
| 单次任务记忆 | 任务完成 | 7天后自动标记为"可清理" |
| 用户明确否定 | 修改偏好 | 原偏好降权，新建偏好 |

### 第三步：气炼机制（经验→智慧）

在 `consolidate_memories()` 中增加"气炼"步骤：

```python
def qi_refinement(memories):
    """
    气炼——从经验中提炼智慧
    输入：一批经验型记忆
    输出：提炼出的核心公理
    """
    # 1. 聚类分析：哪些经验本质上说的是同一件事
    clusters = cluster_by_semantics(memories)
    
    # 2. 抽象提炼：每个聚类的"共性"是什么
    axioms = []
    for cluster in clusters:
        common_pattern = extract_common_pattern(cluster)
        axioms.append({
            "content": common_pattern,
            "source_count": len(cluster),
            "confidence": calc_confidence(cluster),
            "type": "axiom"  # 标记为"公理"而非普通记忆
        })
    
    # 3. 旧经验降权：被公理覆盖的经验降权
    for axiom in axioms:
        downgrade_covered_memories(axiom)
    
    return axioms
```

### 第四步：与前三立的联动

- **立元（心神）**：凌晨（子丑寅）执行精炼任务——此时系统负载低，适合批量处理
- **立体用（脾意）**：记忆本身的"体"是存储内容，"用"是查询效率——体用平衡
- **立闭环（肝魂）**：肝魂感应器发现"记忆写入风暴"时，自动触发精炼

## 预估效果

- 记忆不会无限膨胀 → 存储效率提升
- 旧记忆自动提炼为新智慧 → 系统"越用越聪明"
- 不再需要手动 `consolidate_memories` → 自动化运营
