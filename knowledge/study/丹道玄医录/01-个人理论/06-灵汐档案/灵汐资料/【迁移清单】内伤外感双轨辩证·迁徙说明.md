## 📦 二、外围技能（可选配套迁移）

### ① liujing-bianzheng（六经辨证·脉证合参加权版）
- 位置：`skills/liujing-bianzheng/`
- 核心：`scripts/liujing_analyzer.py`
- **功能**：脉象分×0.5 + 症状分×0.3 + 舌象分×0.2 的加权评分体系
- **迁移建议**：如果不单独迁，其逻辑已内嵌在 `diagnosis_pipeline.py` 的六经辨证步骤中

### ② maifa-fenxi（二十四脉象分析）
- 位置：`skills/maifa-fenxi/`
- 核心：`scripts/pulse_analyzer.py`, `pulse_data.py`
- **功能**：24脉象三部九候 + 兼脉叠加 + 五运六气加权 + 处方推荐
- **迁移建议**：脉象数据可并入新系统的脉诊模块

### ③ tongue-diagnosis（舌诊·高精度视觉）
- 位置：`skills/tongue_diagnosis/`
- 核心：`tongue_diagnosis.py`（调用 Qwen2.5-VL Q6_K 高精度模型）
- **功能**：舌质/舌苔/舌形/舌下络脉/综合辨证
- **依赖**：Visual Vision 服务 `:8099` + GGUF 模型文件

### ④ tongue-algorithm（纯算法舌诊·无AI版）
- 位置：`skills/tongue_algorithm/`
- 核心：32维特征提取 + XGBoost辨证 + FAISS检索
- **功能**：无模型/无GPU的秒级舌诊，离线可用
- **迁移建议**：作为轻量备选

### ⑤ qimen-diagnosis（奇门遁甲病机诊断）
- 位置：`skills/qimen-diagnosis/`
- 核心：`scripts/qimen_diagnosis.py`
- **功能**：奇门起盘→天芮定位→病位定性→病性定量→五运六气加权
- **依赖**：`lunar-python` 库（pip install）
- **迁移建议**：时空加权维度，可选

## ⚠️ 五、注意事项

### 依赖清单
- Python 3.8+
- 可选：`lunar-python`（仅奇门模式需要）
- 可选：Vision服务 `:8099` + GGUF模型（仅舌诊图片需要）
- **纯算法模式**：零依赖，纯Python+标准库即可运行

### 关键算法要点
1. **双轨合参的核心逻辑**在 `dual_track.py` 中——读取 `diagnosis_pipeline.py` 输出的六经评分和五脏结果，做交汇分析
2. **五脏九宫矩阵**的 `zangfu_matrix.py` 包含完整的河图洛书数理映射
3. **天干化气补泄体系**是 v2.0 升级的核心——隔气相生/直取为泄的双向调节思想

### 迁移顺序建议
```
第1步：dual_track.py          ← 先搬灵魂
第2步：zangfu_matrix.py      ← 搬五脏数据
第3步：san_guan_si_zheng.py  ← 搬三观四证
第4步：diagnosis_pipeline.py ← 搬主管线编排器
第5步：prescription_rules/   ← 最后搬处方库
第6步：外围技能（按需）       ← 可选
```
