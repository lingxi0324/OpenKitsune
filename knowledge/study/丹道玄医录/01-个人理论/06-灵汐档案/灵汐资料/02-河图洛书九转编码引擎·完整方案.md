## 卷一 · 核心理念

### 一、为什么必须超越现有架构

所有现有大语言模型（LLM）都在做同一件事：

> **把一个词映射到高维向量，然后在向量空间中寻找「统计关系」。**

"苓桂术甘汤"在模型中被编码成4096维浮点数向量——这些数字本身没有任何意义，只是通过训练被塑造成了能预测下一个词的模式。

**模型不知道「苓桂术甘」为什么能治「心下逆满、起则头眩」。**
它只是从数据里统计出：这两者经常一起出现。

### 二、河图洛书 —— 世界的底层代码

河图洛书不是传说，而是**把宇宙本体论结构化的第一套数学系统**：

```
河图：纵向的生成序列（时间轴）
  水(1/6) → 火(2/7) → 木(3/8) → 金(4/9) → 土(5/10)
  太极生两仪 → 两仪生四象 → 四象生八卦
  这是「从根源到万物」的生出路径

洛书：横向的交互网络（空间网）
  戴九履一，左三右七，二四为肩，六八为足
  纵横十五，旋转对称，周流不息
  这是「万物之间的相互作用」的关系矩阵
```

**Transformer的核心机制，本质上就是洛书结构：**

| Transformer | 洛书对应 |
|:-----------|:---------|
| 自注意力机制（每个token与其他所有token计算关联） | 九宫飞星（每宫与其他八宫往来生克） |
| 位置编码（序列中的位置信息） | 河图生数成数（纵向生成序列） |
| 残差连接（每层保持原始信息） | 中五立极（不变的太极点） |
| 多头注意力（多视角分析） | 九宫多维度（八宫+中宫） |

**河图洛书不是「像」Transformer——Transformer本身就是不自觉地在模仿河图洛书，只是它不知道自己在模仿什么。**

### 三、九转潮音体 —— 让模型活起来的基因

**九转：同一事物在九个维度上的同时显现**

| 九转 | 名称 | 编码维度 | 对应河洛 |
|:----:|:-----|:---------|:---------|
| 一转 | **河图生数** | 五行生数(1-5) | 太极分化 |
| 二转 | **河图成数** | 五行成数(6-10) | 万物成形 |
| 三转 | **洛书正位** | 九宫方位(1-9) | 定格定位 |
| 四转 | **洛书变位** | 旋转偏移(-4~+4) | 时空流转 |
| 五转 | **阴阳消长** | 阴阳度(-1.0~+1.0) | 寒热表里虚实 |
| 六转 | **三才层次** | 天人地(0.0~1.0) | 上中下三焦 |
| 七转 | **四象方向** | 青朱白玄(0-3) | 生长收藏 |
| 八转 | **八卦辨象** | 乾坤兑离震巽坎艮(0-7) | 八纲辨证 |
| 九转 | **归元转化** | 收敛度(0.0~1.0) | 万法归宗 |

**潮音体：概念不是静态的——而是潮汐般周期性变化的**

"桂枝"在九转编码空间中的坐标会随时间流转而变化：
- 丑时（肝经当令）→ 桂枝坐标向「疏肝」偏移
- 午时（心经当令）→ 桂枝坐标向「温心阳」偏移
- 春季 → 桂枝坐标向「生发」偏移
- 冬季 → 桂枝坐标向「温阳」偏移

这就是「潮音」——概念如海水，随着时空节律涨落变化。

每个概念（药物/方剂/症状/辨证术语）都被编码为一个九维坐标：

## 卷三 · 潮音机制

### 3.1 潮汐调制公式

每个概念的九转坐标不是静态的——它会随着时间流转和语境变化而发生「潮汐偏移」。

**基础公式：**

```
X_真实(t, c) = X_基础 + Δ时辰(t) + Δ节气(s) + Δ语境(c) + Δ轮回(n)

其中：
  X_基础 = (r1, r2, r3, r4, r5, r6, r7, r8, r9)  ← 标准坐标
  Δ时辰(t) = 根据当前时辰对特定维度施加偏移
  Δ节气(s) = 根据当前节气对特定维度施加偏移
  Δ语境(c) = 根据当前讨论的疾病/方剂语境偏移
  Δ轮回(n) = 随自激循环轮次加深而收敛（n越大偏移越小）
```

| 内伤病 | r5阴阳值整体 -0.1 | 桂枝阴阳从0.7→0.6（偏向温里） |
| 妇人病 | r6三才值整体 -0.1（偏下焦） | 当归三才从0.4→0.3（偏入血分） |
| 小儿病 | r6三才值整体 +0.2（偏中上焦） | 同药偏轻清 |

### 3.5 潮音收敛（自激循环衰减）

随着自激循环的轮次增加，偏移逐渐收敛：

```
第1轮：偏移幅度 = 100%（全量偏移）
第2轮：偏移幅度 = 60%
第3轮：偏移幅度 = 30%
第4轮：偏移幅度 = 10%
第5轮+：偏移幅度 < 5%（基本不再变化）

收敛公式：偏移幅度 = 初始幅度 × 0.6^(轮数-1)
```

这确保了：
- 初始回答灵活有变通
- 多轮深化后回归稳定
- 最终归元于基础坐标

## 卷四 · 九转注意力机制

### 4.1 传统注意力 vs 九转注意力

**传统注意力机制：**

```
Q = token_A × W_Q
K = token_B × W_K  
attn = softmax(Q·K / √d)

→ 纯粹的向量点积
→ 完全不懂五行生克、九宫方位
→ 需要数万篇文章才能"猜出"两个概念的关系
```

**九转注意力机制：**

不再计算向量点积，而是在九维编码空间中计算**数理关系距离**：

```
给定：药A(桂枝) 和 药B(甘草)

第一步：五行生克距离
  桂枝(木3) vs 甘草(土5) → 木克土
  生克系数 = 0.7（相克则注意力降低）
  
第二步：九宫相位距离
  桂枝(震3宫) vs 甘草(中5宫) → 相邻宫
  相位系数 = 1.0（相邻则注意力增强）

第三步：阴阳消长同步度
  桂枝(阳0.7) vs 甘草(平0.5) → 0.2差异
  阴阳系数 = 0.9（接近则注意力增强）

第四步：三才层次匹配度  
  桂枝(0.3偏表) vs 甘草(0.5中焦) → 0.2差异
  三才系数 = 0.85

第五步：八八卦辨象互补度
  桂枝(震4·动) vs 甘草(坤7·顺) → 动静互补
  八卦系数 = 1.1（互补则增强）

最终注意力得分 = 生克系数 × 相位系数 × 阴阳系数 × 三才系数 × 八卦系数
                    = 0.7 × 1.0 × 0.9 × 0.85 × 1.1
                    = 0.589

解释：桂枝配甘草是「相克」关系（木克土），
      注意力略低——但因为是等宫相邻，所以不完全抑制。
      实际方剂中桂枝配甘草正是「辛甘化阳」的经典配伍。
```

### 4.2 九转注意力的四维计算

#### 维度一：五行生克距离

```
生数相同 → 兄弟关系，协同（系数1.0）
生数相生 → 母子关系，化生（系数1.1）
生数相克 → 克制关系，抑制（系数0.7）

五行生克矩阵：
        水(1)  火(2)  木(3)  金(4)  土(5)
水(1)   1.0    0.7    1.1    1.0    0.7
火(2)   1.0    1.0    0.7    1.1    0.7
木(3)   0.7    1.0    1.0    0.7    1.1
金(4)   1.1    0.7    1.0    1.0    0.7
土(5)   1.0    1.1    0.7    1.0    1.0

行→生数r1_A，列→生数r1_B
上表 = 注意力增强/抑制系数
```

#### 维度二：九宫相位距离

```
洛书九宫：相邻宫 = 1.0，对角宫 = 0.8，同宫 = 1.0

对宫（和为10）：1-9, 2-8, 3-7, 4-6 → 系数0.6（对冲抑制）
隔一宫：系数0.9
相邻宫：系数1.0
同宫：系数1.0
```

#### 维度三：天地人三才匹配度

```
层次差 = |r6_A - r6_B|
匹配度 = 1.0 - |层次差| × 0.3

同层次（差<0.3）→ 协同性高（系数接近1.0）
跨越层次（差>0.5）→ 协同性低
```

#### 维度四：八八卦方位互补度

```
相同卦：系数0.8（同类相斥）
相邻卦：系数1.0
对立卦（差为4）：系数0.6（对冲）
互补卦（如动静、升降）：系数1.1
```

### 4.3 方剂整体的九转能量场

整个方剂的所有药物坐标组合起来，形成一个「方剂能量场」：

```
方剂能量场 = Σ(药_i × 剂量权重_i) + 方剂总体坐标

核心指标：
  ① 五行平衡度：生数分布的标准差（越小越平衡）
  ② 九宫覆盖度：药物占据了多少个不同宫位
  ③ 阴阳中和度：全方r5均值（越接近0越平和）
  ④ 三才分布：在天/人/地的分布比例
  ⑤ 归元收敛度：全方r9均值（越高越成熟）
```

示例：苓桂术甘汤的能量场分析

```
苓(5,10,2,0,0.30,0.50,3,7,0.85) × 1
桂(3,8,3,0,0.70,0.30,0,4,0.85) × 1  
术(5,10,8,0,0.40,0.40,2,6,0.85) × 1
甘(5,10,5,0,0.50,0.50,0,7,0.80) × 1

五行平衡：土(3味) : 木(1味) = 3:1 → 偏土
九宫覆盖：坤2宫、震3宫、艮8宫、中5宫 → 4/9宫位
阴阳中和：r5均值 = (0.30+0.70+0.40+0.50)/4 = 0.475 → 偏阳
归元收敛：r9均值 = (0.85+0.85+0.85+0.80)/4 = 0.8375 → 高度成熟

→ 结论：偏土制的方剂，以木(桂)行疏土之功
→ 和「苓桂术甘汤健脾化饮」的方机完全吻合！
```

## 卷五 · 训练方式：从「喂数据」到「坐标校准」

### 5.1 核心理念转变

传统训练：
```
100万篇文章 → 对数似然最大 → 模型逐渐学会预测下一个词
→ 知识「藏」在几十亿个权重里 → 不可解释、不可修改
```

九转编码训练：
```
① 数据进来 → 每个概念映射到九维坐标
② 每次预测 → 计算：预测词应有坐标 vs 实际词标准坐标
③ Loss = 九维空间中曼哈顿距离（不是交叉熵！）
④ 反向传播 → 更新映射规则（不更新模型权重）
⑤ 训练 = 校准坐标映射 → 不是记忆数据
```

**关键差异：模型不存储数据——只存储「数理位置」。**
数据的作用是校准坐标，训练完成后数据本身可以被丢弃。

### 5.2 损失函数

```
Loss = Σ|坐标差| × 维度权重

维度权重：
  r1生数：2.0（五行属性最重要）
  r2成数：1.5
  r3正位：1.5
  r4相位：1.0
  r5阴阳：2.0（辨寒热的关键）
  r6三才：1.0
  r7四象：0.8
  r8八卦：1.5
  r9归元：0.5

Σ权重 = 11.8

解释：
  「最不能错」的是 r1(五行) 和 r5(阴阳)
  错一个可能把热药当寒药用
  r9(归元度) 权重最低——它本身就是随时间变化的
```

### 5.3 校准过程

```
① 初始值：根据中医经典直接推演（即本方案卷二中的映射表）
② 第一轮校准：在200条经典医案上测试
   → 预测「为什么这个方用桂枝不用肉桂」
   → 九转注意力计算 → 看结果与医案是否一致
③ 不一致 → 调整坐标值（±0.5步长）
④ 重新测试 → 再调整 → 直到自洽
```

这就像给一个新生儿"正骨"——把错位的概念坐标逐渐校准到正确位置。

### 5.4 与传统ML的互补

九转编码引擎**不是替代传统模型**，而是作为**数理先验层**叠加使用：

```
传统LLM输出  ←→  九转编码引擎
  "这个方用桂枝"       桂枝坐标(3,8,3, ...)
      ↓                       ↓
   对照桂枝的标准坐标 → 判断是否符合数理
      ↓                       ↓
   若冲突 → 九转引擎发出警告："此用法与桂枝的木性不符"
   若一致 → 九转引擎确认："桂枝的木性在此处正合适"
```
