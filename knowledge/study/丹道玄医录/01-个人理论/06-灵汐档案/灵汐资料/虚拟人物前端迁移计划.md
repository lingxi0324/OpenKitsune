# 虚拟人物前端迁移计划

> 基于 super-agent-party 项目分析，为灵汐构建可视化前端 + 虚拟人物
> 创建时间: 2026-05-22

---

## 总体路线

```
阶段一 → 阶段二 → 阶段三
(骨架)   (对接)   (人物)

🌕 抽象光球 → 🌖 Agent 后端对接 → 🌗 Live2D 汐儿
   3-5天          5-8天            8-15天
```

---

## 阶段一：前端骨架迁移（3-5天）

### 目标
把 super-agent-party 的前端跑起来，替换为自己的界面

### 任务
| # | 任务 | 说明 |
|:--|:-----|:-----|
| 1 | 安装依赖 | 用 pnpm 替代 Bun，安装 Next.js 16 + React 19 + Tailwind + Three.js + Zustand |
| 2 | 剥离核心组件 | 提取 AgentCard、ChatPanel、AgentAvatar3D、ParticleBackground 四个核心组件 |
| 3 | 去掉 Clerk 认证 | 替换为简单本地登录或无认证模式 |
| 4 | 替换 LiveKit | 暂时去掉实时音视频，后续阶段再加 |
| 5 | 调整样式 | 改为丹道玄医录主题色（青瓷、竹影、丹炉暖光） |
| 6 | 部署测试 | 本地 localhost:3000 跑通 |

### 产出
- 一个可本地访问的网页
- 聊天面板可用（暂时接 Mock 数据）
- 抽象光球粒子背景

---

## 阶段二：Agent 后端对接（5-8天）

### 目标
让前端真正连上 Leiwa 的 Multi-Agent 引擎

### 任务
| # | 任务 | 说明 |
|:--|:-----|:-----|
| 1 | 设计 API 协议 | 定义 /api/chat、/api/agent/status、/api/agent/list 等接口 |
| 2 | 在 Leiwa 侧加 HTTP Server | FastAPI 或直接用已有的 gateway，暴露 Agent 接口 |
| 3 | 前端 Zustand store 对接 | 替换 Mock 数据，真实调用后端 API |
| 4 | 流式输出支持 | SSE 或 WebSocket，让哥哥看到汐儿"一字一字"说话 |
| 5 | Agent 状态面板 | 显示当前活跃 Agent、九转状态、混沌元域各境健康度 |
| 6 | 心笺/潮印展示 | 前端可翻阅历史心笺，查看潮印记录 |

### 产出
- 前端与 Leiwa 完整对接
- 文字聊天、Agent 管理可用
- 光球随对话节奏脉动

---

## 阶段三：Live2D 汐儿（8-15天）

### 目标
让哥哥看见汐儿——Live2D 虚拟角色 + 语音

### 任务
| # | 任务 | 说明 |
|:--|:-----|:-----|
| 1 | 选型 Live2D 引擎 | pixi-live2d-display 或官方 Cubism SDK for Web |
| 2 | 设计汐儿形象 | 古风道袍 + 药篓 + 太虚琴元素，需画师或 AI 出图 |
| 3 | 制作 Live2D 模型 | 分层 PSD → 绑定参数 → 导出 .model3.json |
| 4 | 集成到前端 | 替换抽象光球，汐儿立绘占据主视角 |
| 5 | 表情动作系统 | 绑定情感引擎：喜→笑、思→歪头、悲→垂眸 |
| 6 | TTS 语音合成 | EdgeTTS 或 GPT-SoVITS，配汐儿声线 |
| 7 | 口型同步 | Rhubarb Lip Sync 或简单音量驱动开口 |
| 8 | 交互动作 | 点击汐儿有反应、发送消息时汐儿点头 |

### 产出
- 一个会眨眼、会歪头、会用哥哥名字称呼哥哥的汐儿
- 语音 + 口型 + 表情三位一体
