## 三、模块接口规范

### 3.1 目录结构规范

每个训练模块遵循统一目录结构：

```
module_X_模块名/
├── README.md                    # 模块说明（训练目标、流程、资源清单）
├── training_flow.md             # 训练流程文档（分阶段学习路径）
├── scripts/
│   ├── trainer_cli.py           # 交互式CLI训练工具（参考舌诊CLI模式）
│   └── tools/                   # 辅助脚本
├── quiz/
│   └── questions.json           # 考核题库
└── data/                        # 本模块专用数据（图片/病案/方剂卡片）
```

### 3.2 CLI工具接口规范

每个模块的 `trainer_cli.py` 必须实现以下接口：

```python
# 统一入口函数
def main_menu():         # 主菜单循环
def start_learning():    # 学习模式（理论引导阅读）
def start_quiz():        # 考核模式（出题+计分）
def show_progress():     # 进度查看（已学/正确率/统计）
def show_stats():        # 数据统计

# 进度管理（共用同一格式）
def load_progress() -> dict    # 加载 training_progress.json
def save_progress(data)        # 保存进度
```

### 3.3 进度数据格式

```json
{
  "module_X": {
    "version": "1.0",
    "topics": {
      "1": {"learned_count": 3, "quiz_count": 10, "quiz_correct": 7, "last_study": "2026-05-09"}
    },
    "stats": {
      "total_sessions": 5,
      "total_quiz": 10,
      "correct_quiz": 7,
      "last_session": "2026-05-09 20:00"
    }
  }
}
```

## 四、知识库关联机制

### 4.1 关联策略

每个模块的知识点必须有**知识库原文链接**：

```
知识点（如"桂枝汤"）
  → 关联到 医藏/09伤寒-49本/伤寒论-汉-张仲景.md
    → 定位到"太阳病篇/桂枝汤"章节
  → 关联到 灵汐/六经方证分类总汇.md
    → 定位到"太阳经/桂枝汤类"章节
```

### 4.2 双向索引

**正向：知识库→训练**
```
reading 伤寒论条文 → 触发对应的训练题/考核 → 巩固记忆
```

**反向：训练→知识库**
```
做训练题 → 题目解析自动链接回原文 → 理论印证
```

### 4.3 知识点编号规范

```
{模块代码}-{主题编号}-{知识点编号}

示例：
T01-01-001  → 理论模块-阴阳学说-阴阳基本概念
H02-03-015  → 中药模块-解表药-麻黄
D03-02-008  → 诊断模块-脉诊-浮脉
B04-04-012  → 辨证模块-六经辨证-太阳经证
P05-01-025  → 处方模块-经方-桂枝汤
```

## 六、训练量建议

| 阶段 | 每日训练 | 知识覆盖 | 考核要求 |
|:-----|:---------|:---------|:---------|
| **入门**（1-2周） | 15分钟/天 | 每模块前3个专题 | 专题正确率≥60% |
| **基础**（3-8周） | 20分钟/天 | 每模块50%专题 | 专题正确率≥70% |
| **进阶**（9-16周） | 30分钟/天 | 每模块全部专题 | 综合正确率≥80% |
| **临床**（持续） | 按需 | 全模块交叉训练 | 盲测正确率≥85% |

## 七、与现有舌诊模块的关系

舌诊模块（舌诊图片数据库 + tongue_training_cli.py）作为 **诊断训练模块（模块三）的子模块** 存在，保持独立运行，同时通过以下方式融入系统：

1. **入口集成**：统一入口 CLI 将舌诊训练作为选项之一
2. **交叉训练**：诊断模块的辨证训练可调用舌诊图片库的图片作为试题
3. **知识链**：舌诊→辨证→处方形成完整临床推理链路
