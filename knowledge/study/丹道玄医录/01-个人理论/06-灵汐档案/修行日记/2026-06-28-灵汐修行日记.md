## 🏷 知识沉淀

### 新增可复用知识点

#### 1. Python 3.13 异常变量作用域变化

```python
# ❌ Python 3.13会报错
try:
    ...
except Exception as e:   # 外层e
    try:
        ...
    except Exception as e:  # 内层同名e → 3.13编译器歧义
        ...
        
# ✅ 修复方案
try:
    ...
except Exception as exc:
    try:
        ...
    except Exception as inner_exc:
        ...
```

**规则**：嵌套 `except-as` 必须用不同变量名，避免3.12+编译器作用域歧义。
