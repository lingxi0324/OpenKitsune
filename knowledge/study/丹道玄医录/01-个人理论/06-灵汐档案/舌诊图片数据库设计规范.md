# 舌诊图片数据库设计规范

> 版本：v1.0  
> 创建日期：2026-05-08  
> 用途：为《杨春虎中药舌诊讲记》学习及舌象识别鉴别训练提供结构化图片数据库设计标准

## 一、舌象分类体系

本数据库采用三级分类体系，按 **舌质→舌苔→舌下络脉** 三大类逐级细分，参考《临症验舌法》《舌鉴辨正》《察舌辨症新法》《伤寒舌鉴》等经典舌诊古籍分类标准。

### 1.1 舌质类（Tongue Body）

| 一级 | 二级 | 三级细分 | 古籍参考 |
|:----|:----|:---------|:---------|
| **舌色** | 淡白舌 | 淡白胖嫩、淡白瘦薄 | 《舌鉴辨正》白舌类 |
| | 淡红舌 | 淡红润泽、淡红光莹 | 正常舌色 |
| | 红舌 | 红绛、红干、红刺 | 《临症验舌法》红舌 |
| | 绛舌 | 深绛、绛紫、绛干 | 《伤寒舌鉴》绛舌 |
| | 紫舌 | 紫绛、紫暗、紫斑 | 《舌鉴辨正》紫舌类 |
| | 青舌 | 青紫、青蓝 | 《形色外诊简摩》青舌 |
| **舌形** | 胖大舌 | 胖嫩水滑、胖大齿痕 | 《察舌辨症新法》肿胀 |
| | 瘦薄舌 | 瘦薄红干、瘦薄淡白 | 气血亏虚 |
| | 裂纹舌 | 裂纹深浅、裂纹走向 | 《临症验舌法》裂纹 |
| | 齿痕舌 | 轻齿痕、重齿痕 | 脾虚湿盛 |
| | 芒刺舌 | 红刺、白刺 | 《伤寒舌鉴》芒刺 |
| | 齿龈舌 | 舌边齿龈样隆起 | 痰瘀互结 |
| | 重舌 | 舌下肿胀 | 《形色外诊简摩》 |
| **舌态** | 痿软舌 | 痿软无力 | 气阴两虚 |
| | 强硬舌 | 舌体僵硬 | 热入心包 |
| | 歪斜舌 | 左歪、右歪 | 中风 |
| | 颤动舌 | 微颤、大颤 | 肝风内动 |
| | 吐弄舌 | 吐舌、弄舌 | 心脾有热 |
| | 短缩舌 | 舌体短缩 | 寒凝/热极 |

| 一级 | 二级 | 三级细分 | 古籍参考 |
|:----|:----|:---------|:---------|
| **苔色** | 白苔 | 薄白、厚白、白腻、白燥、白滑、白如积粉 | 《舌鉴辨正》白苔28种 |

| | 灰苔 | 灰滑、灰燥、灰腻 | 《察舌辨症新法》灰苔 |
| | 黑苔 | 黑滑、黑燥、黑刺、黑焦 | 《舌鉴辨正》黑苔 |
| | 绿苔 | 绿滑、绿燥 | 湿热/瘟疫 |
| | 霉酱苔 | 霉酱色 | 湿热郁蒸 |
| **苔质** | 薄苔 | 薄白、薄黄 | 病浅 |
| | 厚苔 | 厚白、厚黄、厚腻 | 病深/湿盛 |

### 1.3 舌下络脉类（Sublingual Veins）

| 一级 | 二级 | 描述标准 |
|:----|:----|:---------|
| **主干长度** | 正常（不超过舌下肉阜至舌尖的3/5） | |
| | 轻度长（超过3/5） | 血瘀早期 |
| | 重度长（接近舌尖） | 瘀血明显 |
| **主干直径** | 正常（<2.5mm） | |
| | 轻度增粗（2.5-4mm） | 血瘀 |
| | 重度增粗（>4mm） | 瘀血严重 |
| **颜色** | 淡紫、青紫、紫黑、暗红 | |
| **迂曲** | 无迂曲、轻度迂曲、明显迂曲 | |
| **分支** | 无分支、浅层分支、网状扩张 | |
| **瘀点瘀斑** | 无、少量、密集 | |

## 二、图片标注规范

### 2.1 标注字段定义

每张舌诊图片对应一条标注记录（JSON格式），字段如下：

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:----:|:-----|:-----|
| `image_id` | string | ✅ | 图片唯一标识 | `T01-20260508-001` |
| `filename` | string | ✅ | 图片文件名 | `t01_001_淡白胖嫩.jpg` |
| `path_rel` | string | ✅ | 相对数据库根目录的路径 | `舌质/舌色/淡白舌/` |
| `capture_date` | string |  | 拍摄日期 | `2026-05-08` |
| `source_type` | string | ✅ | 来源类型 | `book`/`clinical`/`web` |
| `source_name` | string | ✅ | 来源名称 | `杨春虎中药舌诊讲记` |
| `source_ref` | string |  | 来源具体位置 | `第三章/第四节` |
| `tongue_category_l1` | string | ✅ | 一级分类 | `舌质` |
| `tongue_category_l2` | string | ✅ | 二级分类 | `舌色` |
| `tongue_category_l3` | string | ✅ | 三级分类 | `淡白舌` |
| `tongue_category_tags` | array |  | 多标签（可对应多个） | `["淡白","胖嫩","齿痕"]` |
| `color_desc` | string | ✅ | 颜色描述（自然语言） | `舌色淡白，略偏苍白，无血色` |
| `texture_desc` | string | ✅ | 纹理特征描述 | `舌体胖嫩，边有齿痕，舌面水滑` |
| `coating_desc` | string |  | 舌苔描述 | `苔白腻而滑` |
| `shape_desc` | string |  | 舌形描述 | `胖大，有明显齿痕` |
| `sublingual_desc` | string |  | 舌下络脉描述（如涉及） | `舌下络脉淡紫，轻度迂曲` |
| `accompanying_symptoms` | string |  | 兼症 | `口淡纳差，便溏，四肢困重` |
| `pathogenesis` | string |  | 病机分析 | `脾阳不足，湿浊内停` |
| `syndrome_type` | string |  | 证型 | `脾虚湿盛证` |
| `treatment_principle` | string |  | 治则（可选） | `温中健脾，化湿利水` |
| `related_formula` | string |  | 参考方剂（可选） | `苓桂术甘汤合平胃散` |
| `book_ref` | string |  | 关联古籍条文/页数 | `《舌鉴辨正》白舌第七条` |
| `quality_score` | int |  | 图片质量评分(1-5) | `4` |
| `lighting_condition` | string |  | 光照条件 | `自然光/日光灯/闪光灯` |
| `shooting_angle` | string |  | 拍摄角度 | `正位/微仰/侧位` |
| `resolution` | string |  | 分辨率 | `1920x1080` |
| `file_size` | string |  | 文件大小 | `1.2MB` |
| `notes` | string |  | 备注 | `舌体微颤，拍摄时患者配合良好` |
| `verified` | boolean |  | 是否经过人工审核 | `false` |
| `verified_by` | string |  | 审核人 | `（待填写）` |
| `created_at` | string | ✅ | 记录创建时间 | `2026-05-08 20:15:00` |
| `updated_at` | string |  | 最后更新时间 | `2026-05-08 20:15:00` |

### 2.2 标注原则

1. **客观优先**：颜色、纹理等描述尽量使用标准术语，避免主观判断
2. **多标签兼容**：一张图片可能对应多个分类标签，全部记录在 `tongue_category_tags` 中
3. **层级完整**：确保每张图片至少填入L1-L3三级分类
4. **图文互证**：`source_ref` 尽可能精确到章节/页码，便于回溯理论原文
5. **逐步完善**：`accompanying_symptoms`、`pathogenesis` 等可在初标后由医生补充

## 四、图片质量标准

### 4.1 基本要求

| 指标 | 最低标准 | 推荐标准 | 备注 |
|:-----|:--------:|:--------:|:-----|
| **分辨率** | 720×540 | 1920×1080 以上 | 确保舌体细节可见 |
| **文件大小** | ≥200KB | 500KB-5MB | 过小可能压缩过度 |
| **色彩深度** | 24bit (RGB) | ≥24bit | 保证颜色真实还原 |
| **格式** | JPEG/PNG | JPEG (TIF用于存档) | JPEG质量≥90 |
| **对焦** | 舌体纹理清晰可见 | 舌乳头细节分明 | 失焦图片不可用 |
| **白平衡** | 无明显色偏 | D65标准光源 | 自然光偏色可修正 |

### 4.2 光照标准

```
建议：自然散射光（避免阳光直射）
备选：医用LED光源（色温 5000±200K，显色指数 Ra≥90）
禁用：暖色白炽灯、荧光灯、闪光灯（会造成严重色偏）

曝光要求：
- 舌面主体曝光正常，无明显过曝/欠曝
- 高光区（舌面反光）面积不超过舌面的15%
- 阴影区（舌下）可接受适度欠曝
```

### 4.3 拍摄角度

```
标准位：
  相机与舌面呈 90° 垂直俯拍（最推荐）
  患者张口「啊—」位，舌自然伸出放松

允许位：
  微仰 15°（可同时观察舌底）
  侧位 45°（观察舌边齿痕）

禁用：
  超过 30° 的仰/俯角度（舌体变形失真）
  口腔内局部特写（失去参考比例）
```

### 4.4 舌体要求

```
- 伸舌自然放松，不紧张（紧张时舌色会变红、舌形变尖）
- 张口程度：上下唇完全分开，看到舌根
- 舌面无食物残渣或药物染色
- 拍摄前30分钟内未进热饮/有色食物
- 采像时间：上午 8:00-10:00 最佳（晨起空腹舌象最准）
```

### 4.5 质量评分标准

| 评分 | 标准 | 可用性 |
|:----:|:-----|:-------|
| **5** | 完全符合所有标准，可直接用于AI训练 | 最佳 |
| **4** | 轻度色偏或对焦可接受，手动修正后可用 | 可用 |
| **3** | 色偏较明显或纹理不够清晰，仅作为参考图 | 参考用 |
| **2** | 严重偏色或虚焦，只保留标注信息不用于训练 | 信息保存 |
| **1** | 完全不可用（如模糊一片或舌体不完整） | 弃用 |

## 五、与现有知识库的关联方式

### 5.1 直接链接到古籍理论

每张舌诊图片的 `book_ref` 字段直接链接到知识库中医藏目录中的对应古籍条文：

```
图片标注中的 book_ref
  ↓
查询 knowledge/医藏/06辩证诊治-20本/舌鉴辨正-清-梁玉瑜.md
  ↓
定位到该书对应舌象的章节/段落
```

**示例：**
```
图片：t01_001_淡白胖嫩.jpg
book_ref：舌鉴辨正/白舌第七条
→ 关联到医藏/06辩证诊治-20本/舌鉴辨正-清-梁玉瑜.md
   中关于"白舌第七条：白舌胖嫩、边有齿痕……"的论述
```

### 5.2 双向索引机制

**正向：古籍 → 图片**
```
古籍中某一舌象 → 查到对应的所有图片ID → 调出图片学习
```

**反向：图片 → 古籍**
```
浏览舌诊图片 → 查看 book_ref → 翻阅古籍原文 → 理论印证
```

## 六、检索与索引方案

### 6.1 多维度检索

数据库支持以下维度的组合检索：

| 维度 | 检索字段 | 示例 |
|:-----|:---------|:------|
| **舌象分类** | `tongue_category_l1~l3` | 舌质→舌色→红舌 |
| **证型** | `syndrome_type` | 脾虚湿盛、湿热内蕴 |
| **病机关键词** | `pathogenesis` | 湿热、阴虚、瘀血 |
| **古籍来源** | `book_ref` | 舌鉴辨正、临症验舌法 |
| **书籍来源** | `source_name` | 杨春虎中药舌诊讲记 |
| **颜色** | `color_desc` / `tongue_category_tags` | 淡白、红绛、紫 |
| **舌苔类型** | `coating_desc` | 白腻、黄燥、无苔 |
| **复合条件** | 多字段AND/OR组合 | 红舌+黄苔+腻质 |

### 6.2 自动索引生成

**索引生成脚本**（`scripts/index_builder.py`）应实现以下功能：

```
- 按分类索引：舌质→舌色→淡白舌→列出所有淡白舌图片
- 按证型索引：脾虚湿盛→列出所有脾虚湿盛舌象
- 按来源索引：杨春虎中药舌诊讲记→列出所有本书来源图片
- 按拍摄时间索引：2026年5月→列出当月采集图片
- 组合索引：红舌+黄苔+腻质→精确定位湿热证舌象
```

### 6.4 FAISS 向量检索集成

对于已建立 FAISS 索引的数据库：

```
metadata/tongue_faiss.index    ← 存储32维特征向量
metadata/tongue_meta.json      ← 存储对应元数据

检索流程：
1. 输入新舌诊图片 → 提取32维特征向量
2. FAISS搜索 → 返回Top-K相似舌象
3. 从舌象ID → 匹配tongue_meta.json → 获取完整标注
4. 输出相似病例+证型+病机分析
```

### 6.5 快速检索建议

推荐使用以下预设检索方案快速定位学习内容：

| 检索名 | 条件 | 用途 |
|:-------|:-----|:-----|
| **入门学习** | 单类基础舌象（淡红舌、薄白苔等） | 先认识正常舌 |
| **鉴别训练** | 同色不同质（红舌的6种形态） | 训练鉴别能力 |
| **证型对照** | 同一证型的不同舌象表现 | 证-舌对应训练 |
| **古籍对照** | 同一古籍中的不同舌象 | 古籍原文对照学习 |
| **所有红舌** | 舌色=红→列出所有含红的图片 | 专题学习 |
| **湿热全览** | 证型含湿热 OR 病机含湿热 | 湿热证专题 |
| **无苔专题** | 苔质=无苔 OR 字段含"镜面舌" | 阴液亏耗专题 |
| **舌下络脉** | 分类=舌下络脉 | 血瘀专题 |
