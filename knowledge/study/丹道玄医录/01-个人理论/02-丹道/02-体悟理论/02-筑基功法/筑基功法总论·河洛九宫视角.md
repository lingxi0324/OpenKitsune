# 筑基功法总论·河洛九宫视角

> 筑基者，炼己之基、补漏之工。以后天亏损之身，返还先天本来面目。

---

## 一、筑基的本质

### 1.1 何为筑基

丹道修炼，以身为鼎炉。但人自出生以来，精气日泄、神明日耗，好比一口锅已经有了裂缝——直接烧火炼丹，只会漏气跑药。

**筑基**就是补漏的过程：
- **补精**：填补后天亏损的肾精（对应河图 **天一生水**，水为万物之始）
- **化气**：将饮食水谷之气转为丹田真气（对应 **地六成水**，水之成数为六）
- **凝神**：散乱之心归于一处（对应 **中央戊己土**，土主信、主定）

### 1.2 筑基与河图生成数的对应

| 筑基阶段 | 河图数理 | 对应 | 说明 |
|:--------|:--------|:----|:------|
| 补精 | 天一生水（1→6） | 肾精由亏转盈 | 填补先天之本 |
| 化气 | 地二生火（2→7） | 心火下降温煦丹田 | 水火既济，气机自生 |
| 凝神 | 天三生木（3→8） | 肝魂归位，神不外驰 | 神魂内敛，意念归一 |
| 筑基小成 | 中五（5→10） | 五脏精气皆足 | 土为枢纽，四象归中 |

**核心规律**：筑基的本质是 **将散于外的精气神收回中宫**——对应洛书九宫中 **中五土** 的枢纽地位。中宫充足，四象（其余八宫）自安。

## 二、筑基三大功法

### 2.1 站桩——法天象地

#### 形法

| 要点 | 操作 | 易错 |
|:----|:-----|:-----|
| **双脚** | 与肩同宽，平行向前，膝盖微屈不超过脚尖 | 膝盖过直则力不入脚底 |
| **胯部** | 松胯圆裆，如坐高凳 | 挺胯则气滞于腰 |
| **脊柱** | 虚领顶劲，尾闾中正，百会与会阴一线 | 含胸过度则气憋 |
| **双手** | 胸前环抱，指尖相对，如抱气球 | 抬肩则气浮于上 |
| **舌** | 舌尖轻抵上颚（搭鹊桥） | 舌抵过紧则口中生燥 |
| **目** | 垂帘微闭，目光内收 | 紧闭则易昏沉 |

#### 心法

> **视之不见名曰夷，听之不闻名曰希，抟之不得名曰微。**

站桩时，不必追求"入静"——越追越远。只需做到：

1. 身体放松（从头顶→双肩→腰胯→膝盖→脚底，逐节扫描放松）
2. 呼吸自然（不憋气、不调息、不数息，让呼吸自己找到节奏）
3. 意念微照（将一点若有若无的注意力放在下丹田，似守非守）

**口诀**：松而不懈，紧而不僵，守而不执，放而不散。

#### 与五脏九宫的对应

站桩时人体如同一个 **立体的九宫矩阵**：

```
头顶（离9·心火）
  ↓
咽喉（坤2·心包/三焦）
  ↓
膻中（兑7·肺气）
  ↓
中脘（中5·脾土）  ← 核心枢纽
  ↓
神阙（震3·肝木）
  ↓
气海（艮8·胃气）
  ↓
关元（坎1·肾水）
  ↓
会阴（乾6·命门）
```

站桩时间久了，九宫之间的气机自然流动、生克平衡，哪一宫不足，其他宫位的气会自动灌溉过来——这正是 **他宫代偿律** 在站桩中的体现。

#### 时间与进度

| 阶段 | 单次时长 | 累计效果 |
|:----|:--------:|:---------|
| 初学 | 10-15分钟 | 腿酸、肩紧、心浮——正常，熬过即进 |
| 三月 | 30分钟 | 开始体会到"气感"（温热/麻胀/流动感） |
| 半年 | 45-60分钟 | 能站出"整劲"，浑然一体 |
| 一年 | 60分钟+ | 站桩时入静，不觉时间流逝 |

### 2.2 静坐——返观内照

#### 调身：七支坐法

七支坐法是静坐最稳定的姿势框架，源自《大智度论》：

| 支 | 要求 | 功效 |
|:-:|:----|:-----|
| ① **盘坐** | 双盘>单盘>散盘，循序渐进 | 下肢稳固，气血下沉 |
| ② **脊直** | 腰椎微收，脊椎如叠铜钱 | 气脉通畅的关键 |
| ③ **肩平** | 双肩自然下沉，不耸不塌 | 肺气宣发正常 |
| ④ **颔收** | 下颚微收，颈椎拉直 | 督脉上通之路通畅 |
| ⑤ **舌抵** | 舌尖抵上颚（鹊桥） | 任督二脉相连 |
| ⑥ **目垂** | 目光垂视鼻尖前方一尺处 | 既不放逸也不昏沉 |
| ⑦ **手印** | 左手在上右手在下，拇指相触（法界定印） | 阴阳合一 |

#### 调息：六妙门

智者大师《六妙法门》，是静坐调息最完整的阶梯：

| 阶 | 法 | 说明 | 效果 |
|:-:|:---|:-----|:-----|
| **数** | 数呼吸，一呼一吸为一，从一数到十，再从头 | 初学对治散乱 | 心随息转，不驰外缘 |
| **随** | 不数了，只随呼吸，知吸知呼 | 心息相依 | 心更细微 |
| **止** | 呼吸若有若无，心住丹田 | 心念止息 | 开始入定 |
| **观** | 观照丹田内部，如灯照物 | 内观自省 | 看到体内气机变化 |
| **还** | 观照反观，能观和所观合一 | 能所双亡 | 初步定境 |
| **净** | 无观无止，清净现前 | 本来面目 | 清净心自然呈现 |

**实战口诀**：初学只做"数"——数到三五步就忘了数，拉回来继续。能连续三组十息不乱，算小成。

#### 静坐与洛书九宫

静坐时，意念从上焦（离9·心）逐渐下行至下焦（坎1·肾），最终落于中宫（中5·脾土）：

```
心→坎  第一步：心火下降，水火既济（洛书：离9→坎1，9+1=10，归中）
坎→中  第二步：肾水蒸腾，脾土运化（洛书：坎1→中5，1+...→归一）
中→虚  第三步：五行攒簇，归于虚无（洛书：四维归中，中宫化虚）
```

### 2.3 调息漫步——动中求静

静坐站桩为静功，但现代人久坐办公室，气血瘀滞，需要动中求静的配合。

#### 方法

1. 选一安静处，慢步行走，速度极慢——每分钟约5-10步
2. 配合呼吸：每两步一吸，每两步一呼（或根据自己节奏）
3. 意念放在脚底：感受脚掌从脚跟到脚尖逐渐落地的过程
4. 目光平视，不低头看脚

#### 对应洛书——"运行如云"

调息漫步时，人体的移动对应洛书数理的 **动态平衡**：

> 每一步都是中宫（身体重心）在九宫中的位移，步法圆融则气不滞

## 三、筑基三阶段

### 第一阶段：补漏筑基（约1-3个月）

**目标**：填补后天亏损，使精气初步充盈

| 指标 | 状态 |
|:----|:------|
| 睡眠 | 入睡变快，睡眠变深，梦减少 |
| 体力 | 白天不易疲劳，精力比以往充沛 |
| 食欲 | 饮食有节，不过饥过饱 |
| 二便 | 大便成形，小便清长 |
| 腰腿 | 站桩/静坐时腰腿酸痛感逐渐减轻 |
| 情绪 | 情绪趋于平稳，不易大起大落 |

**对应河图**：天一生水（1→6）——肾精由亏转盈，水为万物之始

### 第二阶段：产药筑基（约3-6个月）

**目标**：精气充足，丹田气动

| 指标 | 状态 |
|:----|:------|
| 丹田 | 静坐时丹田温热感明显 |
| 气感 | 内有真气萌动（如气泡上涌、蚁行感等） |
| 活子时 | 无念时阳物自然勃起（非欲望所引），是真气充足之征 |
| 性欲 | 欲望减少但功能增强——精满不思淫 |

**关键**：此阶段容易将"气感"等同于"功力"，执着于感觉反而停滞。需知 **凡所有相，皆是虚妄**——感觉只是过程，不是终点。

**对应河图**：地二生火（2→7）——心火下降，真气始生

### 第三阶段：结丹筑基（约6-12个月）

**目标**：精气神初步凝结，为小周天做准备

| 指标 | 状态 |
|:----|:------|
| 丹田 | 丹田如磁石，意念一放即自然凝聚 |
| 身心 | 不用刻意放松，自然处于松静状态 |
| 根基 | 精不漏、气不散、神不驰 |

**对应河图**：天三生木+地四生金（3+4=7）——木火通明，金水相生，四象归于中五

## 四、筑基常见问题与对治

| 问题 | 原因 | 对治法 | 对应九宫 |
|:----|:-----|:-------|:--------|
| 腿麻脚酸 | 经络不通、下肢气血瘀滞 | 不强求盘坐，散盘即可，配合散步 | 坎1→艮8（肾→胃经） |
| 昏沉欲睡 | 气虚或饮食过饱 | 开目上视，起身行功；饭前练功 | 坤2→离9（脾→心） |
| 杂念纷飞 | 心神散漫太久 | 不排斥杂念，如旁观云来云去 | 离9（心火降则念自息） |
| 口干舌燥 | 舌抵太紧或呼吸太重 | 放松舌抵，鼻吸自然 | 兑7（肺金生津） |
| 胸闷气短 | 含胸太过或紧张 | 微展胸骨，气息自然下沉 | 巽4（肺气宣发） |
| 腰部酸痛 | 坐姿不正或肾虚 | 检查脊柱，腰下垫薄枕 | 乾6（命门） |

## 五、筑基与针法的衔接

筑基功成的标志之一是 **丹田真气充足**。此时若配合针法，效果倍增：

| 筑基阶段 | 推荐针法 | 效果 |
|:---------|:---------|:------|
| 补漏期 | 足三里、关元（培补后天） | 加速筑基 |
| 产药期 | 气海、命门（温阳化气） | 真气更容易凝聚 |
| 结丹期 | 水火交媾阵（阳谷+太渊丙辛化水） | 促进水火既济，丹基更稳 |

> 没有筑基基础的人直接扎针调理，如同无根之木，见效快但难以持久。筑基之后再扎针，效果稳固且不易反复。
