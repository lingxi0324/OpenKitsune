# 炼精化炁体用详解 · 卷一

## 核心命题：精为水体，化炁为木用，尾闾为关

> 炼精化炁，即"坎水逆行，化为震木"——水体1→木用3的河图生数转化。

---

## 一、精的二层结构

### 先天元精（体·水1）

| 属性 | 说明 |
|:----|:------|
| 来源 | 父母媾精时禀受，命门真水，肾间动气 |
| 性质 | 无形无质，纯粹能量态，生命本源 |
| 位置 | 肾间（命门）→ 一身之根本 |
| 体用定位 | **纯体**（坎之中爻为阳，一阳陷二阴） |

### 后天精（用·水6）

| 属性 | 说明 |
|:----|:------|
| 来源 | 水谷精微所化，五脏六腑之精 |
| 性质 | 有形有质，生殖之精，濡养之精 |
| 体用定位 | **体之用**（先天元精的外显功能） |

### 精的体用关系

```
先天元精（体·水1）→ 通过命门火（少火）→ 转化为后天精（用·水6）
                    → 通过炼精化炁（武火）→ 转化为炁（木3）

体（元精）不变，用（后天精、炁）常转——体用第一定律的完美体现！
```

## 二、尾闾关体用详解

### 位置与体用

| 项目 | 说明 |
|:----|:------|
| 位置 | 脊椎最末端，长强穴深处，肛门与尾骨之间 |
| 体 | 肾精之海、命门之门户——**精的仓库出口** |
| 用 | 精→炁的转化阀门——**精的出口闸门** |
| 河图对应 | 水体1 → 开始向木3转化 |

### 尾闾通关三阶段

| 阶段 | 体用状态 | 体感特征 | 火候 | 时间跨度 |
|:----|:---------|:---------|:----|:--------|
| **积精** | 水体充足·用未启动 | 腰部微热，精力充沛 | 文火温养 | 数月至一年 |
| **冲动** | 水体满溢·用始萌动 | 尾闾处跳动·热流·蚁行感 | 武火急催 | 数日至数周 |
| **通关** | 体用贯通·化炁上行 | 热流沿脊椎上行至夹脊 | 武火+止火交替 | 瞬间至数日 |

### 尾闾不通的体用诊断

| 体征 | 体用诊断 | 河图分析 | 调治 |
|:-----|:---------|:---------|:-----|
| 腰膝酸软·遗精 | 体亏（精不足） | 水1虚 | 金水相生·六味地黄 |
| 尾闾冷痛·久坐加重 | 用不通（精不化） | 水1→木3卡住 | 温阳化气·肾气丸 |
| 二便失禁·肛坠 | 用失控（闸门松） | 水6成数不收 | 升提固涩·补中益气 |
| 尾闾热痛·坐卧不安 | 用太过（火旺灼精） | 水1被火2所克 | 滋阴降火·知柏地黄 |

## 三、筑基三阶段（炼精化炁前的基础）

### 第一阶段：炼己筑基

| 维度 | 内容 |
|:----|:------|
| 体 | 祛病·补虚·填精（先修身体） |
| 用 | 调息·静心·断欲（再修心性） |
| 目标 | 精满·气足·神旺——"三全" |
| 对应方药 | 八珍汤（补气血）+ 六味地黄（填肾精） |
| 体用口诀 | **先补体后调用，体不固则用不彰** |

### 第二阶段：开关通窍

| 维度 | 内容 |
|:----|:------|
| 体 | 三关的"门"需要预热打开 |
| 用 | 武火冲关·橐籥呼吸 |
| 目标 | 尾闾初步通畅 |
| 对应功法 | 丹田呼吸·提肛·叩齿 |
| 体用口诀 | **关不通则化不行，闭目塞听待炁生** |

### 第三阶段：采药归炉

| 维度 | 内容 |
|:----|:------|
| 体 | 活子时现→外肾勃起（精已满） |
| 用 | 火候恰好（武火）+ 吸提撮闭（采药手法） |
| 目标 | 精不泄而化炁上行 |
| 体用口诀 | **活子时至用急采，提吸撮闭炁自升** |
