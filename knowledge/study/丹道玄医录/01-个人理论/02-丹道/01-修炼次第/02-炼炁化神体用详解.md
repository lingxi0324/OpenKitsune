# 炼炁化神体用详解 · 卷二

## 核心命题：炁为木体，化神为火用，夹脊为关

> 炼炁化神，即"震木逆行，化为离火"——木体3→火用2的河图生数转化。

---

## 一、炁的二层结构

### 先天元炁（体·木3）

| 属性 | 说明 |
|:----|:------|
| 来源 | 精化而来，从尾闾上行的生命动能 |
| 性质 | 无形无质，纯粹能量态，生命之火 |
| 位置 | 夹脊关→丹田→全身经脉 |
| 体用定位 | **体用之间**（精已化炁，炁尚未化神） |

### 后天宗炁（用·木8）

| 属性 | 说明 |
|:----|:------|
| 来源 | 呼吸之气（肺）x 水谷之气（脾） |
| 性质 | 半形半质，推动血液运行、温煦脏腑 |
| 体用定位 | **炁之用**（先天元炁的外显） |

### 炁的体用关系

```
先天元炁（体·木3）→ 通过夹脊关（通道）→ 升入泥丸→ 化为神（火2）
                    → 通过经脉流转（用）→ 温养全身（木8）

注：夹脊关是"体用转化"的关键卡口——炁在此从"能量储能"变为"精神光明"
```

---

## 二、夹脊关体用详解

### 位置与体用

| 项目 | 说明 |
|:----|:------|
| 位置 | 脊椎中段，与两肾尖相对（命门对应处），约T10-L2水平 |
| 体 | 命门相火、两肾之间——**精炁交会之地** |
| 用 | 炁升督脉、输布全身——**炁的枢纽站** |
| 河图对应 | 木体3 → 转化通道 → 火用2 |

### 夹脊通关三阶段

| 阶段 | 体用状态 | 体感特征 | 火候 |
|:----|:---------|:---------|:----|
| **积炁** | 精→炁已化，炁聚夹脊 | 背部发热、两肾烫感 | 文火温养 |
| **冲关** | 炁充夹脊，欲破关上行 | 背部有物拱动、强烈热感 | 武火急冲 |
| **通关** | 炁过夹脊，直上玉枕 | 热流沿脊柱涌上后脑 | 自然呼吸 |

### 夹脊不通的体用诊断

| 体征 | 体用诊断 | 河图分析 | 调治 |
|:-----|:---------|:---------|:-----|
| 气短乏力·语音低微 | 体亏（炁不足） | 木3虚 | 补中益气汤 |
| 中气下陷·内脏下垂 | 用不升（炁陷） | 木3→火2不通 | 补中益气+升麻柴胡 |
| 腰背僵硬·活动受限 | 用不畅（炁滞） | 木3滞 | 行气活血·逍遥散 |
| 上火下寒·上热下寒 | 用乱（炁逆） | 木3→火2无序 | 交通心肾·交泰丸 |

## 三、炼炁化神的火候三阶段

### 第一阶段：炁聚夹脊（文火温养）

| 维度 | 内容 |
|:----|:------|
| 体 | 精已足，炁渐生，夹脊处炁感渐强 |
| 用 | 呼吸深长，意念守夹脊，文火徐温 |
| 火候值 | 阳+0.2~+0.4（文火上限） |
| 时长 | 数日至数周 |

### 第二阶段：炁冲夹脊（武火急冲）

| 维度 | 内容 |
|:----|:------|
| 体 | 炁满夹脊，欲破关而出 |
| 用 | 提肛·闭气·意念猛提，武火急冲 |
| 火候值 | 阳+0.5~+0.8（武火区间） |
| 时长 | 数次呼吸致数次功 |
| **注意** | 此阶段最容易出偏差！武火太急则炁散（壮火食气） |

### 第三阶段：炁升督脉（自然运转）

| 维度 | 内容 |
|:----|:------|
| 体 | 夹脊已通，炁自然沿督脉上升 |
| 用 | 不再用意念引导，只"观照" |
| 火候值 | 阳+0.3~+0.5（自然火候） |
| 时长 | 持续运转→进入炼炁化神深层 |
