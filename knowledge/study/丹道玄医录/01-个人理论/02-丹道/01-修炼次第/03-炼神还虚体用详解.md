# 炼神还虚体用详解 · 卷三

## 核心命题：神为火体，还虚为土用，玉枕为关

> 炼神还虚，即"离火逆行，归中入土"——火体2→土用5的河图生数归元。

---

## 一、神的二层结构

### 先天元神（体·火2）

| 属性 | 说明 |
|:----|:------|
| 来源 | 本觉灵知，与生俱来的光明觉性 |
| 性质 | 纯阳无阴，照明一切而不分别 |
| 位置 | 泥丸宫（脑中心）→ 一身之主宰 |
| 体用定位 | **纯用**（神以用为体，不用则不存在） |

### 后天识神（用·火7）

| 属性 | 说明 |
|:----|:------|
| 来源 | 眼耳鼻舌身意六根与外界接触而生 |
| 性质 | 思虑分别、七情六欲、记忆判断 |
| 体用定位 | **体之用**（元神的对外作用） |

### 神的体用关系

```
先天元神（体·火2）→ 通过六根→ 后天识神（用·火7）
                   → 通过炼神还虚（止观）→ 虚（土5）

关键洞见：神的"体"恰恰是"用"
——神不像精（有形的坎水），也不像炁（半形的震木）
——神的本质就是"能照能觉"的用，体用一体！
```

## 二、玉枕关体用详解

### 位置与体用

| 项目 | 说明 |
|:----|:------|
| 位置 | 后脑枕骨下方凹陷处，风府穴深处 |
| 体 | 脑髓之海（泥丸宫的后门） |
| 用 | 炁入泥丸→化为神光（能量转意识） |
| 河图对应 | 木3（炁）→ 火2（神）的最终入口 |

### 玉枕通关三阶段

| 阶段 | 体用状态 | 体感特征 | 火候 |
|:----|:---------|:---------|:----|
| **炁聚玉枕** | 炁已过夹脊，聚于玉枕 | 后脑沉重、胀满感 | 自然呼吸 |
| **破关** | 炁冲玉枕，欲入泥丸 | 轰然一声或眼前一亮 | 武火一冲即止 |
| **炁入泥丸** | 炁已入脑→化为神光 | 眼前光明、头脑清醒 | 止火·文火温养 |

### 玉枕不通的体用诊断

| 体征 | 体用诊断 | 河图分析 | 调治 |
|:-----|:---------|:---------|:-----|
| 头晕目眩·耳鸣 | 体亏（髓海不足） | 火2虚 | 补肾填精·左归丸 |
| 后脑沉重·颈僵 | 用不畅（炁滞玉枕） | 木3→火2受阻 | 升清降浊·半夏白术天麻 |
| 健忘·思维迟钝 | 用不彰（神不明） | 火2用不及 | 开心窍·孔圣枕中丹 |
| 失眠多梦·神躁 | 用太过（神不归位） | 火2浮越 | 镇心安神·朱砂安神丸 |

## 三、还虚三层次

### 第一层：神归泥丸（还虚初步）

| 维度 | 内容 |
|:----|:------|
| 体 | 炁入泥丸后，神开始"归位"——从向外奔驰变为向内收摄 |
| 用 | 止观双运——止（停止杂念）·观（观照光明） |
| 体感 | 眉心印堂发胀、眼前有光、头脑异常清明 |
| 火候 | 纯文火·阳+0.1~+0.2 |

### 第二层：神入虚谷（还虚中乘）

| 维度 | 内容 |
|:----|:------|
| 体 | 神不再仅仅"在泥丸"，而是"遍满全身"——神即炁·炁即神 |
| 用 | 无修无证——不刻意止观，自然在定中 |
| 体感 | 身体界限模糊、与周围空间合一 |
| 火候 | 无火·阳0.0 |

### 第三层：神合太虚（还虚上乘·大成）

| 维度 | 内容 |
|:----|:------|
| 体 | 神与虚空合一——个体意识融入宇宙意识 |
| 用 | 无不用——应物现形，如镜照像 |
| 体感 | 无我相·无人相·无众生相 |
| 火候 | 超越火候·归元（土5） |
