## 一、少阴经——子午冲：六经最核心的命门

### 地支关系：午（心） ↔ 子（肾）——子午正冲

**这是六经中最根本的一对矛盾——水火不交。**

```
子水（肾阴）═══════ 冲 ═══════ 午火（心阳）
  寒水                相冲              君火
（寒化证）                          （热化证）
```

### 冲的病理表现

| 冲的方向 | 病机 | 方证 |
|:--------|:-----|:-----|
| **子水冲午火**（水胜） | 肾寒上犯→心阳被遏 | **四逆汤**：脉微细，但欲寐，四肢厥逆 |
| **午火冲子水**（火胜） | 心火下灼→肾阴被耗 | **黄连阿胶汤**：心烦不得卧，舌红少苔 |
| **子午相搏不分胜负** | 水火皆衰，精神萎靡 | **茯苓四逆汤**：烦躁，昼夜不安 |

### 子午冲的三层传变

```
第一层：子午正冲
  肾寒 ↔ 心热  → 寒化/热化两极

第二层：子午冲引发的相冲连锁
  子冲午 → 午火衰 → 不能生己土（脾） → 太阴病起
  午冲子 → 子水耗 → 不能涵卯木（肝） → 厥阴病起

第三层：子午冲的终极转归
  子胜午 → 纯阴无阳 → 死
  午胜子 → 阴液告竭 → 死（热深厥亦深）
  子午各退 → 阴阳俱衰 → 转为厥阴（厥热胜复）
```

**点睛**：少阴病的本质就是**子与午的拉锯战**——不是简单的"虚"，而是两股力量在打仗。四逆汤是帮午火打回去，黄连阿胶汤是帮子水防守。**谁胜谁负，判人生死。**

## 二、太阳经——申午夹戌，阳气所居

### 地支关系：申（膀胱）+ 午（小肠）

申的藏干：庚（金）+ 壬（水）+ 戊（土）
午的藏干：丁（火）+ 己（土）

申和午之间不是冲，而是**申金生壬水，午火生丁火**——太阳经的本质是**水（壬）与火（丁）同居一经**。

### 申午之间的「内卷」

```
申（寒水之源）
│
├─ 庚金藏 → 寒凝收敛 → 伤寒表实（麻黄汤）
├─ 壬水藏 → 水势浩大 → 蓄水证（五苓散）
└─ 戊土藏 → 湿困 → 湿家表证（麻黄加术汤）

午（阳气之极）
│
├─ 丁火 → 温化之力 → 表虚自汗（桂枝汤）
└─ 己土 → 中气 → 兼太阴证（桂枝人参汤）
```

### 关键地支关系：申子辰三合水局

```
太阳（申）═══ 三合 ═══ 少阴（子）═══ 三合 ═══ 阳明（辰）
       水局初成          水局已成          水局圆满
```

这是整部《伤寒论》最关键的**三合链条**：

| 阶段 | 状态 | 方证 |
|:----|:-----|:-----|
| **申→子**（太阳水气直犯少阴） | 申子半合，水势骤起 | **麻黄附子细辛汤**——太阳少阴同病 |
| **子→辰**（少阴寒水传入阳明） | 子辰半合，水湿从燥 | **真武汤→五苓散**——少阴水停→阳明水湿 |
| **申→辰**（太阳直传阳明） | 申辰半合，跳过少阴 | **葛根汤/五苓散**——太阳阳明合病 |

**点睛**：张仲景把三合局藏在方证里——**申子辰三合水局**是太阳少阴阳明之间的水路暗道。太阳的寒水（申）可以通过子（少阴）直接到辰（阳明），这就是为什么太阳病可以跳过少阴直接传阳明，也解释了为什么真武汤能治水、五苓散也能治水——**水走的是同一条三合暗道**，只是从不同经出来的表现不同。

### 截断法·地支版

```
申水欲合子（太阳欲传少阴）
  → 急温之 → 麻黄附子细辛汤阻断申子半合

子水欲合辰（少阴欲传阳明）
  → 真武汤温阳利水 → 拆散子辰半合

申水直接合辰（太阳直传阳明）
  → 葛根汤截断 → 升津液以破申辰半合
```

## 三、阳明经——卯辰穿害，燥湿相搏

### 地支关系：卯（大肠）+ 辰（胃）

> **卯辰穿害**——卯木克辰土，辰土反侮卯木

```
卯（燥金·大肠）
   穿害↕
辰（湿土·胃）
```

### 穿害的病理

| 穿害方向 | 病机 | 方证 |
|:---------|:-----|:-----|
| **卯穿辰**（大肠克胃） | 燥气伤胃津→胃燥津枯 | **白虎汤/麦门冬汤** |
| **辰反穿卯**（胃湿浸大肠） | 湿困大肠→下利粘滞 | **葛根芩连汤** |
| **卯辰不分胜负** | 燥湿互结→痞满燥实 | **承气汤类** |

### 巳酉丑三合——太阴阳明的「表里暗道」

```
巳（肺·太阴）——金之长生
酉（肾·少阴）——金之帝旺  ← 肾藏金气
丑（脾·太阴）——金之墓库
```

**巳酉丑三合金局**——肺（巳）、肾（酉）、脾（丑）构成三合局！

这揭示了一个被忽略的深层关系：**少阴肾（酉）是太阴肺（巳）和太阴脾（丑）的金气枢纽。**

**临床意义**：
- 肺虚久咳（巳）→ 补肾纳气（酉）→ 金水相生
- 脾虚痰饮（丑）→ 温肾化饮（酉）→ 补火生土的理论补充——实际上是**补酉金以生丑土**

**更深层的发现**：《金匮》治痰饮用肾气丸——因为**巳丑三合需要酉金来贯通**！补肾就是补巳丑之间的金气链，痰饮自化。

## 四、少阳经——寅亥合木，枢机之秘

### 地支关系：寅（胆）+ 亥（三焦）

> **寅亥合木**——寅木与亥水相合，水能生木，自然亲和。

```
寅（胆·甲木）
  合↕  → 寅亥合木
亥（三焦·壬水）
```

### 寅亥合的生理与病理

| 状态 | 机转 | 方证 |
|:-----|:-----|:-----|
| **寅亥合顺**（常态） | 三焦水通利→胆气条达→枢机通畅 | → 健康 |
| **寅旺亥衰**（胆火旺） | 相火被水不制→上炎 | **小柴胡去参加桂** |
| **亥旺寅衰**（水盛木郁） | 水饮阻滞→枢机失灵 | **柴胡桂枝干姜汤** |
| **寅亥不合**（枢机不利） | 三焦塞→胆气不舒→寒热往来 | **小柴胡汤**——恢复寅亥合 |

### 寅申冲——太阳少阳的「表气拉锯」

```
寅（少阳）═══════ 冲 ═══════ 申（太阳）
  枢机                        藩篱
```

| 冲的状态 | 病机 | 方证 |
|:---------|:-----|:-----|
| **申胜寅**（太阳未解） | 表寒郁闭→少阳枢机亦闭 | **柴胡桂枝汤各半** |
| **寅胜申**（枢机已开） | 少阳向外透邪→微汗出 | **小柴胡汤**得汗而解 |
| **寅申交战** | 寒热往来，一日二三度 | **柴胡桂枝干姜汤** |

**点睛**：小柴胡汤为什么叫"和解"？它恢复的是**寅亥合**——柴胡疏寅木（胆），黄芩清寅火（胆热），半夏生姜通亥水（三焦），参草枣补已伤之气。**寅亥一合，枢机自转。**

## 五、太阴经——丑巳半合，湿火互藏

### 地支关系：丑（脾）+ 巳（肺）

> **丑巳半合**——湿土与燥金，内藏火气

```
丑（脾·己癸辛）
   半合↕  → 巳丑半合（无酉不成全金局）
巳（肺·丙庚戊）
```

### 巳丑半合的病理

| 状态 | 病机 | 方证 |
|:-----|:-----|:-----|
| **丑湿胜** | 脾湿困肺→痰饮咳嗽 | **苓桂术甘汤**——温化湿饮 |
| **巳燥胜** | 肺燥伤脾津→口干腹满 | **麦门冬汤**——润燥 |
| **巳火生丑土**（顺） | 肺气通调→脾运自健 | → 正常生理 |
| **丑土侮巳火**（逆） | 脾湿上犯→肺气不降 | **厚朴麻黄汤** |

### 巳亥冲——太阴少阳「湿火交争」

```
巳（太阴·肺中有火）═══════ 冲 ═══════ 亥（少阳·三焦水）
        湿+火                    相火+水
```

| 冲的状态 | 病机 | 方证 |
|:---------|:-----|:-----|
| **巳胜亥**（肺热盛） | 三焦水被灼→口干、小便不利 | **猪苓汤** |
| **亥胜巳**（水饮盛） | 寒湿困肺→咳喘、痰多清稀 | **小青龙汤** |
| **巳亥交战**（湿火互结） | 湿热壅滞→黄疸、胸痞 | **茵陈蒿汤** |

## 六、厥阴经——卯戌合火，风火相煽

### 地支关系：卯（肝）+ 戌（心包）

> **卯戌合火**——卯木生戌火，风火相生

```
卯（肝·乙木）
   合↕  → 卯戌合火
戌（心包·丁火）
```

### 卯戌合的深层意义

卯戌合火是厥阴经最独特的地支关系——**肝胆风木与心包相火相合，火借风势，风助火威。**

这与少阳的寅亥合木完全不同：
- **寅亥合木**（少阳）：水生木，是**顺生**，稳定和缓
- **卯戌合火**（厥阴）：木生火，是**暴发**，迅急猛烈

### 卯戌合的病理

| 状态 | 病机 | 方证 |
|:-----|:-----|:-----|
| **卯盛戌旺**（风火相煽） | 肝火挟心火上冲→消渴、气上撞心 | **乌梅丸**中用黄连黄柏降火 |
| **卯衰戌弱**（木火俱衰） | 肝寒+心阳虚→厥逆、下利 | **当归四逆汤**温之 |
| **卯戌分离**（阴阳离决） | 上热下寒→厥热胜复 | **乌梅丸**寒热并调，恢复卯戌合 |
| **卯被寒郁**（木不生火） | 肝寒犯胃→呕逆 | **吴茱萸汤**温肝散寒 |

### 卯酉冲——厥阴阳明「风燥相激」

卯酉冲在临床中表现为：**肝木克胃土/肠燥**。乌梅丸里用黄柏，正是入大肠（酉），清阳明之热反制肝木。

## 七、六经传变的三大「地道」链条

### 🌊 地道一：申子辰三合水局——水液传变暗道

```
申（太阳）——水之初生
  ↓ 半合
子（少阴）——水之正位
  ↓ 半合
辰（阳明）——水之归藏
```

**传变方证链**：
```
太阳蓄水（五苓散）
  → 少阴水泛（真武汤）
    → 阳明水停（五苓散）
```

**截断法**：见申防子 → 太阳病初期即顾护少阴阳气 → 麻黄附子细辛汤预断

---

### 🔥 地道二：寅午戌三合火局——火热内传暗道

```
寅（少阳）——火之初生（相火）
  ↓ 半合
午（少阴）——火之正位（君火）
  ↓ 半合
戌（厥阴）——火之归藏（风火）
```

**传变方证链**：
```
少阳火郁（小柴胡去参加桂）
  → 少阴热化（黄连阿胶汤）
    → 厥阴风火（乌梅丸寒凉部分）
```

**截断法**：见寅防午 → 少阳病即清相火 → 小柴胡加黄连
