## 一、总纲：从「平面断局」到「立体穿断」

传统奇门遁甲断局多停留在「单宫单符号」的平面解读。例如："天芮星落坤宫主脾胃病"——这是平面断。

九维奇门遁甲的立体穿断，是在此基础上增加**三重立体维度**：

```
平面断局          立体穿断
┌─────────┐      ┌─────────────────────┐
│ 宫位+符号│  →   │ 宫位+符号+层叠剖面    │
│ 单一解读 │      │ +因果链+时间演化      │
└─────────┘      └─────────────────────┘
```

**立体度的核心定义**：
在九宫盘面上，对任意一个事物（事件/人物/病症/走势），同时从**空间剖面、因果链条、时间演化**三个轴向进行穿透解读的能力。

## 二、九维立体度：三维度九层法

### 2.1 第一维：空间剖面（立体深度）

将奇门盘从「平面九宫格」扩展为**层叠剖面**：

| 层级 | 名称 | 对应盘面 | 解读要点 |
|:---:|:----|:---------|:--------|
| L1 | **天盘层** | 天盘九星+天干 | 外部能量、天时大运、不可抗力 |
| L2 | **人盘层** | 八门+八神 | 人间事态、人际关系、执行过程 |
| L3 | **地盘层** | 地盘九宫+地支 | 地理位置、底层根基、地气环境 |
| L4 | **格局层** | 天干组合格局 | 特定"化学配方"（辛加乙＝白虎猖狂等） |
| L5 | **年命层** | 问事人年命落宫 | 个人命运底色与当前事的交集 |
| L6 | **时令层** | 节气+四时旺衰 | 当下天时对盘面的强弱影响 |

**实战案例对照**：

| 案例 | 空间剖面运用 |
|:----|:------------|
| **002·东莞虚实辨** | L1天盘(玄武天网)+L2人盘(杜门)+L4格局(六合休门)=三重锁定虚假信息 |
| **003·AMD走势预测** | L1天盘(双午火炎)+L5年命(问事人庚)+L6时令(芒种火旺)=短期艰难但长期可期 |
| **004·升平镇搬迁** | L3地盘(艮坤宫)+L4格局(值符坎一出)+L6时令(三午聚火)=经济主因+政策底色 |

### 2.2 第二维：因果链条（穿透深度）

将事件从「是什么」扩展到「为什么」，构建完整的因果路径。

**三层因果穿透法**：

```
第一层·表象层（文件上写的）
  ↓ 杜门玄武时——这是"给外人看的理由"
第二层·实因层（真实推动力）
  ↓ 生门值使+戊土伤门——这是"真正的利益驱动"
第三层·底色层（最深的不可抗力）
     值符+天蓬/天柱——这是"连执行者也无法改变的格局"
```

**实战案例对照**：

| 案例 | 因果穿透 |
|:----|:--------|
| **002·东莞虚实辨** | 表象(视频光鲜)→实因(公司空壳无资质)→底色(对方浸淫虚假生态) |
| **003·AMD走势** | 表象(96G显存诱人)→实因(天芮星病气/生态不成熟)→底色(火天大有卦的"小人弗克") |
| **004·升平镇搬迁** | 表象(地质/地理隐患)→实因(土地收储/经济开发)→底色(国家级区域战略规划) |

### 2.3 第三维：多宫联动（网络深度）

不只看单宫，而是看**宫与宫之间的生克制化网络**。

**三种联动模式**：

| 模式 | 定义 | 实战应用 |
|:----|:----|:--------|
| 🔗 **回路模式** | A宫生B宫+B宫生A宫=正反馈回路 | 案例002·诱惑回路(六合休门生白虎生门→越想越去) |
| ⚡ **冲击模式** | A宫克B宫=单向压制 | 案例004·乾宫被白虎伤门冲击=受搬迁冲击 |
| 🌐 **平衡模式** | 多宫制衡=稳定态 | 案例003·坎宫六合+离宫九天+中宫生门=三方制衡可入手 |

**案例002·三回路网络（立体网络的典范）**：

```
【回路一·诱惑回路】震三六合休门 → 生 → 巽四白虎生门(越动越想去)
【回路二·虚假回路】兑七九天杜门 ↔ 乾六玄武天网(视频光鲜互证公司空壳)
【回路三·结局回路】离九值符死门 → 克 → 坎一腾蛇伤门(事不成+钱受损)
```

### 2.4 暗干穿透（古籍验证新增 · 2026-06-13）

**《奇门法窍》卷六·暗干核心发现**：人盘八门之中藏有暗干。明干显象，暗干隐机。

**暗干查询三法**：

| 查法 | 方法 | 用途 |
|:----|:-----|:----|
| **时干暗干** | 时干落地盘九宫，所临之宫的地盘天干 | 事件隐藏本质 |
| **值使暗干** | 值使门所在宫的地盘天干 | 执行的隐秘动机 |
| **日干暗干** | 日干落地盘九宫，所临之宫的地盘天干 | 事主的隐藏状态 |

**九维实战对照**：

| 案例 | 明干（表象） | 暗干（隐藏） | 破解效果 |
|:----|:-----------|:-----------|:--------|
| 004·搬迁 | 时干己入兑→"己土地利变迁"（文件理由） | 暗干壬→隐藏水利/能源规划 | 真实动因从"地质"转向"国策" |
| 002·虚实辨 | 丙火入离→"表面光鲜" | 暗干癸→阴湿虚假 | 对方无实质一眼看穿 |
| 003·AMD预测 | 丁火旺→"性能强大" | 暗干辛→技术困于生态 | 预判短期无法兑现 |

**明暗关系判定规则**：
- 明干暗干相同 → 表里如一
- 明干暗干相生 → 方向一致，稍有偏差
- 明干暗干相克 → 表里严重不符，必有一假
- 暗干为乙丙丁（隐门奇仪）→ 隐藏中有转机
- 暗干为庚 → 隐藏中有障碍/阻力

## 三、三维时间判断逻辑：从「三段论」到「六步穿时」

### 3.1 传统三段时间的局限性

大多数奇门推演止步于：**过去→现在→未来**三段。但这太粗了——"未来"可以是3天，也可以是3年，模糊不清。

### 3.2 三维时间判断：时量/时质/时势

#### 🕐 维度一：时量（时间跨度校准）

根据事发宫位的星门神组合，判断推演的时间尺度：

| 符号组合 | 时间尺度 | 适用场景 | 案例 |
|:--------|:-------:|:--------|:----|
| **天冲+伤门+白虎** | 3天~2周（突发急迫） | 突发的冲击性事件 | 案例004·搬迁通知 |
| **天辅+杜门+玄武** | 1~3个月（暗中推进） | 信息不透明的事务 | 案例004·搬迁执行 |
| **天任+腾蛇+惊门** | 3~6个月（拉扯反复） | 谈判、补偿、争议 | 案例004·谈判期 |
| **天心+九天+景门** | 6个月~1年（战略落地） | 政策/规划公开 | 案例004·新规划出 |
| **天芮+六合+生门** | 1~2年（利益闭环） | 商业项目全周期 | 案例002·工程落地 |
| **天柱+值符+死门** | 不可逆/终结 | 旧格局彻底终结 | 案例004·搬完拆旧 |

**实战校准口诀**：
> 白虎天冲数日内，杜门玄武月余藏
> 腾蛇天任半载扯，九天心景一年量
> 生门芮合两年事，柱符死门不可挡

#### 🎭 维度二：时质（阶段性质定位）

确定事件在时间轴上的性质：

| 时间段 | 性质 | 能量状态 | 案例002 | 案例003 | 案例004 |
|:------|:----|:--------|:-------|:-------|:-------|
| **前因期** | 起念、谋划、筹备 | 暗/未显 | 对方建人设 | 产品规划 | 闭门会议规划 |
| **爆发期** | 事件公开、冲突发生 | 明/剧烈 | 对方变得更热情 | 参数发布引关注 | 搬迁通知下达 |
| **拉扯期** | 信息博弈、反复调整 | 缠/混乱 | 查不到实质资质 | 社区适配问题 | 补偿条件谈判 |
| **定型期** | 结果明朗、格局落定 | 定/可见 | 不去无事 | 效能六到七成 | 新格局公开 |
| **余波期** | 影响延伸、长期效应 | 散/渐弱 | 念头消失 | 下一台机器跳板 | 旧镇成新规划区 |

#### 🌊 维度三：时势（气机强弱判定）

结合节气+四时旺衰+当前干支，判断事件推进的**速度与阻力**：

| 四柱特征 | 时势判断 | 推力/阻力 | 案例 |
|:--------|:--------|:---------|:----|
| **三午聚火** | 火炎鼎革，势不可逆 | 推力极强 | 案例004·三午火局→搬迁不可逆 |
| **双午夹金** | 烈火烧金，短期艰难 | 先阻后通 | 案例003·双午克辛丑→短期折腾 |
| **四柱火旺** | 火主虚象，表面繁荣 | 阻力（虚假） | 案例002·巳午齐全→信息粉饰 |
| **金水当令** | 肃杀沉降，宜静不宜动 | 阻力（退散） | — |
| **土木相战** | 竞争冲突，拉扯拉锯 | 阻力明显 | — |

## 四、三维时间轴：六阶推进法（核心工具）

综合时量/时质/时势，将事件在时间轴上标注为六个阶段：

```
阶段        时量参考      主要工作        验证方法
┌─────────────────────────────────────────────┐
│ ① 前因酝酿  1~2年前   收集背景信息    问当事人/查资料 │
│ ② 引爆触发  当前±2周  定位直接导火索 对应宫位白虎冲星 │
│ ③ 短期演化  1个月内   观察第一轮反馈 用六合/腾蛇验动 │
│ ④ 中期定型  1~6个月   锁定核心走向   值符/值使定方向  │
│ ⑤ 长期结果  6月~2年   验证最初判断   死门/生门看终局 │
│ ⑥ 余波延展  2年以上   评估长尾效应   年命宫判个人后续 │
└─────────────────────────────────────────────┘
```

## 六、六爻应期法：时间窗口的五行定位

综合四个案例，提炼判断具体"什么时候"的六种法则：

| 法则 | 适用 | 判断依据 |
|:----|:----|:--------|
| **① 值符动应** | 重大决策落地 | 值符所在宫位的五行被流月/流日引动时 |
| **② 值使门应** | 事务性进程 | 值使门所在的宫位五行被引动时 |
| **③ 杜门开应** | 信息/隐蔽事务 | 杜门的对冲宫位被引动时（信息将从暗到明） |
| **④ 六合合应** | 牵涉多方的事务 | 六合宫位的三合/六合年月 |
| **⑤ 旺衰应** | 季节性事件 | 事件所在宫位的五行当令季节 |
| **⑥ 伏吟反吟应** | 延迟/加速 | 伏吟以冲为应期，反吟以合为应期 |

### 6.1 《奇门法窍》三大应期法门（古籍补入）

《奇门法窍》应期判断的三大法门，可直接融入九维时间判断体系：

| 法门 | 原文 | 九维融合用法 |
|:----|:----|:------------|
| **⑦ 神星门三应** | "神应时之初，星应时之中，门应时之末" | 八神定事件初动时段，九星定中段进程，八门定收尾结果。同一事件三段时间分判 |
| **⑧ 符使先后应** | "符应在先，始应在后" | 值符落宫定事件启动时间（初应），值使门所在宫位定事件落地时间（终应）。两宫相隔远则时限长，相隔近则速 |
| **⑨ 空亡出旬应** | "直符落在旬空，必以出旬断之" | 值符/事体宫若空亡，不以当前月断应期，必等出旬之日，空亡填实方才应事 |

**法门⑦的临床运用示例**：
- 兑宫玄武+杜门+己开穴 → 八神玄武定初动（3天内暗流涌动），九星天辅定中段（7~10天酝酿），八门杜门定收尾（信息公开日最迟在21天后对冲宫动时）

**法门⑧的案例验证**：
- 案例004升平镇搬迁：值符在坎1（水），值使生门在中宫（土）。水至土的时序为夏→秋的跨度，值符先动（甲午月已推进），值使后应（入秋文件公开）

**法门⑨的特殊场景**：
- 若排盘时发现值符落宫恰在甲午旬的辰巳空亡，则当前占断需要等出旬（即丙午月出旬）方有实际消息，此前的一切研判为"虚象"

> **来源**：《奇门法窍》应期卷 · 丙午年甲午月戊午日经五部古籍合参验证补入

**案例004示范**：
- 值符在坎一（水），流月甲午（午火为财）→ 甲午月即在推进
- 杜门在兑七（金），对冲震三（木），乙未月（乙木）→ 未月可能信息开始公开
- 艮宫九地景门 → 入秋（申酉金生水）→ 秋季文件公开

## 七、奇门演卦法（新增 · 《奇门旨归》符使演卦验证）

**来源**：《奇门旨归》符使演卦法——值符星名+值使门名直接转为六十四卦，以卦象交叉验证九维盘面结论。

### 7.1 演卦规则

| 步骤 | 操作 |
|:----|:----|
| ① 值符配卦 | 天蓬→坎、天芮→坤、天冲→震、天辅→巽、天禽→中（寄坤）、天心→乾、天柱→兑、天任→艮、天英→离 |
| ② 值使配卦 | 休门→坎、生门→艮、伤门→震、杜门→巽、景门→离、死门→坤、惊门→兑、开门→乾 |
| ③ 定本卦 | 值符星卦为上卦，值使门卦为下卦，合成本卦 |
| ④ 看世应 | 以时干定变爻，断世应吉凶 |

### 7.2 九维现有案例全验证

**案例004·升平镇搬迁**：天柱（兑☱）+死门（坤☷）→ **泽地萃䷬**

> 萃卦象曰："泽上于地，萃。君子以除戎器，戒不虞。"泽在地之上，水聚成泽——人口聚集之地被重新收聚分配。"戒不虞"即预警不可预料之事——搬迁在百姓眼中正是不虞之变。六二爻"引吉无咎"——引动（搬迁）最终无咎。

✅ **与九维盘面结论完全一致**：搬迁虽痛苦，安置结果无咎。

**案例003·AMD走势**：天芮（坤☷）+惊门（兑☱）→ **地泽临䷒**

> 临卦象曰："君子以教思无穷，容保民无疆。"AMD需要"容保"（生态兼容）才能无疆——正应九维盘中"六七月关键期"。

✅ **与九维结论一致**：需等待生态成熟。

**案例002·东莞虚实辨**：天芮（坤☷）+杜门（巽☴）→ **地风升䷭**

> 升卦象曰："积小以高大。"对方之事看似在累积上升，但九维已判虚假——演卦揭示"积累"是包装出来的，非真实。九四爻"王用亨于岐山，吉无咎"，但需看世应在谁——时干辛金为问事人，处于被"升"所惑的位置。

✅ **交叉验证**：卦象与九维盘面的"虚假繁荣"判断互为表里。

## 九、综合实战流程（九维立体穿断七步法）

将上述所有方法整合为可执行的七步流程：

```

第二步：九维全盘 → 完整列出九宫表格（天地星门神格局）

第三步：用神定位 → 确定事体宫、日干、时干、年命、值符

第四步：选择切题穿透组合 →
  根据事件类型（辨伪/预测/前因/病机）
  从 3×3 矩阵中选择 3~4 种穿透力场

第五步：立体因果链 →
  ① 表象层（文件/表面理由）
  ② 实因层（真实推动力）
  ③ 底色层（格局级不可抗力）

第六步：六阶时间轴 →
  前因→引爆→短期→中期→长期→余波
  按星门神组合校准时量
  按四柱干支判定时势

第七步：产出结论 →
  ① 根本原因（三维因果链）
  ② 时间走向（六阶推进表）
  ③ 核心建议（找准自身位置）
```
