## 一、核心理论骨架

### 公理一：四象五味

| 四象 | 五味 | 无甘单行 | 配甘则 |
|:----:|:----:|:--------:|:------:|
| 东木 | **辛** | 泄 | 补 |
| 南火 | **苦** | 疏 | 固 |
| 西金 | **酸** | 通 | 养 |
| 北水 | **咸** | 降/破实邪 | 培脏体 |
| **中央土** | **甘** | — | 万物生化之母 |

> **四象单行（不用甘）** = 泄、疏、通、降、破实邪
> **四象 + 甘** = 由泄转补、由疏转固、由通转养、由降转培

### 公理二：五脏体用二分

| 五脏 | 体味（补脏体） | 用味（疏脏用） |
|:----:|:--------------:|:--------------:|
| **肝木** | 酸为肝体 | 辛为肝用 |
| **心火** | 苦为心体 | 咸为心用 |
| **脾土** | 甘为脾体 | 淡为脾用 |
| **肺金** | 辛为肺体 | 酸为肺用 |
| **肾水** | 咸为肾体 | 苦为肾用 |

### 公理三：双轨对应病机

| 轨 | 来源 | 病机 | 治则 |
|:-:|:----:|:----:|:----:|
| **先天轨** | 五运化气 | 脏体亏虚 | 本脏体味 + 甘味，以甘成补 |
| **后天轨** | 五行相生 | 脏用郁实 | 单用本脏用品味，不用甘，四象单行成泄 |

## 二、医理底层验证

### 2.1 河图四象配五味逻辑

河图：东木、南火、西金、北水为四象四正，对应辛、苦、酸、咸；
中央土为甘，为万物生化之母。

- **四象** → 主动、散、泄、制邪
- **中土甘** → 主静、守、补、固本

与《黄帝内经》"五味阴阳、补泻随配伍"完全一致。

### 2.2 五脏体用分体 → 《内经》体阴用阳

五脏皆体阴而用阳：
- **体** = 藏精、藏血、藏津液、本位之阴
- **用** = 疏泄、宣发、肃降、气化、气机之阳

每脏固定一味为体、一味为用，将抽象的体阴用阳落到性味用药、取穴治则，成为可临床操作的定式。

### 2.3 打破世俗误区：不是"酸只入肝、苦只入心"

同一味可入多脏，只分是入**体**还是入**用**：

| 五味 | 入脏体 | 入脏用 |
|:----:|:------:|:------:|
| 酸 | 肝之体 | 肺之用 |
| 辛 | 肝之用 | 肺之体 |
| 苦 | 心之体 | 肾之用 |
| 咸 | 肾之体 | 心之用 |

> 比课本"机械五味入五脏"高一个维度。

## 三、逐脏临床病机实战验证

### 3.1 肝脏 — 酸体辛用

| | 虚证（脏体亏） | 实证（脏用郁） |
|:-:|:--------------:|:--------------:|
| **见症** | 眼干、胁隐胀、烦躁不耐劳、月经量少、筋脉拘急 | 易怒、胸胁胀痛、嗳气、口苦、失眠多梦、梅核气 |
| **治则** | 酸养肝体 + 配甘成补 | 单用辛味，不用甘，四象单行泄 |
| **代表方** | 四物汤、一贯煎 | 柴胡、香附、川芎（辛散疏肝用） |
| **效果** | 酸甘化阴，专补肝体阴血，不耗肝用、不克脾胃 | 只疏气机、不壅补、不恋邪，不会"补药助火" |

> **结论**：肝的一切阴虚、血虚、肝郁、肝火、肝脾不和，全被酸体辛用+甘补辛泄框架全覆盖。

### 3.2 心脏 — 苦体咸用

| | 虚证（脏体亏） | 实证（脏用郁） |
|:-:|:--------------:|:--------------:|
| **见症** | 心慌、失眠、多梦、健忘、劳心加重 | 心火上炎、口舌生疮、心烦躁扰 |
| **治则** | 苦养心体 + 配甘成补 | 单用咸味泄心用，不兼甘 |
| **代表方** | 炙甘草汤、天王补心丹 | 导赤散类（咸苦下行） |
| **效果** | 苦甘养心阴、固心本体，治本不反复 | 清心而不伤心体，只泻心用邪热 |

### 3.3 脾土 — 甘体淡用

| | 虚证（脏体亏） | 实证（脏用郁） |
|:-:|:--------------:|:--------------:|
| **见症** | 食少乏力、便溏、中焦虚寒 | 湿滞、食积、脘腹胀满、舌苔厚腻 |
| **治则** | 甘为脾体，纯甘即补 | 淡味渗泄为脾用，不用甘 |
| **代表方** | 理中汤、四君子汤 | 茯苓、猪苓、泽泻、苍术（淡渗利湿） |
| **效果** | 补脾本体中气 | 只通脾之运化功用，不补不壅 |

> **现代人最强优势**：脾虚夹湿 → 甘补其体、淡泄其用，一边补脾一边渗湿，完美对应90%脾胃病病机。

### 3.4 肺金 — 辛体酸用

| | 虚证（脏体亏） | 实证（脏用郁） |
|:-:|:--------------:|:--------------:|
| **见症** | 气短自汗、易感冒、久咳气虚 | 痰热咳嗽气喘、胸闷 |
| **治则** | 辛补肺体 + 配甘成补 | 单用酸味敛降泄肺用 |
| **代表方** | 玉屏风散、补肺汤 | 白芍、五味子、杏仁（酸收肃降） |
| **效果** | 固卫实表、补肺体之气 | 敛肺用之逆气、实热、痰壅，不伤正 |

> **分型**：久咳虚咳 → 辛甘补体；新咳实咳 → 酸味泄用。

### 3.5 肾水 — 咸体苦用

| | 虚证（脏体亏） | 实证（脏用郁） |
|:-:|:--------------:|:--------------:|
| **见症** | 腰酸耳鸣、早衰、肾精亏虚 | 水湿泛滥、下焦湿热、小便不利 |
| **治则** | 咸滋肾体 + 配甘成补 | 单用苦味泄肾用 |
| **代表方** | 六味地黄丸、左归丸 | 黄柏、知母、猪苓（苦味泄浊利水） |
| **效果** | 专补肾之本体精髓，不温阳浮火 | 只通肾之气化功用，不滋腻恋邪 |

## 四、虚实夹杂证 — 终极验证

> 临床 **90%** 病人不是纯虚、不是纯实，都是 **本虚标实**。

| 常见病型 | 先天脏体虚（本） | 后天脏用实（标） |
|:--------:|:----------------:|:----------------:|
| 脾虚湿阻 | 甘补脾体 | 淡渗脾湿 |
| 肝郁阴亏 | 酸甘养肝体 | 辛散疏肝用 |
| 肾虚浊留 | 咸甘滋肾体 | 苦泄肾浊 |
| 肺虚痰壅 | 辛甘补肺体 | 酸敛泄肺用 |

### 双轨分层施治公式

```
治本（先天脏体） = 体味 + 甘味  培补本体
治标（后天脏用） = 单用品味    疏泄实邪
```

> ✅ **一补一泄、一体一用、一先天一后天**，同时施治，不会犯"补则留邪、泄则伤正"的临床大忌。
