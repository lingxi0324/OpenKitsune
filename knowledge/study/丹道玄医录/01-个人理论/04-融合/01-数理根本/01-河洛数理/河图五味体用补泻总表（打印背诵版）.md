# 🧬 河图四象五味·五脏体用补泻总表（打印背诵版）

---

## 一、核心公理

> **四象单行（不用甘）** → 泄、疏、通、降、破实邪
> **四象 + 甘** → 由泄转补、由疏转固、由通转养、由降转培

---

## 二、五脏体用对照表

| 五脏 | 体味（补） | 用味（泄） | 甘配（成补） |
|:----:|:----------:|:----------:|:------------:|
| **肝** | 酸 | 辛 | 酸+甘 ⇨ 补肝体 |
| **心** | 苦 | 咸 | 苦+甘 ⇨ 固心体 |
| **脾** | 甘（自补） | 淡 | 纯甘 ⇨ 补脾体 |
| **肺** | 辛 | 酸 | 辛+甘 ⇨ 补肺体 |
| **肾** | 咸 | 苦 | 咸+甘 ⇨ 滋肾体 |

## 三、一脏一页·速查表

### 3.1 肝 — 酸体辛用

| | 虚证（酸甘补体） | 实证（辛味单泄） |
|:-:|:----------------:|:----------------:|
| **见症** | 眼干、胁隐胀、烦躁不耐劳、筋脉拘急 | 易怒、胁痛、嗳气、口苦、梅核气 |
| **药** | 白芍 + 当归/熟地/甘草 | 柴胡、香附、川芎 |
| **方** | 四物汤、一贯煎 | 逍遥散去白术姜 |
| **穴** | 补太冲、肝俞、期门 | 泻行间、蠡沟 |
| **禁忌** | 湿盛中满勿腻补 | 血虚勿过散 |

### 3.2 心 — 苦体咸用

| | 虚证（苦甘固体） | 实证（咸味单泄） |
|:-:|:----------------:|:----------------:|
| **见症** | 心悸、失眠、健忘、劳心加重 | 口疮、心烦、躁扰、面赤 |
| **药** | 麦冬、生地 + 人参/炙甘草 | 竹叶、通草、犀角/水牛角 |
| **方** | 炙甘草汤、天王补心丹 | 导赤散、泻心汤 |
| **穴** | 补神门、心俞、巨阙 | 泻少府、少海 |
| **禁忌** | 痰湿壅盛勿滋腻 | 虚火勿过苦燥 |

### 3.3 脾 — 甘体淡用

| | 虚证（纯甘补体） | 实证（淡味单泄） |
|:-:|:----------------:|:----------------:|
| **见症** | 食少、乏力、便溏、中焦寒 | 腹胀、苔腻、湿阻、食积 |
| **药** | 人参、白术、炙甘草 | 茯苓、猪苓、泽泻、苍术 |
| **方** | 四君子汤、理中汤、补中益气汤 | 平胃散、五苓散去桂枝 |
| **穴** | 补太白、脾俞、章门 | 泻阴陵泉、丰隆、内庭 |
| **禁忌** | 湿阻苔腻勿纯补 | 脾虚明显勿过渗 |

### 3.4 肺 — 辛体酸用

| | 虚证（辛甘补体） | 实证（酸味单泄） |
|:-:|:----------------:|:----------------:|
| **见症** | 气短、自汗、易感冒、久咳 | 痰热、咳喘、胸闷气逆 |
| **药** | 黄芪、防风 + 白术/甘草 | 白芍、五味子、杏仁 |
| **方** | 玉屏风散、补肺汤 | 黛蛤散合泻白散减甘草 |
| **穴** | 补太渊、肺俞、中府 | 泻尺泽、孔最、列缺 |
| **禁忌** | 外感属实勿补 | 久咳肺虚勿过敛 |

### 3.5 肾 — 咸体苦用

| | 虚证（咸甘滋体） | 实证（苦味单泄） |
|:-:|:----------------:|:----------------:|
| **见症** | 腰酸、耳鸣、早衰、精亏 | 湿热、水停、小便不利、相火郁 |
| **药** | 熟地、山茱萸 + 山药/甘草 | 黄柏、知母、猪苓 |
| **方** | 六味地黄丸、左归丸 | 知柏地黄去山药、猪苓汤 |
| **穴** | 补太溪、肾俞、京门 | 泻涌泉、水泉、阴谷 |
| **禁忌** | 湿浊苔腻勿滋腻 | 肾阳虚冷勿苦寒 |

## 四、虚实夹杂·双轨同施公式

```
处方 = [体味 + 甘味]   +   [单用品味]
       ↑ 补先天脏体      ↑ 泄后天脏用
       ↑ 治本             ↑ 治标
```

### 典型组合速查

| 证型 | 补体（治本） | 泄用（治标） |
|:----:|:------------:|:------------:|
| 肝郁阴亏 | 白芍+甘草（酸甘） | 柴胡、香附（辛） |
| 脾虚湿阻 | 白术+炙甘草（甘） | 茯苓、苍术（淡） |
| 肾虚湿热 | 熟地+山药（咸甘） | 黄柏、知母（苦） |
| 肺虚痰热 | 黄芪+甘草（辛甘） | 杏仁、白芍（酸） |

## 五、五味纵横·体用互入（进阶记忆）

```
       入  体  →          入  用  →
 酸 ───→ 肝体             肺用（敛降）
 辛 ───→ 肺体             肝用（疏泄）
 苦 ───→ 心体             肾用（泄浊）
 咸 ───→ 肾体             心用（下行）
 甘 ───→ 脾体（自补）      ——
 淡 ───→ ——               脾用（渗湿）
```
