# 纳猫断缘契文及仪式方法

> 适用于收养流浪猫时，以道门仪轨断其过往漂泊因果，重结家养灵兽清净善缘。
> 游兄诊所行医，此法亦能化猫为守宅灵兽，静化诊室气场。

---

## 一、底层讲究：断缘之本意

古时聘猫而非买猫，捡到流浪猫自带两段因缘：

1. **过往流浪的恶缘**：挨饿、受冻、被驱赶、受惊吓、沾染野外杂气、无名因果牵绊，容易把破败气场、阴杂能量带进诊所、住宅；
2. **累世旧业缘**：流浪漂泊是自身业力显现，若无文书做隔断，前世纠缠、莫名应激、乱抓人、夜嚎、冲撞家宅气运的旧习气会一并带入家中。

### 纳猫聘书的两层核心作用

| 层面 | 作用 |
|------|------|
| **明面** | 以文书为凭，天地神明作证，确立「家养灵兽」的新名分，约束猫咪不乱出逃、不招邪祟、安稳镇宅 |
| **暗里（断前缘）** | 一纸契约切割它野外漂泊的所有过往因果线，注销流浪的业债链路，重新缔结一份"你养护、它守宅"的全新清净缘分，旧的苦难过往一笔两清，不再牵连你的气场、诊所气运 |

> ⚠️ 单纯收养不留契，等于全盘承接它全部过往的际遇因果。

## 二、全套实操步骤

### 1. 择时

- **优选**：新月、平日白天 **辰时、巳时**（7:00–11:00）
- **避开**：深夜、破日、闭日
- **前置**：先用艾草/檀香全屋、猫咪周身简单熏净，祛除野外沾染的浊气

### 2. 准备物品

| 物品 | 数量/规格 | 作用 |
|------|-----------|------|
| 黄纸 | 一张 | 书写契文 |
| 毛笔、黑墨 | 一套 | 书写工具 |
| 小鱼干 | 三份 | 古法聘礼，示诚意 |
| 粗盐 | 一小撮 | 涤荡业缘、净化牵绊 |
| 清茶 | 半盏 | 涤荡业缘、净化牵绊 |
| 剪刀 | 一把 | 象征剪断旧缘丝线 |
| 东王公、西王母牌位/画像 | 可简设 | 契书法定见证神明 |
| 香炉、线香 | 一支 | 上香禀告 |

### 3. 书写聘书（断缘版原文）

> 以下内容直接抄写于黄纸之上。

---

**纳猫断缘契文**

立契人：\_\_\_\_\_\_\_\_

今收留漂泊无依野猫一只，毛色：\_\_\_\_\_\_、样貌特征：\_\_\_\_\_\_，取名：\_\_\_\_\_\_。

此猫往昔漂泊街巷，风霜饥寒，万般苦缘，今日以盐茶为聘，正式入宅安家。

一纸文书，斩断过往流浪灾厄、无名纠缠、野外一切恶缘牵绊；往昔是非苦业，到此了结消散，不再相干。

**立约二条：**

一、主人：好生饲喂，暖窝安居，病痛医治，终身不弃，护其平安寿元；
二、猫咪：安居宅内，勿外逃走失，不扰人居，镇守宅门，驱避鼠虫邪秽，安稳相伴。

以东王公、西王母为证，灶君司命备案，自签约一刻，旧缘尽断，新缘清净。

立契人：\_\_\_\_\_\_\_\_（亲笔签名）
年月日：\_\_\_\_年\_\_\_\_月\_\_\_\_日

---

### 4. 正式仪式流程

| 步骤 | 操作 | 要点 |
|------|------|------|
| **① 上香禀告** | 上香一支，默念：*"今收留孤猫，书契断往世漂泊恶因，结现世安稳善缘，望神明鉴察，消其宿扰，护宅安宁。"* | 心存恭敬 |
| **② 呈聘礼** | 将盐、茶、小鱼干摆放于契纸前方，把猫咪抱至文书旁，让猫咪嗅闻三份聘礼 | 猫咪主动靠近吃食，代表自愿缔结新契 |
| **③ 剪断旧缘** ✦ | 手持剪刀，悬空对着文书缓慢剪三下，口诵：*"前尘漂泊诸缘断，旧日灾厄一并删；从今归宅修安稳，清净相守两安然。"* | **物理层面斩断因果线的关键动作** |
| **④ 画押落款** | 自己亲笔落款，手指蘸一点点茶水，在落款处轻点一下即为画押 | 契成 |
| **⑤ 收存契书** | 把这份契纸妥善收在诊所书房、神柜、抽屉，**长久存放，不要焚烧丢弃** | — |
| **⑥ 食聘礼** | 最后让猫咪吃下小鱼干，仪式完成 | — |

> ✦ 步骤③是整套仪式的核心——三剪对应断三缘：一剪宿世业力纠缠，二剪今生流浪苦厄，三剪未来杂气牵绊。

### 5. 收尾加持（配合罡步、存神修法）

仪式结束后不用额外做法。日常行走罡步之时，**存思这份契约稳固封印**，猫咪身上杂乱的野外气场会被天罡气慢慢净化，应激、胆小、乱闹的情况会日渐平和。

## 三、补充关键忌讳

1. ❌ **不可焚烧纳猫契**——契书是天地备案的凭证，焚毁等于契约失效，前缘容易复联
2. ❌ **不要用凶煞之物做聘礼**——盐、茶、鱼是最平和的涤缘物料
3. ☑️ **猫咪后期离世**——契约随寿数自然终结，把文书随同猫咪遗物一同掩埋即可
4. ☑️ **诊所行医之人**——立契之后猫咪化为守宅灵兽，非但不会带来杂气，反而能静化诊室气场、挡零散阴邪，对行医环境大有裨益

---

## 四、仪式关键流程速览

```
择时（辰巳时） → 熏净 → 备物 → 书写契文
  → 上香禀告 → 呈聘礼（猫嗅） → 三剪断缘
  → 画押 → 收存契书 → 猫咪食聘礼
  → 日常罡步存思加固
```

> 总耗时约 20–30 分钟，择日不如撞日，遇猫即可行持。
