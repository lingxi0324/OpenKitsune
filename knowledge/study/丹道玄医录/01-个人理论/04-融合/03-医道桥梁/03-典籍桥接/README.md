# 🌉 丹道玄医录 ↔ 知识库 桥梁系统

> ⚡ **阅读须知**：本目录及下属所有文件**由脚本自动生成**（图谱桥接器 + 知识卡片生成器），用于在丹道玄医录与原典图书馆之间建立双向链接索引。
>
> **学习建议**：优先阅读 `00-索引/` 总索引 → 01~10 各分类目录下的核心笔记。本目录内容为辅，适合在深入某个知识点时查证原典引用、查看知识图谱关联，不建议逐篇通读。



## 为什么要有这个桥梁？

```
丹道玄医录（121篇个人理论）       knowledge/（3410本原典）
     │                                  │
     └──────────── 🌉 ──────────────────┘
                    │
          AI 做桥接：查原典 → 引证 → 建双链
```

- **丹道玄医录** = 你的个人理论体系、辨证心法、针法推演（消化后的思考）
- **knowledge/** = 原典图书馆（伤寒/素问/道藏/易经/训练数据）（未加工的原材料）

各自独立，互不污染，AI（我）通过桥梁文件在两者间自由穿梭。

## 📂 文件说明

| 文件 | 功能 | 用法 |
|:----|:-----|:-----|
| `bridge_search.py` | 🔍 **全文检索桥梁** | 在知识库中搜索关键词，返回原文和引用格式 |
| `bridge_cite.py` | 📖 **引用格式生成器** | 搜索文献名，生成 `[[双链]]` 引用格式 |
| `bridge_graph.py` | 🕸️ **图谱桥接器** | 自动发现 vault 双链与知识库文献的关联 |
| `out/图谱桥接报告.md` | 📊 桥接报告 | 图谱关联完整报告 |
| `out/图谱桥接数据.json` | 📊 结构化数据 | 供 AI 程序化使用的 JSON 数据 |

## 🚀 快速上手

### 1️⃣ 重建索引（首次使用）

```powershell
python _bridge/bridge_search.py --rebuild
```

### 2️⃣ 搜索原文

```powershell
# 搜索关键词
python _bridge/bridge_search.py "阴阳"

# 限定分类
python _bridge/bridge_search.py "少阳" --scope 伤寒

# 列出所有分类
python _bridge/bridge_search.py --list-scopes
```

### 3️⃣ 生成引用

```powershell
# 搜索相关文献并生成双链引用格式
python _bridge/bridge_cite.py 素问

# 输出到笔记
python _bridge/bridge_cite.py 伤寒 --output "06-资源库/参考文献/伤寒类文献.md"
```

### 4️⃣ 生成图谱桥接报告

```powershell
python _bridge/bridge_graph.py
```

## 🤖 AI 如何使用这座桥？

当你想让我引经据典时，我内部流程是：

```
你问 → 我理解意图
     → bridge_search("关键词") 在知识库中查原典
     → 读原典相关段落
     → 在丹道玄医录中建立 [[双链]] 引用
     → 回答你
```

示例互动：
> 你："帮我查《伤寒论》少阳证的原文"
> 我：运行 bridge_search "少阳" --scope 伤寒 → 返回原文 → 更新笔记并引用
