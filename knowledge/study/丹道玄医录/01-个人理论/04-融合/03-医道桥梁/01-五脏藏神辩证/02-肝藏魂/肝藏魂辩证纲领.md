# 🌿 肝藏魂辩证纲领

> **标签**: `#五脏藏神/肝` `#肝藏魂`
> **关联**: [[../总纲-五脏藏神辩证纲领.md|总纲]]

## 核心定位

肝主疏泄，调畅情志，藏血舍魂。疏泄失常则气机郁滞，肝血不足则魂不守舍，肝火亢盛则魂不安定。

**适用疾病**: 抑郁症、焦虑症、双相情感障碍、强迫症、精神分裂症等，常为精神疾病发病之始因

---

### 一、肝气郁结，情志失调证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肝失疏泄，气机郁滞，情志不畅 |
| **精神症状** | 情绪抑郁、闷闷不乐、善太息、烦躁易怒、胸胁胀痛、焦虑强迫、多疑善虑、女性月经前后情绪加重 |
| **躯体症状** | 胁肋胀痛、脘腹胀满、嗳气反酸、舌苔薄白、脉弦 |
| **治则** | 疏肝解郁，理气调畅 |
| **处方** | **柴胡疏肝散加减** |
| **组成** | 柴胡12g、白芍15g、枳壳12g、香附10g、川芎9g、郁金12g、合欢皮15g、佛手10g、炙甘草6g |
| **加减** | 肝郁化火加丹皮12g、栀子12g；强迫症状明显加煅龙骨、煅牡蛎各30g；失眠加酸枣仁20g |

---

### 二、肝火亢盛，魂不安舍证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肝郁化火，肝火上炎，扰动肝魂 |
| **精神症状** | 急躁易怒、暴怒无常、躁狂发作、头痛失眠、多梦易惊、幻觉、视物昏花、情绪失控 |
| **躯体症状** | 头晕胀痛、面红目赤、口苦咽干、耳鸣耳聋、舌红苔黄、脉弦数 |
| **治则** | 清肝泻火，镇惊安神 |
| **处方** | **龙胆泻肝汤合镇肝熄风汤加减** |
| **组成** | 龙胆草10g、黄芩12g、栀子12g、泽泻12g、车前子15g（包煎）、生龙骨30g（先煎）、生牡蛎30g（先煎）、代赭石30g（先煎）、白芍15g、甘草6g |
| **加减** | 肝风内动加钩藤15g（后下）、天麻10g；阴亏加生地黄15g、麦冬15g；妄想明显加石菖蒲10g、远志10g |

---

### 三、肝血不足，魂失所养证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肝血亏虚，魂无所藏，神志不宁 |
| **精神症状** | 情绪低落、胆怯易惊、失眠多梦、梦多怪异、记忆力下降、视物模糊、情感淡漠 |
| **躯体症状** | 头晕耳鸣、肢体麻木、爪甲不荣、舌淡苔白、脉弦细 |
| **治则** | 滋养肝血，安神定魂 |
| **处方** | **四物汤合酸枣仁汤加减** |
| **组成** | 当归12g、白芍20g、熟地黄15g、川芎9g、酸枣仁30g、知母10g、茯神15g、枸杞子15g、女贞子12g、炙甘草6g |
| **加减** | 胆怯易惊加珍珠母30g（先煎）；血虚失眠加龙眼肉10g、夜交藤30g |

---

### 临证要点

1. **肝气郁结 → 肝火亢盛** — 郁久化火为常见传变，早期疏肝可防传变
2. **肝血不足** — 多见于慢性精神疾病、久病体虚者，养血即安魂
3. **肝与河洛对应** — 肝对应洛书位 **3（木生）、8（木成）**，位于左纵、中横左位
