> **标签**: `#五脏藏神/心` `#心藏神`

## 核心定位

心主神明，为精神活动之主宰。心血不足、心神失养，或心火亢盛、痰火扰心，均可导致神明失司，是多数精神疾病的核心病变脏腑。

**适用疾病**: 焦虑症、抑郁症、双相躁狂发作、失眠伴精神异常

---

### 一、心血不足，心神失养证

| 项目 | 内容 |
|------|------|
| **核心病机** | 心血亏虚，心神失于濡养，神不守舍 |
| **精神症状** | 情绪低落、兴趣减退、焦虑多疑、记忆力减退、注意力不集中、失眠多梦、易惊醒、悲忧善哭 |
| **躯体症状** | 心悸心慌、头晕眼花、面色苍白、唇甲色淡、舌淡苔白、脉细弱 |
| **治则** | 养血安神，补益心气 |
| **处方** | **归脾汤合酸枣仁汤加减** |
| **组成** | 党参15g、黄芪20g、白术12g、当归12g、龙眼肉10g、酸枣仁30g、茯神15g、远志10g、川芎9g、知母10g、炙甘草6g |
| **加减** | 失眠严重加夜交藤30g、柏子仁15g；焦虑明显加煅龙骨、煅牡蛎各30g（先煎）；悲忧不止加浮小麦30g、大枣5枚 |

---

### 二、心火亢盛，扰乱神明证

| 项目 | 内容 |
|------|------|
| **核心病机** | 心火内炽，灼伤阴血，神明被扰 |
| **精神症状** | 烦躁易怒、躁狂妄动、言语不休、失眠易醒、口舌生疮、心烦不宁，甚至出现幻觉、妄想 |
| **躯体症状** | 面红目赤、口干口苦、小便短赤、舌尖红绛、苔黄、脉数有力 |
| **治则** | 清心泻火，宁心安神 |
| **处方** | **朱砂安神丸合导赤散加减** |
| **组成** | 黄连9g、黄芩12g、生地黄15g、当归12g、酸枣仁20g、木通6g、竹叶10g、甘草6g、磁石30g（先煎） |
| **加减** | 躁狂甚者加龙胆草10g、栀子12g；幻觉明显加石菖蒲10g、郁金12g；阴伤明显加麦冬15g、玄参12g |

---

### 三、痰火扰心，神昏窍闭证

| 项目 | 内容 |
|------|------|
| **核心病机** | 痰浊内生，郁而化火，痰火上扰心神，清窍闭塞 |
| **精神症状** | 狂躁不安、打人毁物、胡言乱语、幻觉妄想、情绪暴躁、失眠噩梦 |
| **躯体症状** | 胸闷痰多、头晕目眩、口苦口臭、舌红苔黄腻、脉滑数 |
| **治则** | 清热化痰，开窍醒神 |
| **处方** | **温胆汤合礞石滚痰丸加减** |
| **组成** | 半夏12g、陈皮12g、茯苓15g、枳实12g、竹茹10g、胆南星10g、礞石20g（先煎）、黄芩12g、大黄6g（后下）、石菖蒲10g、远志10g |
| **加减** | 窍闭神昏加麝香0.1g（冲服）或苏合香丸；痰盛加天竺黄12g；肝火旺盛加柴胡10g、夏枯草15g |

---

### 临证要点

1. **心血不足 vs 心火亢盛** — 一虚一实，需严格区分，虚证忌苦寒，实证忌滋腻
2. **痰火扰心** — 多见于精神分裂症急性期、双相躁狂，以"痰"和"火"为关键，化痰与清热并重
3. **心藏神与河洛对应** — 心对应洛书位 **2（火生）、7（火成）**，位于上横右位、右纵
