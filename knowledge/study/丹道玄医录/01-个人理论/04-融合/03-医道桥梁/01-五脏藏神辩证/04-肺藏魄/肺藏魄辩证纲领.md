# 💨 肺藏魄辩证纲领

> **标签**: `#五脏藏神/肺` `#肺藏魄`
> **关联**: [[../总纲-五脏藏神辩证纲领.md|总纲]]

## 核心定位

肺主气，司呼吸，藏魄主知觉。肺气不足则魄失所养，肺气郁滞则魄气闭阻。

**适用疾病**: 焦虑症、恐惧症、神经衰弱、精神分裂症伴躯体感知异常等，以恐惧、感知异常、气短乏力为核心

---

### 一、肺气不足，魄失所养证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肺气亏虚，宗气不足，魄无所依 |
| **精神症状** | 恐惧不安、胆怯畏缩、情绪低落、感知迟钝、声音低微、不愿与人交流 |
| **躯体症状** | 气短乏力、自汗畏风、咳嗽声低、舌淡苔白、脉虚弱 |
| **治则** | 补益肺气，安神定魄 |
| **处方** | **补肺汤合玉屏风散加减** |
| **组成** | 黄芪20g、党参15g、白术12g、防风10g、熟地黄12g、五味子10g、紫菀10g、桑白皮10g、炙甘草6g |
| **加减** | 恐惧甚者加煅龙骨、煅牡蛎各30g；自汗加浮小麦30g、麻黄根10g；情绪低落加合欢皮15g |

---

### 二、肺气郁滞，魄气闭阻证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肺气郁闭，气机不畅，魄气不得宣发 |
| **精神症状** | 胸闷焦虑、恐惧多疑、呼吸不畅、情绪压抑、感知异常（如皮肤蚁行感） |
| **躯体症状** | 胸闷气短、咳嗽痰多、咽干口燥、舌苔薄白、脉弦 |
| **治则** | 宣肺理气，开郁安神 |
| **处方** | **柴胡疏肝散合杏苏散加减** |
| **组成** | 柴胡12g、白芍15g、枳壳12g、杏仁10g、苏叶10g、桔梗10g、陈皮12g、茯苓15g、郁金12g、炙甘草6g |
| **加减** | 痰热内阻加黄芩12g、瓜蒌15g；阴虚肺燥加麦冬15g、沙参12g |

---

### 临证要点

1. **肺与恐惧** — "肺藏魄"之魄主本体知觉，肺虚则魄不安，表现为莫名其妙的恐惧、胆怯
2. **感知异常** — 皮肤蚁行感、幻触等躯体感知异常多从肺论治
3. **肺与河洛对应** — 肺对应洛书位 **4（金生）、9（金成）**，位于上横左位、中纵上
