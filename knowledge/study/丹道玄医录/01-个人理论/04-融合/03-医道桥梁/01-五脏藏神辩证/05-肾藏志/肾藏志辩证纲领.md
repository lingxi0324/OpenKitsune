# 💎 肾藏志辩证纲领

> **标签**: `#五脏藏神/肾` `#肾藏志`
> **关联**: [[../总纲-五脏藏神辩证纲领.md|总纲]]

## 核心定位

肾藏精，主志，为精神活动之根本。肾精亏虚则志不坚，肾阴不足则虚火扰神，肾阳不足则精神萎靡。

**适用疾病**: 慢性精神疾病、双相情感障碍、精神分裂症、老年性精神异常、焦虑症伴惊恐发作等，久病多及肾

---

### 一、肾精亏虚，志意不足证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肾精亏损，髓海不足，志意不坚 |
| **精神症状** | 精神萎靡、意志减退、健忘痴呆、思维迟钝、情感淡漠、惊恐不安、腰膝酸软 |
| **躯体症状** | 头晕耳鸣、腰膝酸软、脱发齿松、舌淡苔白、脉沉细 |
| **治则** | 补肾填精，益智安神 |
| **处方** | **六味地黄丸合五子衍宗丸加减** |
| **组成** | 熟地黄15g、山茱萸12g、山药20g、枸杞子15g、菟丝子12g、五味子10g、远志10g、石菖蒲10g、益智仁12g、炙甘草6g |
| **加减** | 阳虚明显加淫羊藿12g、巴戟天10g；阴虚火旺加知母10g、黄柏10g；健忘加核桃仁15g、龙眼肉10g |

### 二、肾阴不足，虚火扰神证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肾阴亏虚，虚火内生，上扰心神 |
| **精神症状** | 焦虑烦躁、失眠多梦、潮热盗汗、惊恐发作、幻觉、手足心热 |
| **躯体症状** | 腰膝酸软、头晕耳鸣、口干咽燥、舌红少苔、脉细数 |
| **治则** | 滋阴降火，宁心安神 |
| **处方** | **知柏地黄丸合黄连阿胶汤加减** |
| **组成** | 知母10g、黄柏10g、熟地黄15g、山茱萸12g、山药20g、黄连6g、阿胶10g（烊化）、白芍15g、酸枣仁20g、麦冬15g |
| **加减** | 惊恐发作加生龙骨、生牡蛎各30g；失眠加夜交藤30g、柏子仁15g |

### 三、肾阳不足，精神萎靡证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肾阳亏虚，温煦无力，神失温养 |
| **精神症状** | 情绪低落、悲观厌世、精神倦怠、懒言少动、意志消沉、畏寒怕冷 |
| **躯体症状** | 腰膝冷痛、四肢不温、小便清长、舌淡胖苔白滑、脉沉迟无力 |
| **治则** | 温补肾阳，振奋精神 |
| **处方** | **金匮肾气丸合右归丸加减** |
| **组成** | 附子10g（先煎）、肉桂6g、熟地黄15g、山茱萸12g、山药20g、枸杞子15g、菟丝子12g、杜仲12g、当归12g、炙甘草6g |
| **加减** | 精神萎靡加黄芪20g、党参15g；抑郁加重加柴胡10g、郁金12g |

### 临证要点

1. **久病及肾** — 慢性精神疾病日久必伤肾，补肾填精是治本之策
2. **精≠志** — 肾精足则志坚，精亏则志弱，此为"肾藏志"的核心
3. **肾与河洛对应** — 肾对应洛书位 **1（水生）、6（水成）**，位于下横中位、下纵下
