# 🔗 五脏同病复合证型

> **标签**: `#五脏藏神/复合` `#五脏同病`
> **关联**: [[../总纲-五脏藏神辩证纲领.md|总纲]]

## 核心定位

多重精神疾病多为五脏相互累及，常见心脾两虚、心肝火旺、心肾不交、肝郁脾虚、脾肾两虚等复合证型，需兼顾多脏，整体调理。

---

### 一、心肾不交证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肾阴不足，心火亢盛，水火不济，神明被扰 |
| **适用疾病** | 焦虑症、抑郁症、双相情感障碍、失眠伴精神异常 |
| **精神症状** | 心烦失眠、焦虑不安、多梦易惊、健忘、情绪不稳 |
| **处方** | **交泰丸合六味地黄丸加减** |
| **组成** | 黄连6g、肉桂3g（后下）、熟地黄15g、山茱萸12g、山药20g、酸枣仁20g、茯神15g、远志10g |
| **病机图解** | 心（火）↑ — 坎离不交 — 肾（水）↓ |

---

### 二、肝郁脾虚证

| 项目 | 内容 |
|------|------|
| **核心病机** | 肝郁气滞，脾虚失运，情志与气血生化同病 |
| **适用疾病** | 抑郁症、焦虑症、强迫症、躯体形式障碍 |
| **精神症状** | 情绪抑郁、烦躁易怒、思虑过度、腹胀便溏、神疲乏力 |
| **处方** | **逍遥散合归脾汤加减** |
| **组成** | 柴胡12g、白芍15g、白术12g、茯苓15g、当归12g、党参15g、黄芪20g、郁金12g、炙甘草6g |
| **病机图解** | 肝（木）郁 → 克脾（土）→ 气血生化不足 → 心神失养 |

---

### 三、心肝痰火证

| 项目 | 内容 |
|------|------|
| **核心病机** | 心肝火旺，痰浊内生，痰火扰及神魂 |
| **适用疾病** | 精神分裂症、双相躁狂发作、焦虑症急性发作 |
| **精神症状** | 狂躁不安、幻觉妄想、易怒暴躁、失眠噩梦 |
| **处方** | **生铁落饮合温胆汤加减** |
| **组成** | 生铁落30g（先煎）、胆南星10g、半夏12g、茯苓15g、陈皮12g、枳实12g、石菖蒲10g、远志10g、黄连6g、钩藤15g（后下） |
| **病机图解** | 心火（君）↑ + 肝火（相）↑ + 痰浊 → 痰火扰神魂 → 狂躁 |

---

### 四、五脏传变规律

```
心 ←→ 肝：母子相传（木生火），心肝火旺最常见
心 ←→ 脾：母子相传（火生土），心脾两虚最多见
心 ←→ 肾：水火既济，心肾不交为慢性精神疾病核心
肝 ←→ 脾：木克土，肝郁脾虚为情志病基础
脾 ←→ 肾：土克水，脾肾两虚见于久病后期
肺 ←→ 肾：金水相生，肺肾气虚见于恐惧/感知异常
```
