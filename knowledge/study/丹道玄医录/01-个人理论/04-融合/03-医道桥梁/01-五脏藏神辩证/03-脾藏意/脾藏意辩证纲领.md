# 🌾 脾藏意辩证纲领

> **标签**: `#五脏藏神/脾` `#脾藏意`

## 核心定位

脾主运化，为气血生化之源，藏意主思。脾虚则气血不足，意失所养，痰湿内生，蒙蔽清窍。

**适用疾病**: 抑郁症、精神分裂症阴性症状、认知障碍、神经衰弱等，以慢性精神异常、乏力健忘为核心

---

### 一、心脾两虚，意失充养证

| 项目 | 内容 |
|------|------|
| **核心病机** | 脾虚气血生化不足，心血亏虚，心意俱虚 |
| **精神症状** | 思虑过度、多疑善虑、情绪低落、记忆力减退、注意力涣散、精神萎靡、失眠多梦 |
| **躯体症状** | 食欲不振、腹胀便溏、神疲乏力、面色萎黄、舌淡苔薄白、脉细弱 |
| **治则** | 健脾益气，养血安神 |
| **处方** | **归脾汤加减** |
| **组成** | 党参15g、白术12g、黄芪20g、当归12g、茯神15g、远志10g、酸枣仁20g、木香6g、龙眼肉10g、炙甘草6g |
| **加减** | 便溏加山药20g、炒扁豆15g；思虑过度加合欢皮15g、郁金12g；精神萎靡加淫羊藿10g、菟丝子12g |

---

### 二、痰湿内阻，蒙蔽脾意证

| 项目 | 内容 |
|------|------|
| **核心病机** | 脾虚失运，痰湿内生，上蒙清窍，意窍不通 |
| **精神症状** | 情感淡漠、反应迟钝、思维迟缓、言语减少、嗜睡懒动、多疑偏执、精神不振 |
| **躯体症状** | 胸闷脘痞、痰多口黏、头重如裹、舌淡胖苔白腻、脉濡滑 |
| **治则** | 健脾化痰，开窍醒神 |
| **处方** | **四君子汤合导痰汤加减** |
| **组成** | 党参15g、白术12g、茯苓15g、半夏12g、陈皮12g、胆南星10g、枳实12g、石菖蒲10g、郁金12g、炙甘草6g |
| **加减** | 痰湿化热加黄连6g、竹茹10g；嗜睡加藿香10g、佩兰10g；反应迟钝加远志10g、益智仁12g |

### 临证要点

1. **心脾两虚** — 思虑过度、劳伤心脾是核心发病机制，"归脾"二字即指归心脾之气
2. **痰湿内阻** — 多见于精神分裂症阴性症状，以"呆、钝、懒、淡"为特征
3. **脾与河洛对应** — 脾对应洛书位 **5（土生）**，为中宫枢纽，贯通八线
