# 五行相生相克治则拓展

> 基于"相生治躯体实病，相克治精神虚病"的思路，
> 探索五行生克关系在针法中的更精细化运用。

## 一、核心命题

**相生治躯体实病，相克治精神虚病**

### 1.1 相生治实——以五行流转疏泄郁滞

躯体实病多为经络阻滞、气机郁结，用相生关系可以"推陈出新"：

| 相生关系 | 针对病证 | 针法思路 |
|:---------|:---------|:---------|
| 木→火 | 肝胆郁结→心火不宣 | 太冲→神门（木生火，疏泄郁火） |
| 火→土 | 心火不降→脾运失司 | 少府→太白（火生土，降火运脾） |
| 土→金 | 脾虚痰湿→肺气不利 | 太白→太渊（土生金，培土生金） |
| 金→水 | 肺失肃降→肾不纳气 | 太渊→太溪（金生水，金水相生） |
| 水→木 | 肾水不涵→肝阳上亢 | 太溪→太冲（水生木，滋水涵木） |

**操作要点**：实证用泻法，但顺着相生方向泻——如木实泻太冲，再补神门以疏泄出路。

### 1.2 相克治虚——以克制关系摄敛浮越

精神虚病多为神气浮越、气血不归，用相克关系可以"摄神归舍"：

| 相克关系 | 针对病证 | 针法思路 |
|:---------|:---------|:---------|
| 木克土 | 肝气横逆→脾虚不运（焦虑+纳差） | 太冲泻肝，三里补土 |
| 土克水 | 思虑过度→肾精暗耗（抑郁+腰酸） | 三里/中脘→太溪（培土制水） |
| 水克火 | 心肾不交→虚火浮越（失眠+心烦） | 太溪→神门（引水制火） |
| 火克金 | 心火灼肺→魄不能藏（焦虑+咳喘） | 神门→太渊（火克金，敛肺安神） |
| 金克木 | 肺金不降→肝气郁结（抑郁+胸闷） | 尺泽/太渊→太冲（金克木，肃金平肝） |

**操作要点**：虚证用补法，但相克方向用微泻——如太溪补水的同时，神门轻泻以引水制火。

## 二、相生与相克的配合使用

### 模式一：先相克后相生（急则治标）

```
例：心肾不交失眠急性期
↓
先相克：水克火（太溪引水制神门浮火）→ 安神定志
后相生：水生木（太溪养太冲），木生火（太冲通神门）→ 重建平衡
```

### 模式二：先相生后相克（缓则治本）

```
例：慢性抑郁伴纳差
↓
先相生：火生土（补神门以温脾土）→ 开胃进食
后相克：木克土（轻泻太冲，使土不郁）→ 舒畅情志
```

### 模式三：生克同用（标本兼治）

```
例：焦虑失眠伴高血压（肝阳上亢）
↓
同用：太溪→太冲（水克火 + 水生木）
      水克火 → 平肝潜阳
      水生木 → 滋养肝阴（防克之大过）
```

## 三、与五门十变化合的衔接

五门十变的**化合关系**（甲己化土等）介于相生与相克之间——不是单向的克制或滋生，而是**两气相合、化生新气**。

三者关系：

```
相生（顺向推进）→ 适用于疏通经络、驱邪外出
相克（逆向制约）→ 适用于摄敛浮阳、安神定志
化合（双向融合）→ 适用于调和阴阳、重建平衡
```

**临床选择建议**：
- 实证为主 → 相生或化合（以通为用）
- 虚证为主 → 相克或化合（以补为用）
- 虚实夹杂 → 化合最为稳妥（调和而不偏）
