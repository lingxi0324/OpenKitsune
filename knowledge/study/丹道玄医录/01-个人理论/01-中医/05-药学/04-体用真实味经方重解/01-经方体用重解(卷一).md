# 第一章·甘草泻心汤（甲己化土正局）

## 方药组成
干姜、黄芩、黄连、人参、炙甘草、大枣、半夏

## 逐药体用推演

| 药 | 体（味→五行） | 用（气→五行） | 体用关系 |
|---|--------------|--------------|---------|
| **干姜** | 大辛→**金体**，微甘→**土体**，微涩→**金敛** | 温→**火用** | 金体火用+微涩金敛 |
| **黄芩** | 苦→**火体** | 寒→**水用** | 火体水用 |
| **黄连** | 大苦→**火体**，淡回甘→**土余韵** | 寒→**水用** | 火体水用 |
| **人参** | 甘→**土体** | 微寒→**水用** | 土体水润 |
| **炙甘草** | 甘→**土体**，微苦→**火底** | 平→**土用** | 土体土用，纯守中 |
| **大枣** | 甘→**土体** | 平→**土用** | 土体土用，助甘草 |
| **半夏** | 辛→**金体** | 平→**土用** | 金体土用，降逆和胃 |

## 合化推演

### 第一步：干姜的气化

干姜：**金体（辛） + 火用（温）** → 火克金

金体被火用所克，金之收敛杀伐之性被销熔，不能以金气呈现。

金气被化之后，**木气自伸**（金不再克木）。
→ 化生 **甲木**（阳木，主生发疏泄）

干姜的**微涩（金敛）**在此扮演节制角色：火克金时，微涩使金的销熔不是一散而尽，而是 **徐徐消散、不骤不烈**——所以干姜"守而不走"。

### 第二步：黄芩+黄连的气化

黄芩：**火体（苦） + 水用（寒）** → 水克火
黄连：**火体（苦） + 水用（寒）** → 水克火

二者皆是火体被水用所克，火性不得伸张。
→ 水制火后，化出的是 **壬水**（阳水，江河之水，清热燥湿）

黄连的**极淡回甘（土余韵）**：苦寒过度伤胃时，回甘能缓冲，使清热而不败胃。

### 第三步：干姜甲木 + 黄芩黄连壬水

**干姜甲木（疏泄）+ 黄芩黄连壬水（润泽）**
→ 甲木得壬水之润 → **木气条达而不燥**
→ 非"肝火"，而是"疏土之木"

### 第四步：参草大枣构筑己土

人参（土体）+ 炙甘草（土体土用）+ 大枣（土体土用）
→ **己土之体**（阴土，主受纳运化）

### 第五步：最终合化

**甲木（干姜化生） + 己土（参草枣构筑）**
→ **甲己化土**
→ 中焦死土复运，痞结得开

### 第六步：半夏的作用

半夏（辛→金体，平→土用）：
金体土用，以降为顺。在甲己化土的全局中，
半夏的 **金降** 帮助甲木疏泄后的浊气下行，
完善了"升清降浊"的完整气化循环。

## 体用总评

> **甘草泻心汤 = 甲己化土正局**
> 干姜化甲木（辛金火克），黄芩黄连助壬水润木，
> 参草枣筑己土，甲己合而中焦运。
> 半夏降浊收功。

## 合化推演

### 第一步：附子——火克金 + 木气直达

附子：**金体（辛）+ 火用（大热）**
→ 火克金 → 金气被销熔 → 木气自伸 → 化出 **甲木**

**麻 = 辛之极致 = 木气直达**：
- 麻不是五味，是**木气透散的感官表现**
- 干姜辛温化甲木，但"守而不走"
- 附子之麻，使化出的甲木 **直透十二经，走而不守**
- 所以附子的甲木，比干姜的甲木多了"通行"之力

附子的**微甘（土体）**：甘味缓中，使大热不至于一焚而尽，有土气缓冲。

干姜：**金体（辛）+ 火用（温）**
→ 同附子之理 → 火克金 → 化出 **甲木**

干姜的**微涩（金敛）**：使自身的甲木不似附子那般奔突，而是 **守中焦而温之**。
→ 附子甲木走表走经，干姜甲木守中焦温脾
→ 一散一守，甲木之气全备

### 第三步：炙甘草——己土归中

炙甘草：**甘土体 + 平土用**
→ **己土之体**，纯守中焦

**甲木（附子化甲木+干姜化甲木） + 己土（炙甘草）**

### 第五步：体用精义

**四逆汤不是直接"灌阳气"的方！**

所谓"回阳救逆"，其理在：
1. **甲己化土** → 中焦枢纽复运
2. 中焦一运 → 清阳自升，浊阴自降
3. 阳气不是外来的，是 **中焦枢纽恢复后自归其位** 的

这与甘草泻心汤的区别：
- 甘草泻心汤：甲己化土以 **开痞结**（中焦死土不通）

同是甲己化土，一开一救，病位深浅不同。

# 第六章·体用推演核心法则总结

## 法则一：体味用气

> **体 = 味（有形之质，归五行）**
> **用 = 气（无形之化，归五行）**
> **体用相克则化，体用相生则顺**

例：辛金体 + 火用 → 火克金 → 化甲木
例：苦火体 + 水用 → 水克火 → 化壬水

## 法则二：涩归金敛

> **涩不在五味正列，归金之收敛面**
> 带涩的药物，其气化过程中多一层"节制"
> 桂枝：散而有节；白芍：收敛为先；干姜：温而不骤

## 法则三：麻归木气

> **麻 = 辛之极致 = 木气直达**
> 附子之麻，使其化生的甲木直透十二经
> "走而不守"的本质在此

## 法则四：甲己化土为经方第一结构

> 以上五方，**甘草泻心汤、四逆汤、桂枝汤、小柴胡汤、麻黄汤**
> 核心气化皆可归为 **甲己化土** 的变局：
> | 方 | 甲木来源 | 己土构成 | 变局特点 |
> |---|---|---|---|
