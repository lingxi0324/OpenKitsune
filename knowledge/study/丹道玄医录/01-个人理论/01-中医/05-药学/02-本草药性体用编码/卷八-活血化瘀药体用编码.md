# 本草药性体用编码·卷八：活血化瘀药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：神农本草经、本草思辨录、本经疏证
> 活血化瘀药共7味：丹参·红花·桃仁·牛膝·益母草·莪术·三棱

---

## 一、丹参

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 苦，微寒 |
| 归经 | 心、心包、肝经 |
| 体 | 味苦质润而色赤，体为火水之体。苦降而色赤入心 |
| 用 | 活血祛瘀（活）、通经止痛（通）、凉血消痈（凉）、清心除烦（清）。用为活通凉清四用 |
| 体用关系 | 火水之体 → 活血凉血之用。一味丹参功同四物——补中有活，活中有清 |

### 1.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 2（火） | 入心 |
| 二转成数 | 3（木） | 入肝 |
| 三转洛书 | 2（离） | 离火 |
| 四转变位 | -1（降） | 微降 |
| 五转阴阳 | -0.3（微寒） | 微寒 |
| 六转三才 | 0.4（气分偏血） | 由气入血 |
| 七转四象 | 1（夏·长） | 助长 |
| 八转八卦 | 2（离） | 离火 |
| 九转归元 | 0.3 | 偏药性 |

简记：火水苦赤，活凉为用；功同四物，补活相济。

## 二、红花

### 2.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 辛，温 |
| 归经 | 心、肝经 |
| 体 | 味辛质轻而色红，体为火木之体。辛散色红，入血分行散 |

| 用 | 活血通经（活）、散瘀止痛（散）。用为活散二用，少用活血多用破血 |

| 体用关系 | 火木之体 → 活血散瘀之用。体轻色红入血，用散而量分峻缓 |

| 五转阴阳 | +0.3（温） | 温通 |

## 三、桃仁

### 3.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 苦、甘，平 |

## 四、牛膝

### 4.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 苦、甘、酸，平 |
| 归经 | 肝、肾经 |
| 体 | 味苦甘酸，质重而韧，色黄白。体为水木之体，重而下行 |
| 用 | 活血通经（活）、补肝肾强筋骨（补）、利水通淋（利）、引火下行（引）。用为活补利引四用 |
| 体用关系 | 水木之体 → 引血下行之用。体质重而用专下行——引药下行第一品 |

| 三转洛书 | 1（坎） | 坎水 |
| 四转变位 | -3（降） | 沉降下行 |
| 五转阴阳 | 0.0（平） | 平性 |
| 六转三才 | 0.5（血分） | 走血分 |
| 七转四象 | 3（冬·藏） | 封藏下行 |
| 八转八卦 | 1（坎） | 坎水 |
| 九转归元 | 0.3 | 偏药性 |

简记：水木重韧，引下为用；引血下行，牛膝独功。
