# 本草药性体用编码·卷十：安神平肝药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：神农本草经、本草思辨录、本经疏证
> 安神平肝药共7味：酸枣仁·柏子仁·远志·龙骨·牡蛎·天麻·钩藤

## 一、酸枣仁

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘、酸，平 |
| 归经 | 肝、胆、心经 |
| 体 | 味甘酸，质润而脂，色紫红。体为木土之体，酸甘化阴 |

| 用 | 养心补肝（养）、宁心安神（宁）、敛汗生津（敛）。用为养宁敛三用 |

| 体用关系 | 木土之体 → 养心安神之用。酸甘化阴——补肝体而安心用，安神第一药 |

### 1.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 3（木） | 入肝 |
| 二转成数 | 7（火） | 入心 |
| 三转洛书 | 3（震） | 震木 |
| 四转变位 | -1（降） | 微降收敛 |
| 五转阴阳 | 0.0（平） | 平性 |
| 六转三才 | 0.6（血分） | 走血分 |
| 七转四象 | 2（秋·收） | 收敛 |
| 八转八卦 | 7（艮） | 艮为止 |
| 九转归元 | 0.6 | 药食可用 |

简记：木土酸甘，养宁为用；补肝安神，酸枣独功。
