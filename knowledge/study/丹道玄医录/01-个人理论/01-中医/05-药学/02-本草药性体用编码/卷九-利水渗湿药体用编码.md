# 本草药性体用编码·卷九：利水渗湿药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：神农本草经、本草思辨录、本经疏证
> 利水渗湿药共5味：茯苓·泽泻·猪苓·薏仁·车前子

---

## 一、茯苓

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘、淡，平 |
| 归经 | 心、脾、肾经 |
| 体 | 味甘淡，质松而白，体轻。体为土金之体，淡渗而升 |

| 用 | 利水渗湿（利）、健脾宁心（健）。用为利健二用，利而不伤正 |

| 体用关系 | 土金之体 → 利水健脾之用。甘淡平和——利水而不伤阴，健脾而不壅滞 |

### 1.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 5（土） | 甘入脾 |
| 二转成数 | 4（金） | 淡渗入肺 |
| 三转洛书 | 5（中宫） | 中宫 |
| 四转变位 | 0（平） | 不升不降 |
| 五转阴阳 | 0.0（平） | 平性 |
| 六转三才 | 0.4（气分） | 走气分 |
| 七转四象 | 1（夏·长） | 助运化 |
| 八转八卦 | 0（坤） | 坤土 |
| 九转归元 | 0.9 | 极近食性 |

简记：土金甘淡，利健为用；利不伤正，健脾宁心。

## 二、泽泻

### 2.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘、淡，寒 |
| 归经 | 肾、膀胱经 |
| 体 | 味甘淡，质轻而粉，色白。体为水金之体，淡渗下行 |

| 用 | 利水渗湿（利）、泄热（泄）、化浊降脂（化）。用为利泄化三用 |

| 体用关系 | 与茯苓相比：泽泻体偏寒，用兼泄热——茯苓健脾，泽泻泄浊 |

### 2.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 1（水） | 入肾/膀胱 |
| 二转成数 | 4（金） | 入肺 |
| 三转洛书 | 1（坎） | 坎水 |
| 四转变位 | -2（降） | 沉降下行 |
| 五转阴阳 | -0.3（微寒） | 微寒 |
| 六转三才 | 0.3（气分） | 走气分 |
| 七转四象 | 3（冬·藏） | 封藏 |
| 八转八卦 | 1（坎） | 坎水 |
| 九转归元 | 0.5 | 可日常用 |

简记：水金淡渗，利泄为用；茯苓健脾，泽泻泄浊。

## 三、猪苓

### 3.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘、淡，平 |
| 归经 | 肾、膀胱经 |
| 体 | 味甘淡，质轻而松，色黑褐。体为水金之体，淡渗力强 |
| 用 | 利水渗湿（利）。用为纯利水——利水之力强于茯苓而弱于泽泻 |
| 体用关系 | 纯利水之药——体最轻，用最专。但无健脾之功，也无泄热之用 |

### 3.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 1（水） | 入肾 |
| 二转成数 | 4（金） | 入膀胱 |
| 三转洛书 | 1（坎） | 坎水 |
| 四转变位 | -2（降） | 下行 |
| 五转阴阳 | 0.0（平） | 平性 |
| 六转三才 | 0.3（气分） | 走气分 |
| 七转四象 | 3（冬·藏） | 封藏 |
| 八转八卦 | 1（坎） | 坎水 |
| 九转归元 | 0.3 | 偏药性 |

简记：水金轻松，纯利为用；功专水道，无补无泄。

## 四、薏仁（薏苡仁）

### 4.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘、淡，微寒 |
| 归经 | 脾、胃、肺经 |
| 体 | 味甘淡，质重而粉，色白。体为土金之体，重而能渗 |
| 用 | 利水渗湿（利）、健脾止泻（健）、除痹排脓（除）、清热消痈（清）。用为利健除清四用 |
| 体用关系 | 土金之体 → 利湿健脾之用。与茯苓相似但体更重——利中兼清，长于除痹 |

### 4.2 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 5（土） | 入脾 |
| 二转成数 | 4（金） | 入肺 |
| 三转洛书 | 5（中宫） | 中宫 |
| 四转变位 | -1（降） | 微降 |
| 五转阴阳 | -0.2（微寒） | 微寒 |
| 六转三才 | 0.4（气分偏血） | 由气入血 |
| 七转四象 | 1（夏·长） | 助运化 |
| 八转八卦 | 0（坤） | 坤土 |
| 九转归元 | 0.7 | 可日常用（药食） |

简记：土金重粉，利健为用；兼清除痹，药食两宜。

## 五、车前子

### 5.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 甘，微寒 |
| 归经 | 肝、肾、肺、小肠经 |
| 体 | 味甘质滑，色黑而小。体为水木之体，滑利下行 |

| 用 | 利尿通淋（利）、清热明目（清）、渗湿止泻（渗）、化痰止咳（化）。用为利清渗化四用 |

| 体用关系 | 水木之体 → 利水明目的用。体滑利下行，用兼清肝明目——利水药中兼明目之功 |

### 5.2 九转坐标

|:----:|:----:|:------|
| 一转生数 | 1（水） | 入肾/小肠 |
| 二转成数 | 3（木） | 入肝 |
| 三转洛书 | 1（坎） | 坎水 |
| 四转变位 | -2（降） | 沉降滑利 |
| 五转阴阳 | -0.3（微寒） | 微寒 |
| 六转三才 | 0.3（气分） | 走气分 |
| 七转四象 | 3（冬·藏） | 封藏下行 |
| 八转八卦 | 1（坎） | 坎水 |
| 九转归元 | 0.4 | 可日常用 |
