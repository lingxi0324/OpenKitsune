# 本草药性体用编码·卷四：补阳药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：神农本草经、本草思辨录、本经疏证
> 补阳药共7味：附子·肉桂·鹿茸·肉苁蓉·巴戟天·淫羊藿·杜仲

## 一、附子

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 辛、甘，大热，有毒 |
| 归经 | 心、肾、脾经 |
| 体 | 味辛为主兼甘，质燥而坚实，色黑褐。体为火金之体，纯阳至刚 |
| 用 | 回阳救逆、补火助阳、散寒止痛。用为回补散三用，通行十二经 |
| 体用关系 | 火金之体 → 回阳救逆之用。体极热而用极峻，为百药之长 |

### 1.2 体用辨证要点

- 体纯阳 → 补命门之火，直入少阴
- 用极峻 → 走而不守，无所不到
- 配干姜（辛+辛）→ 四逆汤，回阳力倍增
- 配人参（辛+甘）→ 参附汤，回阳益气
- 配熟地（火+水）→ 右归丸，水中补火
- 禁忌：阴虚阳亢、热证、孕妇禁用

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 1（水） | 入肾（命门） |
| 二转成数 | 6（水） | 补肾阳 |
| 三转洛书 | 1（坎） | 坎中一阳 |
| 四转变位 | +4（升散极） | 升散力极强 |
| 五转阴阳 | +1.0（大热） | 热性极值 |
| 六转三才 | 0.3（气分） | 走气分 |
| 七转四象 | 0（春·生） | 生发阳气 |
| 八转八卦 | 1（坎） | 坎中真阳 |
| 九转归元 | 0.0 | 纯药性（有毒） |

简记：火金纯阳，回阳为用；百药之长，坎中真火。

| 六转三才 | 0.3（气分） | 0.4（气分偏血） |
