# 🌿 本草药性体用编码·卷二：补血药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：《神农本草经》《本草思辨录》《本经疏证》

---

## 一、当归

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 甘、辛，温 |
| **归经** | 肝、心、脾经 |
| **体** | 味甘为主兼辛，质润而油，色黄褐，气香浓。**体为「土木兼金之体」** |
| **用** | 补血活血（双调）、调经止痛（通）、润肠通便（润）。**用为「补通行润四用」** |
| **体用关系** | 甘为土体补血，辛为金用活血。——**体用兼备，补而不滞** |

### 1.2 体用分层：归头·归身·归尾

| 部位 | 体之偏向 | 用之偏向 | 主治 |
|:----|:---------|:---------|:------|
| 归头 | 体厚 | 止血用 | 崩漏下血 |
| 归身 | 体中 | 养血用 | 血虚萎黄 |
| 归尾 | 体薄 | 破血用 | 血瘀经闭 |

**一体三用**，同一味药在不同部位体用偏重不同——这是本草体用编码的精细度体现。

### 1.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | **3（木）** | 入肝经 |
| 二转成数 | **8（木）** | 补肝血 |
| 三转洛书 | **3（震）** | 震为动，活血 |
| 四转变位 | **+1（升）** | 辛散升浮 |
| 五转阴阳 | **+0.4（温）** | 温通 |
| 六转三才 | **0.5（气分→血分）** | 从气入血 |
| 七转四象 | **0（春·生）** | 生发之气 |
| 八转八卦 | **4（震）** | 震动而活 |
| 九转归元 | **0.4** | 药食可用 |

**简记**：土木兼金，补通双用；一体三变，血中圣药。

## 二、熟地黄

### 2.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 甘，微温 |
| **归经** | 肝、肾经 |
| **体** | 味甘纯厚，质润而重，色黑如漆。**体为「水土之体，至阴至厚」** |
| **用** | 滋阴补血（养）、填精益髓（填）。**用为「养填二用」** |
| **体用关系** | 水土至阴之体 → 滋养肝肾之用。**体极厚而用极专** |

### 2.2 体用辨证要点

- **体极厚**：熟地是补血药中「体最厚」者——质润重坠，非脾胃健运者不能运化
- **配砂仁**（辛温行气）→ 防熟地体厚腻膈
- **配陈皮**（辛苦行气）→ 助运化
- **配肉桂**（辛甘化阳）→ 引血归元

### 2.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | **1（水）** | 入肾经 |
| 二转成数 | **6（水）** | 补肾水 |
| 三转洛书 | **1（坎）** | 坎水正位 |
| 四转变位 | **-2（降）** | 质重下沉 |
| 五转阴阳 | **+0.1（微温）** | 温而不燥 |
| 六转三才 | **0.7（血分偏精）** | 走血分精分 |
| 七转四象 | **3（冬·藏）** | 封藏之本 |
| 八转八卦 | **1（坎）** | 坎水正象 |
| 九转归元 | **0.2** | 偏药性（需炮制） |

**简记**：水土至阴，养填为用；至厚至专，非健不运。

## 三、白芍

### 3.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 苦、酸，微寒 |
| **归经** | 肝、脾经 |
| **体** | 味酸为主兼苦，质润而收，色白。**体为「木体之酸收，兼火体之苦降」** |
| **用** | 养血柔肝（养）、缓急止痛（缓）、敛阴止汗（敛）。**用为「养缓敛三用」** |
| **体用关系** | 酸木之体 → 柔肝之用。**体以酸收为主，用以柔养为纲** |

### 3.2 体用辨证要点

- **酸收之体**：与川芎（辛散）正好相反——**一收一散，体用互补**
- **四物汤体用结构**：
  - 当归（甘辛·补通）→ 体用兼备
  - 熟地（甘厚·养填）→ 体极厚
  - 白芍（酸收·柔敛）→ 体以酸收
  - 川芎（辛散·行血）→ 用以辛散
  - **四药合为一体用闭环：补→养→收→散**

### 3.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | **3（木）** | 酸入肝 |
| 二转成数 | **8（木）** | 养肝血 |
| 三转洛书 | **3（震）** | 震木之位 |
| 四转变位 | **-1（敛）** | 酸收敛降 |
| 五转阴阳 | **-0.2（微寒）** | 微寒清热 |
| 六转三才 | **0.5（血分）** | 走血分 |
| 七转四象 | **2（秋·收）** | 酸主收敛 |
| 八转八卦 | **4（震）** | 震动而柔 |
| 九转归元 | **0.5** | 药食同源 |

**简记**：酸收为体，柔养为用；四物之一，收散相济。

## 四、川芎

### 4.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 辛，温 |
| **归经** | 肝、胆、心包经 |
| **体** | 味辛纯正，质轻而香烈，色黄褐。**体为「纯金之体，辛散至极」** |
| **用** | 活血行气（行）、祛风止痛（散）。**用为「行散二用，上行头目」** |
| **体用关系** | 纯辛之体 → 行散之用。**体用皆为动，无静无守** |

### 4.2 体用关键对比

| 对比 | 当归 | 川芎 |
|:----|:-----|:-----|
| 体 | 甘+辛（补通兼有） | 纯辛（只通不补） |
| 用 | 补血活血 | 行血破滞 |
| 体用定性 | **体用兼备** | **用大于体** |
| 宜忌 | 血虚+血瘀皆宜 | 血虚而无瘀者慎用 |

### 4.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | **3（木）** | 入肝经 |
| 二转成数 | **8（木）** | 行肝血 |
| 三转洛书 | **3（震）** | 震动之象 |
| 四转变位 | **+3（升散）** | 升散力强 |
| 五转阴阳 | **+0.5（温）** | 温通 |
| 六转三才 | **0.4（气分偏血）** | 气中行血 |
| 七转四象 | **0（春·生）** | 生发透达 |
| 八转八卦 | **4（震）** | 震雷动散 |
| 九转归元 | **0.2** | 偏药性 |

**简记**：纯辛之体，行散为用；上达头目，下行血海。
