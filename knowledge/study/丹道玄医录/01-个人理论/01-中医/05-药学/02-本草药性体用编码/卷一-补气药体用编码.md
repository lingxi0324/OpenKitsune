## 一、人参

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 甘、微苦，微温 |
| **归经** | 脾、肺、心经 |
| **体** | 味甘为土体之正味，微苦兼火体之润。质润多汁，色黄白相间。**体为「土金相生之体」** |
| **用** | 大补元气（升）、补脾益肺（化）、生津止渴（润）、安神益智（敛）。**用为「升化润敛四用兼备」** |
| **体用关系** | 土金之体 → 补气升阳之用。体厚而用正，不偏不倚 |

### 1.2 体用辨证要点

- **体虚用衰**：气短乏力、脉虚 → 人参补气（体用双补）
- **体不虚而用亢**：实热证不可用 → 用亢则体伤
- **配伍铁律**：
  - 配白术（土土相合）→ 补气健脾力增
  - 配麦冬（补水润肺）→ 气阴双补
  - 配附子（水火既济）→ 回阳救逆

## 三、白术

|:----|:------|
| **性味** | 甘、苦，温 |
| **归经** | 脾、胃经 |
| **体** | 味甘为主兼苦，质燥而坚实，色灰黄。**体为「土体中正兼火体之燥」** |
| **用** | 健脾益气（运）、燥湿利水（燥）、止汗安胎（固）。**用为「运燥固三用」** |
| **体用关系** | 土体得火气而燥 → 运化水湿之用最强。**脾喜燥恶湿，白术正合其性** |

### 3.2 体用辨证要点

- **脾虚湿盛**：白术最宜 — 体补脾、用燥湿，体用双解
- **阴虚燥渴**：慎用 — 白术体燥，更伤阴液
- 配枳实（金克木→木疏土）→ 消痞除满
- 配茯苓（土+水→水行土化）→ 利水渗湿

## 四、甘草

### 4.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| **性味** | 甘，平 |
| **归经** | 心、肺、脾、胃经 |
| **体** | 纯甘之味，质润而中和，色黄褐。**体为「纯土之体，甘味至极」** |
| **用** | 补脾益气（补）、清热解毒（清）、缓急止痛（缓）、调和诸药（和）。**用为「补清缓和四用俱全」** |
| **体用关系** | 体纯甘至极 → 用最广泛。**甘草是体用公理中「甘味开关」的典型代表** |

### 4.2 体用核心地位

在河图五味公理中，**甘草的甘味是「补泄开关」**：
- 辛+甘 → 补肺体（辛甘化苦）
- 酸+甘 → 补肝体（酸甘化阴）
- 苦+甘 → 补心体（苦甘化咸）
- 咸+甘 → 补肾体（咸甘化苦）
- 纯甘单用 → 补脾体

**没有甘草的甘，四味只是「泄」；有了甘草的甘，四味才变成「补」**。
