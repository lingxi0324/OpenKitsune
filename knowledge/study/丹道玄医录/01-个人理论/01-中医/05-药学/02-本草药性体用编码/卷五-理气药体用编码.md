> 理气药共7味：柴胡·枳实·陈皮·木香·砂仁·厚朴·香附

## 一、柴胡

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 苦、辛，微寒 |
| 归经 | 肝、胆经 |
| 体 | 味苦辛，质轻而升散，色黄绿。体为木火之体，轻扬疏散 |
| 用 | 疏散退热（散）、疏肝解郁（疏）、升举阳气（升）。用为散疏升三用 |
| 体用关系 | 木火之体 → 疏散疏肝之用。体轻而上行，用散而能升 |

### 1.2 体用辨证要点

- 柴胡最独特之处：体轻主升，能引少阳之气上达
- 配黄芩（辛+苦）→ 小柴胡汤，和解少阳
- 配白芍（辛+酸）→ 四逆散，疏肝解郁
- 配升麻（升+升）→ 补中益气汤，升举阳气
- 关键：柴胡用量决定走向——3-5g升阳，10-15g疏肝，20g+退热

### 1.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 3（木） | 入肝经 |
| 二转成数 | 8（木） | 疏肝气 |
| 三转洛书 | 3（震） | 震为动，主疏散 |
| 四转变位 | +3（升散） | 升散力强 |
| 五转阴阳 | -0.2（微寒） | 微寒清肝胆热 |
| 六转三才 | 0.3（气分偏表） | 走气分表 |
| 七转四象 | 0（春·生） | 生发之气 |
| 八转八卦 | 4（震） | 震为雷，动而散 |
| 九转归元 | 0.3 | 偏药性 |

简记：木火轻扬，疏散为用；少阳要药，升降有度。

| 特性 | 破积第一 | 行气宽中 |
