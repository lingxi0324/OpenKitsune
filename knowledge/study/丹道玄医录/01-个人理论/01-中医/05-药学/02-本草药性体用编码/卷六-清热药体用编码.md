# 本草药性体用编码·卷六：清热药

> 基于河图五味公理 + 体用双轨 + 九转坐标
> 核心参考：神农本草经、本草思辨录、本经疏证
> 清热药共7味：黄芩·黄连·黄柏·栀子·石膏·知母·生地

---

## 一、黄芩

### 1.1 体用双轨分析

| 维度 | 内容 |
|:----|:------|
| 性味 | 苦，寒 |
| 归经 | 肺、胆、脾、大肠、小肠经 |
| 体 | 味苦纯正，质轻而中空，色黄。体为金火之体，苦而能降 |
| 用 | 清热燥湿（清）、泻火解毒（泻）、止血安胎（止）。用为清泻止三用 |
| 体用关系 | 金火之体 → 清肺泻火之用。体轻上浮而用清降——上清肺热，下泻大肠 |

### 1.2 体用关键区别

| 对比 | 黄芩 | 黄连 | 黄柏 |
|:----|:-----|:-----|:-----|
| 体 | 质轻中空（金火） | 质重坚实（火土） | 质燥厚实（水金） |
| 用 | 清上焦肺热 | 清中焦心胃热 | 清下焦肾膀胱热 |
| 特性 | 体轻上浮 | 体重守中 | 体燥下行 |

### 1.3 九转坐标

| 转次 | 编码 | 说明 |
|:----:|:----:|:------|
| 一转生数 | 2（火） | 苦入心 |
| 二转成数 | 4（金） | 入肺 |
| 三转洛书 | 6（乾） | 乾金 |
| 四转变位 | -2（降） | 降泄 |
| 五转阴阳 | -0.6（寒） | 寒性 |
| 六转三才 | 0.3（气分） | 走气分 |
| 七转四象 | 2（秋·收） | 收敛降火 |
| 八转八卦 | 5（乾） | 乾金 |
| 九转归元 | 0.2 | 偏药性 |

简记：金火轻降，清泻为用；上清肺热，下泻大肠。
