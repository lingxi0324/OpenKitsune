## 凡例

### 关键前提：药物公理性味归位（扩补）

温病方大量使用的药物在公理体系中需先归位。单味药的性味按以下原则确定：
1. 凡传统有明确「五味」归属的，直接归入公理
2. 复合性味药物（如石膏之辛甘、生地之苦甘）按公理原配规则分析
3. 纯寒性但五味不明确的药物（如金银花），标记「需补四气理论」

**温病常用药物的公理性味归位表：**

| 药物 | 传统性味 | 公理性味 | 归位依据 |
|:----|:--------|:---------|:--------|

| 沙参 | 甘微苦微寒 | **甘(土)+微苦(水)** | 同上 |
| 金银花 | 甘寒 | **甘(土)+微苦(水)** | 甘为主·苦为辅 |

## 一、卫分·辛凉解表类（4方）

### 1. 银翘散——《温病条辨》

**组成**：金银花、连翘、薄荷、淡豆豉、牛蒡子、桔梗、甘草、竹叶、荆芥、芦根

**公理性味拆解**：

| 药物 | 公理性味 | 公理作用 |
|:----|:--------|:--------|
| 金银花 | 甘(土)+微苦(水) | 驱寒(固护中气)+微清热 |
| 连翘 | 苦(水) | 清热 |
| 薄荷 | 辛(木) | 除湿开散表邪 |
| 淡豆豉 | 苦(水) | 清热 |
| 牛蒡子 | 辛(木)+苦(水) | 除湿+清热 |
| 桔梗 | 辛(木)+苦(水) | 开肺+清热 |
| 甘草 | 甘(土) | 驱寒(补中) |
| 竹叶 | 甘(土) | 利水清热 |
| 荆芥 | 辛(木) | 除湿开散 |
| 芦根 | 甘(土) | 生津 |

**药对化合分析**：

| 药对 | 化合类型 | 效应 |
|:----|:--------|:----|
| 金银花(甘)+连翘(苦) | **苦甘化咸潜力**（肾原配弱化） | 微润燥养阴 |
| 薄荷(辛)+牛蒡子(辛苦) | 辛+辛苦·非原配·功效叠加 | 辛开表湿+苦清热 |
| 荆芥(辛)+薄荷(辛) | 双辛叠加 ·非原配 | 辛开表湿 |
| 桔梗(辛苦)+甘草(甘) | 辛苦+甘→**甘辛化苦辅助** | 开肺化痰 |
| 金银花(甘)+竹叶(甘) | 甘甘叠加 | 和中 |

**三步走模式识别**：
```
【核心模式】双辛走表（薄荷+荆芥打开表湿）+ 苦清热（连翘+牛蒡子）+ 甘和中（金银花+甘草）
→ 相当于：辛散 → 苦降 → 甘守（模式A变体：先开后清后守）
```

**传统主治**：温病初起，发热无汗或有汗不畅，微恶风寒，头痛口渴，咳嗽咽痛，舌尖红苔薄白或薄黄，脉浮数。

**公理预测**：
- 辛木（薄荷/荆芥/牛蒡子）走表开散→汗出，表湿散→恶风寒退
- 苦水（连翘/牛蒡子/桔梗/淡豆豉）清热→热退
- 甘土（金银花/甘草/竹叶/芦根）和中驱寒→护中气防苦寒伤胃
- 苦甘化咸弱作用→微润生津止渴

**吻合分析**：
| 传统症状 | 公理解释 | 吻合度 |
|:--------|:---------|:-----:|
| 发热 | 苦水清热→热退 | ✅ |
| 微恶风寒 | 辛木开散表湿→恶风解 | ✅ |
| 口渴 | 苦甘化咸弱→润燥生津（力度弱，不完全） | ⚠️ |
| 头痛 | 辛木+苦水→风湿+热郁散→痛止 | ✅ |
| 咽痛 | 桔梗辛苦开肺→咽郁解 | ✅ |
| 脉浮数 | 表湿（浮）+热（数） | ✅ |

**局限**：银翘散有明确的"清热解毒"作用，其核心药物金银花的主要功效更多来自**四气之寒性**，而非五味之甘味。公理中"甘土驱寒"与金银花的临床清热作用方向相反——这是**公理体系在温病方上的关键缺口**。

**验证判断**：⚠️ **部分吻合（约70%）**。辛开+苦降+甘守三步走可解释大部分症状，但"寒性清热解毒"的机制超出公理覆盖范围。

### 2. 桑菊饮——《温病条辨》

**组成**：桑叶、菊花、杏仁、连翘、薄荷、桔梗、甘草、芦根

**公理性味拆解**：

| 药物 | 公理性味 | 作用 |
|:----|:--------|:----|
| 桑叶 | 苦(水)+甘(土) | 清热为主兼甘润 |
| 菊花 | 甘(土)+苦(水) | 甘润兼清热 |
| 杏仁 | 苦(水) | 清热降气 |
| 连翘 | 苦(水) | 清热 |
| 薄荷 | 辛(木) | 开散 |
| 桔梗 | 辛(木)+苦(水) | 开肺清热 |
| 甘草 | 甘(土) | 和中 |
| 芦根 | 甘(土) | 生津 |

**药对分析**：
- 桑叶(苦)+连翘(苦) → 双苦叠加·清热
- 菊花(甘)+芦根(甘) → 双甘叠加·和中生津
- 薄荷(辛)+桔梗(辛苦) → 辛+辛苦·开肺表
- 杏仁(苦)+甘草(甘) → 苦甘·微化咸润

**三步走模式**：
```
双苦清肺（桑叶+连翘+杏仁）→ 辛开肺表（薄荷+桔梗）→ 甘守和中（菊花+甘草+芦根）
与传统「辛凉轻剂」定位一致
```

**传统主治**：风温初起，咳嗽，身热不甚，口微渴，脉浮数。

**公理预测**：
- 苦（桑叶+连翘+杏仁）→ 清肺热→热退咳止
- 辛（薄荷+桔梗）→ 开肺表→咳嗽通畅
- 甘（菊花+甘草+芦根）→ 和中生津→止渴

**吻合度**：⚠️ **约65%**。核心症状可解释，但"风热"概念（四气之热）超出公理范围。

## 二、气分·清热类（3方）

### 5. 黄连解毒汤——《外台秘要》引崔氏方

**组成**：黄连、黄芩、黄柏、栀子

**公理性味**：
- 黄连：苦(水) → 清热
- 黄芩：苦(水) → 清热
- 黄柏：苦(水) → 清热
- 栀子：苦(水) → 清热

**核心特征**：四味纯苦药。没有甘、辛、咸、酸配入。
→ **纯苦水四方叠加**，无原配、无非原配（因为纯苦没有其他味相配）。

**传统主治**：三焦火毒证。大热烦躁，口燥咽干，错语不眠，或吐血衄血，舌红苔黄，脉数有力。

**公理预测**：
- 四苦(水)叠加 → 极强清热 → 一切热象全退
- 无甘味 → 无护中 → 易伤胃气
- 无辛味 → 无开散 → 仅清不散

**吻合分析**：
| 症状 | 公理解释 | 吻合度 |
|:----|:---------|:-----:|
| 大热 | 四苦清热→热退 | ✅ |
| 烦躁错语不眠 | 苦水间接助咸苦化酸(清心热→神安) | ✅ |
| 口燥咽干 | 清热 ≠ 生津——纯苦反伤津 | ⚠️ |
| 舌红苔黄脉数 | 热象 | ✅ |

**关键发现**：黄连解毒汤**没有甘味护中**，所以传统说"服之伤胃"——公理体系完全吻合这个临床观察。纯苦无甘→无苦甘化咸→不润燥反伤津。

**局限**：同样是"四气之寒"（大寒）清热，超公理范围。

**吻合度**：⚠️ **约70%**。公理可解释热象消散和伤胃的机制，但四气之寒覆盖不住。

| 黄连 | 苦(水) | 清热 |

| 连翘 | 苦(水) | 清热 |
| 板蓝根 | 苦(水) | 清热 |
| 薄荷 | 辛(木) | 开散 |
| 牛蒡子 | 辛(木)+苦(水) | 开散兼清热 |

| 甘草 | 甘(土) | 和中 |

**药对分析**：
- 连翘(苦)+板蓝根(苦)+黄芩(苦)+黄连(苦) → **四苦叠加**·清热
- 玄参(甘苦咸) → 自身即**苦甘化咸（肾原配）+ 咸苦化酸（心原配）**
- 薄荷(辛)+牛蒡子(辛苦)+升麻(辛)+柴胡(辛苦) → **四辛走表开散**
- 僵蚕(咸)+甘草(甘) → 咸+甘·非原配·软坚和中

**三步走模式**：
```
多重苦水清热（芩连翘板根）→ 多重辛木开散（薄牛升柴）→ 甘守和中（玄参甘草）
——与传统「清热解毒，疏风散邪」高度一致
```

**传统主治**：大头瘟。恶寒发热，头面红肿焮痛，目不能开，咽喉不利，舌燥口渴，舌红苔黄，脉数有力。

**吻合度**：✅ **约85%**。多味辛开散表湿（大头瘟之肿为湿+热郁结）+ 多苦清热 + 玄参三味润燥，余下的"疫毒"概念超出公理范围。

### 7. 甘露消毒丹——《温热经纬》

**组成**：滑石、茵陈、黄芩、石菖蒲、川贝母、木通、藿香、连翘、白蔻仁、薄荷、射干

**公理性味拆解**：

| 药物 | 公理性味 | 作用 |
|:----|:--------|:----|
| 滑石 | 甘(土)+淡 | 利湿清热 |
| 茵陈 | 苦(水)+辛(木) | 清热利湿 |
| 黄芩 | 苦(水) | 清热 |
| 石菖蒲 | 辛(木) | 开窍除湿 |
| 川贝母 | 苦(水)+甘(土) | 清热润肺 |
| 木通 | 苦(水) | 清热利水 |
| 藿香 | 辛(木) | 芳香除湿 |
| 连翘 | 苦(水) | 清热 |
| 白蔻仁 | 辛(木) | 化湿行气 |
| 薄荷 | 辛(木) | 开散 |
| 射干 | 苦(水) | 清热利咽 |

**药对核心特征**：
- **辛+苦并重型**：茵陈(辛苦)+藿香(辛)+白蔻(辛)+薄荷(辛)+石菖蒲(辛) = 大量辛木除湿
  + 黄芩(苦)+连翘(苦)+木通(苦)+射干(苦)+茵陈(苦) = 大量苦水清热
- **辛苦除痞（非原配）**大量叠加 → 湿热痞结同治
- 少量甘（滑石、川贝母）→ 和中

**三步走模式**：
```
大量辛木除湿 + 大量苦水清热 并行 → 湿热双解
→ 区别于传统「芳香化湿，清热解毒」——公理说「辛苦除痞大量叠加」
```

**传统主治**：湿温时疫。发热困倦，胸闷腹胀，肢酸咽肿，身黄，口渴，小便短赤，舌苔淡白或厚腻或干黄。

**吻合度**：✅ **约85%**。辛+苦大量叠加→辛苦除痞（湿+热痞结）的机理完全吻合湿温的核心病机。但"湿温"的概念（湿热合邪的温病分类）中"温"（四气之温→热）超出公理，但"湿热"的邪气本质可以被辛苦覆盖。

## 三、营血分·清热凉血养阴类（4方）

### 8. 清营汤——《温病条辨》

**组成**：犀角（水牛角代）、生地、玄参、竹叶心、麦冬、丹参、黄连、金银花、连翘

**公理性味拆解**：

| 药物 | 公理性味 | 作用 |
|:----|:--------|:----|
| 水牛角 | 咸(火)+苦(水) | 咸苦·除燥+清热 |
| 生地 | 甘(土)+苦(水) | 甘润+清热 |
| 玄参 | 甘(土)+苦(水)+咸(火) | 三味融合·双原配 |
| 竹叶心 | 甘(土) | 和中 |
| 麦冬 | 甘(土)+微苦(水) | 甘润为主 |
| 丹参 | 苦(水) | 清热活血 |
| 黄连 | 苦(水) | 清热 |
| 金银花 | 甘(土)+微苦(水) | 甘润为主 |
| 连翘 | 苦(水) | 清热 |

**药对化合分析**：

| 药对 | 化合类型 | 效应 |
|:----|:--------|:----|
| 水牛角(咸)+连翘(苦) | **咸苦化酸（心原配·除烦）** | 敛心安神 |
| 水牛角(咸)+黄连(苦) | **咸苦化酸（心原配·除烦）** | 同上·加强 |
| 生地(甘苦)+连翘(苦) | **苦甘化咸潜力（肾原配·除燥）** | 润燥养阴 |
| 玄参(甘苦咸)单味 | 自身三味→**双原配并行** | 心肾同治 |
| 麦冬(甘)+苦多药 | 苦甘化咸辅助 | 润燥 |

**核心机理解读**：
清营汤是**公理体系下最完整的温病方**——咸苦化酸（心原配·宁心止烦）与苦甘化咸（肾原配·润燥养阴）**双原配并行**，正好对应营分证的核心病机：**热入营分→心肾两燔**。

**传统主治**：热入营分。身热夜甚，神烦少寐，时有谵语，目常开或喜闭，口渴或不渴，斑疹隐隐，舌绛而干，脉细数。

**【公理全盘推演】**

| 传统症状 | 公理解释（不借助四气理论） | 吻合度 |
|:--------|:-------------------------|:-----:|
| 身热 | 苦水（连翘/黄连/丹参）→ 清热 | ✅ |
| 夜甚 | 苦甘化咸（生地/玄参/麦冬）→ 润肾燥→阴复则夜热退 | ✅ **（深入一层）** |
| 神烦少寐 | 咸苦化酸（水牛角+苦）→ 酸敛心神→宁心 | ✅ |

**吻合度**：✅ **约90%**。这是温病方中与公理体系最匹配的一首方。双原配并行（心+肾）直接对应营分证的心肾两燔病机。唯一的缺口是"斑疹"和"热入营分"中"热"的四气属性。

### 9. 犀角地黄汤——《备急千金要方》

**组成**：犀角（水牛角）、生地、芍药、丹皮

**公理性味拆解**：
- 水牛角：咸(火)+苦(水)
- 生地：甘(土)+苦(水)
- 芍药：酸(金)【白芍】或苦(水)【赤芍】——温病多用赤芍
- 丹皮：苦(水)+辛(木)

**药对化合**：
- 水牛角(咸)+苦(赤芍/丹皮) → **咸苦化酸（心原配·敛血）**——主活血凉血而不散
- 生地(甘苦)+水牛角(咸苦) → **苦甘化咸（肾原配·润燥）** + **咸苦化酸（心原配）**
- 丹皮(苦辛)+芍药(酸或苦) → 若芍为酸：**辛酸化甘（肝原配·散瘀血之痞）** / 若芍为苦：辛苦除痞

**传统主治**：热入血分。身热谵语，斑色紫黑，舌绛起刺，吐衄发斑。

**公理预测**：
- 咸苦化酸（水牛角+芍药/丹皮苦）→ 敛血宁心→谵语止、血不妄行
- 苦甘化咸（生地+水牛角）→ 润肾燥→舌绛起刺退
- 辛酸化甘（丹皮辛+芍药酸）→ 散血瘀痞→斑色变淡

**吻合度**：✅ **约85%**。咸苦化酸加辛酸化甘，双原配可解释凉血散瘀的机制。但"血分热毒"中"毒"的概念超出公理范围。

### 10. 沙参麦冬汤——《温病条辨》

**组成**：沙参、麦冬、玉竹、天花粉、生甘草、桑叶、扁豆

**公理性味拆解**：
- 沙参：甘(土)+微苦(水)
- 麦冬：甘(土)+微苦(水)
- 玉竹：甘(土)
- 天花粉：甘(土)+微苦(水)
- 生甘草：甘(土)
- 桑叶：苦(水)+甘(土)
- 扁豆：甘(土)

**核心特征**：**六甘一苦**。全方以甘土为主，仅桑叶带苦。
→ 主要是**甘土叠加驱寒补中** + 微弱的**苦甘化咸润燥**

**传统主治**：燥伤肺胃阴分。咽干口燥，干咳少痰，舌红少苔。

**公理预测**：
- 大量甘土 → 驱寒补中（但其临床作用是"养阴"而非"驱寒"）
- 微苦（桑叶/花粉/沙参/麦冬）→ 微清热
- 苦甘化咸微弱 → 微润燥

**吻合度**：⚠️ **约45%**。公理体系对"养阴"机制的解释力非常有限。大量甘味叠加→传统说甘寒养阴，在公理中只能解释为"甘土驱寒补中"——与养阴的临床效果不完全对应。

**重要发现**：**甘味在公理中定位为"驱寒"（土克水），但在温病方中大量甘味用于"养阴"——如果甘味只能驱寒，那如何解释沙参麦冬汤的养阴效果？**

**这可能意味着公理体系需要在甘味上补充**：甘土除了"土克水→驱寒"之外，还有"土生金→生津养肺"的机制（五行相生补充），才能完整覆盖甘味的全部作用。

### 11. 增液汤——《温病条辨》

**组成**：玄参、麦冬、生地

**公理性味拆解**：

| 药物 | 公理性味 | 原配潜力 |
|:----|:--------|:--------|
| 玄参 | 甘(土)+苦(水)+咸(火) | **双原配并行** |
| 麦冬 | 甘(土)+微苦(水) | 苦甘化咸弱 |
| 生地 | 甘(土)+苦(水) | 苦甘化咸 |

**药对化合**：
- 玄参(甘苦咸) + 生地(甘苦) → **苦甘化咸双倍·肾原配·强润燥** ✓
- 玄参(咸)+苦(自身/麦冬/生地) → **咸苦化酸辅助·心原配**
- 三药全含甘味 → **甘甘叠加**·和中

**核心机制**：增液汤是公理体系下**苦甘化咸（肾原配·除燥）最简洁的纯化版本**——三味药全部同时含苦+甘，合力化咸润肾燥。没有任何一味药偏辛、偏酸来干扰这条主线。

**传统主治**：阳明温病，津亏便秘。大便秘结，口渴，舌干红，脉细数。

**公理预测**：
- 三味苦甘 → 强力苦甘化咸（肾原配·除燥）→ 润肾燥→肾主二便→燥除便通
- 同时咸味（玄参）+甘味（全方）→ 咸甘非原配·缓润 → 辅助通便而不伤正

**吻合度**：⚠️ **约60%**。"增液"（增加津液）的核心机制在公理中只能解释为"苦甘化咸→除燥→间接增液"——不等于直接"生津"。公理没有定义"生津/养阴/补水"的机制。

## 四、滋阴熄风类（2方）

### 12. 大定风珠——《温病条辨》

**组成**：白芍、阿胶、生龟板、生鳖甲、生牡蛎、生地、火麻仁、麦冬、五味子、鸡子黄、甘草

**公理性味拆解**（主力）：
- 白芍：酸(金) → 祛风
- 阿胶：甘(土) → 补中
- 龟板：咸(火) → 除燥
- 鳖甲：咸(火) → 除燥
- 牡蛎：咸(火) → 除燥（潜镇）
- 生地：甘(土)+苦(水)
- 麦冬：甘(土)+微苦(水)
- 五味子：酸(金) → 祛风敛收
- 鸡子黄：甘(土) → 补中
- 甘草：甘(土) → 和中
- 火麻仁：甘(土) → 润

**药对化合**：

| 药对 | 化合类型 | 效应 |
|:----|:--------|:----|
| 白芍(酸)+阿胶(甘) | **甘+酸·非原配·敛散固阴** | 敛阴缓急 |
| 白芍(酸)+五味子(酸) | 双酸叠加 | 强祛风 |
| 鳖甲(咸)+龟板(咸)+牡蛎(咸) | 三咸叠加 | 强除燥潜镇 |
| 生地(甘苦)+麦冬(甘苦)+阿胶(甘) | 多甘+苦→苦甘化咸 | 润燥养阴 |
| 白芍(酸)+鳖甲(咸) | **酸+咸→酸咸化辛（肺原配·散滞）** | 软坚散结（此处应为滋阴潜阳而非散滞——定位有差异） |

**三步走模式**：
```
大量咸除燥（龟板鳖甲牡蛎）+ 酸祛风（白芍五味子）+ 甘补中（阿胶鸡子黄甘草麦冬）
+ 苦甘化咸（生地麦冬+多甘）= 涩以固脱，滋以养正
```

**传统主治**：阴虚动风。神倦瘛疭，脉气虚弱，舌绛苔少，时时欲脱。

**吻合度**：⚠️ **约50%**。酸（祛风）可解释"动风"的收敛→提出了"阴虚风动"中"风"的机制是阴虚导致的虚风（内风），与辛酸化甘散风湿之痞的外风截然不同。公理中酸金祛风似可解释，但**内风（阴虚阳亢）与外风（外邪入中）的本质区别在公理中没有定义**。

**关键发现**：**酸金祛风的"风"在公理中是外风（金克木），但温病中的"阴虚动风"是内风（阴虚阳亢→肝风内动）——两者病机不同。公理体系需要区分外风与内风**。

### 13. 青蒿鳖甲汤——《温病条辨》

**组成**：青蒿、鳖甲、生地、知母、丹皮、天花粉/桑叶（不同版本略有差异，以经典版为准）

**公理性味拆解**：
- 青蒿：苦(水)+辛(木) → 清热兼透散
- 鳖甲：咸(火) → 除燥（入阴分）
- 生地：甘(土)+苦(水) → 润+清
- 知母：苦(水)+甘(土) → 清+润
- 丹皮：苦(水)+辛(木) → 清+散
- （天花粉：甘+微苦 → 润+清）

**药对化合**：
- 鳖甲(咸)+生地(甘苦) → **咸+苦→咸苦化酸（心原配）** + 苦甘化咸（肾原配）
- 青蒿(苦辛)+鳖甲(咸) → **辛+咸（广义化滞）→ 透阴分热邪**——关键组合
- 丹皮(苦辛)+知母(苦甘) → 辛苦+苦甘→辛苦开泄+苦甘化咸

**核心机制**（公理版）：
鳖甲（咸）直入阴分除燥 + 青蒿（辛苦）透散阴分郁热 = 辛+咸广义化滞，但病位在"阴分"而非"有形之滞"。这是**公理的一个延伸应用**。

**吻合度**：⚠️ **约55%**。辛+咸在公理中定义是"燥湿互结→化滞"，但阴分伏热的病机是"热伏阴分而非痰湿互结"——病机基础不同。公理的广义化滞不能完全套用在此处。

**组成**：杏仁、白蔻仁、薏苡仁、滑石、通草、竹叶、半夏、厚朴

**公理性味拆解**：

- 厚朴：辛(木)+苦(水) → 行气燥湿

**药对分析**：
- 白蔻(辛)+半夏(辛)+厚朴(辛苦) → **多辛叠加除湿**


**吻合度**：✅ **约80%**。辛+苦辛苦除痞在大方向上吻合。但"湿温"中"温"的四气属性、午后身热的特殊节律（温病中的时间特征）超出公理范围。

## 七、温病方核心缺口分析

### 缺口1：四气（寒热温凉）未纳入公理体系

公理体系以**五味（辛甘酸苦咸）**为唯一坐标，但温病方的核心特色之一是**四气（寒热温凉）的运用**。

| 公理现有 | 温病所需 | 缺口 |
|:--------|:--------|:----|
| 苦水清热 | 寒性药直接清热 | 苦水可以解释清热，但不能覆盖所有寒性药的清热作用 |
| 甘土驱寒 | 甘寒药养阴清热 | 甘土"驱寒"与"甘寒养阴"的临床效果方向不同 |
| 辛木除湿 | 辛凉药解表透热 | 辛+凉时，"凉"的机制无解释 |

**结论**：四气理论需要在公理体系中补充定义，或至少明确公理体系在"气"层面的适用边界。

### 缺口2：养阴生津的机制未定义

公理体系的补泻机制基于五行克邪——每一味药的作用是"克一种邪气"。
但养阴生津不是"克邪"，而是"补充正气"——这是完全不同的机制层面。

在伤寒经方中，养阴生津的需求较少（仲景多用甘药补中兼润），但在温病方中频繁出现，公理无法覆盖。

### 缺口3：内风与外风的区分

公理中「酸金祛风」的"风"是外风（金克木→克制风邪）。
温病中的"阴虚动风"是内风（水不涵木→肝阳化风），病机完全不同。

### 缺口4：疫毒/火毒的定位

温病学中的"热毒""疫毒""火毒"等概念，是温病独有的病理概念（传染性、热象极端），公理体系完全没有定义。

---

## 八、温病方验证·总判

> **郎君公理体系对温病方的综合吻合率约65-70%。**
> 
> 低于伤寒方的91%，主要不是因为公理"错了"，而是因为：
> 1. **公理体系基于五味克邪（攻邪）**→ 伤寒经方以攻邪为主，所以高度吻合
> 2. **温病方大量依赖四气（寒性）** + **养阴（补正气）**→ 超出公理当前的覆盖范围
> 3. **约30-35%的不吻合**中，约20%是"四气"缺口，约10-15%是"养阴/内风"缺口
>
> **核心结论**：公理体系对温病方的**攻邪部分**（辛开、苦降、甘守、咸润）依然适用，但对**寒性清热、养阴生津、内风熄风**等机制需要补充四气理论和补益理论才能完整覆盖。
