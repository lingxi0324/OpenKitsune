## 二、核心发现：适用性递减的深层原因

### 2.1 一个坐标轴看清全貌

```
                       公理覆盖度
                         │
                   ◉ 伤寒方 (91%)  ← 纯攻邪 - 五味克邪无缝对接
                         │
                   ◉ 温病方 (65-70%) ← 攻邪为主 + 寒性清热 + 养阴
                         │
                   ◉ 时方   (35-40%) ← 攻邪 + 补虚（补虚远超攻邪）
                         │
                    ──────────────→ 补虚占比递增
```

**根本规律**：**公理体系对"攻邪方剂"的覆盖度远高于"补虚方剂"。** 这本质上不是缺陷，而是公理体系的底层设计决定的——它建立在五味克邪逻辑上（每味药克一种邪气），不是建立在补正逻辑上（每味药补充一种正气）。

### 2.2 为什么伤寒方高达91%？

伤寒方的共同特征：
1. **以攻邪为主**——桂枝汤攻风湿、麻黄汤攻寒湿、承气汤攻燥实、白虎汤攻燥热
2. **药味精简**——平均5-7味，药对化合关系清晰
3. **五味对应明确**——仲景用药的性味选择与公理极为一致
4. **六经气机与五味克邪共用河洛数理**——底层逻辑相通

### 2.3 为什么温病方降至65-70%？

温病方引入的新变量：

| 温病新要素 | 公理对标 | 覆盖情况 |
|:----------|:--------|:--------|
| 四气之寒（清热） | 苦水清热 | ⚠️部分覆盖（苦水只解释五味之清，不解释四气之寒） |
| 养阴生津 | 无对应 | ❌ 未定义 |
| 内风（阴虚动风） | 酸金祛风（外风） | ⚠️方向不同（外风vs内风） |
| 芳香化湿 | 辛木除湿 | ✅ 可覆盖 |
| 疫毒/热毒 | 无对应 | ❌ 未定义 |
| 透热转气 | 辛苦除痞→透散 | ⚠️部分可解释 |

**关键发现**：温病方中与公理体系高度吻合的6方（清营汤、普济消毒饮、甘露消毒丹、犀角地黄汤等）均有一个共同特征——**以药对化合为核心驱动力**，也就是"五味"层面的作用占主导。而吻合度低的2方（沙参麦冬汤、大定风珠）则主要靠"四气之寒"和"补正"发挥作用。

### 2.4 为什么时方降至35-40%？

时方引入的最根本变化：**补虚逻辑与攻邪逻辑完全不同**

公理定义的"五味克邪"路线：
```
辛→克湿  |  咸→克燥  |  酸→克风  |  苦→克热  |  甘→克寒
```

时方需要但公理未定义的"五味补正"路线：
```
甘→补气   |  甘→补血(？) |  甘酸→补阴(？) |  辛→补阳(？)
```

**这个缺口是根本性的**。不是公理错了，而是公理的目的和时方的目的不在同一个维度——公理回答的是"药克什么邪"，时方回答的是"药补什么正"。两者可以互补，但不能相互替换。

时方中吻合度相对较高的3方（血府逐瘀~65%、二陈汤~60%、温胆汤~55%）均为**攻邪类时方**——这一事实再次验证了上述结论。

## 三、公理体系当前的理论边界

### 3.1 明确可以覆盖的领域

| 病邪类型 | 公理对应 | 适用方剂范围 |
|:--------|:--------|:-----------|
| 湿邪 | 辛木除湿 | 一切湿证方剂（经方+时方中治湿方） |
| 燥邪 | 咸火除燥 | 一切燥证方剂 |
| 风邪（外风） | 酸金祛风 | 外风证（桂枝汤族、川芎茶调散等） |
| 热邪（通过五味） | 苦水清热 | 五味层面清热方剂 |
| 寒邪（寒实） | 甘土驱寒 | 寒实证方剂 |
| 湿热痞结 | 辛苦除痞 | 辛开苦降类方（泻心汤族、温胆汤等） |
| 燥湿互结（滞） | 辛+咸广义化滞 | 攻坚破结类方 |
| 风湿相结 | 辛酸化甘（肝原配·散痞） | 肝郁风湿类方 |
| 燥热扰心 | 咸苦化酸（心原配·除烦） | 清热安神类方 |
| 寒湿满中 | 甘辛化苦（脾原配·消满） | 温中消满类方 |
| 燥湿瘅滞（肺） | 酸咸化辛（肺原配·散滞） | 肺郁瘅滞类方 |
| 肾燥 | 苦甘化咸（肾原配·除燥） | 润肾燥类方 |

### 3.2 明确不能覆盖的领域（需要扩展补充）

| 病理领域 | 公理不可覆盖的原因 | 需要补充的理论板块 |
|:--------|:-----------------|:-----------------|
| **补气** | 甘土驱寒≠补气 | **四气理论之"温补"** |
| **补血** | 公理无"血"的对应 | **五脏正补理论** |
| **滋阴** | "甘能补阴"在公理中不可推导 | **五脏正补理论** |
| **温阳** | 辛木除湿≠温阳 | **四气理论之"温助"** |
| **四气之寒** | 苦水清热只覆盖五味层面 | **四气理论之"寒凉"** |
| **内风** | 酸金祛风只针对外风 | **内风发病机制补充** |
| **痰** | 可勉强归为"湿聚"，但机制不同 | **病理产物独立分类** |
| **瘀血** | 公理无"血"的定位 | **气血理论** |
| **苦寒直折** | 大苦大寒药（黄连解毒汤类）的强力清热 | **四气理论之"大寒"** |

## 四、理论扩展的路径建议

### 4.1 最优先扩展：四气理论（寒热温凉）

温病方的65-70%吻合率中，主要缺口（约20-25%）来自四气之寒。这是最需要优先补充的理论板块。

具体来说，四气在公理体系中的定位可以这样理解：

| 四气 | 对应层面 | 与五味的关系 |
|:----|:--------|:-----------|
| 寒 | 药性之寒→清热 | 与苦水清热方向一致但机制不同→**寒为性之苦，苦为味之苦** |
| 热 | 药性之热→散寒 | 与辛木除湿方向相近但本质不同→**热为性之温通** |
| 温 | 药性之温→助阳 | 公理未覆盖→**补正之温** |
| 凉 | 药性之凉→清热 | 与苦同类但弱化→**轻清透热** |

**四气与五味的结合公式（初步推演）**：
```
性寒+味苦 = 强力清热（苦水清热 × 寒性加速）
性寒+味甘 = 甘寒养阴（甘土 + 寒性 → 补阴——超出公理，需新定义）
性温+味辛 = 辛温发散（辛木除湿 + 温性 → 风湿外散）
性温+味甘 = 甘温补气（甘土 + 温性 → 补中——超出公理，需新定义）
```

### 4.2 次优先：补虚理论（五脏正补）

时方的35-40%吻合率中，主要缺口（约50-60%）来自补虚。这是一个需要全新定义的理论板块。

最合理的路径是**将公理的五味克邪逻辑翻转——从"克邪"变为"补正"**：

| 五脏 | 克邪（公理已有） | 补正（需要新建） |
|:----|:---------------|:--------------|
| 肝 | 辛木除湿（克肝湿） | **酸补肝**——酸金祛风但金生水→酸可补肝体（？） |
| 心 | 咸火除燥（克心燥） | **苦补心**——苦水清热但水火既济→苦可养心（？） |
| 脾 | 甘土驱寒（克脾寒） | **甘补脾**——甘土已定义"驱寒"，但补脾需扩展 |
| 肺 | 酸金祛风（克肺风） | **辛补肺**——辛木开散→肺气宣发 |
| 肾 | 苦水清热（克肾热） | **苦补肾**——苦水+甘土→苦甘化咸→肾润（已有雏形） |

**这个翻转需要大量临床验证支撑**——目前只是理论推演方向。

### 4.3 长期积累：临床验证闭环

目前所有结论（91%、65-70%、35-40%）都基于"理论推演→与经典原文/传统认知对照"的验证模式。要真正验证公理体系，需要：
1. **真实临床案例**——从患者来诊→公理推导→选方→疗效验证的完整闭环
2. **温病/时方的公理预测**——用公理体系推测未经分析的方剂的性味组合，然后验证
3. **反向验证**——用公理重新组方，看能否推导出有效的新方

## 五、最终结论

### 一句话总结

> **郎君公理体系在攻邪层面高度自洽（91%），在温病清热养阴层面部分适用（65-70%），在时方补虚层面覆盖有限（35-40%）。它不是"错的"，而是"有边界的"——这个边界本身就是理论成熟度的重要标志。**

### 三界定位

```
                  攻邪（克邪）                         补正（补虚）
                      │                                    │
    ┌─────────────────┼────────────────────┬───────────────┘
    │                 │                    │               
  伤寒方            温病方                时方            
 (91%)            (65-70%)              (35-40%)         
    │                 │                    │
    └────────┬────────┘                    │
             │                             │
      攻邪部分高度适用              补虚部分基本不适
      四气+养阴需补                 攻邪部分仍可用
```
