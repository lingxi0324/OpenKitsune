## 第一类：辛咸化滞（6方）· 上横4-9-2

**病机本质**：湿+燥互结。湿气黏滞+燥气干结，二者胶着成滞。辛以行散开结，咸以软坚润燥。
**九宫定位**：上横4-9-2（金金火肃降），以降为顺

### 1. 大承气汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 厚朴(辛)+枳实(辛) → 辛味叠加，行气破滞开路 |
| 药对链② | 大黄(咸)+芒硝(咸) → 咸味叠加，软坚润燥攻下 |
| 药对链③ | 厚朴枳实(辛) → 大黄芒硝(咸) → 辛先开后咸攻，开→下的递进 |
| L1药对层 | 两链平行，各司其职：辛走气分开滞，咸走血分攻实 |
| L2方剂层 | 辛开→咸下，厚朴枳实先开道路，大黄芒硝随后攻下，缺一不可 |
| L3临床层验证 | 原文：阳明腑实"痞满燥实坚"全具。辛开解决"痞满"（气滞），咸下解决"燥实坚"（燥结闭阻），完全对应 |
| 三步走 | 辛散(厚朴枳实)→咸软(大黄芒硝)→[无甘补]，急下存阴，不可甘缓 |
| 九宫 | 4巽+3震(辛)开→9离(咸)下→1坎(水)，全方以降为顺 |
| 类内鉴别 | 小承气汤无芒硝，少咸软之力→"痞满"重温，"燥实坚"轻一档 |

### 2. 小承气汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 厚朴(辛)+枳实(辛) → 辛味叠加行气 |
| 药对链② | 厚朴枳实+大黄(咸) → 辛先开→后咸下 |
| L1药对层 | 辛开路线完整，但缺乏芒硝的咸软坚结 |
| L2方剂层 | 全方辛开有余而咸下不足→气机已通但燥结不重时适用 |
| L3临床层验证 | 原文："阳明病，其人多汗，以津液外出，胃中燥，大便必硬，硬则谵语，小承气汤主之。"——大便硬但未到"燥实坚"的程度，所以去芒硝 |
| 三步走 | 辛散→咸软(弱)→无甘补 |
| 九宫 | 4-3(辛)开→9(咸)下(轻)，气通即可 |
| 类内鉴别 | vs大承气：无芒硝→燥坚不重；vs调胃承气：有枳朴行气→痞满重 |

### 3. 调胃承气汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 大黄(咸)+芒硝(咸) → 咸味叠加，软坚攻下 |
| 药对链② | 大黄芒硝(咸)+甘草(甘) → 咸后甘缓，延缓攻下之势 |
| L1药对层 | 核心攻下药对，甘草缓之使药力不峻 |
| L2方剂层 | 全方无辛散行气→不治痞满，专攻燥结 |
| L3临床层验证 | 原文："太阳病三日，发汗不解，蒸蒸发热者，属胃也，调胃承气汤主之。"——发热为主，未见痞满，故去枳朴 |
| 三步走 | 无辛散→咸软(大黄芒硝)→甘缓(甘草)，是"缓攻"模式 |
| 九宫 | 9(咸)下→5(甘)缓，攻而不峻 |
| 类内鉴别 | vs大承气：无枳朴→不治痞满；vs小承气：有芒硝有甘草→攻下力介乎二者之间，但缓攻不急 |

### 4. 麻子仁丸

| 维度 | 分析 |
|:----|:------|
| 药对链① | 枳实厚朴(辛) → 行气开滞 |
| 药对链② | 大黄(咸)+麻仁(咸) → 润下而非攻下 |
| L1药对层 | 辛开路线+咸润路线，与承气汤类不同的是"润"而非"攻" |
| L2方剂层 | 全方辛行气+咸润下+蜜甘缓，是"脾约证"的润下方 |
| L3临床层验证 | 原文："趺阳脉浮而涩，浮则胃气强，涩则小便数，浮涩相搏，大便则坚，其脾为约，麻子仁丸主之。"——胃气强+脾阴不足，非阳明燥实，故用麻仁润之 |
| 三步走 | 辛散(枳朴)→咸润(大黄麻仁)→甘缓(蜜) |
| 九宫 | 4-3辛开→9咸润→5甘缓 |
| 类内鉴别 | vs承气汤类：麻仁代芒硝→润下非攻下；兼有芍药→酸收养阴 |

### 5. 麻杏石甘汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 麻黄(辛)+杏仁(辛) → 辛开肺气 |
| 药对链② | 麻黄杏仁(辛)+石膏(咸) → 辛开→咸降，宣肺+清肺 |
| L1药对层 | 麻黄开肺表，杏仁降肺气，石膏清肺热——一个宣、一个降、一个清 |
| L2方剂层 | 全方辛开后以咸降收功，是"开→清"模式，走肺经而非胃经 |
| L3临床层验证 | 原文："发汗后，不可更行桂枝汤，汗出而喘，无大热者，可与麻黄杏仁甘草石膏汤。"——汗出+喘+无大热，肺热壅盛而非表虚，故用石膏清肺 |
| 三步走 | 辛散(麻黄杏仁)→咸降(石膏)→甘缓(甘草) |
| 九宫 | 4(辛肺)开→9(咸)清→5(甘)和 |
| 类内鉴别 | vs承气汤类：同样辛咸组合但走肺经而非胃经；vs麻黄汤：去桂枝加石膏→由辛温发散转为辛凉清宣 |

### 6. 白通汤

| 维度 | 分析 |

## 第二类：咸苦化酸（7方）· 中纵9-5-1

**病机本质**：燥+热互结。燥气伤津+热气灼血，二者互结成瘀。咸以软坚润燥，苦以降火清热，化酸为收敛除瘀。
**九宫定位**：中纵9-5-1（火中水），治在血分

### 7. 白虎汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 石膏(咸)+知母(苦) → 咸清+苦降，化合为酸以收敛浮火 |
| 药对链② | 石膏知母+粳米甘草(甘) → 咸苦化酸→甘缓养胃 |
| L1药对层 | 石膏咸寒清气分大热，知母苦寒润燥，二者配合"咸清苦降→化酸收火" |
| L2方剂层 | 全方"清气热+养胃津"并行，热清津回则诸证自愈 |
| L3临床层验证 | 原文："伤寒脉浮滑，此以表有热，里有寒，白虎汤主之。"——大热、大渴、大汗、脉洪大四大症。咸苦化酸收浮越之热 |
| 三步走 | 咸清(石膏)→苦降(知母)→甘养(粳米甘草) |
| 九宫 | 9(咸)清→3(苦)降→5(甘)养 |
| 类内鉴别 | vs白虎加人参汤：加人参→津伤更重，益气生津 |

## 第三类：辛苦化甘（4方）· 左上-右下斜4-5-6

**病机本质**：湿+热互结。辛开湿郁，苦降热结，化合为甘以缓中除痞。
**九宫定位**：左上-右下斜4-5-6

### 14. 葛根芩连汤

| 维度 | 分析 |
|:----|:------|
| 药对链① | 葛根(辛)+黄芩(苦)+黄连(苦) → 辛开+苦降 |
| 药对链② | 芩连(苦)+甘草(甘) → 苦降→甘缓，化甘除痞 |
| L1药对层 | 葛根辛升脾胃清阳，芩连苦降湿热，一升一降一苦一辛 |
| L2方剂层 | 全方"升清+降浊"并行，辛开路→苦降浊→甘和中 |
| L3临床层验证 | 原文："太阳病，桂枝证，医反下之，利遂不止，脉促者，表未解也；喘而汗出者，葛根黄芩黄连汤主之。"——误下后利不止+喘而汗出，湿热下利 |
| 三步走 | 辛散(葛根升清)→苦降(芩连降浊)→甘缓(甘草和中) |
