## 0. 公理定位

| 要素 | 内容 |
|:----|:------|
| **化合类型** | 甘辛化苦（脾体用原配） |
| **味A** | 甘（土·驱寒）— 脾之用补 |
| **味B** | 辛（木·除湿）— 脾之体泻 |
| **五行关系** | 土+木，木克土（辛耗甘） |
| **新生味** | **苦**（水·燥湿清火） |
| **病机对应** | 寒湿停中→中焦胀满壅塞 |
| **主治** | **消满**——苦水燥湿之力散中焦寒湿满 |
| **旧框架错误** | 旧说"辛甘化阳→鼓动阳气/发散解表"，实际是**甘辛化苦→脾原配消满**。甘土驱寒+辛木除湿→化生苦水燥湿散寒之力，不在"阳"而在"燥" |

### 代表方1：理中丸（群主·第一方）

| **药对链②** | 人参(甘)+白术(甘) → 甘味叠加，驱寒补中 |

| **类内鉴别** | vs四逆汤：理中有参术偏补中虚，四逆有附偏温下焦；理中纯守中，四逆能通脉 |

## 四、A3c · 桂枝/生姜为君（散寒湿偏表）7方

### 代表方1：五苓散（群主·化气行水）

| 维度 | 分析 |
|:----|:------|
| **全药** | 桂枝(辛) 白术(甘) 茯苓(甘) 猪苓(甘) 泽泻(甘) |
| **药对链①** | **桂枝(辛)+四甘(术苓猪泽)** → **甘辛化苦主干** |
| **药对链②** | 术苓猪泽(四甘) → 甘味叠加强力驱寒利水 |
| **L1药对层** | 一辛带四甘：桂枝辛木除膀胱经湿气，四甘各以甘土驱寒之力帮利水。甘辛交融化生苦水之力—苦水本身就是"燥湿行水"的底力 |
| **L2方剂层** | 治"太阳蓄水证"——表邪入里导致膀胱气化不利、水湿停聚。桂枝在此**不温阳**，而是以辛木除湿之力化膀胱经之湿；四甘帮水排出体外。化生苦水的本质是：被运化的水以正常通道排出 |
| **L3临床验证** | 原文："太阳病，发汗后，大汗出，胃中干……脉浮，小便不利，微热消渴者，五苓散主之。"（71条）——汗后膀胱气化不行+水停+消渴。**甘辛化苦之力解决了"水停而渴"的矛盾：水不是不够，是停在不该停的地方，化苦燥湿行水则渴自止** |
| **L4九宫气机** | 桂枝(3震辛)→四甘(5中土+8艮)→化苦(1坎)：3→5→8→1，从木到土到水的完整气化通道 |
| **三步走** | 辛散(桂枝行膀胱经湿)→甘利(四甘驱寒行水)→化苦(水有出路)——**G型·行水版** |
| **类内鉴别** | vs苓桂术甘汤：五苓散利水更强(猪泽双用)，治下焦蓄水；苓桂术甘治中焦水饮上冲 |

## 七、跨类深层鉴别

### 甘辛化苦 vs 辛酸化甘（脾vs肝）

| 对比维度 | 甘辛化苦（脾原配） | 辛酸化甘（肝原配） |
|:---------|:----------------|:----------------|
| **病机** | 寒湿停中→满 | 风湿相结→痞 |
| **核心症状** | 胀满/下利/呕/眩 | 汗出/身痛/胁痞 |
| **九宫气机** | 8→5→1 | 3→7→5 |
| **药对特征** | 干姜/附/桂+参术草/苓 | 桂/麻/姜+芍/味+草 |
| **三步走** | 甘补+辛散→化苦燥 | 辛散+酸敛→化甘和 |
| **舌象推断** | 苔白厚腻/胖大 | 苔白润/薄白 |
| **代表方** | 理中丸·四逆汤·五苓散 | 桂枝汤·小青龙·当归芍药散 |

### 同一方·双化合并存的处理（小建中汤为例）

小建中汤含桂芍辛酸+饴草甘→同时触发两条化合路径：
1. **桂+芍**→辛酸化甘→散风湿之痞（肝原配）
2. **桂+饴草**→甘辛化苦→消寒湿满（脾原配）

双化合并存不冲突：**肝主血分、脾主气分**——辛酸化甘散肝血之痞、甘辛化苦消脾气之满。一方两路，各司其职。临床判定以患者"偏肝还是偏脾"为鉴别点：
- 痛偏胁肋+脉弦→辛酸化甘为主治肝
- 胀偏腹部+苔腻→甘辛化苦为主治脾
