## 第一部分 · 肝原配辛酸化甘（18方）

### 0. 公理定位

| 要素 | 内容 |
|:----|:------|
| **化合类型** | 辛酸化甘（肝体用原配） |
| **味A** | 辛（木·除湿）— 肝之用补 |
| **味B** | 酸（金·祛风）— 肝之体泻 |
| **五行关系** | 木+金，金克木（酸制辛） |
| **新生味** | **甘**（土·和缓） |
| **病机对应** | 风湿相结→胁下痞塞 |
| **主治** | **散痞**——甘土和缓之力散木金相争 |
| **旧框架错误** | 旧说"辛酸化辛→开阖环流"，实际应是"辛酸化甘→散痞" |

### 1. 桂枝汤（群主·第一方）

| 维度 | 分析 |
|:----|:------|
| **全药** | 桂枝(辛) 白芍(酸) 甘草(甘) 生姜(辛) 大枣(甘) |
| **药对链①** | **桂枝(辛)+白芍(酸)** → **辛酸化甘（肝原配·散痞）** ← 全方灵魂 |
| **药对链②** | 生姜(辛)+大枣(甘) → 甘辛非原配叠加（甘土驱寒+辛木除湿） |
| **药对链③** | 桂枝(辛)+甘草(甘) → 甘辛非原配叠加 |
| **药对链④** | 白芍(酸)+甘草(甘) → **酸甘非原配**（甘缓酸收敛散固阴） |
| **L1药对层** | ①肝原配辛酸化甘为核心纲领；②③甘辛叠加驱寒除湿；④酸甘非原配辅助敛阴 |
| **L2方剂层** | 全方两大原配并行：**肝原配(辛酸化甘)定调散痞 + 非原配(甘+辛)驱寒除湿**。桂枝白芍是君对，不是单味君药 |
| **L3临床验证** | 原文："太阳中风，阳浮而阴弱，阳浮者热自发，阴弱者汗自出，啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕者，桂枝汤主之。"——汗出恶风+发热，不是"风寒束表"而是**风湿在表+营卫不和**。辛除湿+酸祛风+甘和缓→散风湿之痞在肌表 |
| **L4九宫气机** | 辛(3震)+酸(7兑)→化甘(5中土)：左升右降汇聚中土。生姜(3震)助辛散，大枣甘草(5中土)助甘和→全方气机从3→7→5，汇聚中土的完整环流 |
| **三步走模式** | **A型·开阖调**：辛散(桂枝生姜行湿)→酸敛(白芍祛风)→甘和(草枣收功) |
| **类内鉴别** | 桂枝汤的核心鉴别点：**辛酸化甘(肝原配)为主轴，配甘辛(脾原配)为辅**——肝脾同调，散风湿之痞在肌表营卫 |

#### 桂枝汤 vs 旧框架对照

| 维度 | 旧框架（错误） | 新公理（正确） |
|:----|:-------------|:--------------|
| 桂芍化合 | 辛酸化辛→开阖环流 | **辛酸化甘→肝原配散痞** |
| 全方性质 | 解表剂→发汗散寒 | **肝原配散风湿+脾原配驱寒湿** |
| 病机 | 风寒束表→营卫不和 | **风湿在表→营卫不和** |

| **茵陈蒿汤** | 茵陈栀(苦)+大黄(咸) | 侧重湿热黄痘 | 9→1→7+3-5 | C型·利湿 |

### 5. 心原配咸苦化酸·伤寒原文验证总结

| 验证项 | 结果 |
|:------|:-----|
| **化合预测一**：咸除燥→苦清热→化酸敛心 | ✅ **7方均有"心烦/狂/谵语"等症状**——白虎(谵语)、黄连阿胶(心烦不得卧)、桃核承气(如狂)、抵当(喜忘/发狂) |

### 6. 心原配vs旧框架对照

| 维度 | 旧框架（错误） | 新公理（正确） |
|:----|:-------------|:--------------|
| 白虎汤 | 清气分热→四大症 | **咸苦化酸→心原配除烦** |
| 黄连阿胶汤 | 滋阴降火→少阴热化 | **咸苦化酸→酸敛宁心** |
| 瘀血三方 | 活血逐瘀→下焦蓄血 | **咸苦化酸(治烦)+辛咸化滞(攻瘀)双线** |
| 病机总纲 | 阳明经证/腑证 | **心原配燥热扰心→全身燥热** |

> **核心洞察**：旧框架将白虎汤归为"阳明经证"、黄连阿胶汤归为"少阴热化"、瘀血方归为"下焦蓄血"——三者用不同的辨证体系各自解释。新公理下统一为**"咸苦化酸心原配"**——病位在心（燥热扰心），病机在燥（咸入心除燥），效应在酸（化酸敛心）。一个化合规则贯穿7方，不同病位的"烦"皆可用同一框架理解。
