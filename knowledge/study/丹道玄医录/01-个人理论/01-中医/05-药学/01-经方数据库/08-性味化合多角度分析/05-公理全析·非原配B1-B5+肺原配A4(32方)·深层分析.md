## 0. 非原配底层逻辑总纲

### 非原配 vs 原配 的本质差异

| 对比维度 | 五脏体用原配（A类） | 非原配（B类） |
|:---------|:-----------------|:-------------|
| **化合行为** | 两味交融→**化生新性味** | 无新生味→仅**功效叠加协同** |
| **新味** | 有（A1化甘/A2化酸/A3化苦/A4化辛/A5化咸） | **无** |
| **病机靶点** | 本脏特有复合邪气 | 两邪各治各的、合力攻坚 |
| **代表** | 肝原配·心原配·脾原配·肺原配·肾原配 | 辛+咸承气类·辛苦开泄类·酸苦风热类 |
| **治疗力型** | 浑然一体、定向调脏 | 各自为战、协同除邪 |

### 非原配五大类速览

| 分类 | 味配 | 病机 | 靶点 | 代表方 | 方数 |
|:----|:----|:----|:----|:------|:---:|
| **B1** | 辛+咸 | 湿+燥互结成实 | 攻坚破结 | 大承气汤 | 6 |
| **B2** | 辛+苦 | 湿+热互结痞堵 | 开泄痞结 | 红蓝花酒 | 5 |
| **B3** | 酸+苦 | 风+热互结 | 清泄风热 | 小柴胡汤 | 9 |
| **B4** | 甘+酸 | 风+寒耗散气阴 | 敛散固阴 | 芍药甘草汤 | 4 |
| **B5** | 咸+甘 | 燥结+寒凝 | 缓攻润燥 | 调胃承气汤（辅） | 3 |

**A类原配与B类非原配的关系**：
同一个方剂可以同时包含A类和B类药对链。判定时以君药和核心病机为准——君药决定方的化合归属，臣佐使决定辅助化合。

## 第一部分 · A4 酸咸化辛（肺原配·散滞）~5方

### A4 · 公理定位

| 要素 | 内容 |
|:----|:------|
| **化合类型** | 酸咸化辛（肺体用原配） |
| **味A** | 酸（金·祛风）— 肺之用补 |
| **味B** | 咸（火·除燥）— 肺之体泻 |
| **五行关系** | 金+火，火克金（咸制酸） |
| **新生味** | **辛**（木·开散） |
| **病机对应** | 燥湿互结肺中→肺气郁滞成瘅 |
| **主治** | **散滞**——化生辛木开散之力→解散肺中燥湿痼结 |
| **旧框架错误** | 旧框架没有独立"酸咸化辛"概念，散见于辛咸化滞的模糊论述中。新公理下：酸咸化辛=肺原配·散滞，是"辛咸化滞"的狭义正统本源 |

### 代表方：桔梗汤（肺原配·酸咸化辛辅助→甘辛化苦主线）

| 维度 | 分析 |
|:----|:------|
| **全药** | 桔梗(辛) 甘草(甘) |
| **药对链①** | **桔梗(辛)+甘草(甘)** → **甘辛化苦（脾原配·消满）** ← 全方主线 |
| **药对链潜链** | 桔梗味辛苦入肺→辛木开散→**暗含酸咸化辛底力**（肺金燥气得辛开则散） |
| **L1药对层** | 桔梗本身辛开+甘守，看似甘辛化苦消满，但桔梗的归经在肺不在脾→本质是**借甘辛化苦之形、行酸咸化辛之实**——甘草守中不让辛开除湿过散，桔梗专注开肺郁 |
| **L2方剂层** | 治少阴病咽痛。咽为肺之门户，肺被燥湿所郁则咽痛。桔梗开肺郁+草守中防苦寒伤正 |
| **L3临床验证** | 原文："少阴病，二三日，咽痛者，可与甘草汤；不差，与桔梗汤。"——咽痛是肺燥之表 |
| **L4九宫气机** | 桔梗(4巽辛)+草(5中土甘)：4→5 |

### A4 · 余4方总览

| 方名 | 核心药对 | 酸+咸体现 | 九宫气机 | 化合类型 |
|:----|:--------|:---------|:-------:|:---------|
| **排脓散** | 桔梗枳(辛)+芍(酸)+鸡子黄 | 桔梗辛开+芍酸收→暗含酸咸化辛底力 | 4→7 | 辛酸+咸润 |
| **温经汤（兼属）** | 归桂芎(辛)+芍(酸)+阿胶(咸) | 芍酸+阿胶咸→酸咸化辛之底 | 3→1→7→2 | 辛酸+咸甘复方 |
| **胶艾汤（兼属）** | 艾归(辛)+芍(酸)+阿胶(咸) | 芍酸+阿胶咸→暗含酸咸化辛 | 3→1→7 | 辛酸+咸甘复方 |
| **排脓汤** | 桔梗(辛)+草(甘)+枣(甘)+姜(辛) | 桔梗辛开→酸咸化辛潜线 | 4→5→8 | 甘辛化苦为主 |

### A4 · 验证总结

| 验证项 | 结果 |
|:------|:-----|
| **A4是新框架的最大缺口** | ⚠️ **需要更多临证案**——桔梗汤/排脓散/排脓汤的肺原配归属需要更多临床验证来确认。目前5方中有3方是兼属，纯酸咸化辛方严重不足 |
| **旧框架无此独立分类** | ✅ 新公理补上了这个缺口——但肺原配的方剂在伤寒金匮中相对少见，需要在时方/温病方中寻找更多案例 |

## 第二部分 · B1 非原配辛+咸（广义化滞）6方

### B1 · 公理定位

| 要素 | 内容 |
|:----|:------|
| **味配** | 辛（木·除湿）+ 咸（火·除燥） |
| **化味** | ❌ 无新生味 |
| **病机** | 湿+燥互结成实 |
| **协同机理** | 辛行湿+咸软燥→同步瓦解燥湿胶结 |
| **主治** | 攻坚破结——气滞/痰瘀/水积/食块 |
| **与A4区别** | B1是辛+咸直配（湿与燥各治各的），A4是酸+咸化新辛味（肺原配化生） |

### 代表方1：大承气汤（群主）

| 维度 | 分析 |
|:----|:------|
| **全药** | 厚朴(辛) 枳实(辛) 大黄(咸) 芒硝(咸) |
| **药对链①** | 厚朴(辛)+枳实(辛) → 辛味叠加，行气破湿滞开路 |
| **药对链②** | 大黄(咸)+芒硝(咸) → 咸味叠加，软坚润燥攻下 |
| **药对链③** | 枳朴(辛)→硝黄(咸) → **辛先开路→咸后攻坚**→湿与燥同步瓦解 |
| **L1药对层** | 双味叠加而非化生：辛味行开+咸味软下，各自在各自的层面作用。辛只是"开路"，不转化成别的味 |
| **L2方剂层** | 治阳明腑实"痞满燥实坚"全具。辛解决"痞满"（气滞湿阻），咸解决"燥实坚"（燥结成实）。**没有化合关系，只有接力关系** |
| **L3临床验证** | ✅ "腹满不减，减不足言"——湿（满）+燥（不减）互结的典型 |
| **L4九宫气机** | 枳朴(4+3辛)→硝黄(9咸)+1(下)：4→3→9→1 |
| **三步走** | 辛行(枳朴开滞)+咸下(硝黄攻实)→**J型·急攻** |

### 代表方2：麻杏石甘汤

| 维度 | 分析 |
|:----|:------|
| **全药** | 麻黄(辛) 杏仁(辛) 石膏(咸) 甘草(甘) |
| **药对链①** | 麻杏(辛)+石膏(咸) → **辛+咸非原配·广义化滞** |
| **药对链②** | 麻杏草(辛甘) → 甘辛化苦辅助 |
| **L1药对层** | 麻杏辛开+石膏咸清。太阳表寒（辛开）+阳明里热（咸清）→不是"化滞"而是"开表清里" |
| **L2方剂层** | 原文"汗出而喘，无大热者"——表寒已解但里热壅肺。麻杏开肺气→石膏清肺热→两路并进 |
| **L3临床验证** | ✅ 汗出而喘+无大热——湿（表寒）+燥（里热）在肺中互结 |
| **L4九宫气机** | 麻杏(4辛)→石膏(9咸)+草(5甘)：4→9→5 |

### B1 · 余4方总览

| 方名 | 核心药对 | 辛+咸体现 | 九宫气机 | 三步走变体 |
|:----|:--------|:---------|:-------:|:---------|
| **小承气汤** | 枳朴(辛)+大黄(咸) | 无芒硝→咸软力弱于大承气 | 4→3→9 | J型·轻攻 |
| **调胃承气汤** | 硝黄(咸)+草(甘) | 无枳朴→不行气，偏润下 | 9→5→1 | J型·缓攻 |
| **麻子仁丸** | 枳朴(辛)+麻仁大黄(咸)+蜜(甘) | 辛开+咸下+甘缓 | 4→3→9+5 | J型·润攻 |
| **白通汤** | 附姜(辛)+葱白(辛)+草(甘) | 白通汤归辛+咸存疑——更偏甘辛化苦 | 1→8→5 | G型为主 |

### B1 · 验证总结

| 验证项 | 结果 |
|:------|:-----|
| **辛+咸无化味** | ✅ 6方中承气类4方完全匹配，麻杏石甘汤匹配（辛+咸开表清里） |
| **攻坚破结** | ✅ 承气类治"痞满燥实坚"——典型燥湿互结 |
| **白通汤归属存疑** | ⚠️ 白通汤(附姜葱+草)更偏甘辛化苦，归入B1是旧框架的残留，待郎君裁定 |
| **吻合率** | **~83%**（5/6方通过） |

## 第四部分 · B3 非原配酸+苦（清泄风热）9方

### B3 · 公理定位

| 要素 | 内容 |
|:----|:------|
| **味配** | 酸（金·祛风）+ 苦（水·清热） |
| **化味** | ❌ 无新生味 |
| **病机** | 风+热互结于半表半里/肝经/肠腑 |
| **协同机理** | 酸敛风+苦清热→表里两清，泄散风热 |
| **旧框架错误** | ❌ 旧说"酸苦化甘"——以为酸苦生甘，原汤液经旧解读 |

### 代表方1：小柴胡汤（群主）

| 维度 | 分析 |
|:----|:------|
| **全药** | 柴胡(苦) 黄芩(苦) 芍药(酸) 半夏(辛) 生姜(辛) 人参(甘) 大枣(甘) 甘草(甘) |
| **药对链①** | **柴芩(苦)+芍药(酸)** → **非原配·酸+苦清泄风热** ← 核心 |
| **药对链②** | 半夏(辛)+生姜(辛) → 辛降之和胃 |
| **药对链③** | 参枣草(甘) → 甘守补中防过 |
| **药对链④** | 柴芩(苦)+参枣草(甘) → 苦甘化咸（肾原配·辅线） |
| **L1药对层** | 核心药对是酸+苦：芍药酸金祛风（入肝经）+柴芩苦水清热（入胆经）。酸收敛散风邪，苦清泄热邪，协同但不化生 |
| **L2方剂层** | 原文"往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕"——风在半表半里（往来寒热），热在里（心烦）。酸清泄风热于半表半里，是少阳枢机的核心药对 |
| **L3临床验证** | ✅ 往来寒热+胸胁苦满——风+热互结在少阳 |
| **L4九宫气机** | 柴芩(1+2苦)+芍(7酸)+夏姜(3+8辛)+参枣草(5甘)：以1→2→7→3→8→5的整体调和环路 |
| **三步走** | 酸敛(芍收风)+苦泄(柴芩清热)+甘守(参草补中)+辛降(夏姜和胃)——**J型·和法** |
| **类内鉴别** | vs大柴胡汤：小柴有参草→虚证兼补；大柴无参有枳黄→实证兼攻 |

## 第五部分 · B4 非原配甘+酸（敛散固阴）4方

### B4 · 公理定位

| 要素 | 内容 |
|:----|:------|
| **味配** | 甘（土·驱寒缓急）+ 酸（金·祛风收敛） |
| **化味** | ❌ 无新生味 |
| **病机** | 风+寒耗散气血阴液 |
| **协同机理** | 甘缓急制酸收+酸收敛制甘散→**合力在"收"不在"补"** |
| **旧框架错误** | ❌ 旧说"酸甘化阴→养阴生津"。实际酸+甘不入原配→无新化味，合力在于"收敛"不是"补阴" |

### 代表方：芍药甘草汤（群主）

| 维度 | 分析 |
|:----|:------|
| **全药** | 芍药(酸) 甘草(甘·倍量) |
| **药对链①** | **芍药(酸)+甘草(甘)** → **非原配·甘酸敛散固阴** |
| **L1药对层** | 甘土驱寒缓急制住酸收太过+酸金祛风收敛制住甘散太过→二者互相制衡形成"收敛固脱"的合力。**不产生新味，只是相制而出收力** |
| **L2方剂层** | 原文："伤寒脉浮，自汗出，小便数，心烦，微恶寒，脚挛急……作芍药甘草汤与之，其脚即伸。"——汗后阴伤→筋脉失濡→脚挛。**不是芍甘"生阴"，是芍甘收敛固脱→防止阴液继续耗散→阴自身恢复** |
| **L3临床验证** | ✅ "脚挛急"+"其脚即伸"——阴耗则挛，收敛固脱则伸 |
| **L4九宫气机** | 芍(7兑酸)+草(5中土甘)：7→5，西金收敛+中土固守 |
| **三步走** | 酸敛(芍收耗散之阴)+甘缓(草制酸收太过)→**J型·敛固** |
| **类内鉴别** | vs小建中汤(甘酸辅助线)：小建中芍+饴糖虽也是甘酸，但受主药桂辛+甘的影响→甘酸仅是辅助敛固，主力是辛酸化甘散痞 |

### B4 · 余3方总览

| 方名 | 核心药对 | 甘酸体现 | 九宫气机 | 三步走变体 |
|:----|:--------|:--------|:-------:|:---------|
| **芍药甘草附子汤** | 芍(酸)+草(甘)+附(辛) | 甘酸敛固+附辛温阳 | 7→5→1 | J型·兼温 |

| **小青龙汤（辅助线）** | 芍味(酸)+草(甘) | 甘酸为辅、辛酸为主 | 7→5(辅) | A型为主·J型辅 |
