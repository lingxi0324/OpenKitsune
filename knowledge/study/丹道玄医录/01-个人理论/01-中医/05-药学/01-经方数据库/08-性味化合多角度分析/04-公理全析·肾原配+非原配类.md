## 第一部分 · 肾原配苦甘化咸（A5·~23方）

### 0. 公理定位

| 要素 | 内容 |
|:----|:------|
| **化合类型** | 苦甘化咸（肾体用原配） |
| **味A** | 苦（水·清热）— 肾之用补 |
| **味B** | 甘（土·驱寒）— 肾之体泻 |
| **五行关系** | 水+土，土克水（甘缓苦） |
| **新生味** | **咸**（火·温润） |
| **病机对应** | 寒热耗阴→肾燥枯槁 |
| **主治** | **除燥**——咸火温润滋养肾精 |
| **旧框架错误** | 旧说"热+寒互结→除烦"——把"烦"当作病机本质，实际"烦"只是肾燥的外标。本质是寒热伤阴→肾燥→化咸润之 |

### 1. 栀子豉汤（肾原配·第一方）

| 维度 | 分析 |
|:----|:------|
| **全药** | 栀子(苦) 淡豆豉(甘) |
| **药对链①** | **栀子(苦)+豆豉(甘)** → **苦甘化咸（肾原配·除燥）** |
| **L1药对层** | 纯肾原配——一苦一甘，苦水清热+甘土驱寒→化生咸火温润之力 |
| **L2方剂层** | 治"虚烦不得眠"——旧说"心中懊憹"是热扰胸膈，新公理下是**肾燥不能藏神→虚火浮越→烦不得卧**。苦甘化咸→咸火润肾燥→肾能藏神→烦止卧安 |
| **L3临床验证** | 原文："发汗吐下后，虚烦不得眠，若剧者，必反复颠倒，心中懊憹。"——汗吐下伤阴→**肾燥→虚火上扰→心中懊憹**。苦甘化咸→润肾燥→火归本位→烦止 |
| **L4九宫气机** | 栀(1坎·苦清热)+豉(5中土·甘驱寒)→化咸(9离·火润)：1→5→9，以水润土生火 |
| **三步走** | 苦降(栀子清热)+甘宣(豆豉驱寒)→化咸(新生润燥之力守肾)——**C型·纯版** |

#### 新旧对照

| 维度 | 旧框架 | 新公理 |
|:----|:------|:------|
| 虚烦 | 余热留胸膈 | **肾燥不能藏神→虚火浮越** |
| 栀子+豆豉 | 一清一宣→宣郁清热 | **苦甘化咸→肾原配·除燥润肾** |
| 治疗原理 | 清胸膈郁热 | **润肾燥→肾藏神→烦自止** |

### 2. 半夏泻心汤（苦甘化咸·寒热杂版）

| 维度 | 分析 |
|:----|:------|
| **全药** | 黄芩(苦) 黄连(苦) 干姜(辛) 半夏(辛) 人参(甘) 大枣(甘) 甘草(甘) |
| **药对链①** | **芩连(苦)+参枣草(甘)** → **苦甘化咸（肾原配·除燥）** ← 核心 |
| **药对链②** | 干姜半夏(辛)+芩连(苦) → **辛+苦非原配·开泄痞结** ← 辅助 |
| **药对链③** | 干姜(辛)+参枣草(甘) → 甘辛非原配叠加 |
| **L1药对层** | ①苦甘化咸为主干→润肾燥；②辛苦开泄为辅→泄湿+热痞结；③甘辛驱寒为底 |
| **L2方剂层** | 全方复杂但主线明确——**肾原配燥润+辛苦泄痞双线并行**。不是"寒热并调"的模糊说法，而是苦甘化咸先润肾→肾水能上济→然后辛苦开泄可施 |
| **L3临床验证** | 原文："伤寒五六日，呕而发热者，柴胡汤证具……但满而不痛者，此为痞。"——**寒热药攻下后→肾燥+湿痞结**。"痞"不是单纯热结，是肾燥不能化气行水→湿气停中。苦甘化咸润肾燥→气化复→湿痞自开 |
| **三步走** | 苦甘(润肾燥·主线)+辛苦(开痞结·辅线)——**C+D混合版** |
| **类内鉴别** | vs生姜泻心汤：姜泻有生姜无干姜量→偏散水气；vs甘草泻心汤：草泻甘草倍量→偏缓急 |

## 第二部分 · 非原配辛+咸·广义化滞（B1·6方）

### 0. 公理定位

| 要素 | 内容 |
|:----|:------|
| **配伍** | 辛（木·除湿）+ 咸（火·除燥） |
| **五行关系** | 木生火，相生相助 |
| **新生味** | **无**——双药功效直接叠加 |
| **病机** | 燥湿互结成实→壅滞结块 |
| **主治** | **广义化滞**——辛行湿+咸软燥同步瓦解 |

**与A4区别**：B1是**非原配辛+咸**（木生火相生，原味叠加不化新），攻坚破结力强；A4是**肺原配酸咸化辛**（金+火交融化辛散），开散肺郁力专。

### 1. 大承气汤（群主）

| 维度 | 分析 |
|:----|:------|
| **全药** | 厚朴(辛) 枳实(辛) 大黄(咸) 芒硝(咸) |
| **药对链①** | **厚朴枳实(辛)+大黄芒硝(咸)** → **辛+咸非原配·广义化滞** |
| **药对链②** | 厚朴(辛)+枳实(辛) → 辛味叠加·行气破滞 |
| **药对链③** | 大黄(咸)+芒硝(咸) → 咸味叠加·软坚攻下 |
| **L1药对层** | 双辛开气分道路+双咸攻燥实结块。辛不开则咸无路可下，咸不攻则辛开了也白开 |
| **L2方剂层** | **辛开路→咸攻坚的典型递进**。没有新生味，纯粹功效叠加——辛攻湿(气滞)+咸攻燥(燥结)。要两种邪气都除掉，滞才能化 |
| **L3临床验证** | 原文："阳明病，脉迟，虽汗出，不恶寒者……手足濈然汗出者，此大便已硬也，大承气汤主之。"——**湿(气滞痞满)+燥(燥实坚)互结**。辛开痞满(气分)+咸攻燥坚(血分) |
| **三步走** | 辛散(枳朴开气分之满)→咸软(硝黄攻血分之燥坚)→[无甘补]——**B型·先开后下** |
| **九宫气机** | 辛(4巽+3震)→咸(9离)→全方以降为顺，气行血攻 |
| **类内鉴别** | vs小承气汤：无芒硝一咸→软坚力弱→轻证；vs调胃承气：无枳朴→辛行气力弱 |

## 第五部分 · 非原配甘+酸/咸+甘（B4+B5·~7方）

### B4 · 甘+酸（敛散固阴）

**五行**：土生金，无新生味
**合力**：甘土驱寒缓急+酸金祛风收敛→敛散固阴

| 方名 | 酸药 | 甘药 | 作用 |
|:----|:----|:----|:-----|
| **芍药甘草汤** | 芍药(酸) | 甘草(甘) | 酸收+甘缓→脚挛急立解 |
| 芍药甘草附子汤 | 芍药(酸) | 草(甘)+附(辛) | 同上+温阳 |
| 小建中汤(辅助对) | 芍(倍酸) | 饴糖(甘) | 酸甘收缓止腹痛 |

**旧错误**：旧说"酸甘化阴→养阴生津"——错误！酸甘不入原配，甘+酸是**缓急敛散**（甘缓急、酸敛散），不是"生阴液"。
