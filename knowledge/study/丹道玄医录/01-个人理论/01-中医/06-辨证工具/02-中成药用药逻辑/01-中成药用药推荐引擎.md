## 一、引擎架构

```
用户输入（症状/主诉）
    ↓
① 证型识别（六经+五脏+专科）
    ↓
② 映射表查找（63证→333中成药）
    ↓
③ 安全校验（禁忌/毒性/特殊人群）
    ↓
④ 加权评分排序（症状匹配40% + 经典30% + 安全20% + 经济10%）
    ↓
⑤ 输出推荐队列 + 用药指导
```

## 三、安全校验规则

### 3.1 毒性药品分级
| 等级 | 药品（示例） | 处理方式 |
|------|------------|---------|
| 🔴 禁用 | 马钱子、斑蝥、蟾酥、雄黄（长期） | 仅信息展示，不做推荐 |
| 🟡 慎用 | 附子、细辛、半夏、大黄 | 标注慎用，提示遵医嘱 |
| 🟢 安全 | 绝大多数中成药 | 正常推荐 |

### 3.2 特殊人群过滤
- **孕妇**：自动过滤妊娠禁忌药（麝香、牛黄、红花、桃仁、大黄、附子等）
- **儿童**：过滤毒性药，标注用量减半
- **老年/肝肾功能不全**：过滤含重金属/毒性药（雄黄、朱砂、铅丹）

## 四、加权评分体系

```python
def calculate_score(prescription, user_symptoms, diagnosis):
    """
    综合评分 = 症状匹配×40% + 经典程度×30% + 安全性×20% + 经济性×10%
    """
    
    # 1. 症状匹配度（0-1）
    symptom_match = calculate_symptom_match(prescription['主治'], user_symptoms)
    
    # 2. 经典程度（0-1）
    # 经方来源/临床指南推荐 → 0.9-1.0
    # 常用中成药 → 0.7-0.8
    # 新近制剂 → 0.5-0.6
    classic_score = get_classic_score(prescription['来源'])
    
    # 3. 安全性（0-1）
    safety_score = {'绿': 1.0, '黄': 0.7, '红': 0.0}[prescription['安全性']]
    
    # 4. 经济性（0-1）
    economic_score = get_economic_score(prescription['医保分类'])
    
    total = (symptom_match * 0.4 + 
             classic_score * 0.3 + 
             safety_score * 0.2 + 
             economic_score * 0.1)
    
    return total
```

## 九、设计原则

1. **经方为体，中成药为用**：经方对证优先，中成药补位（经方无对应、需长期调理、患者偏好时）
2. **安全为首**：峻药必标禁忌，急重症转诊建议
3. **经济实用**：优先平价经方/中成药
4. **高效精准**：疗程明确，7-14日复评
5. **标注免责**：所有建议标注"AI辅助参考，不替代执业医师面诊"
