## 二、特殊成分清单

### 2.1 剧毒成分（禁止推荐）
- **马钱子**：马钱子含量>0.2g可能致死
- **斑蝥**：含斑蝥素，治疗窗窄
- **蟾酥**：含强心苷，过量致心律失常
- **川乌/草乌**：含乌头碱，0.2mg可致中毒
- **巴豆**：含巴豆油，峻下逐水

### 2.2 含重金属成分
- **朱砂**（HgS）：安宫牛黄丸、天王补心丸等，不宜长期服用
- **雄黄**（As₂S₂）：牛黄解毒丸、西黄丸，不宜久服
- **轻粉**（HgCl）：舟车丸、生肌玉红膏，外用为主

### 2.3 孕妇禁忌成分
| 成分 | 禁忌等级 | 含此成分的中成药 |
|------|----------|------------------|
| 麝香 | 绝对禁忌 | 西黄丸、马应龙麝香痔疮膏、麝香祛痛搽剂 |
| 斑蝥 | 绝对禁忌 | 癣湿药水、复方斑蝥胶囊 |
| 水蛭 | 绝对禁忌 | 通心络胶囊、脑心通胶囊 |
| 三棱/莪术 | 相对禁忌 | 痛经宝颗粒、大黄䗪虫丸 |

## 三、安全校验流程

### 3.1 推荐前校验（Pre-Recommendation）

```
输入：候选药品列表 + 患者信息
    ↓
1. 毒性过滤
   ├─ 患者为儿童（<12岁）→ 过滤所有含毒性成分药品
   ├─ 患者肝功能不全 → 过滤含朱砂、雄黄药品
   ├─ 患者肾功能不全 → 过滤含大黄、芒硝药品
   └─ 患者为孕妇 → 过滤所有孕妇禁忌药品
    ↓
2. 剂量提示
   ├─ 含附子 → 标注"含附子，需控制剂量"
   ├─ 含细辛 → 标注"含细辛，日用量不宜过大"
   └─ 含朱砂/雄黄 → 标注"含重金属，不宜连续服用超过7天"
    ↓
3. 禁忌症匹配
   └─ 将药品禁忌与患者已知症状/疾病交叉验证
```

### 3.2 推荐后校验（Post-Recommendation）

```
推荐结果
    ↓
1. 配伍禁忌检查
   ├─ 含十八反/十九畏成分的中成药
   ├─ 多药联用时的重复成分
   └─ 含毒性成分的多药联用
    ↓
2. 服用时长提示
   ├─ 含朱砂/雄黄 → "连续服用不超过7天"
   ├─ 含附子/川乌 → "服用后如有口舌麻木立即停药"
   └─ 一般药品 → "建议服用7天后复诊评估"
    ↓
3. 最终输出
   └─ 标注所有安全警示
```

## 五、临床使用规则

### 5.1 儿童用药（<12岁）
- 🔴 禁止推荐：含剧毒、有毒成分的中成药
- 🟠 限制使用：含细辛（日用量≤3g）、附子（日用量≤15g，先煎）的中成药
- 🟢 安全推荐：以药食同源为主的平和方剂
- 剂量：按体重折算（通常为成人1/3-1/2）

### 5.2 老年人用药（>65岁）
- 肝功能减退：优先选择不含朱砂、雄黄的中成药
- 肾功能减退：注意含大黄、芒硝等泻下药品的剂量
- 多病共存：注意药物相互作用，优先单药治疗

### 5.3 肝肾功能不全
- **肝功能不全**：禁用含朱砂、雄黄、马钱子、斑蝥的中成药
- **肾功能不全**：慎用含大黄、芒硝、甘遂、大戟的峻下逐水药
- 用药期间需定期监测肝肾功能

### 5.4 孕妇用药
- 🔴 绝对禁用：含麝香、斑蝥、巴豆、水蛭、虻虫、三棱、莪术的中成药
- ⚠️ 慎用：含红花、桃仁、冰片、牛黄的中成药
- 🟢 优先选择：药性平和、经方加减的方剂
- 所有含特殊成分的中成药需标注"孕妇需医师评估后使用"

## 六、用药时长限制

| 含毒性成分 | 建议最长连续服用 | 说明 |
|------------|------------------|------|
| 朱砂/雄黄 | 7天 | 重金属蓄积风险 |
| 附子/川乌 | 14天 | 乌头碱蓄积风险 |
| 细辛 | 14天 | 含黄樟素 |
| 大黄 | 30天 | 长期使用致结肠黑变病 |
| 含蟾酥 | 7天 | 强心苷蓄积风险 |
| 含马钱子 | 7天 | 士的宁蓄积风险 |
| 一般中成药 | 30天 | 建议定期复诊评估 |
