## 一、整体架构：三阶用药决策链

```
辨证结果（证型）
    ↓ ① 辨证-功效映射
功效分类筛选
    ↓ ② 证型-药品精确匹配
候选药品队列
    ↓ ③ 安全校验 + 优选排序
最终推荐方案
```

### 核心原则
1. **经方优先**：六经辨证匹配经方者，优先用经方（180首），不用中成药
2. **中成药补位**：经方无对应、或需长期调理、或患者偏好中成药时，用中成药替代/补充
3. **安全红线**：孕妇、儿童、肝肾功能不全者，自动过滤含毒烈成分药物

## 三、证型-药品精确匹配（第②阶）

### 3.1 核心匹配引擎

对每个辨证输出（证型→功效分类），在中成药数据库中执行三层筛选：

#### 层1：功效分类硬匹配
```
WHERE 功效分类 = 证型对应功效分类
```

#### 层2：主治症状语义匹配
```
WHERE 主治/适应症 CONTAINS 证型症状关键词
```

#### 层3：成分-病机逆向验证
```
检查药品成分是否覆盖证型所需药性：
- 证型需温 → 药品应含温性药（附子、干姜、肉桂等）
- 证型需清 → 药品应含清热药（黄连、黄芩、金银花等）
- 证型需补 → 药品应含补益药（人参、黄芪、熟地等）
```

### 3.2 科室自动过滤

辨证结果含科室信息时（如"妇科月经不调"），自动限制匹配范围至对应科室的中成药。

## 四、安全校验规则（第③阶）

### 4.1 绝对禁忌（自动排除）

| 患者特征 | 自动过滤类别 |
|---------|------------|
| 孕妇 | 含麝香、三棱、莪术、水蛭、虻虫、斑蝥、大戟、芫花、甘遂、轻粉、蟾酥等 |
| 儿童（<6岁） | 含朱砂、雄黄、马钱子、川乌、草乌等矿物/毒性药 |
| 肝肾功能不全 | 含马钱子粉、朱砂、雄黄、制川乌、制草乌等 |
| 高血压/心脏病 | 含麻黄、甘草（大量）、附子等 |
| 驾驶员/高空作业 | 含马来酸氯苯那敏等抗组胺药 |

### 4.2 相对禁忌（需标注警示）

| 禁忌类型 | 标注方式 |
|---------|---------|
| 证型禁忌（如风寒感冒用清凉药） | ⚠️ 红色标注，说明不匹配原因 |
| 饮食禁忌（如忌辛辣、忌茶） | 📋 黄色标注，附注意事项 |
| 相互作用（多药联用） | 🔔 蓝色标注，提示潜在相互作用 |
| 疗程限制（不可久服） | ⏳ 提示最大疗程 |

### 4.3 成分毒性分级

| 等级 | 成分示例 | 用药规则 |
|-----|---------|---------|
| 🔴 剧毒 | 蟾酥、斑蝥、马钱子、川乌、草乌 | 仅限专科医师使用，AI仅提示不可自行服用 |
| 🟡 有毒 | 朱砂、雄黄、轻粉、苦杏仁（过量） | 标注"不可过量久服"，建议疗程≤7天 |
| 🟢 无毒 | 绝大部分中成药 | 正常推荐 |

## 五、优选排序策略

当候选药品>3首时，按以下优先级排序：

### 5.1 排序权重

```
排序得分 = 症状匹配度 × 0.4 + 经典程度 × 0.3 + 安全性 × 0.2 + 经济性 × 0.1
```

| 维度 | 评分标准 |
|-----|---------|
| 症状匹配度 | 主治中直接包含证型主症者得1.0，部分包含得0.6，无关得0.2 |
| 经典程度 | 出自《中国药典》/国家基药目录/临床指南推荐者得1.0，一般药品得0.6 |
| 安全性 | 无毒/无毒烈成分得1.0，含小毒得0.7，含大毒得0.2 |
| 经济性 | 基药/平价药得1.0，贵细药得0.6 |

### 5.2 推荐输出格式

```
【首选推荐】
药品：XX胶囊
依据：主治直接覆盖证型主症，药典收录
用法：××次/日，××粒/次，疗程7-14日
注意：⚠️ 孕妇禁用，服药期间忌生冷

【备选1】
药品：XX丸
依据：功效相符，主治部分覆盖
注意：脾胃虚寒者慎用

【备选2】
药品：XX口服液
依据：功效相符
注意：含乙醇，服药后不得驾驶
```

## 七、中成药用药决策流程图

```
输入：患者四诊信息
    ↓
辨证引擎：输出证型（六经 + 五脏 + 病机）
    ↓
判断：是否有经方对应？
    ├─ 有 → 推荐经方（180首标准集）
    └─ 无 → 进入中成药推荐
         ↓
    功效分类映射：证型 → 功效分类列表
         ↓
    中层筛选：功效分类匹配 + 科室过滤
         ↓
    深层筛选：症状语义匹配 + 成分病机验证
         ↓
    安全校验：禁忌过滤 + 毒性分级
         ↓
    优选排序：多维度加权排序
         ↓
    输出：推荐方案（含首选+备选+注意事项+疗程）
```

## 八、用药禁忌红线清单

### AI不可自行推荐（必须建议就医）

1. 急重症：高热昏迷、胸痛剧烈、呼吸困难、大出血
2. 孕妇用药：含妊娠禁忌成分的中成药
3. 毒性药：含马钱子、斑蝥、蟾酥等
4. 多药联用：≥3种中成药同时使用（需药师审核）
5. 慢性病患者长期用药：需医师定期评估

### AI推荐限制

- 中成药推荐仅限**轻症、常见病、慢性病调理**
- 所有推荐标注：**"AI辅助参考，不替代执业医师面诊"**
- 含毒烈成分药品仅做信息展示，不做推荐

## 附：与经方的关系定位

| 层级 | 内容 | 适用场景 |
|-----|------|---------|
| 第一层 | 经方（180首） | 六经辨证明确，经方对证 |
| 第二层 | 中成药 | 经方无对应、需长期调理、患者偏好 |
| 第三层 | 食疗/外治 | 轻症调理、辅助治疗 |

**核心原则：经方为体，中成药为用。经方对证优先，中成药补位。**
