## 二、辨证分析

### 2.1 症候群归类

| 症候 | 定位 | 病机 | 权重 |
|:----|:----:|:-----|:----:|
| 暴食加重 → 腰部胀满疼痛 | 脾胃·中焦 | 暴伤脾 → 运化失司 → 气机壅滞 → 胀满 | ⭐⭐⭐ |
| 舌中裂纹 | 脾胃·阴分 | 脾阴不足，气不化津，舌失濡养 | ⭐⭐⭐ |
| 耳聋 | 脾·清阳不升 / 肾·窍失养 | 李东垣"脾不及则九窍不通" | ⭐⭐ |
| 大便干结 | 脾胃·津亏气滞 | 脾气虚不布津 → 肠道失濡 | ⭐⭐ |
| 六脉细紧 → 脾脉沉紧 | 太阴·里寒 | 初诊浮泛 → 复诊真相显露 | ⭐⭐⭐ |

### 2.2 核心病机

> **太阴脾阳虚寒为本，阴津枯涸为标，清阳不升为变**

- **本**：太阴虚寒（脾脉沉紧、暴食加重→脾不运化）
- **标**：脾阴不足（舌中裂纹）、津亏肠燥（大便干结）
- **变**：清阳不升（耳聋）

### 2.3 六经定位

**太阴病（主）→ 涉及少阴（肾窍开于耳）+ 阳明（大便干结）**

> 太阴之腑寒凝不收，故脾脉沉紧；太阴之宫阴津枯涸，故舌裂便干——**寒热错杂于太阴，非纯虚纯实也**。

## 三、初诊处方批评

**黄芪桂枝五物汤 ± 辨证思考的有误之处**

| 维度 | 初诊判断 | 实际证情 | 偏差 |
|:----|:--------|:---------|:----|
| 病位 | 表·血痹（桂枝汤结构走表） | **里·太阴脾**（脾脉沉紧） | ❌ 偏向表浅 |
| 病性 | 气虚营卫不和 | 里虚寒为主 + 阴津不足 | ❌ 遗漏阴伤 |
| 温中 | 生姜（走表散寒） | 须干姜（入里温中） | ❌ 温不达里 |
| 养阴 | ❌ 无对应药物 | 须麦冬/麻仁等 | ❌ 完全未顾及 |
| 升清 | ❌ 无对应药物 | 须升麻/葛根 | ❌ 完全未顾及 |
| 通便 | ❌ 无对应药物 | 须润肠 | ❌ 完全未顾及 |

> 初诊以**桂枝汤法**治里证，犹射箭而靶移也。

### 复诊脉象揭示真相

**六脉细紧 → 脾脉沉紧**——此变化为大关键。

初诊芪桂走表后，全身浮泛之象（六脉紧）稍缓，但**太阴脾脏的本寒**反而暴露出来（脾脉沉紧）。好比撤去草席露出地上的寒冰——**病根在脾，从未动摇**。

## 四、汐儿处方 · 温中养阴升清方

### 4.1 方药组成

| 药组 | 药物 | 剂量 | 作用 | 六经/五脏靶向 |
|:----|:----|::---:|:-----|:-------------|
| **温中散寒**（理中法） | 干姜 | 10g | 温太阴脾寒 | **太阴·脏寒** |
| | 党参 | 15g | 补脾益气 | **太阴·气虚** |
| | 白术 | 15g | 健脾燥湿 | **太阴·湿困** |
| **温阳通脉**（建中法） | 黄芪 | 30g | 补气升阳 | **太阴·清阳** |
| | 桂枝 | 10g | 温通经脉 | **太阴·经脉** |
| | 大枣 | 5枚 | 补脾和营 | **太阴·气血** |
| **缓急养阴**（芍药甘草法） | 白芍 | **20g** | 养阴缓急止痛 | **太阴·阴分** |
| | 炙甘草 | **10g** | 补中和诸药 | **中宫·调和** |
| **升举清阳**（益气聪明法） | 升麻 | 6g | 升阳明之清气 | **脾·清阳** |
| | 葛根 | **15g** | 升阳生津（舌裂便干双效） | **脾·津液** |
| **润燥通便** | 麦冬 | 15g | 养肺阴以生脾胃之津（培土生金） | **肺·润燥** |
| | 火麻仁 | 15g | 润肠通便而不伤正 | **大肠·津亏** |

### 4.2 全方结构

```
理中法（干姜+党参+白术） ← 温中散寒，治太阴本寒
       ↓
建中法（黄芪+桂枝+芍药+大枣+甘草） ← 温阳通脉，取原方合理之处
       ↓
芍药甘草（大剂芍药） ← 缓急止痛、养阴增液
       ↓
升阳法（升麻+葛根） ← 升清治耳聋
       ↓
润燥法（麦冬+麻仁） ← 润肠治便干、生津治舌裂
```

## 六、按语

此案最值得玩味之处在于**初诊与复诊脉象的变化**。六脉细紧而初按芪桂，表象略有松动，反露出脾脉沉紧之本寒。这与《金匮辨证玉册》天轨传变篇中"太阳之邪误汗则入太阴"之理暗合——虽此案非外感，但芪桂走表不达里，**药不对病位则真气外越，寒气更深一层暴露**。

太阴为三阴之首，脾阳虚寒一旦明确，不可再用走表之药耽误。理中法为核心，辅以养阴升清，方为周全。
