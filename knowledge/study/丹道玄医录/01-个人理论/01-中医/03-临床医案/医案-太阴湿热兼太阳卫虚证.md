## 三、综合辨证

### 病机链条

```
脾虚（本）→ 湿浊内生 → 湿郁化热（苔厚腻黄）→ 湿热下注大肠（大便粘滞稀溏）
                                  ↓
                        卫气生化不足 → 表阳不固（怕风怕冷、易感冒）
```

### 八纲归纳

| 纲目 | 辨证 | 依据 |
|:----|:-----|:------|
| **表里** | 表里同病 | 表有怕风怕冷（表虚），里有便溏苔腻（里湿） |
| **寒热** | 外寒内热 | 外怕冷（寒象），苔厚腻黄（湿热） |
| **虚实** | 本虚标实 | 脾虚卫弱为本（虚），湿热内蕴为标（实） |
| **阴阳** | 阳虚湿阻 | 怕冷怕风为阳虚，苔腻便溏为湿阻 |

### 核心病机

> **脾虚湿热内蕴（太阴） + 卫阳不固于表（太阳）——太少合病，湿热互结**

## 四、治法与处方

### 治则

> 温阳固表治其标 + 辛开苦降治其本 —— 内伤外感双规并行

### 主方：附子桂枝汤合半夏泻心汤化裁

| 药组 | 药物及用量 | 作用 | 归属线 |
|:----|:-----------|:-----|:------|
| **温阳固表** | 制附子6g（先煎）、桂枝10g、白芍10g | 温少阴、固太阳、和营卫 | 🌬️ **外感线** |
| **辛开苦降** | 法半夏12g、黄连6g、黄芩10g、干姜6g | 开中焦痞结、清湿热 | 🔍 **内伤线** |
| **健脾益气** | 党参15g、炙甘草6g、大枣5枚 | 顾护中气，正邪兼顾 | 🔍 **内伤线** |
| **加味化湿** | 苍术12g、茯苓20g | 增强化湿之力，针对苔厚腻 | 🔍 **内伤线** |
| **加味升清** | 葛根20g | 升清止泻，兼清阳明热 | 🔍 **内伤线** |

**煎服法**：每日1剂，水煎400ml，分早晚饭后温服。

### 关键配伍解析

1. **附子+黄连** — 寒热配伍精髓：附子温阳不助热，黄连清热不伤阳
2. **桂枝+白芍** — 调和营卫的经典对药
3. **干姜+黄连+黄芩** — 辛开苦降核心组合
4. **苍术+茯苓** — 强化燥湿健脾

### 加减法

| 兼证 | 加减 |
|:-----|:-----|
| 怕冷甚、手足不温 | 加**炮附子增至10g** → 温少阴之阳 |
| 便溏次数多、腹痛 | 加**白芍增至15g、乌梅10g** → 缓急止泻 |
| 苔黄厚腻明显、口苦 | 加**茵陈15g、栀子6g** → 加强清热利湿 |
| 纳差、饭后腹胀 | 加**砂仁6g（后下）、神曲10g** → 理气消食 |

## 七、生活调摄建议

1. **饮食**：忌生冷、油腻、甜食、奶制品——助湿生热
2. **宜食**：薏仁粥、山药、冬瓜、赤小豆、白扁豆——健脾化湿
3. **艾灸**：每日巳时（9-11点）艾灸足三里+关元各15分钟
4. **避风**：出汗后及时擦干，后颈大椎穴注意保暖
