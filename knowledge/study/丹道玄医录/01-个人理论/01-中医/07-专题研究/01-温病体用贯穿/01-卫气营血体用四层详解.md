# 卷一·卫气营血体用四层详解

> **体系**：丹道玄医录·体用双轨  
> **核心命题**：卫气营血 = 体用四层演进模型  
> **标签**：`#卫气营血` `#体用四层` `#叶天士` `#温病辨证`

---

## 凡例：体用四层的根本逻辑

卫气营血不是四个独立的证型，而是**病邪从「用」层面逐步侵及「体」层面的四个连续阶段**。

- **卫分** = 用之表（功能失调的初始阶段）
- **气分** = 用之里（功能亢盛的极盛阶段）
- **营分** = 体之浅（形质受损的初始阶段）
- **血分** = 体之深（形质受损的极盛阶段）

> **诊断意义**：辨别在卫在气还是在营在血，本质是判断"病在体还是在用，体伤有多深"。
> **治疗意义**：在卫在气只需调"用"，在营在血必须兼顾补"体"。

---

## 一、卫分证——用之表

### 1.1 体用定位

| 维度 | 内容 |
|:----|:------|
| **体用层次** | **用之表**——卫气（人体最表层的防御功能）失调 |
| **河图对应** | 坎水（卫气属水·行于脉外） |
| **病机本质** | 用的开阖失常——该开不开则无汗（表闭），该阖不阖则有汗（表虚） |
| **体是否伤** | ❌ 体未伤——津液尚充，形质无损 |

### 1.2 症状的体用分析

| 症状 | 体用解释 |
|:----|:---------|
| 发热 | 用之郁——卫气被遏，郁而化热 |
| 恶寒 | 用之闭——卫气不能温分肉 |
| 无汗 | 用之不开——卫气开阖功能失调 |
| 有汗 | 用之不阖——卫气固摄功能失调 |
| 口微渴 | 用之津液输布障碍——非体之阴伤 |
| 脉浮 | 用之向外——气血趋向于表 |

### 1.3 治法的体用逻辑

**叶天士："在卫汗之"**

| 治法 | 体用解释 |
|:----|:---------|
| 辛开腠理 | 复用辛开——恢复卫气之开阖功能 |
| 透热外出 | 给邪以出路——不让郁热从"用"层面转入"体"层面 |
| 不可早用寒凉 | 寒凉直接降"用"——过早用会抑制卫气开阖，反而闭门留寇 |

**体用公式**：卫分 = 用失调 → 治用不治体 → 辛开复用

---

## 二、气分证——用之里

### 2.1 体用定位

| 维度 | 内容 |
|:----|:------|
| **体用层次** | **用之里**——气（全身脏腑功能活动）过于亢盛 |
| **河图对应** | 离火（气属火·行于脉中） |
| **病机本质** | 用的太过——功能亢进导致产热过度 |
| **体是否伤** | ⚠️ 体未重伤——但津液已开始被消耗，口渴便是信号 |

### 2.2 症状的体用分析

| 症状 | 体用解释 |
|:----|:---------|
| 壮热（大热） | 用之太过——气机亢盛至极 |
| 大汗 | 用之开太过——卫气开阖功能过度开放 |
| 大渴 | 体始耗——津液被热消耗，但体仍可自我补充 |
| 脉洪大 | 用之极度向外——气血奔涌于表 |
| 面赤 | 用之炎上——火热之气上冲 |

### 2.3 治法的体用逻辑

**叶天士："到气清气"**

| 治法 | 体用解释 |
|:----|:---------|
| 苦寒清气 | 苦体克热 + 寒用制亢 = 体用双重降热 |
| 辛寒清气（石膏） | 辛（体）开腠理+寒（用）降热 = 给热出路+降温 |
| 甘寒生津（口渴时） | 甘体补阴 + 寒用清热 = 体用兼顾（已开始保护体） |

**体用公式**：气分 = 用太过 → 清用为主 → 辅以保体（甘寒生津）

### 2.4 气分证的转折意义

气分证是温病治疗中**最关键的转折点**：

```
气分（用太过·体未伤）→ 正确清用 → 邪退正复 ✅
气分（用太过·体未伤）→ 失治误治 → 体伤入营 ❌
```

**体用意义**：在气分阶段正确清"用"，是阻断传变的关键。一旦体伤（入营），治疗难度大幅上升。

## 三、营分证——体之浅

### 3.1 体用定位

| 维度 | 内容 |
|:----|:------|
| **体用层次** | **体之浅**——营阴（津液中较清稀的部分）开始被耗损 |
| **河图对应** | 离→兑（从火到金——热极将伤阴） |
| **病机本质** | 体的轻度损伤——阴液被热灼，但尚未伤及血分 |
| **体是否伤** | ✅ 体始伤——津液不足，阴分已亏 |

### 3.2 症状的体用分析

| 症状 | 体用解释 |
|:----|:---------|
| 身热夜甚 | 用仍有余 + 体已不足——入夜阴气当令，体虚则热更显 |
| 心烦谵语 | 体伤及神——心阴不足，心不藏神（五脏藏神体系） |
| 斑疹隐隐 | 体伤显于外——营阴不足，血络失养 |
| 舌红绛 | 体之血色外露——阴不敛阳 |
| 脉细数 | 体不足（细） + 用有余（数） |

### 3.3 治法的体用逻辑——核心：透热转气

**叶天士："入营犹可透热转气"**

这是温病治法中最具体用深意的一句——为什么入营了还能"透热转气"？

| 体用解释 | 内容 |
|:---------|:------|
| **营分体伤不深** | 只是体之浅伤（津液层面），未及血分之深 |
| **用层面尚有通路** | 虽然体已伤，但用的通道未被完全堵死 |
| **透热转气** | 通过辛味（体·开）打开用的通道，让营分之热重新回到气分排出 |

**体用公式**：营分 = 体始伤 + 用有余 → 透热转气 = 复用通道 + 清用余热 + 甘补阴体

**透热转气的体用三步骤**：
```
① 辛开（用）→ 打开营热外达的通道
② 苦寒（体用）→ 清解已透出之热
③ 甘寒（体）→ 补充已耗之阴液
```

## 四、血分证——体之深

### 4.1 体用定位

| 维度 | 内容 |
|:----|:------|
| **体用层次** | **体之深**——血（人体最深的营养物质）被热灼、被迫妄行 |
| **河图对应** | 坎水（血属水·藏于肝·行于脉中）受离火煎熬 |
| **病机本质** | 体的重伤——血热、血瘀、血溢、动风 |
| **体是否伤** | ✅ 体重伤——血的质（热毒）和量（耗损）均严重受损 |

### 4.2 症状的体用分析

| 症状 | 体用解释 |
|:----|:---------|
| 吐血/衄血/便血/发斑 | 体失其位——血热迫血妄行，体不能守位 |
| 抽搐/角弓反张 | 体用俱乱——血不养筋（体）+ 肝风内动（用失控） |
| 神昏/深度昏迷 | 体伤及神——心不藏神（体重伤导致神无所依） |
| 舌深绛/紫暗 | 体之血色呈瘀——热入血分，血行不畅 |
| 脉细数/促 | 体极不足（细）+ 用极亢（数/促） |

### 4.3 治法的体用逻辑

**叶天士："入血就恐耗血动血，直须凉血散血"**

| 治法 | 体用解释 |
|:----|:---------|
| **凉血** | 寒用降血热 + 咸体入血分——直接降血分之用的太过 |
| **散血** | 辛体散血瘀——血分证不仅有热，还有瘀（热迫血凝） |
| **补阴** | 甘体补阴——血分已重伤，必须补体才能复其用 |

**体用公式**：血分 = 体重伤 + 用失控 → 凉血散血 + 补阴复体

### 4.4 血分证的三种体用模式

| 模式 | 体偏 | 用偏 | 治法侧重 |
|:----|:----|:----|:---------|
| 热迫血妄行 | 血体被热破 | 血用失控妄行 | 凉血为主（降用） |
| 热毒瘀互结 | 血体凝滞 | 热用仍亢 | 散血+凉血并重 |
| 阴虚动风 | 血体极亏 | 肝用化风 | 补体为主（酸甘化阴熄风） |

## 五、四层的体用鉴别要点

| 鉴别点 | 卫分（用之表） | 气分（用之里） | 营分（体之浅） | 血分（体之深） |
|:------|:------------|:-------------|:-------------|:-------------|
| **体伤程度** | 无 | 无/微 | 轻 | 重 |
| **用偏状态** | 失调（不开/不阖） | 太过（亢盛） | 有余（余热未清） | 失控（妄行/化风） |
| **治法核心** | 复用开 | 清用+保体 | 透热转气+补体 | 凉血+补体+熄风 |
| **用药体用比** | 用100% | 用80%+体20% | 用50%+体50% | 用30%+体70% |
| **预后** | 极好 | 好 | 尚可 | 差（需长期调理） |

## 六、九转坐标定位

卫气营血四层的九维坐标（统一编码，便于九转引擎调用）：

| 概念 | 一转生数 | 二转成数 | 三转洛书 | 四转变位 | 五转阴阳 | 六转三才 | 七转四象 | 八转八卦 | 九转归元 |
|:----|:-------:|:-------:|:--------:|:--------:|:--------:|:--------:|:--------:|:--------:|:--------:|
| **卫分** | 1 | 6 | 1坎 | +1 | -0.1~+0.1 | 0.8（天） | 0（太阳） | 4震 | 0.8（初） |
| **气分** | 2 | 7 | 9离 | +3 | +0.5~+0.8 | 0.6（人） | 1（少阴） | 9离 | 0.5（中-前） |
| **营分** | 4 | 9 | 2坤 | -1 | -0.3~-0.5 | 0.4（地之浅） | 2（太阴） | 2坤 | 0.3（中-后） |
| **血分** | 5 | 10 | 8艮 | -3 | -0.6~-0.8 | 0.2（地之深） | 3（厥阴） | 8艮 | 0.1（末） |

**坐标解读**：
- 卫分（1/6/1坎）→ 气分（2/7/9离）：生数从1→2（用从初始到亢盛），洛书从坎→离（水→火）
- 营分（4/9/2坤）→ 血分（5/10/8艮）：生数从4→5（体从金到土），八卦从坤→艮（地之深浅）
- **四转（偏位）从+1→+3→-1→-3**：卫气在阳位偏，营血在阴位偏——验证了"卫气为用属阳，营血为体属阴"
