## 一、为什么需要「六经体用」？

### 1.1 丹道玄医录体系中的逻辑缺口

丹道玄医录目前已有两大体用体系完整成型：

| 体系 | 覆盖范围 | 核心公理 | 完成度 |
|:----|:---------|:---------|:------:|
| 🏛️ **河图五脏体用** | 五脏·五味·体用补泄 | 单用为泄，兼甘为补 | ✅ 成熟 |
| 🌡️ **温病学体用** | 四气为用·五味为体·卫气营血四层 | 四气=用，五味=体 | ✅ 已打通 |
| 🔲 **伤寒六经体用** | 六经·气机·体用编码 | ❌ 尚未定义 | ❌ **空缺** |

五脏体用管的是「精血形质」——治的是**慢病虚证**的核心。温病体用管的是「气机亢变」——治的是**急性热证**的核心。但伤寒论治的是**外感病从表入里的全过程**——它既管气机（太阳·少阳的开阖枢），也管形质（太阴·少阴的精血），还管寒热错杂（厥阴的阴阳交争）。

**五脏体用和温病体用之间，缺少一座桥——这座桥就是六经体用。**

### 1.2 六经体用回答了什么问题

| 问题 | 旧回答 | 六经体用回答 |
|:----|:-------|:------------|
| 太阳病为什么用桂枝汤？ | "调和营卫" | 太阳之体在营，太阳之用在卫；营虚则体弱，卫郁则用滞 → 辛酸开阖复其体用 |
| 阳明病为什么用承气汤？ | "泻下热结" | 阳明之体在津液，阳明之用在通降；津枯则体竭，燥结则用闭 → 辛咸化滞通其用、苦甘化咸复其体 |
| 少阳病为什么用小柴胡汤？ | "和解少阳" | 少阳之体在胆液，少阳之用在枢转；胆液枯则体不柔，枢机郁则用不转 → 酸苦清泄复其体，辛甘化苦助其用 |
| 太阴病为什么用理中汤？ | "温中散寒" | 太阴之体在营血，太阴之用在运化；营血寒则体不温，运化滞则用不运 → 甘辛化苦复其体用 |
| 少阴病为什么有寒化热化两极？ | "心肾阳衰vs阴虚火旺" | 少阴之体在精血（君火以明），少阴之用在气化（君火以位）；精血竭则体不藏（热化），气化绝则用不彰（寒化） |
| 厥阴病为什么寒热错杂？ | "阴极阳生，阴阳混淆" | 厥阴之体在肝血，厥阴之用在疏泄；体阴而用阳，体寒则血凝，用亢则风动 → 寒热并用的体用本质 |

## 二、六经体用的底层定义

### 2.1 核心公式

> **六经 = 六种体用偏向的气机通道**

每条经的「体」是什么？不是经络本身，是**该经所主之气/血/津/液/精的物质基础**。
每条经的「用」是什么？不是功能描述，是**该经的气化运动方向（开/阖/枢）**。

| 六经 | 体（物质基础） | 用（气化运动） | 三才 | 河图成数 | 洛书穿行 |
|:----|:-------------|:-------------|:----:|:--------:|:--------:|
| **太阳** ☀️ | 营血·津液（体阴） | 卫气·开散（用阳） | 天·寒水 | 一六共宗 | 坎一→乾六 |
| **阳明** 🌾 | 津液·糟粕（体阴） | 通降·阖收（用阳） | 地·燥金 | 四九为友 | 巽四→离九 |
| **少阳** 🌬️ | 胆液·相火（体阴中阳） | 枢转·出入（用半表半里） | 人·相火 | 二七同道 | 坤二→兑七 |
| **太阴** 🌍 | 营血·精气（体阴） | 运化·升清（用阳） | 地·湿土 | 五十同途 | 中宫 |
| **少阴** 💧 | 精血·真阴（体阴） | 君火·藏照（用阳中阴） | 天·君火 | 二（先天） | 坤二 |
| **厥阴** 🌿 | 肝血·阴精（体阴） | 疏泄·生发（用阳中阳） | 人·风木 | 三八为朋 | 震三→艮八 |

### 2.2 体用的两层内涵

#### 第一层：经体·经用（经脉层面的体用）

每条经有自己的「经体」和「经用」：

```
      经体（物质基础）           经用（气化运动）
    ┌────────────────┐        ┌────────────────┐
    │ 太阳·营血津液  │        │ 太阳·卫气开散  │
    │ 阳明·津液糟粕  │        │ 阳明·通降阖收  │
    │ 少阳·胆液相火  │        │ 少阳·枢转出入  │
    │ 太阴·营血精气  │        │ 太阴·运化升清  │
    │ 少阴·精血真阴  │        │ 少阴·君火藏照  │
    │ 厥阴·肝血阴精  │        │ 厥阴·疏泄生发  │
    └────────────────┘        └────────────────┘
```

#### 第二层：体病·用病（病理层面的体用失衡）

每条经的病态表现为「体病」或「用病」或「体用皆病」：

```
经体病 → 物质不足（虚/枯/竭）→ 补其体
经用病 → 功能失常（郁/亢/闭）→ 调其用
体用皆病 → 既虚且郁 → 先通后补 或 通补兼施
```

## 三、六经体用与五脏体用的对接

### 3.1 对接原理

六经是**气机通道**，五脏是**精血仓库**。六经体用管的是「通道状态」，五脏体用管的是「仓库储量」。

```
六经体用（通道）                   五脏体用（仓库）
┌───────────────────┐            ┌───────────────────┐
│ 太阳经↔通表卫    │ ←→ 气化 → │ 肺（宣发）        │
│ 阳明经↔通燥结    │ ←→ 气化 → │ 大肠·胃（传化）  │
│ 少阳经↔通枢机    │ ←→ 气化 → │ 胆·三焦（决断）  │
│ 太阴经↔通运化    │ ←→ 气化 → │ 脾（运化）        │
│ 少阴经↔通心肾    │ ←→ 气化 → │ 心·肾（神明·藏精）│
│ 厥阴经↔通肝血    │ ←→ 气化 → │ 肝·心包（藏血·臣使）│
└───────────────────┘            └───────────────────┘
```

**对接规则**：
- 六经「开路」→ 五脏「填补」→ 六经开路在前，五脏填补在后
- 六经「用病」为主 → 优先调六经（如：太阳用病→桂枝汤调卫）
- 五脏「体病」为主 → 优先补五脏（如：少阴体病→六味地黄补肾精）
- 六经与五脏同病 → 先开六经之路，再补五脏之体

### 3.2 六经体用失衡的五脏映射

| 六经体用失衡 | 症状表现 | 对应的五脏体用问题 | 治法 |
|:------------|:---------|:-----------------|:----|
| 太阳体虚（营弱） | 汗自出、恶风、脉浮缓 | 肺宣发太弱（肺体虚） | 桂枝汤辛酸化甘→助肺宣发 |
| 太阳用郁（卫强） | 无汗、恶寒、脉浮紧 | 肺宣发被郁（肺用滞） | 麻黄汤辛开→开肺郁 |
| 阳明体枯（津竭） | 大便硬、口渴、舌燥 | 胃体阴亏（胃阴虚） | 增液汤/白虎加人参汤→养胃体 |
| 阳明用闭（燥结） | 腹满痛、潮热、谵语 | 胃用不降（胃气不降） | 承气汤辛咸化滞→通胃用 |
| 少阳体郁（胆郁） | 口苦、咽干、目眩 | 胆体郁滞（胆汁不利） | 小柴胡汤酸苦→清胆体 |
| 少阳用滞（枢机不利） | 寒热往来、胸胁苦满 | 三焦用不枢（气机不畅） | 小柴胡汤辛甘化苦→助枢转 |
| 太阴体寒（血寒） | 腹满、食不下、自利 | 脾体阳虚（脾阳不足） | 理中汤甘辛化苦→温脾体 |
| 太阴用滞（湿困） | 腹满、呕吐、下利 | 脾用不运（湿困脾运） | 理中汤/平胃散→燥脾用 |
| 少阴体竭（精虚） | 脉微细、但欲寐 | 肾体精虚（肾精不足） | 四逆汤/肾气丸→温肾体 |
| 少阴用衰（火衰） | 四肢厥逆、下利清谷 | 心用不彰（心阳衰） | 四逆汤甘辛化苦→助心用 |
| 厥阴体寒（血寒） | 手足厥寒、脉细欲绝 | 肝体血寒（肝血虚寒） | 当归四逆汤辛酸→温肝体 |
| 厥阴用亢（风动） | 消渴、气上冲心、心中疼热 | 肝用亢（肝阳化风） | 乌梅丸寒热并用→平肝用 |

## 四、六经体用的「三才·三阴三阳」底层结构

### 4.1 三阴三阳不是六条线，是三个层面

传统认为六经是六条经络。但从体用角度看，**三阴三阳是三个层面的体用结构**：

| 层面 | 阳经（用为主） | 阴经（体为主） | 三才 |
|:----|:-------------|:-------------|:----:|
| **表层（天）** | 太阳（用之表·开） | 少阴（体之里·枢） | 天部·寒热 |
| **中层（人）** | 少阳（用之枢·枢） | 厥阴（体之枢·阖） | 人部·风火 |
| **里层（地）** | 阳明（用之里·阖） | 太阴（体之表·开） | 地部·燥湿 |

### 4.2 体用在三层面中的分布

```
表层（天·寒热）：
    太阳（用之开）—— 卫气开散于表 —— 体少用多
    少阴（体之枢）—— 精血藏照于里 —— 体多用少

中层（人·风火）：
    少阳（用之枢）—— 相火枢转出入 —— 体用各半
    厥阴（体之阖）—— 肝血封藏生发 —— 体用皆重

里层（地·燥湿）：
    阳明（用之阖）—— 燥金通降于里 —— 体少用多
    太阴（体之开）—— 湿土运化于里 —— 体多用少
```

### 4.3 核心规律

> **阳经偏用** — 太阳·阳明·少阳 → 病多以「用病」为主（郁/闭/亢/滞）
> **阴经偏体** — 太阴·少阴·厥阴 → 病多以「体病」为主（虚/寒/竭/枯）
> **阴阳同经** — 少阴（体之枢）与太阳（用之开）共属天部 → 太阳用病不解则伤少阴之体
> **开阖枢规律** — 太阳开→阳明阖→少阳枢；太阴开→厥阴阖→少阴枢

## 五、六经体用与温病体用的接壤

### 5.1 外感病的两大体系：伤寒体用 vs 温病体用

| 维度 | 伤寒六经体用 | 温病卫气营血体用 |
|:----|:------------|:----------------|
| 病邪性质 | 寒湿为主（辛主除湿） | 温热为主（苦主清热） |
| 病机演化 | 由表入里：太阳→阳明→少阳→太阴→少阴→厥阴 | 由浅入深：卫→气→营→血 |
| 体用偏向 | 阴经偏体·阳经偏用 | 卫气偏用·营血偏体 |
| 治法核心 | 辛酸开阖·甘辛化苦·辛咸化滞 | 辛凉解表·苦寒清热·甘寒养阴 |
| 底层公理 | 五味克邪公理（辛除湿·酸祛风·甘驱寒·苦清热·咸除燥） | 四气为用·五味为体公理 |

### 5.2 伤寒体用→温病体用的传变接口

伤寒体用与温病体用不是对立关系——它们是**同一外感病的不同切入点**：

```
伤寒体用路径（寒湿为起点）：
  太阳(寒湿表) → 阳明(燥湿互结) → 少阳(风热枢) → 太阴(寒湿里) → 少阴(水火不交) → 厥阴(寒热错杂)

温病体用路径（温热为起点）：
  卫分(热在表) → 气分(热在经) → 营分(热入阴) → 血分(热竭阴)
  
接口：
  太阳·伤寒 ↔ 卫分·温病 （表证入口不同，但都在表位）
  阳明·燥结 ↔ 气分·热盛 （里热实证，治法有重叠）
  少阴·热化 ↔ 营分·热入 （阴虚热扰，本质相同）
  厥阴·血寒 ↔ 血分·热竭 （血分病变，寒热两极）
```

**打通意义**：伤寒体用和温病体用打通之后，丹道玄医录的体用体系就覆盖了**从伤寒到温病的全部外感病谱**——寒邪从表入里用六经体用，热邪从浅入深用卫气营血体用，两者在接口处无缝衔接。

## 六、六经体用的「九转坐标」定义

### 6.1 六经作为九维概念

按九转编码系统的概念注册规范，每条经的九维坐标定义如下：

| 转次 | 维度 | 范围 | 六经共性特征 |
|:----:|:----|:---:|:-----------|
| 一转 | 河图生数 | 1-5 | 太阳1、阳明4、少阳2、太阴5、少阴2、厥阴3 |
| 二转 | 河图成数 | 6-10 | 太阳6、阳明9、少阳7、太阴10(归中)、少阴2(无成数)、厥阴8 |
| 三转 | 洛书正位 | 1-9 | 太阳1→6、阳明4→9、少阳2→7、太阴5→5、少阴2、厥阴3→8 |
| 四转 | 洛书变位 | -4~+4 | 太阳+5(坎→乾)、阳明+5(巽→离)、少阳+5(坤→兑)、太阴0(中宫)、少阴0(坤)、厥阴+5(震→艮) |
| 五转 | 阴阳消长 | -1.0~+1.0 | 太阳+0.5(阳中之阴)、阳明+0.8(阳中之阳)、少阳+0.3(阴中之阳)、太阴-0.3(阳中之阴)、少阴-0.5(阴中之阴)、厥阴-0.2(阴中之阳) |
| 六转 | 三才层次 | 0.0~1.0 | 太阳0.9天、阳明0.2地、少阳0.5人、太阴0.1地、少阴0.8天、厥阴0.5人 |
| 七转 | 四象方向 | 0-3 | 太阳3(北)、阳明1(南)、少阳2(西)、太阴0(中)、少阴3(北/西南)、厥阴0(东) |
| 八转 | 八卦辨象 | 0-7 | 太阳5坎→6乾、阳明4巽→7离、少阳2坤→8兑、太阴0中、少阴2坤、厥阴5震→1艮 |
| 九转 | 归元转化 | 0.0~1.0 | 太阳0.7(开散→阖收)、阳明0.3(阖收→开散)、少阳0.5(枢)、太阴0.6(开→阖)、少阴0.4(藏→照)、厥阴0.5(阖→开) |

> 注：六经的九转坐标是「动态穿行坐标」——因为六经不在九宫中固定，而是在九宫中穿行。因此每条经的坐标有一个「起点→终点」的向量，而非一个固定点。

### 6.2 六经体用与九转引擎的接口

```
六经体用分析流程：
  ① 输入症状（如：恶寒发热、无汗、脉浮紧）
  ② 九宫定向 → 定位到太阳经（坎一宫，用病为主）
  ③ 体用判断 → 太阳用病（卫气被郁）→ 体尚足，用滞
  ④ 化合选择 → 辛酸开散（太阳经用病的主化合类型）
  ⑤ 方剂推荐 → 麻黄汤（辛味开表+苦味降气=辛开苦降）
  ⑥ 输出 → 太阳经用病·麻黄汤证
```

## 七、六经体用体系的使用方法

### 7.1 辨证操作流程

```
第一步：定经
  根据症状定位到病在哪一经（或哪几经合病）
  → 参考「伤寒六经63证全表」

第二步：判体用
  判断是该经的体病还是用病（或是体用皆病）
  → 体病：物质不足（虚/寒/枯）→ 补体
  → 用病：功能失常（郁/亢/闭）→ 调用
  → 体用皆病：→ 先通后补 或 通补兼施

第三步：选化合
  根据体用失衡类型，选择对应的化合类型
  → 参考「性味化合新解」各卷

第四步：定方
  根据化合类型，确定主方
  → 参考「伤寒六经63证全表」的主方列表

第五步：验算
  用体用公理验算方剂的每一条药对链
  → 参考「性味化合新解」的三层穿透法
```

### 7.2 体病·用病的具体判断标准

| 判断维度 | 体病（物质不足） | 用病（功能失常） |
|:--------|:---------------|:----------------|
| **病因** | 久病、内伤、失治误治伤正 | 新感、外邪、情志郁结 |
| **病程** | 较长（数日至数年） | 较短（数时辰至数日） |
| **脉象** | 虚、弱、微、细、迟 | 浮、紧、弦、滑、数 |
| **舌象** | 舌淡、胖、嫩、少苔 | 舌红、绛、紫、苔厚 |
| **对补药反应** | 补后改善 | 补后壅滞或上火 |
| **对攻药反应** | 攻后更虚 | 攻后缓解 |

### 7.3 六经体用与合病·并病

合病与并病的体用处理原则：

> **合病**：两经或三经同时发病 → 各经的体用问题同时处理，主次分明
> **并病**：一经病未解，另一经病又起 → 先治首发病的体用，兼顾后续经的体用

**合病体用处理示例——太阳阳明合病（葛根汤）**：
```
太阳体用：太阳用病（卫郁）→ 辛开
阳明体用：阳明用病（气逆）→ 苦降
葛根汤：麻黄+桂枝（辛开太阳）+ 葛根（苦降阳明）= 辛开苦降
→ 太阳与阳明用病同治
```

## 八、本体系在丹道玄医录中的定位

```
丹道玄医录体用体系全景图：

  五脏体用（仓库·精血）
      ↕ 精血通道
  六经体用（通道·气机） ←—— 本卷（伤寒六经体用映射）
      ↕ 气机入口
  温病体用（气机·亢变）
  
  三者的关系：
  - 五脏体用是「体」的根基——管精血是否充足
  - 六经体用是「用」的通道——管气机是否通畅 ← 本卷
  - 温病体用是「用」的亢变——管气机是否过度
  
  六经体用是连接五脏体用和温病体用的桥梁：
  - 五脏体用的精血，通过六经通道输送到全身
  - 温病体用的亢变，从六经通道侵入人体
  - 六经通道通畅则精血得运、邪不能入
  - 六经通道郁滞则精血不达、邪气留着
```

## 卷首结语

六经体用不是对伤寒论的「新解」，而是对伤寒论底层逻辑的**体用化归位**。

张仲景写伤寒论时，没有用「体用」这个词。但他所做的每一件事——辛酸化甘散太阳之痞、甘辛化苦消太阴之满、辛咸化滞破阳明之结、咸苦化酸宁少阴之烦、苦甘化咸润少阴之燥——每一件都是在**调体用**。

体用不是强加给伤寒论的框架，是伤寒论本来就有、但一直没被说破的底层逻辑。丹道玄医录所做的，是把这套底层逻辑说破、说透、说系统。

当你用体用的眼光再读伤寒论时，每一首方都不再是「经验总结」，而是**体用公理的必然推演**。
