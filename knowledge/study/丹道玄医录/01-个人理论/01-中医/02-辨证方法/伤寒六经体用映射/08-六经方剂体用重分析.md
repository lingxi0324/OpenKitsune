# 伤寒六经体用映射

## 08-六经方剂体用重分析

> **版本**：v1.0
> **覆盖范围**：18首伤寒核心经方的体用重分析（每经3首主方）
> **分析方法**：按00-总纲的五步法（定经→判体用→选化合→定方→验算）

## 一、太阳经方剂体用重分析

### 1.1 桂枝汤 — 太阳体病主方

| 分析步 | 内容 |
|:------|:------|
| 定经 | 太阳经 |
| 判体用 | 体病（营虚）+ 用病（卫郁风扰） |
| 化合 | A1·辛酸化甘（肝原配·散痞）+ B4·甘酸（非原配·敛阴） |
| 体用效应 | 辛（桂枝/生姜）开太阳用 + 酸（白芍）敛太阳体 + 甘（草枣）补太阳体 |
| 体用验算 | ✅ 辛酸配=散太阳表位风湿之痞 → 体用皆复 |

### 1.2 麻黄汤 — 太阳用病主方

| 分析步 | 内容 |
|:------|:------|
| 定经 | 太阳经 |
| 判体用 | 用病（卫郁）→ 体尚足，用闭 |
| 化合 | A3·甘辛化苦（脾原配·消满） |
| 体用效应 | 辛（麻黄/桂枝）强力开太阳用 + 苦（杏仁）降太阳逆气 + 甘（甘草）护中 |
| 体用验算 | ✅ 纯辛甘=甘辛化苦消太阳寒湿之满 → 用复体自安 |

### 1.3 桂枝麻黄各半汤 — 太阳体用皆病

| 分析步 | 内容 |
|:------|:------|
| 判体用 | 体用皆病（营虚+卫郁） |
| 化合 | A1 + A3 轻剂 |
| 体用效应 | 小量辛酸（桂芍）复体 + 小量辛甘（麻桂）调 = 通补兼施 |

| 体用验算 | ✅ 热清津复 → 体用皆安 |

### 2.2 大承气汤 — 阳明用病主方

|:------|:------|
| 判体用 | 用病（燥结闭阻） |
| 化合 | B1·辛咸化滞（广义·破结） |
| 体用效应 | 辛（枳实/厚朴）破气散湿结 + 咸（芒硝）软坚润燥结 = 辛咸合力破阳明燥结 |
| 体用验算 | ✅ 燥结破 → 阳明用复（通降） |

### 2.3 调胃承气汤 — 阳明体用皆病

| 体用效应 | 咸（芒硝）润燥 + 甘（甘草）护津 + 苦（大黄）通下 = 缓攻不伤体 |
