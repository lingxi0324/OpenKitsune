## 一、少阴经体用定义

### 1.1 少阴之体

**少阴之体 = 精血·真阴**

少阴经的物质基础是「精血」和「真阴」——心主血、肾主精，少阴统领一身之精血。少阴之体是六经中最深层的「体藏」——精血是生命的物质根基，真阴是生命之火（君火）的燃料。

**少阴体病（精虚热化）的标志性表现：**
- 心中烦（阴虚火旺，心火亢盛）
- 不得卧（阴虚阳亢，心神不藏）
- 舌红少苔（阴虚热扰）
- 脉细数（阴虚有热）

### 1.2 少阴之用

**少阴之用 = 君火·藏照**

少阴的功能是「君火」和「藏照」——心主神明——君火以明；肾主蛰藏——君火以位。少阴之用的本质：君火藏在精血之中，如灯油中的火苗——油足则火明而不亢，油竭则火浮而不藏。

**少阴用病（阳虚寒化）的标志性表现：**
- 脉微细（阳气衰微，鼓动无力）
- 但欲寐（阳气不振，精神萎靡）
- 四肢厥逆（阳气不能温煦四末）
- 下利清谷（肾阳不能温煦脾土）

### 1.3 少阴体用的两极特征

少阴是六经中**唯一同时存在「体病（热化）」和「用病（寒化）」两极的经**——这不是少阴的自相矛盾，而是少阴体用关系的必然规律：

```
少阴之体（精血）足 → 君火（用）藏而不亢 → 正常
少阴之体（精血）耗 → 君火（用）浮越 → 热化（体病）
少阴之用（君火）衰 → 精血（体）无以温 → 寒化（用病）

热化：体竭→用亢（黄连阿胶汤证）
寒化：用衰→体寒（四逆汤证）
```

## 二、少阴病体用失衡模式

### 2.1 少阴热化（体竭用亢）

| 层面 | 状态 | 说明 |
|:----|:----:|:------|
| 少阴之体（精血） | ❌ 竭 | 真阴耗损，水不制火 |
| 少阴之用（君火） | ⚠️ 亢 | 君火浮越，不能安居其位 |
| 体用关系 | 体竭→用亢 | 精血不足以涵养君火 |

**主方**：黄连阿胶汤（黄连+黄芩+阿胶+白芍+鸡子黄）
**化合**：A2·咸苦化酸（苦寒清心·咸润滋肾→化酸收敛浮火）

### 2.2 少阴寒化（用衰体寒）

| 层面 | 状态 | 说明 |
|:----|:----:|:------|
| 少阴之体（精血） | ⚠️ 尚存但失温 | 精血未竭但无阳气温煦 |
| 少阴之用（君火） | ❌ 衰 | 君火衰微，不能温煦全身 |
| 体用关系 | 用衰→体寒 | 阳衰无以温化精血 |

**主方**：四逆汤（附子+干姜+甘草）
**化合**：A3·甘辛化苦（辛附除深层寒湿+甘草护中→苦水燥湿回阳）
