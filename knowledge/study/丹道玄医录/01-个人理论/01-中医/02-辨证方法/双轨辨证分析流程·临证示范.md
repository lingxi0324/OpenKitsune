# 双轨辨证分析流程·临证示范

> **核心原则：** 外感走六经，内伤走五脏，双轨合参、病机总括、而后处方。

---

## 一、分析流程总纲

```
收集四诊信息
    ↓
┌──────────────────────────────┐
│ ① 外感线（六经辨证）         │ ← 主攻表证、经气、传变
│    浮沉定表里                │
│    六经循行定位              │
│    六气属性定性              │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│ ② 内伤线（五脏辨证）         │ ← 主攻里证、脏腑、气血
│    舌象定虚实寒热            │
│    五脏定位（舌/脉/症互参）   │
│    湿痰瘀郁定性              │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│ ③ 双轨合一（病机总括）       │ ← 外内合参，提炼核心病机
│    三邪/多邪交加分析         │
│    标本缓急判断              │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│ ④ 处方                      │ ← 据病机立法，方证对应
│    经方/时方化裁             │
│    方解（君臣佐使）           │
│    服药禁忌                  │
└──────────────────────────────┘
```

## 二、各步详细操作

### 第一步：外感线（六经辨证）

**核心问诊：** 浮沉定表里 + 六经循行部位 + 六气属性

| 脉象 | 分析逻辑 |
|:-----|:---------|
| **浮脉** | 病在表——太阳/少阳/阳明 |
| **沉脉** | 病在里——太阴/少阴/厥阴 |
| **紧脉** | 主寒（浮紧=风寒束表，沉紧=寒凝于里） |
| **浮紧** | 风寒束表，太阳经气不利 |

| 症状部位 | 归属经 |
|:---------|:-------|
| 肩背、项、腰正中 | **太阳经** |
| 胸胁、偏头 | **少阳经** |
| 前额、鼻、面 | **阳明经** |
| 腹满、食少 | **太阴经** |
| 心悸、腰痛、畏寒 | **少阴经** |
| 巅顶、厥冷 | **厥阴经** |

**六气定性：**
- **风**——走串疼痛、善行数变、脉浮缓
- **寒**——紧脉、拘急疼痛、畏寒
- **湿**——白腻苔、沉重感、脉濡缓
- **热**——黄苔、数脉、口干
- **燥**——干裂纹、涩脉
- **火**——红舌、数脉、心烦

---

### 第二步：内伤线（五脏辨证）

**核心问诊：** 舌象定虚实寒热 + 五脏定位 + 气血津液状态

| 舌象 | 辨证 |
|:-----|:-----|
| **舌苔白腻** | 寒湿内停，脾阳不振 |
| **舌苔黄腻** | 湿热内蕴 |
| **舌中裂纹** | 脾主舌中——**湿阻津路**（非阴虚，乃津液输布受阻） |
| **舌质淡胖** | 阳虚水湿 |
| **舌质红绛** | 热入营血 |
| **舌边齿痕** | 气虚湿盛 |

**五脏定位参合：**
- **脉右关浮紧** → 脾寒湿
- **脉右寸浮紧** → 肺风寒
- **脉左关弦** → 肝郁/肝风
- **脉左尺沉细** → 肾虚

**常见内伤病机链条：**

```
脾虚 → 湿蕴 → 阻气机 → 津不上承 → 舌中裂纹
                          ↓
                     胸阳不展 → 胸痛
                     清阳不升 → 头闷痛
                     湿注下焦 → 腰痛
```

---

### 第三步：双轨合一（病机总括）

**原则：** 外感与内伤不是割裂的，而是**互为因果、互相加重**。

**典型双轨合参格式：**

```
外：______（六经+六气分析）
内：______（五脏+气血津液分析）
                 ↓
三邪交加：___ × ___ × ___
                 ↓
核心病机：______
```

**标本缓急判断：**
- **标急** → 先解表/先通络（如左侧无力为中风先兆，以通络为首务）
- **本急** → 先温阳/先扶正（如脉微欲绝，以回阳为急）
- **标本并重** → 表里双解，内外兼治

---

### 第四步：处方

**立法原则：** 据病机立法，方证对应，灵活化裁。

| 病机类型 | 主方 | 化裁方向 |
|:---------|:-----|:---------|
| 风寒湿客太阳 | 羌活胜湿汤 | + 威灵仙走串止痛 / + 秦艽舒筋 |
| 太阴虚寒湿蕴 | 苓桂术甘汤 / 理中汤 | + 附子温阳 / + 茯苓利湿 |
| 少阳郁热 | 小柴胡汤 | + 黄芩清胆 / + 牡蛎安神 |
| 阳明热结 | 白虎汤 / 承气类 | 据燥实程度选方 |
| 少阴寒化 | 四逆汤 / 真武汤 | + 细辛通经 |
| 厥阴寒热错杂 | 乌梅丸 | 调寒热、和阴阳 |

**方解结构：**
```
君药：1-2味 — 针对核心病机
臣药：2-4味 — 辅助君药或治兼证
佐药：2-3味 — 反佐/调和/引经
使药：1味   — 调和诸药

全方合力：______
```

## 三、临床示范案例

### 案例：46岁男性，胸痛腰痛肩背疼痛

**四诊摘要：**
- 主诉：胸痛，腰痛，肩背疼痛，头闷痛，走串疼痛
- 舌象：舌苔白腻，舌中裂纹
- 脉象：右肺脾脉浮紧

---

#### 第一步：外感线（六经辨证）

| 症状 | 归属 | 分析 |
|:-----|:-----|:------|
| **右肺脉浮紧** | 表证 | 浮主表，紧主寒——风寒束表 |
| **肩背疼痛** | **太阳经** | 太阳经循行部位——经气不利 |
| **走串疼痛** | **风邪** | 风性善行数变 |
| **头闷痛** | **太阳经** | 风寒上扰清阳 |

**外感结论：** 风寒湿邪客于太阳经脉，兼风邪走窜

---

#### 第二步：内伤线（五脏辨证）

| 症状 | 归属 | 分析 |
|:-----|:-----|:------|
| **舌苔白腻** | 脾（太阴） | 寒湿内停，脾阳不振 |
| **舌中裂纹** | 脾（舌中主脾） | 湿阻气机，津不上承（非真阴虚） |
| **右脾脉浮紧** | 脾（右关） | 紧为寒，脾阳不足，寒湿内蕴 |
| **胸痛** | 心肺之廓 | 胸阳不展，气机痹阻 |
| **腰痛** | 肾（腰为肾府） | 寒湿下注，太阳经脉亦过腰 |

**内伤结论：** 太阴脾虚湿蕴，湿阻气机，津不上承

---

#### 第三步：双轨合一（病机总括）

```
外：风寒湿三气杂至合而为痹（太阳经）
内：太阴脾虚湿蕴，湿阻气机
                 ↓
三邪交加：风（走串）× 寒（紧脉）× 湿（白腻苔）
                 ↓
经络不通 → 不通则痛 → 走串疼痛、胸痛、肩背痛、腰痛
清阳不升 → 头闷痛
湿阻津路 → 舌中裂纹（非阴虚，乃湿阻）
```

---

#### 第四步：处方

**立法：** 祛风散寒除湿，兼健脾化湿通络

**方选：** 羌活胜湿汤合苓桂术甘汤化裁

| 药味 | 剂量 | 作用定位 |
|:----|:---:|:---------|
| **羌活** | 10g | **君** — 入太阳，祛上半身风寒湿 |
| **独活** | 10g | **君** — 入少阴，祛下半身风寒湿，治腰痛 |
| **防风** | 10g | **臣** — 祛风胜湿，走表散邪 |
| **川芎** | 10g | **臣** — 血中气药，祛风活血止痛，治头闷痛 |
| **藁本** | 6g | **臣** — 入太阳巅顶，祛风寒止头痛 |
| **蔓荆子** | 10g | **臣** — 清利头目，疏散风邪 |
| **茯苓** | 20g | **佐** — 健脾渗湿（苓桂术甘汤君药） |
| **桂枝** | 10g | **佐** — 温阳化气，通太阳经脉 |
| **白术** | 15g | **佐** — 健脾燥湿 |
| **炙甘草** | 6g | **使** — 调和诸药，补中 |
| **威灵仙** | 10g | **引** — 祛风通络，走串止痛要药 |
| **秦艽** | 10g | **引** — 祛风通络，舒筋止痛 |
| **白芍** | 10g | **护** — 酸收敛阴，防温燥太过（照顾舌中裂纹） |
| **桑寄生** | 15g | **引** — 祛风湿，强腰膝，治腰痛 |

**方解：**
> 羌独二活，一上一下，搜周身风寒湿邪——此为君
> 防风藁本蔓荆川芎，祛风散寒通窍止痛——此为臣
> 苓桂术甘四味，健脾化湿，温阳展气——此为佐
> 威灵仙秦艽祛风通络，专走串痛——此为引
> 白芍酸收敛阴，防诸风药温燥太过——此为护

**服用：** 3剂，水煎服，每日1剂，分2次温服。服药后宜避风，微微汗出佳。

**禁忌：** 忌生冷、油腻、黏滑；忌当风受凉；3剂后复诊。

## 四、流程要点总结

1. **先外后内** — 六经辨证先走，五脏辨证跟上，两线不能颠倒
2. **舌脉为主** — 舌象是内伤的窗口，脉象是外感的钥匙
3. **双轨合参** — 外感可引动内伤，内伤可招致外邪，不可截然分开
4. **据机立法** — 病机是处方的唯一依据，不可凭症状堆药
5. **方必有解** — 每味药在方中都有明确的定位（君臣佐使引护）

---

> **备案：** 本流程基于"内伤外感双规辩证"体系，以六经为纬（外感线）、五脏为经（内伤线），经经纬纬、纵横交错，方得病机全貌。
