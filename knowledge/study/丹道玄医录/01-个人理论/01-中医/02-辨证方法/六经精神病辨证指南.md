## 一、六经精神病·舌脉鉴别表（一看舌脉直接定经）

### 1. 太阳（惊、恐、悸、夜惊、焦虑表证）

| 项目 | 内容 |
|------|------|
| **舌** | 淡红/淡，苔薄白、薄白润 |
| **脉** | 浮、浮缓、浮紧、或浮而虚 |
| **精神主征** | 易惊、恐惧、心悸、卧起不安、噩梦、外感后精神异常 |

### 2. 阳明（狂躁、谵妄、躁狂发作、实热亢奋）

| 项目 | 内容 |
|------|------|
| **舌** | 红/深红，苔黄燥、黄厚燥、焦黄燥、起芒刺 |
| **脉** | 洪大、滑数、沉实、沉紧有力 |
| **精神主征** | 狂乱、骂詈、不眠、易怒暴力、面红目赤、大便硬 |

### 3. 少阳（双相、焦虑抑郁交替、郁怒、多疑、胸满烦惊）

| 项目 | 内容 |
|------|------|
| **舌** | 偏红，苔薄黄/白腻、黄腻、少苔 |
| **脉** | 弦、弦细、弦数、弦滑 |
| **精神主征** | 情绪起伏、时郁时躁、口苦、胸胁满、多疑、失眠惊悸 |

### 4. 太阴（痰湿抑郁、思虑强迫、身重懒动、多思多虑）

| 项目 | 内容 |
|------|------|
| **舌** | 淡胖、边有齿痕，苔白腻、水滑、厚腻 |
| **脉** | 缓、弱、濡、沉缓 |
| **精神主征** | 情绪低落、身重困倦、思虑不休、强迫、腹胀便溏 |

### 5. 少阴（淡漠、无欲、嗜睡、重度抑郁、自杀意念、精神衰微）

| 项目 | 内容 |
|------|------|
| **舌** | 淡白、青紫，苔白滑/少苔、水润 |
| **脉** | 微细、沉微、沉迟、极弱 |
| **精神主征** | 无欲、淡漠、少语少动、但欲寐、畏寒、反应极迟钝 |

### 6. 厥阴（快速循环、寒热错杂、自伤、幻觉妄想、重症难治）

| 项目 | 内容 |
|------|------|
| **舌** | 红（上热）+淡白（下寒），苔黄白相兼、干润交错 |
| **脉** | 弦细、弦微、乍数乍迟、强弱不定 |
| **精神主征** | 烦躁欲死↔消沉欲绝极速切换、气上冲心、心中疼热、自伤 |

## 二、双相情感障碍（躁↔郁循环）六经传变路线+阶梯用药方案

### 总纲

> **双相本质** = 少阳枢机不利为本，发作时转出阳明（躁）、转入少阴（郁）、终入厥阴（快速循环）。

---

### 阶段1：稳定期/轻起伏（少阳本证）

| 项目 | 内容 |
|------|------|
| **证候** | 情绪不稳、时好时差、易烦易闷、口苦、眠差、胸胁不适 |
| **舌脉** | 弦脉，苔薄黄/薄白 |
| **主方** | **小柴胡汤**（基础调枢机） |

### 阶段2：轻躁→偏阳明（轻躁发作）

| 项目 | 内容 |
|------|------|
| **证候** | 话多、兴奋、眠少、易怒、面热、大便偏干 |
| **舌脉** | 舌红、苔薄黄，脉弦数/滑 |
| **主方** | **柴胡加龙骨牡蛎汤**（减桂枝、加重龙牡） |
| **加减** | 偏热甚：合**栀子豉汤** |

### 阶段3：典型躁狂发作（纯阳明腑实/气分热）

| 项目 | 内容 |
|------|------|
| **证候** | 彻夜不眠、夸大、冲动、面红目赤、便秘、腹满 |
| **舌脉** | 舌红苔黄燥，脉沉实洪大 |
| **主方** | |
| 腑实狂乱 | **大承气汤** |
| 心火烦躁狂 | **大黄黄连泻心汤** |
| 大热无腑实 | **白虎汤** |

### 阶段4：抑郁发作（转入少阴/太阴）

#### A. 少阴抑郁（淡漠、无欲、迟滞、自杀意念）

| 项目 | 内容 |
|------|------|
| **主方** | **麻黄附子细辛汤** → **四逆汤** → **附子汤**（逐级温阳） |

#### B. 太阴抑郁（身重、思虑、懒动、痰湿）

| 项目 | 内容 |
|------|------|
| **主方** | **苓桂术甘汤**、**理中汤**、**半夏厚朴汤** |

### 阶段5：快速循环、躁郁一日数变（厥阴寒热错杂）

| 项目 | 内容 |
|------|------|
| **证候** | 上热烦躁、下寒腹冷便溏、自伤、极端波动 |
| **主方** | **乌梅丸**（双相终末期、难治循环首选） |

---

### 双相六经阶梯用药（从轻到重完整路线）

| 步骤 | 方剂 | 对应阶段 |
|:----:|------|----------|
| ① | **小柴胡汤** | 基础稳情绪 |
| ② | **柴胡加龙骨牡蛎汤** | 轻躁轻郁交替 |
| ③ | **承气类/泻心汤/白虎汤** | 躁狂实热 |
| ④ | **麻黄附子细辛汤/四逆/附子汤** | 抑郁淡漠 |
| ⑤ | **苓桂术甘/理中/半夏厚朴** | 痰湿思虑抑郁 |
| ⑥ | **乌梅丸** | 极速循环、难治重症 |

## 三、精神分裂（阳证狂/阴证僵）六经分型方证（逐条）

### （一）阳证：狂躁型、阳性症状

> 妄言、妄见、躁动、幻觉、妄想偏热

#### 1. 阳明燥热狂乱（最常见阳证）

| 项目 | 内容 |
|------|------|
| **证** | 狂言骂詈、不避亲疏、登高弃衣、不眠、便秘腹满、口渴喜冷 |
| **舌** | 红绛，苔黄燥/焦黄 |
| **脉** | 沉实、洪大 |
| **方** | **大承气汤**（狂重）；**调胃承气汤**（狂轻） |

#### 2. 阳明心火亢盛（烦躁妄想、焦虑幻听）

| 项目 | 内容 |
|------|------|
| **证** | 心烦狂乱、失眠、面赤、口舌生疮、焦虑激越 |
| **舌** | 红，苔黄 |
| **脉** | 滑数 |
| **方** | **大黄黄连泻心汤** |

#### 3. 少阳痰火扰神（多疑、被害妄想、幻听、情绪不稳）

| 项目 | 内容 |
|------|------|
| **证** | 胸满烦惊、多疑、幻听、时躁时静、口苦 |
| **舌** | 红，苔黄腻 |
| **脉** | 弦滑 |
| **方** | **柴胡加龙骨牡蛎汤** + 温胆汤意 |

#### 4. 太阳惊狂（外感后、受惊起病、惊狂不安）

| 项目 | 内容 |
|------|------|
| **证** | 惊狂、卧起不安、心悸、怕声怕光 |
| **舌** | 淡红，苔薄白 |
| **脉** | 浮 |
| **方** | **桂枝去芍药加蜀漆龙骨牡蛎救逆汤** |

---

### （二）阴证：淡漠僵滞型、阴性症状

> 孤僻、退缩、呆滞、少语、无欲、木僵倾向

#### 1. 少阴阳衰（核心阴证：淡漠、无欲、呆滞、退缩）

| 项目 | 内容 |
|------|------|
| **证** | 终日寡言、对一切无兴趣、嗜睡、畏寒、反应极慢、自杀意念重 |
| **舌** | 淡白，苔水润 |
| **脉** | 微细、沉微 |
| **方** | **麻黄附子细辛汤**（神困嗜睡）；**四逆汤**（阳衰更甚）；**附子汤**（身痛倦怠） |

#### 2. 少阴水泛（恐惧、幻视偏阴、心悸、头晕、浮肿）

| 项目 | 内容 |
|------|------|
| **证** | 惊恐不安、夜恐、幻视阴暗、下肢沉肿 |
| **舌** | 淡胖水滑 |
| **脉** | 沉迟 |
| **方** | **真武汤** |

#### 3. 太阴虚湿痰湿（孤僻、懒动、思维迟缓、身重）

| 项目 | 内容 |
|------|------|
| **证** | 情绪低沉、思维黏滞、不愿动、腹胀便溏、痰多 |
| **舌** | 淡胖齿痕，苔白腻 |
| **脉** | 濡缓 |
| **方** | **苓桂术甘汤**、**理中汤** |

#### 4. 厥阴寒热错杂（阴阳离决前兆）

| 项目 | 内容 |
|------|------|
| **证** | 时而呆滞不语，时而突然烦躁冲动、自伤、上热下寒 |
| **舌** | 寒热错杂苔 |
| **脉** | 弦微不定 |
| **方** | **乌梅丸**（阴证夹杂躁动最合拍） |

---

> **核心法度**：
> - 狂躁=阳明→承气/泻心
> - 双相=少阳→柴胡龙牡
> - 淡漠=少阴→麻黄附子细辛
> - 难治极速循环=厥阴→乌梅丸
