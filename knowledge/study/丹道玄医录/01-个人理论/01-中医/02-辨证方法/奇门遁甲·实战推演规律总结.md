> 基于古籍《奇门遁甲统宗》《奇门法窍》《奇门旨归》与数次临床/事业推演经验归纳
> 整理时间：丙午年癸巳月甲午日（2026-05-20）

## 一、起局底层逻辑的修正

### 1.1 飞盘法 vs 转盘法

| 对比 | 转盘法（时家） | 飞盘法（本书用） |
|:-----|:-------------|:----------------|
| 九星排法 | 值符带星转 | 值符定宫后星顺飞九宫 |
| 八门 | 值使定宫后转 | 值使定宫后顺/逆飞 |
| 八神 | 阳顺阴逆转 | 阳顺阴逆飞 |
| 适用场景 | 应期、择日 | 气机推演、病机分析 |
| 特点 | 稳定、易断应期 | 细腻、能看出动势 |

**核心口诀**（《奇门统宗·值符值使诀》）：
```
一逢坎上一坎休        → 坎1宫值符天蓬、值使休门
芮死还排第二流        → 坤2宫天芮、死门
更有冲伤居震位        → 震3宫天冲、伤门
巽逢杜辅数为头        → 巽4宫天辅、杜门
禽心死五心开六        → 中5天禽、乾6天心+开门
惊柱还从七上来        → 兑7天柱、惊门
惟有任生居八艮        → 艮8天任、生门
九寻英景逐方周        → 离9天英、景门
```

**三元判定**：每节气15天分上中下三元
- 上元：甲子/己卯/甲午/己酉 符头到节前 → **超神**
- 中元：符头到节后 → **正授**
- 下元：符头晚到 → **接气**

**置闰法则**：芒种大雪后、二至前，超至9-10日则置闰（《奇门统宗》）

| 八神 | 象意 | 吉凶 | 主事 |
|:-----|:-----|:-----|:------|
| 值符 | 领袖、正气、高层 | 大吉 | 贵胄、统领、中央 |
| 腾蛇 | 缠绕、虚惊、怪异 | 凶 | 虚惊、纠缠、梦境 |

**实战经验**：
- 六合+死门 = 群体氛围僵死（秋田犬群推演验证）
- 六合+惊门 = 合伙有口舌（闺蜜事业推演验证）
- 值符+生门 = 贵人相助大吉（师兄推演验证）
- 白虎+天芮 = 病势凶险、肿瘤征兆
- 玄武+杜门 = 暗中不畅、阳奉阴违

### 3.2 格局与五行生克的结合

**关键规则**：
1. 格局优先于一般生克：格局一出，直接定性
2. 格局+门比格局+星更重：门管事的走向，星管气的状态
3. 年干格/月干格/日干格/时干格按层次归属：
   - 年干格 → 大环境、上司、长辈
   - 月干格 → 平辈、同事、朋友
   - 日干格 → 自身、患者、问事人
   - 时干格 → 下属、子女、结果

## 四、事业抉择推演规律（多次实战验证）

### 4.1 核心框架

```
日干（问事人）      → 看自身状态、能力、决断力
年干（上司/长辈）   → 老板态度、母亲建议的大方向
月干（平辈/合伙）   → 合作伙伴、表姐、同事
时干（结果/下属）   → 最终走向、下属感受
值符（最高领导）    → 行业趋势、天命大运
值使（执行层面）    → 招聘/离职/合同的执行力
```

### 4.2 生克判定规则（★ 实战核心）

| 关系 | 象意 | 判词 |
|:-----|:-----|:------|
| 年干生日干 | 老板器重、长辈支持 | 「木生火→火生土→生她」 |
| 月干克日干 | 合伙不顺、同辈竞争 | 「惊门克日干」 |
| 年干入伤门 | 老板心中不快、被迫留人 | 「伤门暗藏」 |
| 月干入惊门 | 合伙有口舌、各怀心思 | 「惊门伏吟」 |
| 时干生年干 | 结果利老板不利自己 | 「白忙一场」 |
| 日干入开门 | 有主动权、有决断力 | 「开门生旺」 |
| 日干值符 | 占天时、大局有利 | 「值符加吉门大吉」 |
| 两宫同五行 | 比和、合作可成 | 「金金比和」 |

### 4.3 多次推演验证

**案例一：闺蜜服装创业**（阳遁4局，癸酉时）
- 日干甲落乾6宫开门大吉 → 有能力有主动权
- 年干丙（老板）落震3伤门 → 老板虽然加薪但心有不甘
- 月干癸（表姐）落兑7惊门 → 合伙有口舌
- **结论：短期留店，年底再考虑独立**

**案例二：秋田犬QQ群不活跃**（阳遁4局）
- 开门落巽宫大吉 → 软件好用没问题
- 景门落坎宫水克火 → 消息石沉大海无反馈
- 六合+死门在坤 → 氛围僵死
- **结论：非软件问题，是反馈机制断了**

**案例三：师兄人品心性**（阳遁4局，壬戌时）
- 天芮+惊门+太阴在巽 → 心机深、有城府
- 天心+生门+值符在乾 → 有真才实学
- **结论：可教真东西，但要有门槛**

## 五、临床病机推演规律

### 5.1 六步推演法（核心）

```
Step 1: 起盘 → 定节气、阴阳遁、局数、四柱
Step 2: 天芮定位 → 找到天芮星落宫（病星）
Step 3: 病位定性 → 八卦对应脏腑（震肝/兑肺/坎肾等）
Step 4: 病性定量 → 门+神+格局三重锁定
Step 5: 五运六气加权 → 司天在泉叠加
Step 6: 出方案 → 针+药+择时
```

### 5.2 天芮+八门综合判定

| 组合 | 病性 | 缓急 | 治法 |
|:-----|:-----|:-----|:------|
| 天芮+死门 | 器质性、肿瘤可能 | 重要 | 结合西医检查 |
| 天芮+伤门 | 外伤/急性炎症 | 急 | 针法先解急 |
| 天芮+惊门 | 情志病、官鬼病 | 缓 | 心药为主 |
| 天芮+杜门 | 堵塞不通 | 中等 | 通利为主 |
| 天芮+景门 | 热证、炎症 | 急 | 清热为主 |
| 天芮+休门 | 虚证、劳损 | 缓 | 补益为主 |
| 天芮+生门 | 新病、预后好 | 中等 | 顺势疗法 |
| 天芮+开门 | 外感、初起 | 急 | 解表为主 |
| 天芮+中宫 | 脾胃病 | 中等 | 调中为主 |

### 5.3 飞星盘临床要点

1. **飞星与转盘的星位差异** → 飞星盘的天芮落宫可能不同，要以病位（症状）为准验证
2. **马星在病机中的意义** → 马星宫位为病势发展方向
3. **五运六气叠加** → 年干决定大环境病机趋势（少阳相火/太阳寒水等）
4. **节气旺衰修正** → 某宫位星门衰则病轻，旺则病重

## 六、工具逻辑完善要点

### 6.1 当前工具缺失的功能

| 缺失项 | 优先级 | 说明 |
|:-------|:------|:------|
| **反吟/伏吟检测** | P0 | 决定急慢病判定 |
| **四十格局检测** | P0 | 龙回首/虎猖狂/蛇妖矫等直接影响定性 |
| **八门旺相** | P1 | 按节气判断各门的能量状态 |
| **九星旺相** | P1 | 按月判断各星能量状态 |
| **八门迫制** | P1 | 门克宫/宫克门的能量折损 |
| **天芮+八神组合** | P0 | 补全所有8种八神+天芮组合 |
| **日干+年干+月干+时干分析** | P0 | 事业抉择类必须 |
| **格局→方案映射** | P1 | 四十格直接对应治疗方案 |

### 6.2 事业抉择与临床病机的交叉验证

**临床经验**：事业抉择推演中的生克规则**完全适用于临床**——
- 年干（天时/大环境）→ 对应五运六气的司天在泉
- 月干（人事/人际） → 对应患者的生活环境、情绪状态
- 日干（自身/核心） → 对应患者体质、正气强弱
- 时干（结果/外邪） → 对应病邪性质、趋势

**这为未来的「奇门论治」打下了基础**：同一盘面既能看事业，也能看病，只是解读角度不同。
