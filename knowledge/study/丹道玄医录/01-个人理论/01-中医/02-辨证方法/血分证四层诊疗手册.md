## 一、血分证总纲

### 1.1 河图数理定位

```
气分（无形·气化） ← 河图生数 1-5（先天之气） → 体用双轨体系覆盖
     ↓ 久病入血，气不摄血
血分（有形·质变） ← 河图成数 6-10（后天之质） → 血分四层模型覆盖
```

**核心规则：**
- 气分病不治→传入血分（叶天士"初病气分，久病入血"）
- 血分病必兼气分（血瘀则气滞，血虚则气少）
- 治血不忘调气（气行则血行，气滞则血瘀）

### 1.2 血分四层总表

| 层 | 病机 | 本质 | 河图成数 | 治法 | 方药方向 | 药味核心 |
|:---:|:---|:---|:---:|:---|:---|:---:|
| **Ⅰ 血热** | 热入血分，迫血妄行 | 血中热盛 | 6（水之成） | 凉血解毒 | 犀角地黄汤、化斑汤 | **咸+苦**（咸下行，苦清热） |
| **Ⅱ 血瘀** | 血行不畅，瘀阻脉络 | 血道壅塞 | 7（火之成） | 活血化瘀 | 血府逐瘀汤、桃红四物 | **辛+苦**（辛行散，苦破泄） |
| **Ⅲ 血虚** | 血不养脏，脏腑失荣 | 血量不足 | 8（木之成） | 养血补血 | 四物汤、当归补血汤 | **甘+酸**（甘补血源，酸藏血） |
| **Ⅳ 血毒** | 瘀腐化毒，败坏形质 | 血败成毒 | 9（金之成）→10（土之成） | 化瘀解毒 | 大黄䗪虫丸、抵挡汤 | **咸+苦+辛**（三焦并攻） |

## 二、血热Ⅰ层（成数6·水之成）

### 2.1 病机详解

热入血分，血中热盛，迫血妄行。本质是**水不制火，血中火毒炽盛**。

河图6为水之成数——水本应制火，但热毒太盛则水反被火灼，津枯血沸。

### 2.2 四诊特征

| 诊法 | 特征 | 说明 |
|:---|:---|:---|
| **望** | 身热夜甚、斑疹显露（色紫黑）、吐血衄血、舌质深绛 | 血热迫血妄行，血溢脉外 |
| **闻** | 气息粗热、口气秽臭 | 血中热毒上蒸 |
| **问** | 心烦不寐、躁扰不安、甚则神昏谵语 | 热扰心神 |
| **切** | 脉细数或弦数，左寸关尤甚 | 血热搏指，阴血已伤 |

### 2.3 方药阶梯

| 层级 | 方剂 | 药味 | 体用解析 |
|:---:|::---|:---|:---|
| **轻型** | 犀角地黄汤 | 水牛角（咸寒）、生地（甘苦寒）、赤芍（酸苦）、丹皮（辛苦寒） | 咸寒入血分→直折血热，苦泄心体→清心凉血 |
| **重型** | 化斑汤 | 石膏（辛甘寒）、知母（苦寒）、犀角、玄参（咸苦寒）、甘草（甘） | 辛甘寒入气分→透热转气，咸苦入血分→凉血化斑 |
| **极重型** | 清瘟败毒饮 | 石膏+犀角+黄连+黄芩+栀子+知母+赤芍+玄参+连翘+丹皮+竹叶+甘草 | 气血两燔→气分血分双清 |

### 2.4 加减规则

- 衄血/吐血重 → +白茅根、藕节炭、侧柏炭（涩血止血）
- 神昏谵语 → +安宫牛黄丸或至宝丹（清心开窍）
- 斑疹紫黑 → +紫草、大青叶（凉血化斑）
- 兼便秘 → +大黄（苦寒通腑，釜底抽薪）

### 2.5 针法配穴

| 取穴 | 手法 | 原理 |
|:---|:---:|:---|
| **曲泽（心包合）** | 泻法 | 清心包血热，咸苦下行 |
| **委中（膀胱合）** | 刺络出血 | 血热从血络排出，咸寒入血 |
| **血海（脾经）** | 泻法 | 清血分热，引血归经 |
| **膈俞（血会）** | 泻法 | 八会穴之血会，凉血止血 |
| **大椎（督脉）** | 泻法 | 清气分热→透热转气 |

### 2.6 临床禁忌

- ❌ **忌辛温燥血**（桂枝、川芎、当归身少用或不用）
- ❌ **忌甘补助火**（纯甘味壅滞，需配苦寒）
- ❌ **过早补血**（血热未清前，补血反助火势）

## 三、血瘀Ⅱ层（成数7·火之成）

### 3.1 病机详解

血行不畅，瘀阻脉络。本质是**火郁于血，气滞不行，血道壅塞**。

河图7为火之成数——火性炎上，郁而不通则成瘀。血瘀又生内热，热瘀互结。

### 3.2 四诊特征

| 诊法 | 特征 | 说明 |
|:---|:---|:---|
| **望** | 面色晦暗、唇色紫暗、舌质紫暗或有瘀斑瘀点、舌下络脉曲张 | 血行不畅，上露于面舌 |
| **闻** | 口气正常或微浊 | 非热毒 |
| **问** | 刺痛固定不移、夜甚、癥瘕积聚、月经紫黑有块、经行腹痛 | 瘀血停积，不通则痛 |
| **切** | 脉涩或细涩、沉弦，左关尺尤甚 | 血行涩滞 |

### 3.3 方药阶梯

| 层级 | 方剂 | 药味 | 体用解析 |
|:---:|::---|:---|:---|
| **轻型** | 桃红四物汤 | 桃仁（苦甘）、红花（辛温）、当归（甘辛）、川芎（辛）、白芍（酸）、熟地（甘） | 辛行血→肝用疏泄，甘补血→脾体归源 |
| **中型** | 血府逐瘀汤 | 桃仁+红花+当归+生地+牛膝+柴胡+枳壳+桔梗+川芎+赤芍+甘草 | 气分+血分双跨，辛行气散瘀、苦引血下行 |
| **重型** | 膈下逐瘀汤 | 桃仁+红花+当归+川芎+赤芍+丹皮+乌药+香附+枳壳+延胡索+五灵脂+甘草 | 专攻膈下瘀血，辛散苦泄并重 |
| **极重型** | 补阳还五汤 | 黄芪（甘温120g）+当归尾+赤芍+地龙+川芎+桃仁+红花 | 气虚血瘀，重补气以行血 |

### 3.4 加减规则

- 痛甚 → +延胡索、蒲黄、五灵脂（活血止痛）
- 兼寒 → +桂枝、细辛（辛温通脉）
- 兼热 → +丹皮、赤芍（凉血活血）
- 癥瘕坚结 → +三棱、莪术（破血消癥）
- 气虚明显 → +黄芪（补气行血，重用30-120g）

### 3.5 针法配穴

| 取穴 | 手法 | 原理 |
|:---|:---:|:---|
| **合谷（大肠原）** | 泻法 | 行气活血，气行则血行 |
| **三阴交（脾经）** | 泻法 | 活血调经，通血分之瘀 |
| **血海（脾经）** | 泻法 | 活血化瘀，血分会聚 |
| **膈俞（血会）** | 泻法 | 活血化瘀，八会之血会 |
| **局部阿是穴** | 泻法 | 直达病所，疏通局部瘀阻 |

### 3.6 临床禁忌

- ❌ **纯补不疏**（血瘀未化前，补血反壅滞，需先瘀后补或攻补兼施）
- ❌ **过用寒凝**（血得寒则凝，血瘀证需适当辛温配伍）
- ❌ **破血太过**（体虚者不宜猛破，免伤正气）

## 四、血虚Ⅲ层（成数8·木之成）

### 4.1 病机详解

血不养脏，脏腑失荣。本质是**生血不足或耗血太过，血量亏虚**。

河图8为木之成数——木为肝，肝藏血。血虚则肝体失养，疏泄无权，五脏失荣。

### 4.2 四诊特征

| 诊法 | 特征 | 说明 |
|:---|:---|:---|
| **望** | 面色萎黄或苍白、唇甲淡白、舌质淡白、毛发干枯 | 血不荣于上 |
| **闻** | 语声低微 | 气血不足 |
| **问** | 头晕眼花、心悸失眠、手足麻木、月经量少色淡、疲乏无力 | 血不养脏、不荣四肢 |
| **切** | 脉细弱或细数，左关尺尤虚 | 阴血不足，脉道不充 |

### 4.3 方药阶梯

| 层级 | 方剂 | 药味 | 体用解析 |
|:---:|::---|:---|:---|
| **轻型** | 四物汤 | 当归（甘辛）、川芎（辛）、白芍（酸）、熟地（甘） | 甘补脾体→生血之源，酸敛肝体→藏血之脏 |
| **中型** | 当归补血汤 | 黄芪（甘温30g）、当归（甘辛6g） | 五比一，大补脾肺气以生血，气旺则血生 |
| **重型** | 人参养荣汤 | 人参+白术+黄芪+当归+白芍+熟地+五味子+远志+肉桂+陈皮+甘草 | 气血双补，脾肺肝肾同调 |
| **极重型** | 十全大补汤 | 八珍汤+黄芪+肉桂 | 温补气血，虚寒血证重症 |

### 4.4 加减规则

- 兼失眠 → +酸枣仁、柏子仁、远志（养心安神）
- 兼心悸 → +龙眼肉、茯神（补心宁神）
- 兼月经不调 → +益母草、香附（调经养血）
- 消化弱 → +砂仁、陈皮（防甘补滋腻碍胃）

### 4.5 针法配穴

| 取穴 | 手法 | 原理 |
|:---|:---:|:---|
| **足三里（胃合）** | 补法 | 补中益气，生血之源 |
| **三阴交（脾经）** | 补法 | 补肝脾肾三阴，养血统血 |
| **血海（脾经）** | 补法 | 养血补血 |
| **膈俞（血会）** | 补法 | 气血双补 |
| **脾俞+胃俞** | 补法 | 补脾健胃，助生化之源 |

### 4.6 临床禁忌

- ❌ **破血耗血**（血虚者禁用桃仁、红花、三棱、莪术等破血之品）
- ❌ **纯辛散太过**（辛散耗血，需配伍酸收之品如白芍、五味）
- ❌ **滋腻太过不运化**（熟地、阿胶等需配砂仁、陈皮）

## 五、血毒Ⅳ层（成数9·金之成→10·土之成）

### 5.1 病机详解

瘀腐化毒，败坏形质。本质是**血瘀日久，腐化为毒，腐蚀血脉、败坏脏腑**。

河图9为金之成数——金主杀伐、肃降、消削。瘀毒入血，如金之杀伐。
河图10为土之成数——土成万物，败亦归土。血毒败坏脏腑形质。

这是四层中最深层、最难治的一层。

### 5.2 四诊特征

| 诊法 | 特征 | 说明 |
|:---|:---|:---|
| **望** | 面色黧黑、肌肤甲错、口唇紫暗、舌质紫暗有瘀斑、爪甲枯槁、皮肤瘀斑或溃疡 | 瘀毒败血，形质已伤 |
| **闻** | 口气腥臭、分泌物恶臭 | 瘀腐成毒 |
| **问** | 癥瘕坚硬、疼痛拒按、久病不愈、发热夜甚、消瘦枯槁 | 瘀毒日久，气血俱伤 |
| **切** | 脉沉涩或沉弦有力，或结代 | 血毒内伏，脉道艰涩 |

### 5.3 方药阶梯

| 层级 | 方剂 | 药味 | 体用解析 |
|:---:|::---|:---|:---|
| **轻型** | 大黄䗪虫丸 | 大黄（苦寒）+䗪虫+水蛭+虻虫+蛴螬+桃仁+杏仁+黄芩+生地+白芍+甘草+干漆 | 咸苦辛三焦并攻，逐瘀解毒 |
| **中型** | 抵挡汤 | 大黄（苦寒）+水蛭（咸苦）+虻虫+桃仁 | 攻逐瘀血，通利血脉 |
| **重型** | 鳖甲煎丸 | 鳖甲+䗪虫+蜂房+鼠妇+大黄+桃仁+丹皮+紫葳+赤硝+柴胡+黄芩+芍药+桂枝+干姜+厚朴+石韦+葶苈+瞿麦+半夏+人参+阿胶+蜂蜜 | 化瘀消癥，攻补兼施 |
| **极重型** | 化癥回生丹 | 人参+肉桂+麝香+姜黄+花椒炭+虻虫+水蛭+䗪虫+三棱+莪术+苏木+桃仁+红花+益母草+两头尖+乳香+没药+降香+丁香+香附+元胡+吴萸+高良姜+干姜+阿魏+艾叶炭+川乌+熟地+白芍+当归+地黄+鳖甲+龟板+大黄+五灵脂+蒲黄炭+杏仁+山茱萸+小茴香 | 极重瘀毒，需大剂攻逐 |

### 5.4 加减规则

- 毒盛 → +全蝎、蜈蚣、僵蚕（虫类搜剔攻毒）
- 兼虚 → +人参、当归、熟地（攻补兼施）
- 局部溃疡 → +黄柏、黄连（苦寒燥湿解毒）
- 疼痛剧烈 → +乳香、没药（活血定痛）

### 5.5 针法配穴

| 取穴 | 手法 | 原理 |
|:---|:---:|:---|
| **血海（脾经）** | 泻法 | 活血化瘀，兼清血毒 |
| **膈俞（血会）** | 泻法 | 逐瘀排毒，血会通诸经 |
| **大椎（督脉）** | 刺络拔罐 | 清热解毒，排毒外出 |
| **委中（膀胱合）** | 刺络出血 | 血毒从血络排出 |
| **局部围刺** | 泻法 | 逐局部瘀毒 |

### 5.6 临床禁忌

- ❌ **纯补不攻**（瘀毒不去，补之反助毒势）
- ❌ **过于恐破**（瘀毒重症需猛攻，中病即止）
- ❌ **不兼顾正气**（攻毒必伤正，须攻补兼施）

## 六、血分四层传变规则

### 6.1 顺传路径

```
    血热Ⅰ ──→ 血瘀Ⅱ ──→ 血虚Ⅲ ──→ 血毒Ⅳ
    （热入血）  （血行滞）  （血亏耗）  （瘀化毒）
```

**自然病程：**
- 急性热病：起病→血热Ⅰ（数日）→治不及时→血瘀Ⅱ（数周）
- 慢性久病：气分久病→入血→血瘀Ⅱ（数月→数年）→血虚Ⅲ→血毒Ⅳ
- 外伤/手术：直接血瘀Ⅱ→久不愈→血虚Ⅲ或血毒Ⅳ

### 6.2 跳层传变

| 路径 | 原因 | 表现 |
|:---|:---|:---|
| Ⅰ→Ⅲ直接 | 血热大耗阴血 | 热退后血虚明显，瘀象不重 |
| Ⅰ→Ⅳ直接 | 疫毒炽盛 | 热毒直入骨髓，败坏形质 |
| Ⅱ→Ⅳ直接 | 外伤感染+瘀血 | 外伤瘀血+感染→瘀毒 |
| Ⅲ→Ⅱ（虚中夹瘀） | 久虚致瘀 | 血虚不运→继发瘀血 |

### 6.3 气分→血分传变

**气分病久治不愈→入血，是内伤杂病最常见的传变路径：**

```
气分阶段（体用双轨体系覆盖）：
气虚（补体）→气郁（泄用）→气逆（降气）

传变节点：
气虚日久→不摄血→血溢脉外→血瘀Ⅱ
气郁日久→气滞血瘀→血瘀Ⅱ
气逆日久→迫血妄行→血热Ⅰ

血分阶段（血分四层覆盖）：
血热Ⅰ→血瘀Ⅱ→血虚Ⅲ→血毒Ⅳ
```

### 6.4 临床决策树

```
患者来诊 → 先分气分还是血分
├─ 主诉在气分 → 体用双轨体系
└─ 主诉在血分 → 血分四层诊断
    ├─ 热象明显（身热夜甚、斑疹、舌绛）→ 血热Ⅰ
    ├─ 痛有定处（刺痛、癥瘕、紫暗）→ 血瘀Ⅱ
    ├─ 面色苍白（头晕、心悸、舌淡）→ 血虚Ⅲ
    └─ 肌肤甲错（癥瘕坚硬、消瘦、紫黑）→ 血毒Ⅳ

├─ 血分单层 → 直接对应层治疗
├─ 血分双层 → 主次分明、兼顾
└─ 血分+气分 → 先调气后治血,或气血双调
    
各层优先治疗顺序：
    血毒Ⅳ > 血热Ⅰ > 血瘀Ⅱ > 血虚Ⅲ
    急则治其标：血毒/血热最急 > 血瘀次之 > 血虚可缓治
```

## 七、血分五经辨证（补充五脏对应）

### 7.1 肝经血分证

## 十、血分证用药禁忌

### 10.1 各层禁忌

| 层级 | 忌用 | 原因 |
|:---:|:---|---:|
| 血热Ⅰ | 辛温燥血（桂枝、川芎、当归身） | 辛温助热，血热更炽 |
| 血热Ⅰ | 纯甘壅补（熟地、阿胶纯用） | 补反助火，需佐苦寒 |
| 血瘀Ⅱ | 纯寒凝滞（石膏、黄连过用） | 血得寒则凝，反加重瘀 |
| 血瘀Ⅱ | 滋腻太过（熟地纯用） | 滋腻碍气，气滞血更瘀 |
| 血虚Ⅲ | 破血攻逐（三棱、莪术、水蛭） | 耗血太过，虚者更虚 |
| 血虚Ⅲ | 纯辛散太过（麻黄、细辛、羌活） | 辛散耗血 |
| 血毒Ⅳ | 纯补不攻（仅用人参、熟地） | 补反助毒，瘀毒不去 |
| 血毒Ⅳ | 攻而不补（纯用虫类攻逐） | 正气不支 |

### 10.2 血分通用禁忌

- **经期慎用破血**（非必要不攻，免致崩漏）
- **妊娠禁用活血破血**（桃仁、红花、水蛭、虻虫）
- **出血倾向慎用活血**（血小板低、凝血障碍）
- **体虚者破血要缓**（中病即止，不能久用）

## 十一、血分框架与体用双轨的临床对接

### 11.1 气血双跨的临床策略

| 场景 | 策略 | 示例 |
|:---|:---|:---|
| 气分证为主，兼血分 | 先调气，后治血 | 肝郁气滞+血瘀→先柴胡疏肝散，后加桃红 |
| 血分证为主，兼气分 | 治血为主，兼调气 | 血瘀+气滞→血府逐瘀（气血双跨） |
| 气分→血分传变中 | 气血同调，偏血分 | 久病入血早期→桃红四物+柴胡 |
| 虚实夹杂（体虚+血瘀） | 先化瘀后补虚，或攻补兼施 | 虚劳夹瘀→大黄䗪虫丸（攻补兼施） |

### 11.2 与间接补益框架的对接

| 场景 | 气分路径 | 血分路径 |
|:---|:---|:---|
| 肝体虚不受补 | 间接补益（补肺→益肝） | 血虚Ⅲ→养血为主 |
| 心体虚夹瘀 | 苦+甘补心体 | 血瘀Ⅱ+血虚Ⅲ→化瘀养血 |
| 肾虚夹湿热水肿 | 咸+甘补肾体+苦泄肾用 | 血热Ⅰ+血瘀Ⅱ→清血热+化瘀 |

### 11.3 与六腑定位框架的对接

| 六腑 | 气分病 | 血分病 |
|:---|:---|:---|
| 胆 | 胆郁痰扰→温胆汤 | 胆郁血瘀→血府逐瘀汤+郁金 |
| 胃 | 胃气不降→半夏泻心 | 胃络血瘀→丹参饮+失笑散 |
| 大肠 | 大肠湿热→芍药汤 | 肠风下血→槐花散 |
| 膀胱 | 膀胱湿热→八正散 | 膀胱瘀热→桃仁承气汤 |

> **临床核心提示：**
> - 血分四层不是独立疾病，是血分病变的四个阶段/层次
> - 多数患者为混合型（如Ⅱ兼Ⅲ、Ⅰ兼Ⅲ），需主次分明
> - 治血不忘调气——气行则血行，气滞则血瘀
> - 血证越深（Ⅳ→Ⅰ），越需急治；血证越浅（Ⅲ→Ⅳ），越需缓图
> - 血分框架与体用双轨体系、间接补益框架、六腑定位框架共同构成完整辨证体系
