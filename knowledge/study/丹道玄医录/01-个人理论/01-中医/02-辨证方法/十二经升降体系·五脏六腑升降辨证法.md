# 十二经升降体系·五脏六腑升降辨证法

> **源出**：《十二经升降提纲》（彭子益/黄元御学派）
> **融合**：后天八卦水火立极、内伤外感双规辩证
> **核心公式**：**中气如轴，经气如轮。左升右降，旋转乃平。**

---

## 一、体系总纲

### 1.1 后天八卦·升降根基

游兄论断——**后天八卦水火立极，左升右降五行循环，土居西南东北中轴，是后天五行五脏辨证的根基理论**：

| 后天八卦 | 五脏新解 | 升降 | 核心功能 |
|:---------:|:---------:|:----:|:---------|
| **乾☰** | **肺与大肠**（金性覆盖如大气层） | 肺降大肠升 | 收敛包裹，覆盖五脏 |
| **坤☷** | **脾与胃**（土性承载居中轴） | 脾升胃降 | 中气运转，四维皆运 |
| **离☲** | **心与小肠**（火居上） | 心降小肠升 | 心火下降→小肠火升→化物分水 |
| **坎☵** | **肾与膀胱**（水居下） | 肾升膀胱降 | 肾阳升→寒水降→水道气化 |
| **震☳** | **肝与胆**（木居左） | 肝升胆降 | 左升疏泄，枢机调达 |
| **兑☱** | **肺与大肠**（金居右） | 肺降大肠升 | 右降收敛，气机肃降 |

**体用使三层关系**：

> **体**：心降肾升为水火既济之体（离坎立极）
> **用**：脾升胃降为中轴运转之用（坤艮居中）
> **使**：肝升胆降为升降枢机之使（震巽调达）

### 1.3 逆则病热，陷则病寒

升降辨证的总原则只有八个字：

> **逆则病热，陷则病寒**

| 方向 | 病性 | 病位 | 常见表现 |
|:----|:----|:-----|:---------|
| **不降（逆）** | 热在上 | 上焦诸经 | 呕、咳、烦、胀、不寐 |
| **不升（陷）** | 寒在下 | 下焦诸经 | 利、带、遗、坠、酸、冷 |

**治病根本**：复其升降，先顾中气。

## 二、降经辨证（不降则上逆）

### 2.1 胃经不降

**核心病机**：「胃是诸经降之门」——胃不降则上焦诸经皆无降路。

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **呕**（呕吐绿色苦水） | 胆逆犯胃，胆汁上冲 | 清降胆热，温补中气 |
| **吐**（食入即吐/朝食暮吐） | 胃虚热/脾弱不化 | 清降胆胃/温补脾土 |
| **嗳**（嗳酸、嗳气） | 宿食停胃，胆经降路受阻 | 去滞清热 |
| **痞**（胸痞闷、心下痞） | 胃不降则胆肺皆无降路 | 清降胆胃（热）/温补中气（寒） |
| **胀**（头项胸腹作胀） | 胃经自头走足，不降则经气盘塞 | 理滞降逆，调木顾中 |
| **眩**（头目晕眩） | 热逆化浊，上重下轻 | 清降胆胃，补中去滞 |
| **惊**（惊悸不安） | 胃不降→胆逆→相火飞腾 | 清降胆胃，温补中气 |
| **不寐**（失眠） | 胃不降→阳气不降不能交阴 | 降胃补中 |
| **血衄**（吐血/鼻衄） | 胃气不降兼肺胆之逆 | 寒湿温补，燥热清降 |
| **痰**（黄稠/白黏） | 相火熏蒸水液不降 | 清降肺胆（黄）/润肺滋肝（白） |
| **烦**（心烦） | 心与心包火气不降 | 清热养中 |
| **渴**（口渴） | 燥气/湿气耗伤津液 | 燥渴补气清肺，湿渴燥土利尿 |
| **浊带遗利**（白浊/带下/遗精/晨泻） | 上焦不降→下焦不藏 | 清降胆胃，敛肺去滞 |
| **鼓肿**（气鼓/水肿） | 胆热阻中→气不化水/水不化气 | 降胃降胆兼降肺（气鼓）/升肝脾（水肿） |

---

### 2.2 胆经不降

**核心病机**：「此经能决十一经」——胆经相火下降则水中火生、中土有根。

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **呕** | 胆属甲木主动，逆而犯胃 | 补中清热，兼降胆胃 |
| **咳** | 胆火逆而刑肺金 | 补中降胆 |
| **胀**（头项胸胁胀） | 胆经循行路线盘塞 | 补中降胆 |
| **头面诸痛**（耳痛耳鸣、目赤、额角痛、腮肿、口苦、牙痛、咽痛） | 胆经不降，横塞上冲 | 补中降胆，兼理逆热 |
| **消**（消渴善饥） | 风火上动，食饮被风气消去 | 息风温肾，清热养水 |
| **冲**（心跳气逆） | 风火上冲 | 息风温肾，清热养水 |
| **泄肾**（肾气被泄而寒陷） | 胆经不降→肾中相火拔泄外出 | 补中降胆 |
| **寒上热下** | 相火逆上则上热，下焦无火则下寒 | 温补中气，兼降胆经 |
| **协热下利** | 胆火上逆，火泄于外 | 清降胆胃，温补中气 |
| **往来寒热** | 胆居半表半里，阻碍阴阳交通 | 清降胆经，兼补中气 |

---

### 2.3 肺经不降

**核心病机**：肺主收敛——**肺金不敛则胆木无制、相火拔根、中气遂寒，虚劳之根在此。**

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **咳** | 中虚而肺胃不降（分风热湿燥寒） | 各随其因而治 |
| **痰** | 肺胃不降，相火熏蒸水液成痰 | 清降肺胃 |
| **短气**（吸气困难） | 胸中水饮阻隔/风热上冲 | 泄水保中/清降 |
| **汗**（自汗/盗汗） | 肺收敛弱→肝疏泄盛 | 降肺补中（自汗）/敛肺降胆（盗汗）|
| **肺痿** | 热痿津亏/寒痿肺虚寒不收 | 清热养肺/温补中气 |
| **肺痈**（咳吐腥臭脓痰） | 肺热瘀积成痈 | 下痰保中 |
| **烦**（心烦） | 火逆伤肺，火气散漫 | 清降胆胃，兼养中气 |
| **喘** | 燥/水/外感/虚/风/湿六种 | 各随其因 |
| **声哑** | 湿气逼住火气，肺不清降 | 除湿敛肺 |
| **喉痛** | 中虚肺逆，火气上炎 | 补中降肺（中气为本）|
| **水肿** | 肺不降→收敛衰→水溢皮肤 | 清降肺胃，除湿温中 |
| **头晕** | 肺不降→浊热逆冲，上重下轻 | 清降肺胃 |

---

### 2.4 心经不降

**核心病机**：心火下降交于肾水则神清，**不降则热浮于上，实为中气大败。**

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **神明昏惑**（神志不清） | 心火不降，热气上炎 | 清肺补中 |
| **舌红**（非真热） | 心火不降浮越于上，唇龈淡白为中败假热 | **温中降火**，切忌凉药 |

---

### 2.5 心包经不降

**核心病机**：心包相火不降则肾水寒、中土绝根，**关键在中虚而非火实。**

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **心烧**（自觉心区灼热） | 心包相火不降 | **温补中气**，清降逆火 |
| **肾水增寒** | 相火不降入水中→水中无火 | 温补中气，兼降胆胃 |

---

### 2.6 膀胱经不降

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **恶寒项强**（外感） | 荣卫外感，膀胱经气不降 | 按伤寒论治 |
| **背恶寒**（无外感） | 肾阴盛灭阳，膀胱腑阳将败 | 温补中气，兼补肾阳 |
| **小便热** | 火陷/木郁/脾湿/肺不降/湿热伤津等 | 随因治之，非膀胱本经之事 |

## 三、升经辨证（不升则下陷）

### 3.1 脾经不升

**核心病机**：「脾是诸经升之关」——脾不升则下焦诸经之气皆不升。

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **利清谷**（完谷不化腹泻） | 脾阳下陷，不能磨化 | 温燥脾土，甚则温肾 |
| **满肿**（腹胀/水肿） | 脾不升→气不运则满，水不运则肿 | 燥土疏木 |
| **带浊**（白带/白浊） | 脾湿下注，兼肺肝之热 | 敛肺润肝，不可燥湿 |
| **脐下筑痛** | 脾不升→肝肾清阳下陷化寒 | 调中击滞，兼温肾肝 |
| **便血** | 脾湿阻碍肝升，肝郁陷而下泄 | 温肾达肝，除湿清热 |
| **后重**（肛门坠重） | 脾寒陷→大肠肝经双陷 | 养木除湿，清热温寒 |
| **腰膝酸** | 脾湿下注，肝肾郁陷 | 燥土暖水，温润肝木 |
| **关节湿疼** | 脾湿淫溢关节 | 燥土暖水，兼清木热 |
| **手足冷** | 脾阳陷败，不能达于四肢 | 温补中气，兼温肾气 |
| **身重** | 脾不升→湿气停瘀 | 除湿燥土 |
| **口干**（不思饮） | 脾阳不升，气不蒸津 | 温升脾阳，兼补中气 |
| **四肢不用** | 脾阳达不到四肢 | 温中燥土，兼调荣卫 |
| **黄疸** | 脾陷湿瘀，肝郁化热传土 | 清热除湿（阳黄）/温补脾肾（阴黄）|
| **疟**（寒热往来定时） | 脾陷磨化弱→阻碍胆经荣卫循环 | 理中去滞，兼调胆经 |
| **癥瘕**（腹中积块） | 脾陷磨化弱→瘀积日深 | 养中补气，磨积消瘀 |

### 3.2 肝经不升

| **腹痛** | 木气下陷，疏泄不通 | 温水达木，补中去滞 |
| **遗精**（有梦） | 肝木疏泄太过，络滞经塞 | 降甲木，舒乙木，养中气，通经络 |
| **遗精**（无梦） | 中下真寒，气陷不升 | 温补肝肾，并补中气 |
| **淋**（小便不通涩痛） | 木陷土湿，郁而生热 | 去湿达木，补中清热 |
| **痢**（里急后重下红白） | 湿热伤金，肝经滞陷 | 温升肝脾，清降肺胃 |
| **痔**（肛门痔疮） | 木火陷于肛门为湿所阻 | 温陷清热，去滞养中 |
| **便血/溺血** | 木陷疏泄于后/前 | 温陷燥土，清热息风 |
| **脱肛** | 中虚木陷，金气不收 | 降肺降胆，温中补脾 |
| **盗汗/阴汗** | 胆不降→肝不升→疏泄郁陷 | 降胆温肝，补中敛肺 |
| **疝**（睾丸肿痛） | 肝木下陷，阳气不达 | 温下清热，去滞养中 |
| **奔豚**（气从少腹上冲） | 中虚胃逆，水寒木陷 | 调木养土，温寒清热 |
| **月经病**（过早/过迟） | 肝陷郁怒生风，疏泄失度 | 降甲木以升乙木 |
| **半产/漏下** | 肝血不足/瘀血阻碍肝升 | 润木息风/养中去滞 |
| **血崩** | 甲木不降→乙木不升→疏泄妄行 | 清木补肺，去滞调中 |
| **目病**（寒痛） | 肝陷目病 | 温补中气，兼达肝阳 |
| **消渴**（食饥饮渴） | 肝木郁陷生风，风消津液 | 滋肝温肾，补肺顾中 |
| **手足厥冷** | 木陷阳亡 | 大温中下 |
| **舌卷** | 肝阳下陷，舌为心窍失养 | 温补肝脾 |
| **躁动**（临终） | 木陷阳亡，中气失根 | 温养水木，回阳补中 |
| **缩阴**（肾囊缩） | 木陷阳亡 | 大温中下，兼补肝血 |

### 3.6 肾经不升

**核心病机**：「肾者身之本」——下焦诸升之气皆以肾中阳气为基。人死阳亡，即是水中火灭。

| 症状 | 病机 | 核心治法 |
|:-----|:-----|:---------|
| **遗尿/遗粪** | 肾中阳微，不能上升 | 温补肾阳 |
| **下利** | 肾阳不升 | 温补肾阳 |
| **足寒/背寒** | 肾寒阳微 | 温补肾阳 |
| **不寐**（但欲寐而寐不着） | 肾阳不升 | 温补肾阳 |
| **尻疼**（尾脊骨痛） | 肾寒阳微 | 温补肾阳 |
| **坐不定**（脊骨无力） | 肾寒阳微 | 温补肾阳 |
| **口淡面灰** | 命门火冷 | 温补中下 |

## 四、辨证口诀

### 4.1 升降总诀

```
心火不降烦不寐    肺气不降咳喘痰
胃气不降呕痞胀    胆气不降呕咳眩
脾气不升利满带    肝气不升痛遗疝
肾气不升遗利寒    上下升降一循环

上焦诸病多不降    下焦诸病多不升
逆不病寒陷不热    逆寒火虚热本性
右虚左实上下根    升降四维中央问
```

### 4.2 降经辨证三步诀

> **一问呕痞胀**（胃经——降之门）
> **二问眩惊苦**（胆经——十二经之决）
> **三问咳痰喘**（肺经——收敛之本）
> **——上焦病先问降，三经不顺百疾生。**

### 4.3 升经辨证三步诀

> **一问利满带**（脾经——升之关）
> **二问痛遗疝**（肝经——五脏之贼）
> **三问遗利寒**（肾经——身之本）
> **——下焦病先问升，三经不升百病成。**

## 五、与内伤外感双规辩证的融合

### 5.1 升降视角下的"双规"新解

| 双规 | 六经辨证（开路） | 五脏辨证（填补） |
|:----:|:----------------|:----------------|
| **升降核心** | 辨经气之**逆陷** | 辨脏腑之**虚实** |
| **主问** | 哪一经不升/不降？ | 哪一个脏腑虚/实？ |
| **主法** | 复其升降，以通为顺 | 补其不足，以填为要 |
| **先后关系** | 逆陷不通，补益无路 | 升降已复，方可进补 |

### 5.2 升降→六经→五脏 三层递进

```
症状
  ↓
① 升降定向（第一步判断）
   ├─ 上焦病（头面胸心）→ 降经不降
   └─ 下焦病（腹腰二便）→ 升经不升
  ↓
② 六经定位（第二步定位）
   ├─ 呕痞胀 → 胃经不降     ├─ 利满带 → 脾经不升
   ├─ 眩惊苦 → 胆经不降     ├─ 痛遗疝 → 肝经不升
   ├─ 咳痰喘 → 肺经不降     ├─ 遗利寒 → 肾经不升
   └─ 心烦烧 → 心/心包不降   └─ 水寒 → 三焦/小肠不升
  ↓
③ 五脏定性（第三步定补）
   ├─ 胃不降 → 养胃阴+降逆     ├─ 脾不升 → 温脾阳+升清
   ├─ 胆不降 → 清胆热+降火     ├─ 肝不升 → 温肝血+达木
   ├─ 肺不降 → 宣肺气+肃降     ├─ 肾不升 → 补肾阳+纳气
   └─ 心不降 → 降心火+交泰     └─ 三焦小肠不升 → 温命门
```

### 5.3 升降辨证与双规辨证的接口

| 升降状态 | 对应双规阶段 | 方药策略 |
|:---------|:------------|:---------|
| **降经逆为主** | 六经开路（降逆） | 半夏厚朴汤/小柴胡汤/杏苏散等降逆方 |
| **升经陷为主** | 六经开路（升陷） | 补中益气汤/理中汤/真武汤等升陷方 |
| **升降俱病** | 六经开路（调中） | 柴胡桂枝干姜汤/黄连汤等调和方 |
| **升降复、脏腑虚** | 五脏填补 | 六味/八味/归脾/补中益气等补益方 |
| **升降复、脏腑实** | 五脏清泻 | 龙胆泻肝/导赤散/泻白散等清泻方 |

## 六、辨证流程优化方案

### 6.1 三阶十步辨证法（优化后）

```
【第一阶：升降定向】—— 辨病势
  ├─ ① 问病位（上焦/中焦/下焦/全身）
  ├─ ② 问病势（逆上/下陷/郁滞/散漫）
  └─ ③ 定升降（降经不降/升经不升/升降俱病）

【第二阶：六经定位】—— 辨病经
  ├─ ④ 降经排查（胃→胆→肺→心/心包→膀胱）
  ├─ ⑤ 升经排查（脾→肝→大肠→小肠→三焦→肾）
  ├─ ⑥ 定主经/次经（主要病经+兼证病经）
  └─ ⑦ 定合病模式（两经同病/三经同病）

【第三阶：五脏定性】—— 辨病本
  ├─ ⑧ 辨虚实（虚则补之，实则泻之）
  ├─ ⑨ 辨寒热（逆则热，陷则寒，兼以五运）
  └─ ⑩ 出方案（针法/方药/外治，升降为纲）
```

### 6.3 工具优化方案

基于现有六经辨证诊断工具，建议增加以下功能模块：

**模块一：升降速诊模式**
- 输入：主诉症状（如上所述主症速查表入口）
- 输出：升降定向结果 + 建议排查的六经顺序
- 位置：放在六经辨证之前，作为第一阶预诊断

**模块二：升降→六经→五脏三层递进诊断**
- 当前六经辨证工具只做六经定性
- 优化后：输出含三个层次——升降方向→六经归属→五脏虚实衔接
- 在六经辨证结果中增加"升降属性"标签（↑降经逆/↓升经陷/↔升降俱病）

**模块三：升降方药推荐**
- 降经不降 → 推荐降逆方药
- 升经不升 → 推荐升陷方药
- 升降俱病 → 推荐调和方药
- 升降已复 → 推荐五脏补益方

## 七、升降辨证核心要义

### 7.1 三个务必

1. **务必先辨升降，再辨六经**——升降定大势，六经定病位
2. **务必顾中气**——中气如轴，轴运则轮行。**治升降必先顾中气**
3. **务必升降互参**——降经之病可引起升经不升（如胃不降→脾不升），升经之病也可引起降经不降（如脾不升→胃不降）。**升降互为因果**

### 7.2 三个切忌

1. **切忌见逆即攻**——逆多为虚，攻之则中气更败
2. **切忌见陷即补**——陷多夹湿/夹滞/夹郁，纯补则壅塞
3. **切忌见热即清**——上热多由下寒（胆经不降→相火逆上），清之则中气更寒

### 7.3 临证心法

> **治升降者，治气机也。**
> **气机一复，百病自退；气机一乱，百药罔效。**

升降辨证的终极目的不是找出"哪一经病了"，而是**恢复人体气机本来的升降秩序**。秩序复，正气自回；正气回，邪气自退。此之谓**以不治治之**。
