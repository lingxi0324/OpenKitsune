# 六经辨证·白血病证治体系

## 一、总纲

### 疾病本质
**正气极虚 → 寒/毒直入少阴、厥阴，深伏骨髓，血分败坏**

### 六经传变规律
```
太阳（表虚）→ 少阳（半表半里，伏热）→ 阳明（毒热炽盛）
→ 太阴（脾虚痰湿）→ 少阴（肾阳虚衰，寒入骨髓）
→ 厥阴（阴阳离决，出血、衰竭）
```

### 临床最多见三型
1. **少阴病型** > 2. **厥阴病型** > 3. **少阳少阴合病** > 4. **太少两感**

---

## 二、六经分型详论

### 1）太阳病型（初发/轻症/化疗后表虚）

| 项目 | 内容 |
|:----|:------|
| **病机** | 卫阳不固，外感寒邪，正气尚在 |
| **主证** | 易感冒、汗出恶风、低热、乏力、骨痛不剧 |
| **治法** | 调和营卫，固表祛邪 |
| **主方** | **桂枝汤合玉屏风散** |
| **药物** | 桂枝、白芍、生姜、大枣、炙甘草、黄芪、白术、防风 |

---

### 2）少阳病型（持续低热、免疫紊乱）

| 项目 | 内容 |
|:----|:------|
| **病机** | 邪郁半表半里，三焦不利，伏毒内蕴 |
| **主证** | 往来寒热、口苦、胸胁满、眠差、淋巴结肿大 |
| **治法** | 和解少阳，清透伏邪 |
| **主方** | **小柴胡汤** |
| **药物** | 柴胡、黄芩、半夏、人参、炙甘草、生姜、大枣 |
| **加味** | 青黛、莪术、浙贝母（散结、抑癌） |

---

### 3）阳明病型（高白、高热、出血、急淋急非淋暴发型）

| 项目 | 内容 |
|:----|:------|
| **病机** | 热毒炽盛，入血入营，迫血妄行 |
| **主证** | 高热、烦躁、出血（皮下、牙龈、鼻衄）、舌红绛、脉洪大 |
| **治法** | 清热解毒，凉血止血 |
| **主方** | **白虎汤合犀角地黄汤**（水牛角代犀角） |
| **药物** | 石膏、知母、粳米、甘草、水牛角、生地、赤芍、丹皮 |
| **加味** | 白花蛇舌草、半枝莲、青黛 |

---

### 4）太阴病型（化疗后、脾虚湿盛、低增生性）

| 项目 | 内容 |
|:----|:------|
| **病机** | 脾阳不足，痰湿内停，气血生化无源 |
| **主证** | 乏力、纳差、便溏、面色萎黄、四肢不温、白细胞低 |
| **治法** | 温中健脾，益气养血 |
| **主方** | **理中汤合四君子汤** |
| **药物** | 人参、干姜、白术、炙甘草、茯苓 |
| **加味** | 黄芪、当归、补骨脂 |

---

### 5）少阴病型（核心型！寒入骨髓）

| 项目 | 内容 |
|:----|:------|
| **病机** | 肾阳虚衰，阴寒内盛，寒邪直入骨髓，精血大亏 |
| **临床地位** | **最多、最核心、最久、最难治的一型** |
| **主证** | 极度畏寒、四肢厥冷、骨痛剧烈（寒凝不通）、面色㿠白/黧黑、精神萎靡、嗜睡、舌淡胖、苔白滑、脉沉微 |
| **治法** | 回阳救逆，温肾填髓，破寒凝 |
| **主方** | **四逆汤合右归丸化裁** |
| **药物** | 制附子（先煎）、干姜、炙甘草、肉桂、熟地、山萸肉、山药、枸杞、杜仲、当归、补骨脂 |
| **必加透骨搜邪** | 细辛、麻黄（少量开表透寒）、青黛、鹿角胶 |

> **核心思路**：砒霜/雄黄类辛热毒烈药最对症——**"以大热破大寒"**。

---

### 6）厥阴病型（终末期、出血、DIC、衰竭）

| 项目 | 内容 |
|:----|:------|
| **病机** | 阴阳格拒，寒热错杂，气阴将绝 |
| **主证** | 四肢厥冷 vs 心中烦热、吐血、便血、崩漏不止、神昏、躁扰、脉微欲绝 |
| **治法** | 寒热并用，固脱止血，回阳益阴 |
| **主方** | **乌梅丸合通脉四逆汤加减** |
| **药物** | 乌梅、黄连、黄柏、附子、干姜、桂枝、人参、当归、蜀椒 |
| **加味止血** | 阿胶、仙鹤草、三七粉（止血固脱） |

## 三、临床最实用的「六经合病」组合

### 1）太少两感（太阳 + 少阴）
- **临床特征**：畏寒、发热、骨痛、极度乏力
- **主方**：**麻黄附子细辛汤**
- **要点**：开表透寒，温少阴，最适合初发、骨痛暴作

### 2）少阳少阴合病（最常见长期型）
- **临床特征**：低热不退、眠差、乏力、畏寒、淋巴结大
- **主方**：**小柴胡汤合四逆汤**
- **要点**：和解伏邪 + 温肾回阳，长期稳定方

### 3）厥阴少阴合病（晚期、反复出血）
- **临床特征**：阴阳两虚，反复出血
- **主方**：**通脉四逆汤 + 乌梅丸**
- **要点**：回阳救逆，固摄精血

## 四、大热药治白血病的六经视角

| 六经 | 治法 | 代表药 |
|:----|:-----|:-------|
| **太阳** | 开表祛邪 | 桂枝、麻黄 |
| **少阳** | 透发伏邪 | 柴胡、黄芩 |
| **阳明** | 清泻毒热 | 石膏、知母 |
| **太阴** | 建中固本 | 人参、干姜、白术 |
| **少阴** | **大辛大热破寒** | **附子、肉桂、细辛、麻黄、砒霜、雄黄** |
| **厥阴** | 回阳固脱 | 附子、干姜、乌梅、人参 |

> **核心结论**：砒霜、雄黄、附子、肉桂、细辛、麻黄——都是少阴、厥阴的**"破寒伏、起沉疴"**之药。

## 五、与丹道玄医录已有体系的衔接

### 5.1 与奇门遁甲诊断法衔接

少阴病型白血病患者就诊时辰的奇门盘，天芮星的落宫可辅助判断病情深浅：
- **天芮落坎宫（肾）** → 少阴寒化，病在骨髓
- **天芮落坤宫（脾）** → 太阴湿困，气血生化乏源
- **天芮+死门** → 预后慎重的信号
- **中宫值符+吉门** → 虽病重仍可治

### 5.2 与五门十变幻化衔接（针法辅助）

对于少阴型（寒入骨髓）患者，针法辅助方案：

| 化合 | 配穴 | 作用 |
|:----|:-----|:-----|
| **戊癸化火** | 阴谷+三里（补法） | 温肾阳，水中化火 |
| **甲己化土** | 临泣+公孙（补法） | 运中焦，生化气血 |
| **丙辛化水** | 阳谷+太渊（平补平泻） | 调水火，防温燥太过 |
| **局部** | 关元、命门（温针灸） | 直接温补肾阳 |

### 5.3 与五脏九宫矩阵衔接

白血病在九宫矩阵中的核心失衡维度：
- **中列（1肾+5脾+9肺脾）** → 肾精亏+脾不运+肺气虚
- **主对角线（6脾肾+5脾+4肺）** → 水液代谢失常
- **核心中宫（5脾）** → 脾土不运，百药难效

## 六、总结

> **白血病六经辨治的核心：**
> 太阳开表、少阳透邪、阳明清毒、太阴建中、
> **少阴破寒（核心）、厥阴固脱**。
>
> **寒入骨髓者，非大辛大热不能破；**
> **精血大亏者，非温肾填髓不能复。**
