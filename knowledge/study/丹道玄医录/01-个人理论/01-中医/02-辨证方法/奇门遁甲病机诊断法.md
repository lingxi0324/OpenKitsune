## 一、理论基础——奇门遁甲何以断病

### 1.1 中医经典中的时空医学依据

> **「不知年之所加，气之盛衰，虚实之所起，不可以为工矣。」**
> ——《素问·六节藏象论》

### 1.3 核心原理

> **「人与天地相参，与日月相应也。」**
> ——《灵枢·岁露论》

奇门遁甲排盘时，将**时间（四柱干支）× 空间（洛书九宫）× 能量（阴阳遁局数）** 三者合为一体，输出的是**此时此刻天、地、人三才之气在九宫中的分布状态**。

患者在此刻就诊，其病机必然与此盘能量分布相应——这便是奇门遁甲可以判断病机的根本依据。

**灵汐按**：奇门断病与传统辨证并非替代关系，而是互补关系。传统辨证＝显微镜（看细节），奇门辨证＝望远镜（看格局）。当信息不全、症状复杂、虚实难辨时，奇门可提供全局参照。

### 3.2 八门组合判断法

两个以上门同时指向同一脏腑时，诊断置信度大幅提升：

| 组合 | 诊断意义 | 举例 |
|:----|:---------|:-----|
| **伤门 + 死门同宫** | 久病入络、瘀血顽疾 | 慢性疼痛伴脏腑损伤 |
| **惊门 + 景门同宫** | 心火亢盛导致神志不安 | 焦虑伴心烦发热 |
| **杜门 + 休门同宫** | 虚性阻塞—正气不足导致的推动无力 | 老年性便秘（气虚不运） |
| **死门 + 杜门同宫** | 肿瘤、癥瘕积聚 | 需高度警惕占位性病变 |

### 3.3 门迫与门制——病情轻重判断

- **门迫**（门克宫）：病邪克脏腑——病进，病势加重
- **门制**（宫克门）：脏腑制病邪——病退，正气可御
- **门迫 + 凶门**：病势凶险，需急治
- **门制 + 凶门**：虽凶但可控，正气尚存

**例**：死门落震宫（门克宫＝门迫），震属木、死门属土，土木相克——肝脾不调的重证，脾胃之气受肝木所克，病势在进展。

### 7.2 第二步：观宫——地盘九宫定位病位

**病星（天芮/死门等凶星凶门）落宫 = 病位所在脏腑**

### 7.3 第三步：辨门——人盘八门定性病机

### 7.5 第五步：合参——五门十变+传统辨证定治疗方案

按**时干化合**选定五门十变化合组为核心，结合八门九星八神的信息做加减。

## 九、特殊情况处理

### 9.1 信息不全时

| 情况 | 处理策略 |
|:-----|:---------|
| **不知患者出生年** | 以日干为患者，时干为病情 |
| **不知具体发病时间** | 以就诊时间为准——就诊时刻的能量场已包含病机信息 |

| **多个患者同时就诊** | 同一盘面，日干相同 → 以**年命干支**区分各人（详见9.4） |

### 9.2 急症判断

|:----|:-----|:-----|

### 9.3 奇门盘空亡的处理

旬空之宫表示**该脏腑正气不足、气血空虚**：
- 患者日干落空亡＝正气已虚，需先扶正
- 病星落空亡＝病有虚证的一面，不可一味攻邪
- 用神落空亡＝信息不全，需结合临床四诊核实

### 9.4 同盘异命·多人分诊法

> **临床场景**：同一时辰来多位患者，排盘完全一样，如何区分？
> **核心原理**：日干（患者符号）相同时，以各人**出生年的干支（年命）** 为区分用神。
> **年命定义**：患者出生年的天干地支，如1984年→甲子、1991年→辛未、1971年→辛亥
> **来源**：《奇门旨归·占病》以年命为患者根本，《遁甲演义》以年命定贵贱寿夭

#### 9.4.1 操作流程图

```
同一时辰 N 位患者同时就诊
         ↓
① 逐一询问年龄 → 推算出生年 → 定年命干支
② 在当日奇门盘中分别标出各人年命落宫
③ 看天芮（病星）与各年命宫的生克 → 定病情缓急
④ 看各人年命宫符号吉凶 → 定病势与预后
⑤ 看生肖地支合冲刑 → 定体质倾向（辅助诊断）
         ↓
排出就诊优先级：天芮克谁的宫，谁最凶险
各人依年命宫符号分别辨证 → 再结合四诊合参
```

> **技术要点**：同一时辰的奇门盘，日干、时干、值符值使**完全相同**。
> 但各人年命干支不同 → 落不同宫位 → 从盘面上各自占据不同"位置"。
> 所以**年命就是同一盘面上区分多人的关键钥匙**。

#### 9.4.2 三步推年命

| 步骤 | 操作 | 示例（42岁女性） |
|:----|:----|:-----------------|
| ① 推出生年 | 当前年 - 虚岁 + 1 | 2026 - 42 + 1 = **1985年**？需确认 |
| ② 精准校准 | 直接用当前年减实岁（若已知确切年龄） | 42实岁 → 2026 - 42 = **1984年** |
| ③ 查年命干支 | 甲子1984、乙丑1985、丙寅1986… | 1984年 → **甲子**（海中金） |

> **临床技巧**：问"您哪一年出生的？"比问年龄更准确。
> 若只知生肖，直接用地支（鼠→子、牛→丑、虎→寅…）。
> 若只知虚岁，附注"大约XX年生"即可，奇门大方向不会走偏。

#### 9.4.3 天芮与年命的生克定缓急

天芮为病星，各人年命宫与天芮宫之间的**五行生克**决定病情轻重：

| 关系 | 解读 | 严重度 |
|:----|:-----|:------:|
| **天芮生年命宫** | 正气能抗邪，病虽重可愈 | ⭐（轻） |
| **天芮克年命宫** | 邪气凌正，病最凶险 | ⭐⭐⭐（最急） |
| **年命宫克天芮** | 正气能制邪，病浅易治 | ⭐（轻） |
| **年命宫生天芮** | 体质"养病"，缠绵难愈 | ⭐⭐（中） |
| **年命宫与天芮比和** | 病邪与体质胶着，慢性病程 | ⭐⭐（中） |

> **临床意义**：天芮克谁的宫，谁就需要**优先诊治**。

#### 9.4.4 年命落宫符号解读

每一位患者的年命干支落宫后，按以下步骤逐一解读：

| 符号层 | 解读要点 | 临床意义 |
|:-------|:---------|:---------|
| **门** | 年命宫所落之门 | 吉门（开休生）→ 预后好；凶门（伤死惊杜）→ 病势重 |
| **星** | 年命宫所落之星 | 吉星→正气足；凶星→邪气盛；天芮同宫→此人病最重 |
| **神** | 年命宫所落之神 | 腾蛇→虚惊怪异；白虎→血光肿痛；玄武→暗耗；九地→慢性 |
| **空亡** | 年命是否落空亡 | 落空亡→正气已虚，需先扶正 |
| **击刑** | 年命干支是否击刑 | 子卯刑→肝郁；寅巳刑→风火；丑未戌刑→脾胃紊乱 |

## 十、禁忌与注意事项

### ⚠️ 必须遵守的原则

1. **奇门不能替代四诊**——信息不全时可用，但有条件时必须以望闻问切为准
2. **奇门是参照系，不是绝对值**——盘面显示的病机必须与临床相互印证
3. **一人一盘**——每个患者就诊时间不同，盘面不同，不可套用
4. **初学者先辨大方向**——先判断阴阳、寒热、表里、虚实四纲，再细化
5. **情志病奇门最验**——八神对情志病因的判断往往比四诊更直接

### ❌ 常见错误

| 错误 | 正确做法 |
|:-----|:---------|
| 只凭奇门下诊断，不看患者 | 奇门+四诊合参 |
| 把一次盘面当全部 | 复诊时重新排盘，看病势变化 |
| 忽略五行生克只看符号 | 吉门也可能因病位不当而成凶 |
| 忽视五运六气的大背景 | 先看节气、年运，再细化到时辰 |

### 12.1 八卦类神系统（源自《奇门旨归》卷三十五）

|:-:|:--|:---------|:-------------------|

### 12.2 九神断人性情·情志病因精细化（源自《奇门旨归》）

《奇门旨归》卷三十五有「分神断人性情法」，比粗分八神更加精细：

**值符加命宫／日干** → 正直端方、贵人相助、心胸开阔
**腾蛇加命宫／日干** → 古怪多疑、言语欺诈、虚幻之病、梦魇
**太阴加命宫／日干** → 多谋少成、隐曲不伸、阴郁、善太息
**六合加命宫／日干** → 心性如萍、善交游、情志不稳、多思
**白虎加命宫／日干** → 性急无情、暴戾、肝阳上亢、头痛
**玄武加命宫／日干** → 心虚诡诈、阴险、暗耗、恐惧
**九地加命宫／日干** → 阴晦暗滞、精神萎靡、健忘
**九天加命宫／日干** → 虚张声势、躁动不宁、失眠

**神将重叠法则**（新增）：
- **白虎+九天** → 阳亢暴怒型（易中风、狂躁）
- **太阴+九地** → 阴郁积压型（易抑郁、肿瘤）

- **六合+朱雀** → 社交过度型（易心悸、气耗）

**临床意义**：情志病用此细化，可精准判断病根在七情中的哪一类，比单纯问诊更客观。


### 12.3 奇门演卦与五运六气衔接（源自《奇门旨归》）

《奇门旨归》卷三十五有「奇门演卦说」，可从奇门盘中再推一卦，辅助判断病机：

**演卦方式**：
1. **符使演卦** → 值符落宫为上卦，值使落宫为下卦

**临床应用**：

### 12.6 占病专章整合（源自《奇门旨归》等综合）

整合各家占病体系形成标准化操作流程：

#### 一、病之轻重

判断标准来源于《奇门旨归·占病》：
- **天芮落宫生年命宫** → 病虽重，可愈（正气存内）
- **天芮落宫克年命宫** → 病凶险（邪气凌正）
- **时干落宫克日干落宫** → 病势在进（新病也重）
- **日干落宫克时干落宫** → 病势将退（虽重可愈）
- **天芮落宫逢旺相** → 病邪盛，难速愈
- **天芮落宫逢休囚** → 病邪衰，易治

#### 二、病位确定

| 符号组合 | 病位判断 |
|:---------|:---------|
| **天芮+死门+某宫八卦类神** | 该脏腑器质性病变（肿瘤、坏死、硬化） |
| **天芮+伤门+某宫** | 该脏腑损伤性病变（炎症、外伤） |
| **天芮+惊门+某宫** | 该脏腑功能紊乱（痉挛、惊悸） |
| **天芮+杜门+某宫** | 该脏腑阻塞性病变（结石、梗阻、闭经） |
| **天芮+景门+某宫** | 该脏腑热性病变（炎症、发热、出血） |
| **天芮+休门+某宫** | 该脏腑虚损性病变（慢性、消耗性） |

#### 三、病程判断

- **反吟 + 天芮** → 急性发作，来势凶猛
  - 反吟主速，数日可愈（吉格）或数日不治（凶格）
- **伏吟 + 天芮** → 慢性缠绵，久病难愈
  - 伏吟主慢，以月计，需缓图
- **空亡填实之日** → 转机之日
  - 天芮落空亡则病减，填实之日病复

#### 四、治与不治

**可治之象**：
- 天心星（西医）+ 乙奇（中药）+ 开休生三吉门
- 天芮星落宫被克（如天芮落震宫，兑宫金克之）
- 时干生日干

**难治之象**：
- 天芮+死门+庚格
- 五不遇时（时干克日干）
- 天芮落宫生日干落宫（正克，邪气凌正）
- 大局反吟+凶门+死门+天芮

#### 五、奇门用药指引（拓展）

- **乙奇（天草药）落宫** → 用药方向
  - 乙奇落坎宫（水） → 滋阴利水之品
  - 乙奇落离宫（火） → 清热泻火之品
  - 乙奇落坤艮宫（土） → 健脾化湿之品
  - 乙奇落震巽宫（木） → 疏肝理气之品
  - 乙奇落乾兑宫（金） → 润肺通肠之品
