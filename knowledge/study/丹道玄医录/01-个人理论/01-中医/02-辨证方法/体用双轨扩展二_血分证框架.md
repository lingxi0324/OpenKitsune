# 🪐 体用双轨扩展方向二 · 血分证框架

> **体系定位**: 体用双轨体系 -> 血分路径 -> 血分四层模型
> **标签**: `#体用双轨` `#血分证` `#河图成数` `#时方解码` `#王清任`

---

## 一、裂隙起源

体用双轨体系处理的是**「气分脏腑虚实」**——五脏的气、血、阴、阳的虚，和六腑气机的郁。

但血分证是另一种东西：
- **气分虚** = 动力不足（补气就够）
- **血分瘀** = 道路壅塞（光补气不行，要化瘀）

**血府逐瘀汤（桃仁+红花+当归+生地+牛膝+柴胡+枳壳+桔梗+川芎+赤芍+甘草）** 不是脏腑气分虚实的问题——这是**血分有形实邪（瘀血）** 的问题。

**吻合度：30%**
→ 用气分的尺子量血分的方，得到30%是正常的——不是方的问题，是尺子类型不对。

## 二、河图数理根基

血分证的核心数理关系：

```
气（阳·无形） ← 河图生数（1-5·先天之气）
     ↓
血（阴·有形） ← 河图成数（6-10·后天之质）
```

| 层次 | 河图数 | 状态 | 病机类型 | 体用对应 |
|:---:|:---:|:---|:---|:---|
| 气分 | 1-5（生数） | 无形·气化 | 气虚/气郁/气逆 | **体用双轨体系覆盖** |
| 血分 | 6-10（成数） | 有形·质变 | 血瘀/血热/血虚/血毒 | **需血分框架覆盖** |

**血分 = 后天成数层面的有形质病变。**
体用公理处理的是生数层面的气化失衡（虚→补体，实→泄用）。
血分框架要处理的是成数层面的形质壅塞（瘀→化瘀，痰→消痰，积→消积）。

## 三、血分证的四层模型

从《金匮要略》+王清任+叶天士血论中提炼，血分证分四层：

| 层 | 病机 | 治法 | 方药方向 | 药味精要 |
|:---:|:---|:---|:---|:---:|
| **Ⅰ 血热** | 热入血分，迫血妄行 | 凉血解毒 | 犀角地黄汤、化斑汤 | 咸+苦（咸下行，苦清热） |
| **Ⅱ 血瘀** | 血行不畅，瘀阻脉络 | 活血化瘀 | 血府逐瘀汤、桃红四物 | 辛+苦（辛行散，苦破泄） |
| **Ⅲ 血虚** | 血不养脏，脏腑失荣 | 养血补血 | 四物汤、当归补血汤 | 甘+酸（甘补血源，酸藏血） |
| **Ⅳ 血毒** | 瘀腐化毒，败坏形质 | 化瘀解毒 | 大黄䗪虫丸、抵挡汤 | 咸+苦+辛（三焦并攻） |

## 四、血分四层的五味规律

结合体用公理的味-五行对应，血分证的五味规律如下：

| 血分证型 | 主味 | 辅味 | 体用解释 | 药例 |
|:---:|:---:|:---:|:---|:---|
| 血热（Ⅰ） | 咸 | 苦 | 咸为肾体→引血归经，苦为心体→清火凉血 | 水牛角、生地、丹皮 |
| 血瘀（Ⅱ） | 辛 | 苦 | 辛为肝用→行血散瘀，苦为心体→破瘀通脉 | 桃仁、红花、川芎 |
| 血虚（Ⅲ） | 甘 | 酸 | 甘为脾体→生血之源，酸为肝体→藏血之脏 | 当归、熟地、白芍 |
| 血毒（Ⅳ） | 咸 | 苦+辛 | 咸软坚破积，苦泻浊，辛通散 | 大黄、䗪虫、水蛭 |

## 五、血分证与体用公理的接口

```
辨证时先分：
├─ 病在气分 → 体用双轨体系（五脏气分虚实）
│   ├─ 直达路径可行 → 体味+甘补体 / 用品单行泄用
│   └─ 直达路径不通 → 转间接补益
└─ 病在血分 → 血分四层模型
    ├─ 兼有气分虚 → 先调气分，再治血分（或气分血分同治）
    ├─ 兼有气分实 → 治血分同时疏气
    └─ 纯血分 → 专治血分
```

### 气分→血分的传变规律

气分病不治或治不得法，必传入血分：

```
气虚 → 血行无力 → 血瘀
气郁 → 血滞 → 瘀血
气逆 → 血随气逆 → 吐血/衄血
气虚不摄 → 血不归经 → 出血/紫癜
气分热 → 热入营血 → 血热/发斑
```

### 血分→气分的反哺规律

血分病治好后，气分自然恢复（"血为气之母"）：

```
血得养 → 气有根 → 脏腑功能复常
瘀得化 → 气道通 → 气机升降如初
热得清 → 血安宁 → 神志自清
```

## 六、血府逐瘀汤体用解析

**药味结构：** 桃仁+红花+当归+生地+牛膝+柴胡+枳壳+桔梗+川芎+赤芍+甘草

| 药 | 味 | 体用定位 | 血分四层归属 |
|:---|:---:|:---|:---:|
| 桃仁 | 苦+甘 | 苦破瘀（心用），甘养血（脾体） | 血瘀Ⅱ |
| 红花 | 辛 | 辛行血（肝用） | 血瘀Ⅱ |
| 当归 | 甘+辛 | 甘补血（脾体），辛行血（肝用） | 血虚Ⅲ→兼Ⅱ |
| 生地 | 甘+苦 | 甘养血（脾体），苦凉血（心体） | 血热Ⅰ→兼Ⅲ |
| 川芎 | 辛 | 辛行气行血（肝用） | 血瘀Ⅱ（气分→血分桥梁） |
| 赤芍 | 苦+微酸 | 苦清血热（心体），酸敛血（肝体） | 血热Ⅰ→兼Ⅱ |
| 柴胡 | 辛+苦 | 辛疏肝（肝用），苦泄热 | 气分 |
| 枳壳 | 苦+辛 | 苦降气，辛行气 | 气分 |
| 桔梗 | 苦+辛 | 苦降肺气，辛行气 | 气分 |
| 牛膝 | 苦+酸 | 苦引血下行（心体），酸益肝肾 | 血瘀Ⅱ |
| 甘草 | 甘 | 甘和药（脾体） | 佐使 |

**结论：** 血府逐瘀汤是一个**气分+血分双跨方**——
- 柴胡+枳壳+桔梗 → 调气分（肝用疏泄）
- 桃仁+红花+川芎+牛膝 → 治血分（血瘀Ⅱ层）
- 当归+生地+赤芍 → 兼顾血热（Ⅰ）+血虚（Ⅲ）
- 全方走血分Ⅱ层为主，覆盖Ⅰ+Ⅲ+气分

用体用公理（纯气分框架）验算它，只能算到柴胡+枳壳+桔梗+川芎的气分部分（约30%），血分部分完全不在验算范围内。

**这就是吻合度30%的根因。**

## 七、血分药物的六维特征

用六维象形辨药的角度看血分药：

| 血分药 | 六维特征 | 血分层 |
|:---|:---|:---:|
| 桃仁 | 形维：果仁油脂→润下，质维：多脂→滑利 | Ⅱ血瘀 |
| 红花 | 色维：赤红→入心活血 | Ⅱ血瘀 |
| 水蛭 | 境维：水生→吸血，质维：韧韧→破坚 | Ⅳ血毒 |
| 丹皮 | 色维：赤→入心，形维：根皮→走下焦 | Ⅰ血热 |
| 三七 | 色维：赤裂→红，形维：根→沉降 | Ⅱ+Ⅲ |
| 鸡血藤 | 色维：红浆→入血，形维：藤蔓→通络 | Ⅱ+Ⅲ |

**规律：** 色红=入血分的基本信号。凡色红者，至少兼有一层血分功能。

## 八、血分框架的临床意义

| 场景 | 无血分框架 | 有血分框架 |
|:---|:---|:---|
| 血府逐瘀汤证 | 用体用公理验算→仅30%匹配→"这方无效"（误判） | 用血分框架→100%可解释→正确使用 |
| 虚劳夹瘀 | 单纯补虚→瘀不去，补不进 | 先化瘀后补虚，或攻补兼施 |
| 妇人癥瘕 | 气分调理无效 | 血分化瘀+软坚散结 |
| 久病入络 | 不明为何久治不愈 | 明确气分→血分的传变路径 |
