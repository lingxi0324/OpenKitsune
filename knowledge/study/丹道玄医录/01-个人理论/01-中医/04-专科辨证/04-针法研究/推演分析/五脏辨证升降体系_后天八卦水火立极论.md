# 五脏辨证升降体系——后天八卦水火立极论

> 基于《十二经升降提纲》与后天八卦核心架构推演
> 灵汐 · 丙午年壬辰月己卯日

## 一、理论根基：后天八卦与五脏升降

### 1.1 后天八卦定位

后天八卦以离（火）坎（水）立极，左升右降、中土斡旋：

```
         离（心火·午）
              ↑
   巽（胆）← 中土 → 乾（大肠）
    ↑                    ↓
   震（肝）           兑（肺）
    ↑                    ↓
   艮（胃）← 中土 → 坤（脾）
              ↓
         坎（肾水·子）
```

**核心规律**：
- **水火两极**：离火在上、坎水在下
- **左升右降**：左为震巽木升发、右为兑乾金肃降
- **中土斡旋**：坤艮土居中为升降枢纽

### 1.2 核心架构

| 卦 | 方位 | 脏腑 | 升降趋势 |
|:--:|:----:|:------|:--------|
| 离☲ | 南（上） | 心·小肠 | 火性炎上（宜降） |
| 坎☵ | 北（下） | 肾·膀胱 | 水性润下（宜升） |
| 震☳ | 东（左） | 肝 | 木性条达（升发） |
| 巽☴ | 东南（左） | 胆 | 木性柔和（和降） |
| 兑☱ | 西（右） | 肺 | 金性收敛（肃降） |
| 乾☰ | 西北（右） | 大肠 | 金性通降（传导） |
| 艮☶ | 东北（左中） | 胃 | 土性和降（受纳） |
| 坤☷ | 西南（右中） | 脾 | 土性升运（运化） |

### 1.3 太极图式的十二经循环

十二经分为六脏六腑，构成六个太极对子，每一对子的升降互济形成一个完整的太极循环：

```
心火（降）───小肠火（升）    │    肺金（降）───大肠金（升）
胃土（降）───脾土（升）      │    胆木（降）───肝木（升）
心包火（降）──三焦火（升）    │    膀胱水（降）──肾水（升）
```

六个太极对子并行运转，各司其职，共同维持全身气机的升降出入。

## 二、五脏升降总纲

### 2.1 六经降（由右下降）

#### 心火下降——离火交坎水

| 条目 | 内容 |
|:----|:------|
| **生理** | 心火下降以温肾水，使肾水不寒 |
| **病理** | 心火不降→上热下寒、心烦失眠、口舌生疮 |
| **治法** | 引火下行（导赤散、交泰丸） |
| **针法** | 神门（泻）、劳宫（泻）、涌泉（补） |

#### 肺气下降——兑金生坎水

| 条目 | 内容 |
|:----|:------|
| **生理** | 肺气肃降，通调水道，下输膀胱 |
| **病理** | 肺气不降→咳嗽喘逆、小便不利、便秘 |
| **治法** | 降气肃肺（苏子降气汤、杏苏散） |
| **针法** | 尺泽（泻）、列缺（平泻）、天突（泻） |

#### 胃气下降——艮土纳坤精

| 条目 | 内容 |
|:----|:------|
| **生理** | 胃气下降，受纳腐熟水谷 |
| **病理** | 胃气不降→脘腹胀满、嗳气呕恶、便秘 |
| **治法** | 和胃降逆（半夏泻心汤、旋覆代赭汤） |
| **针法** | 足三里（平泻）、内关（平泻）、中脘（泻） |

### 2.2 六经升（由左上升）

#### 肾水上济——坎水制离火

| 条目 | 内容 |
|:----|:------|
| **生理** | 肾水上济以制心火，维持心肾相交 |
| **病理** | 肾水不升→腰膝酸软、耳鸣、阴虚火旺 |
| **治法** | 滋水涵木、壮水制火（六味地黄丸、知柏地黄丸） |
| **针法** | 太溪（补）、复溜（补）、涌泉（温灸） |

#### 肝气上升——震木助坤土

| 条目 | 内容 |
|:----|:------|
| **生理** | 肝气升发，疏泄条达，助脾运化 |
| **病理** | 肝气不升→胸胁胀满、抑郁、月经不调 |
| **治法** | 疏肝理气（柴胡疏肝散、逍遥散） |
| **针法** | 太冲（补）、期门（补）、阳陵泉（平补） |

#### 脾气上升——坤土运四维

| 条目 | 内容 |
|:----|:------|
| **生理** | 脾气升清，运化水谷精微，濡养四肢 |
| **病理** | 脾气不升→腹胀、便溏、乏力、脏器下垂 |
| **治法** | 补气升阳（补中益气汤、升陷汤） |
| **针法** | 足三里（补）、三阴交（补）、百会（温灸） |

## 三、脏腑配对升降——表里经的太极循环

### 3.1 心（降）↔ 小肠（升）

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 心火下降→温煦小肠→小肠泌别→精气上奉→养心 |
| **生理表现** | 心火下移小肠则小便清利；小肠吸收精微则心血充盈 |
| **病理表现** | 心火亢盛→移热小肠→小便短赤、口舌生疮 |
| **治疗原则** | 清心利小便（导赤散） |
| **代表方** | 导赤散（生地、木通、竹叶、甘草） |
| **升降针法** | 神门（泻）引心火下降 + 支正（补）助小肠升清 |

### 3.2 肺（降）↔ 大肠（升）

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 肺气肃降→大肠传导→糟粕排出→浊气不犯肺 |
| **生理表现** | 肺气清肃则大肠传导正常；大肠通畅则肺气不壅 |
| **病理表现** | 肺热壅盛→大肠燥结→便秘；大肠积滞→肺气不降→咳喘 |
| **治疗原则** | 宣肺通腑（宣白承气汤）；通腑泻肺（大承气汤急下存阴） |
| **升降针法** | 尺泽（泻）降肺气 + 曲池（泻）通大肠 |

### 3.3 胃（降）↔ 脾（升）——中轴核心

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 胃降→脾升→中土斡旋→四维升降有序 |
| **生理表现** | 胃气降则脾气升，中焦如沤，运化精微 |
| **病理表现** | 胃不降→脾不升→中焦痞塞→上热下寒、腹胀满 |
| **治疗原则** | 辛开苦降、调和脾胃（半夏泻心汤） |
| **代表方** | 半夏泻心汤、补中益气汤 |
| **升降针法** | 足三里（平补平泻）调胃降 + 太白（补）助脾升 |

### 3.4 胆（降）↔ 肝（升）——升降枢纽

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 胆气下降→肝气上升→少阳枢转→全身气机条达 |
| **生理表现** | 胆气通降则胆汁排泄正常，肝气疏泄有度 |
| **病理表现** | 胆气不降→胆汁上逆→口苦；肝气不升→郁滞→胁痛 |
| **治疗原则** | 疏肝利胆（小柴胡汤、温胆汤） |
| **代表方** | 小柴胡汤、柴胡疏肝散、温胆汤 |
| **升降针法** | 阳陵泉（泻）降胆气 + 太冲（补）升肝气 |

### 3.5 心包（降）↔ 三焦（升）——相火循环

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 心包火下降→三焦通行相火→温煦全身 |
| **生理表现** | 心包代心受邪，三焦为相火运行之通道 |
| **病理表现** | 心包热盛→神昏谵语；三焦不畅→水液代谢失常 |
| **治疗原则** | 清心包、通三焦（清营汤、三仁汤） |
| **升降针法** | 大陵（泻）清心包 + 外关（补）通三焦 |

### 3.6 膀胱（降）↔ 肾（升）——水火气化

| 方面 | 内容 |
|:----|:------|
| **太极循环** | 膀胱气化→水液排出→肾精封藏→气化有源 |
| **生理表现** | 膀胱排尿通利则肾精不扰，肾气充足则膀胱气化有源 |
| **病理表现** | 膀胱湿热→小便不利；肾气不化→癃闭、遗尿 |
| **治疗原则** | 温阳化气（五苓散、真武汤）；清热利湿（八正散） |
| **升降针法** | 中极（泻）通膀胱 + 太溪（补）助肾气化 |

## 四、五脏辨证的升降法则

### 4.1 辨证总诀

> **心肺在上宜降，肝肾在下宜升，脾胃居中斡旋。**

| 部位 | 功能 | 正常趋势 | 病理趋势 |
|:----|:-----|:---------|:---------|
| 心肺（上） | 主气主血 | 下降（心火下温、肺气肃降） | 上逆（心烦、咳喘） |
| 肝肾（下） | 主精主血 | 上升（肾水上济、肝气升发） | 下陷（腰酸、遗精、下利） |
| 脾胃（中） | 主运主化 | 脾升胃降（中轴枢转） | 中痞（胀满、痞塞） |

### 4.2 八纲辨证结合升降

| 八纲证型 | 升降表现 | 治法核心 |
|:---------|:---------|:---------|
| **表证** | 气机出入不畅 | 宣发升散（麻黄、桂枝） |
| **里证** | 气机升降失常 | 和降通下（大黄、枳实） |
| **寒证** | 阳气不升、寒气凝滞 | 温升（附子、干姜） |
| **热证** | 火气上逆、热壅于上 | 清降（黄连、石膏） |
| **虚证** | 升举无力或摄纳无权 | 补中升陷（黄芪、升麻） |
| **实证** | 气机壅滞或上逆 | 通降导下（大黄、厚朴） |

### 4.3 五脏升降的五行生克

#### 相生关系中的升降

| 相生 | 升降关系 | 临床意义 |
|:-----|:---------|:---------|
| 木生火（肝→心） | 肝气升→心火应降 | 肝升太过→心火不降（木生火太过） |
| 火生土（心→脾） | 心火降→脾气应升 | 心火不降→脾气不升（火不生土） |
| 土生金（脾→肺） | 脾气升→肺气应降 | 脾不升清→肺气不降（土不生金） |
| 金生水（肺→肾） | 肺气降→肾水应升 | 肺不肃降→肾水不升（金不生水） |
| 水生木（肾→肝） | 肾水升→肝气应升 | 肾水不升→肝气不升（水不涵木） |

#### 相克关系中的升降

| 相克 | 升降关系 | 临床意义 |
|:-----|:---------|:---------|
| 木克土（肝→脾） | 肝升太过→脾升受阻 | 肝旺乘脾→腹胀、便溏 |
| 土克水（脾→肾） | 脾不升→肾水不化 | 脾虚水泛→水肿 |
| 水克火（肾→心） | 肾水不升→心火不降 | 心肾不交→失眠 |
| 火克金（心→肺） | 心火亢→肺气不降 | 心火灼肺→咳喘 |
| 金克木（肺→肝） | 肺降太过→肝升不得 | 肺壅肝郁→胁痛 |

### 4.4 三部定位辨证

#### 上部（心肺）

| 证型 | 表现 | 治法 |
|:-----|:-----|:------|
| 心火上炎 | 心烦失眠、口舌生疮、小便短赤 | 导赤散清心降火 |
| 心阳不振 | 心悸怔忡、胸闷气短、面白畏寒 | 桂枝甘草汤温通心阳 |
| 肺气上逆 | 咳嗽喘逆、胸闷、咳痰 | 苏子降气汤降气止咳 |
| 肺失宣降 | 感冒咳嗽、鼻塞、咽痒 | 杏苏散宣肺散寒 |

#### 中部（脾胃）

| 证型 | 表现 | 治法 |
|:-----|:-----|:------|
| 胃气上逆 | 嗳气、反酸、恶心、呕吐 | 旋覆代赭汤和胃降逆 |
| 脾不升清 | 头晕、乏力、便溏、脱肛 | 补中益气汤升阳举陷 |
| 中焦痞塞 | 胃脘胀满、纳差、大便不调 | 半夏泻心汤辛开苦降 |
| 升降失常 | 上热下寒、口干不欲饮、便溏 | 黄连汤调升降、和寒热 |

#### 下部（肝肾）

| 证型 | 表现 | 治法 |
|:-----|:-----|:------|
| 肝气郁结 | 胁肋胀痛、抑郁烦躁、月经不调 | 柴胡疏肝散疏肝解郁 |
| 肝阳上亢 | 头晕头痛、面红目赤、易怒 | 天麻钩藤饮平肝潜阳 |
| 肾气不固 | 腰膝酸软、小便频数、遗精滑泄 | 金匮肾气丸温补肾气 |
| 肾不纳气 | 喘促气短、呼多吸少、动则喘甚 | 人参蛤蚧散补肾纳气 |

### 升降口诀

> 心降小肠升，肺降大肠升。
> 胃降脾脏升，胆降肝脏升。
> 包降三焦升，膀胱降肾升。
> 六对升降轮，太极默运行。
> 降者如秋冬，敛藏归根精。
> 升者如春夏，生长发陈荣。
> 升降若失序，百病由是生。
> 上病责降少，下病责升穷。
> 中病责枢转，升降在其中。
> 知此升降理，辨证如有神。
