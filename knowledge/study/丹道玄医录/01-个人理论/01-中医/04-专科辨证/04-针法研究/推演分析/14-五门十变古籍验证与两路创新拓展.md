# 五门十变·古籍验证与两路创新拓展

## 验证时间
2026年5月4日（乙巳年四月初八）亥时

## 验证底层：古籍直接印证

### 《针灸大成·标幽赋》杨氏注解
> **「五门者，天干配合，分于五也。甲与己合，乙与庚合之类是也。」**

### 《针灸大成·卷五·流注开阖》
> **「阳日遇阴时，阴日遇阳时，则前穴已闭，取其合穴针之。合者：甲与己合化土，乙与庚合化金，丙与辛合化水，丁与壬合化木，戊与癸合化火。五门十变，此之其所以然者。」**

### 《针灸大全》（明·徐凤）卷五
载完全相同内容，并附有"甲与己合"的兄妹嫁娶之喻讲解化合原理。

**结论**：五组天干化合（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火）的理法——**古籍有明确记载** ✅

## 独创取穴规律（古籍未记载）

您的独创融合——将五输穴层次与天干化合做精密嵌套匹配：

| 化合 | 取穴层次 | 常规取穴（五行精粹） |
|:----:|:---------|:-------------------|
| 甲己化土 | **输穴**（输属土） | 临泣（胆输木）+ 公孙（脾输土）→ 土中土 |
| 乙庚化金 | **井穴**（井属金系） | 少商（肺井木）+ 商阳（大肠井金）→ 金中金 |
| 丙辛化水 | **经穴**（经属金系） | 阳谷（小肠经火）+ 太渊（肺经输土）→ 水中水 |
| 丁壬化木 | **荥穴**（荥属火系） | 前谷（小肠荥水）+ 鱼际（肺荥火）→ 木中木 |
| 戊癸化火 | **合穴**（合属水系） | 阴谷（肾合水）+ 足三里（胃合土）→ 火中火 |

**核心原则**：取"层"不取"性"——五输穴层次（井荥输经合）自带五行符号，取层次即取符号之力，与穴位具体五行属性无关，此谓"取五行之精粹"。

**古籍记载**：两部经典各有记载——
1. 《针灸大成》杨注：五门 = 天干配合
2. 《扁鹊神应针灸玉龙经》（王国瑞）：**「五门者，井荥输经合也」**
但**无任何一部经典**将两种"五门"叠加对应。此为您的独创融合。✅

## 思路一：五行中心重构——"一物一太极"

常规以**土为中心**（甲己化土为媒），一物一太极，金木水火皆可为中心：

### 🌳 以木为中心：丁壬化木阵

```
       丙辛化水（水以生木）
              ↓
  乙庚化金（金以克木） → 木（中心） → 甲己化土（木以克土）  
              ↑
       戊癸化火（木以生火）
```

**中心**：丁壬化木 → 取荥穴（荥属火，木生火为用）
**水火配**：丙辛化水为"母"，戊癸化火为"子"
**克我**：乙庚化金为"所不胜"，用井穴化金制约
**我克**：甲己化土为"所胜"，用输穴化土疏泄
**应用**：肝郁、胁痛、月经不调、高血压

### 🔥 以火为中心：戊癸化火阵

```
       甲己化土（火以生土）
              ↓
  丙辛化水（水以克火） → 火（中心） → 乙庚化金（火以克金）
              ↑
       丁壬化木（木以生火）
```

**中心**：戊癸化火 → 取合穴（合属水，水火既济意）
**水火配**：丁壬化木为"母"生火，丙辛化水为"克我"需制
**应用**：心火失调（焦虑、失眠、口疮）

### 💎 以金为中心：乙庚化金阵

```
       戊癸化火（火以克金）
              ↓
  甲己化土（土以生金） → 金（中心） → 丙辛化水（金以生水）
              ↑
       丁壬化木（木以克金）
```

**中心**：乙庚化金 → 取井穴（井为气之始，金主肃杀）
**应用**：肺金不降（咳喘、便秘、皮肤疾患）

### 💧 以水为中心：丙辛化水阵

```
       乙庚化金（金以生水）
              ↓
  戊癸化火（火以克水） → 水（中心） → 丁壬化木（水以生木）
              ↑
       甲己化土（土以克水）
```

**中心**：丙辛化水 → 取经穴（经属金，金生水为母气）
**应用**：肾水不藏（遗精、腰痛、水肿）

### 🏔️ 以土为中心（已验）：甲己化土阵

**中心**：输穴（土中土）
**应用**：水火交媾治疗心肾不交（已验证2年）

### 各中心对比

| 中心 | 核心阵型 | 媒人角色 | 适合病证 |
|:----:|:---------|:---------|:---------|
| **土** | 甲己化土为媒 | 土为媒聘 | 心肾不交（已验证） |
| **木** | 丁壬化木为枢 | 木为枢机 | 肝郁气滞 |
| **火** | 戊癸化火为君 | 火为君药 | 心火亢/阳虚 |
| **金** | 乙庚化金为令 | 金为号令 | 肺气不降 |
| **水** | 丙辛化水为藏 | 水为根蒂 | 肾水不藏 |

**古籍验证**：古籍只记载了"以土为中枢"模式（甲己化土为媒），未见其他五行做中心的具体配穴。**此为独创拓展** ❌（未记载）

## 思路二：五行杂气——"穴位之合补益经脉之合"

常规取穴是**纯化**（取穴位的纯五行之气加强经脉化合），杂气取穴则通过**穴位自身五行与经脉五行之间的错位**产生更细腻调节。

### 原理

```
常规五门十变：
  经脉A（天干甲）+ 经脉B（天干己）→ 合化出土气
  取穴 = 取土属性最纯的穴（输穴）→ 土气最强

五行移位五门十变：
  经脉A（天干甲）+ 经脉B（天干己）→ 合化出土气
  取穴 = 取其他属性的穴（如井金/荥火）→ 土气之中带金/火杂气
  结果：化出的土气具有"金之收"或"火之散"的特性
```

### 以丙辛化水为例

**常规（纯化）**：阳谷（经火）+ 太渊（输土）→ 经穴层次化水
**杂气（移位）**：少泽（井金）+ 少商（井木）
- 少泽的金性 → 金生水，助经脉之化合 → **生者助其化**
- 少商的木性 → 木泄水气 → **泄者防其过**
- 一**生**一**泄**，对化出水形成制衡

### 五组化合杂气推演

| 化合 | 纯化取穴（本气） | 杂气取穴（错位） | 杂气效应 |
|:----:|:----------------|:----------------|:---------|
| **丙辛化水** | 阳谷（经火）+ 太渊（输土） | 少泽（井金）+ 少商（井木） | 金生水利、木泄水气——补中有制 |
| **戊癸化火** | 阴谷（合水）+ 三里（合土） | 涌泉（井木）+ 厉兑（井金） | 木生火、金克木制衡 |
| **甲己化土** | 临泣（输木）+ 公孙（输土） | 丘墟（原木）+ 太白（输土） | 原型土加木，木克土为制 |
| **乙庚化金** | 少商（井木）+ 商阳（井金） | 经渠（经金）+ 阳溪（经火） | 金气中带火性，防金气过肃 |
| **丁壬化木** | 前谷（荥水）+ 鱼际（荥火） | 行间（荥火）+ 二间（荥水） | 水中火中更精微调节 |

### 同一化合因层次不同的"药性"差异

以丙辛化水为例取不同层次：

| 取穴层次 | 穴位组合 | 化水之"性" |
|:---------|:---------|:-----------|
| **井穴** | 少泽+少商 | 化水有"井穴开窍"之性——醒神通窍 |
| **荥穴** | 前谷+鱼际 | 化水有"荥穴清热"之性——清心火 |
| **输穴** | 后溪+太渊 | 化水有"输穴通痹"之性——通调水道 |
| **经穴** | 阳谷+经渠 | 化水有"经穴通利"之性——疏利三焦 |
| **合穴** | 小海+尺泽 | 化水有"合穴降逆"之性——引水下行 |

**古籍验证**：古籍无此"杂气赋予化气性格"的具体记载。但五输穴主病规律（井主心下满、荥主身热、俞主体重节痛、经主喘咳寒热、合主逆气而泄）在《针灸大成》卷五有详述，为杂气思路提供间接理论支撑。**此为独创拓展** ❌（未记载）

## 两思路交汇点

| | 思路一（五行中心） | 思路二（五行杂气） |
|:--|:------------------|:------------------|
| 回答的是 | **以谁为中心？** | **用什么气来调？** |
| 操作的层面 | 天干化合的框架选择 | 五输穴的五行选择 |
| 变化的是 | 中心五行 | 取穴的五行属性 |
| 共同目标 | **使五门十变从固定模式→灵活辩证体系** |

**交汇应用**：
```
对于一个肝郁患者：
  思路一选 → 以木为中心（丁壬化木阵）
  思路二选 → 杂气取穴（在水化中加金气制约木的过亢）
  组合 = 丁壬化木阵 × 经穴杂气（金气制木）
```
