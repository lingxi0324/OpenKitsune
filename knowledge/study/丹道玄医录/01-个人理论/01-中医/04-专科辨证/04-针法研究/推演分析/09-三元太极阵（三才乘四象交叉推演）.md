# 三元太极阵（三才x四象交叉针阵）

> **类型**: 基于公式推演的新针阵
> **推导依据**: 三才奠基律 x 四象护卫律 x 星穴能量共振公式

---

## 一、推导逻辑

### 公式
```
N = 三才(3) x 四象(4) = 12穴交叉矩阵 / 时辰
12时辰 x 12穴 = 144穴周天循环
```

### 核心法则
每时辰取一宫位的三才穴（天/地/人），配四象护卫穴（青龙/白虎/朱雀/玄武），形成12组周天配穴。

## 三、总纲

| 项目 | 说明 |
|:----|:------|
| **周期** | 每时辰一换，12时辰完成一周天循环 |
| **疗程** | 7天一疗程，循环7次为一大疗程（49日） |
| **主治** | 阴阳失调、寒热错杂、虚实夹杂之复杂证候 |

| **验证** | 红外热像：全身经络温差需 < 1.5度 |
