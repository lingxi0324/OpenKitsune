# 五行流转连环阵（五行相生连环治疗针阵）

> **类型**: 基于公式推演的新针阵
> **推导依据**: 五行生克链 x 时间法则(本命/施辰/节气) x 星穴能量共振公式

---

## 一、推导逻辑

### 公式
```
连环单元 = 2时辰 x 五行相生链 = 6组治疗单元
总效 = 各单元能量乘积 > 单一时辰针法的总和
```

### 核心法则
每2个时辰一组，前一辰泻实、后一辰补虚，形成完整补泻循环。
前一辰疏通本经脉郁滞，后一辰顺势补益母经，让气机顺传不逆。

## 二、五组连环单元

### 第一环：木火相生（寅 + 巳）

#### 寅时（3-5时）- 木 - 泻肝
| 项目 | 内容 |
|:----|:------|
| **主穴** | 太冲 LR3（泻）、章门 LR13（泻） |
| **辅穴** | 阳陵泉 GB34、尺泽 LU5 |
| **手法** | 青龙摆尾泻法，疏泄肝郁 |
| **目的** | 疏肝解郁，清泻木郁 |

#### 巳时（9-11时）- 火 - 补心
| 项目 | 内容 |
|:----|:------|
| **主穴** | 少府 HT8（补）、神门 HT7（补） |
| **辅穴** | 劳宫 PC8、内关 PC6 |
| **手法** | 赤凤迎源补法，木生火顺传 |
| **目的** | 养心安神，承接木气生火 |

**衔接法**: 寅时三刻起针时，针尖朝向巳位（东南），留针3分引木气入火

**临床适用**: 肝郁化火 + 心神不宁（双相抑郁之郁转躁期）

## 三、疗程设计

| 阶段 | 内容 |
|:----|:------|
| **基础疗程** | 每个连环单元连续施针2日（每日取对应2时辰），5组完成需10日 |
| **强化疗程** | 连续3个基础疗程（30日）为一完整治疗周期 |
| **巩固疗程** | 每月初一至十五完成1轮，连续3月 |
| **验证标准** | 每单元前后测量对应经络原穴电阻值，变化 > 15% 为有效 |
| **禁忌** | 子午卯酉四正时辰为核心枢纽，不可颠倒顺序 |
