# 九宫飞星三合阵（洛书九宫 x 北斗九星 x 十二经三合针阵）

> **类型**: 基于公式推演的新针阵
> **推导依据**: 九宫飞星配穴法 x 北斗七星+辅弼九星 x 五行生克制化律

---

## 一、推导逻辑

### 公式
```
阵型组合数 = 九宫数(9) x 北斗星(9) x 十二经(12) > 972种组合
每宫取三角主穴 + 三才层次 = 完整的治疗单元
```

### 核心法则
每宫三合（星力+穴位+时辰），一宫主一周治疗。

## 三、疗程设计

| 阶段 | 内容 |
|:----|:------|
| **基础疗程** | 每宫针3日，九宫共27日为一完整周期 |
| **强化疗程** | 遇节气/朔望时，当令之宫加针1次 |
| **完整疗程** | 3个基础周期（81日）为一完整疗程 |
| **验证** | 每宫疗程前后测对应原穴生物电，差值>20%为有效 |
