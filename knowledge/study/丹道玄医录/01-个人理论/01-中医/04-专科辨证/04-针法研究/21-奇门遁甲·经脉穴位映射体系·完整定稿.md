## 一股·经典依据溯源——《针灸大成》对奇门针法的四大验证

奇门针法并非凭空推演，在《针灸大成·标幽赋》及《灵枢》中有明确经典依据：

### 验证①：察岁时于天道→阴阳遁定深浅

> **标幽赋：「凡刺之法，必候日月星辰四时八正之气，气定乃刺之。」**

奇门遁甲分阴阳遁（冬至后阳遁、夏至后阴遁），正应《灵枢》"春夏刺浅、秋冬刺深"之理：
- 阳遁（冬至→夏至）：阳气升发 → 宜浅刺（3～5分），应春夏季
- 阴遁（夏至→冬至）：阳气收敛 → 宜深刺（5～8分），应秋冬季

### 验证②：推十干知开阖→时干化合取穴

> **标幽赋：「推于十干十变，知孔穴之开阖；论其五行五脏，察日时之旺衰。」**

此句直接支持天干化合取穴之理。十干十变即五门十变，开阖即时干所主经脉气血盛衰——时干化合组（甲己化土取临泣+公孙等）正是此赋的直接运用。

### 验证③：八脉始终连八会→九星配八脉

> **标幽赋：「八脉始终连八会，本是纪纲。」**

八脉（奇经八脉）连八会（八脉交会穴），是奇门针法九星配穴的经典根基。九星与八脉的对应，实质是将奇经八脉纳入九宫体系：
- 天蓬→坎→肾经（通阴跷）
- 天芮→坤→脾经（通阴维）
- 天冲→震→肝经（通冲脉）
- 天辅→巽→三焦（通阳维）
- 天心→乾→肺经（通督脉）
- 天柱→兑→心经（通阴跷）
- 天任→艮→胃经（通阳跷）
- 天英→离→心经（通任脉）
- 天禽→中→脾经（统摄）

### 验证④：春夏瘦浅秋冬肥深→洛书针深

> **标幽赋：「春夏瘦而刺浅，秋冬肥而刺深。」**

洛书数理推导的针深（百会9分、照海9分等），经《针灸大成》卷九校核后修正为临床安全深度（百会3分、照海4分）。数理为体，临床为用——经典是最后的校验标准。

### 4.2 九星落宫的配穴法则

星落某宫 = 该星能量 + 该宫能量叠加，配穴需合参。

**公式：** 星穴 + 宫位配穴 + 化合配穴 = 完整针方

**案例：** 天芮星落艮8宫
- 天芮星穴 → 足三里（调脾胃病）
- 艮8宫配穴 → 丰隆+三阴交（化湿通滞）
- 化合配穴 → 根据时干选五门十变
- **完整针方：** 足三里(ST36) + 丰隆(ST40) + 三阴交(SP6) + 时干化合组

## 八、整合临床操作流程（六步针法）

奇门针法临床完整流程：

### 第一步：起局排盘

就诊时间 → 四柱干支 → 节气定局 → 排九宫八门九星八神

### 第二步：定位·定经

天芮落宫 → 对应脏腑 → 对应经脉
天芮落某宫+伤门/死门等 → 病位+病性

### 第三步：定星·取星穴

九星对应经脉 → 取星穴（见4.1表）
例：天芮星 → 足三里（调脾胃病）

### 第四步：定格局·取特定穴

查看天干组合格局 → 查6.2表取特定穴方
例：辛+乙 → 尺泽+太冲（缓解金克木）

### 第五步：时干化合·定针方

时干选定五门十变化合组 → 加配穴
例：时干戊/癸 → 阴谷+足三里

### 第六步：四时加减·完整处方

根据季节和诊所见候做穴位加减

### 临床案例演示：胃痛患者（辰时·戊辰）

**第一步·起局：** 辰时 → 戊辰时柱，阳遁3局

**第二步·定位：** 天芮落艮8宫 → 脾胃经；伤门+天芮 → 损伤性质，胃腑经筋

**第三步·星穴：** 天芮星穴 → 足三里（核心）；艮8宫配穴 → 丰隆+三阴交

**第四步·格局：** 时干戊辰 → 戊土当令。"戊土入辰"格局 → 配穴：太白(补土)+足三里(燥湿)

**第五步·化合：** 时干戊 → 戊癸化火 → 取合穴：阴谷(肾)+足三里(胃) → 温中散寒、引火归元

**第六步·完整针方：**
- 足三里(ST36) — 天芮星穴+戊癸合穴
- 丰隆(ST40) — 艮8配穴
- 三阴交(SP6) — 艮8配穴
- 阴谷(KI10) — 戊癸化火
- 公孙(SP4) — 中焦调和

**针法：** 太白、足三里用补法烧山火，丰隆平补平泻

## 十、奇门为体·七星为用——两套针法融合总论

### 体用关系

两套针法不是竞争关系，而是**一体一用**：

| 维度 | 奇门遁甲针法（体） | 北斗七星针法（用） |
|:----|:-----------------|:-----------------|
| 角色 | 辨证定局者 | 施针配伍者 |
| 解病 | 定位病宫、病性、格局 | 定三焦气机升降 |
| 取穴 | 九星定脏腑、天干定穴 | 七星定奇经、斗杓定补泻 |
| 时宜 | 四时旺衰加减、子午流注 | 斗柄指北/指南定大周期 |
| 专注 | 一人一局，因时因地 | 七针一气，贯通三焦 |

### 融合临床三模式

**模式一：奇门定盘·七星行针（最常用）**
先起奇门局定位，再依北斗七星阵施针。奇门局中值符星与时干落宫不冲突时直接在七星阵上加配穴；冲突时以时干化为先、七星阵法为主不变。

**模式二：奇门定盘·七星收功**
先取奇门病宫主穴刺治（前20分钟泄标），再依七星三才三穴收功治本（后20分钟）。适用于急性发作、局部病机为主。

**模式三：七星布阵·九宫轮刺**
前两周七星阵整体通关→第三周按九宫顺序轮刺（每宫2日）→第四周回七星阵收功。适用于慢性疑难病、需长期调理者。

### 经典合参路径

《针灸大成》为两套针法提供共同根基：
- 奇门针法得"察岁时""推十干"之验（标幽赋）
- 七星针法得"八脉始终连八会"之证（标幽赋）
- 两法在临床互为体用，不分主次
