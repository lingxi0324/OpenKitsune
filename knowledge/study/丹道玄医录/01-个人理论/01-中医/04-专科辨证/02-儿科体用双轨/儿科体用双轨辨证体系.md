## 一、总纲：儿科的体用特殊性

### 1.1 小儿与成人体用的根本差异

| 维度 | 成人 | 小儿 |
|:----|:-----|:------|
| **体质** | 五脏已全，阴阳已定 | 纯阳之体，五脏未全 |
| **体** | 精血充盈，形质完备 | **体未全**—脏腑娇嫩，形气未充 |
| **用** | 气机稳定，功能成熟 | **用未固**—易虚易实，易寒易热 |
| **体用关系** | 体→用稳定转化 | **体用皆弱且不稳定**—变化极快 |
| **病理特征** | 病势相对缓慢 | 朝病暮变，暮病朝变 |

### 1.2 钱乙五脏辨证·体用解读

钱乙最大的贡献是建立了**五脏辨证体系**，这正好与体用双轨完美吻合：

| 脏 | 体（物质） | 用（功能） | 钱乙补方 | 钱乙泻方 |
|:--|:----------|:----------|:---------|:---------|
| **肝** | 肝血 | 疏泄/风木 | 地黄丸（补肾即补肝） | 泻青丸 |
| **心** | 心血 | 神明/火热 | 安神丸 | 导赤散 |
| **脾** | 脾肉 | 运化/升清 | 益黄散 | 泻黄散 |
| **肺** | 肺气 | 肃降/治节 | 阿胶散（补肺散） | 泻白散 |
| **肾** | 肾精 | 封藏/作强 | 地黄丸 | 无泻（肾无实证） |

### 1.3 万全"三不足两有余"的体用本质

万全将钱乙体系总结为：
- **肝常有余** = 肝用易亢（风火易动）
- **心常有余** = 心用易亢（火热易炎）
- **脾常不足** = 脾体常虚（运化力弱）
- **肺常不足** = 肺体常虚（卫外不固）
- **肾常虚** = 肾体未充（先天未实）

**体用总结**：**三脏体不足（脾·肺·肾）+ 两脏用有余（肝·心）**
→ 治病以"保体"为先，"泄用"为辅

## 二、急惊与慢惊·体用辨证的核心范例

惊风是儿科最特殊的病种，钱乙的"急惊慢惊"二分法完美展示了体用框架：

### 2.1 急惊——阳盛阴虚·用太过体不及

| 维度 | 内容 |
|:----|:------|
| **定义** | 因闻大声或大惊而发搐，发过则如故 |
| **体用病机** | **用（心火热/肝风）太过 + 体（阴液）不足** |
| **钱乙原话** | "此无阴也。"—阴体不足 |
| **核心矛盾** | 心火热用亢 + 肝风用动 → 耗伤阴体 |
| **治则** | **凉泻**—利惊丸（泻心肝亢用） |
| **体用意义** | 用太过时必须急泻其用，不可用温补 |

### 2.2 慢惊——阳虚阴盛·体不及用亦衰

| 维度 | 内容 |
|:----|:------|
| **定义** | 因病后或吐泻，脾胃虚损而发搐 |
| **体用病机** | **脾体虚极 + 肝用亦衰** |
| **钱乙原话** | "此无阳也。"—阳体不足 |
| **核心矛盾** | 脾体虚→土不生金→肺体虚→金不制木→肝用妄动 |
| **治则** | **温补**—益黄散/理中汤（补脾体） |
| **体用意义** | 体虚极时必须急补其体，不可用凉泻 |

### 2.3 急慢惊的体用鉴别

| 对比项 | 急惊（体用太过） | 慢惊（体用不及） |
|:-------|:----------------|:----------------|
| 体 | 阴体未大亏（但被亢用耗） | **体大虚** |
| 用 | **用急亢**—抽掣有力 | **用衰微**—抽掣无力 |
| 阴阳 | 阳盛阴虚 | 阴盛阳虚 |
| 治则 | 凉泻—**急泄其用** | 温补—**急补其体** |
| 钱乙方 | 利惊丸（大黄/朴硝/青黛） | 益黄散（丁香/陈皮/青皮） |

## 三、疳证·体用辨证

### 3.1 疳证的体用本质

> 疳 = **脾体大虚 + 五脏用俱损**

钱乙将疳证按五脏分五疳：

| 疳证 | 体用病机 | 钱乙方 | 体用吻合度 |
|:----|:---------|:-------|:---------:|
| 肝疳 | 肝体亏→肝用拘急 | 地黄丸 | 90% |
| 心疳 | 心体亏→心用烦热 | 安神丸 | 85% |
| 脾疳 | 脾体亏→运化用衰 | 益黄散 | **95%** |
| 肺疳 | 肺体亏→喘咳用不利 | 补肺散（阿胶散） | 88% |
| 肾疳 | 肾体亏→生骨用迟缓 | 地黄丸 | 92% |

### 3.2 脾疳的间接补益路径

脾疳最典型—脾体虚极，但直接补脾往往不受（因为胃用亦衰）。

**间接补益方案（接入间接补益框架）：**
`
脾体衰（水土体衰）
  ├─ 隔一（补我生者）：补心火→脾土受益 → 小建中汤（桂心/饴糖）
  ├─ 隔二（补生我者）：补肾阳→脾土受益 → 附子理中汤
  └─ 对宫（补克我者）：疏肝木→脾土解放 → 逍遥散化裁
`

## 四、儿科方剂体用重分析

### 4.1 钱乙核心七方体用验算

| 方名 | 体用结构 | 吻合度 |
|:----|:---------|:------:|
| **泻青丸**（当归/龙脑/川芎/栀子/川大黄/羌活/防风） | 苦寒泄火用 + 辛散疏风用 + 养血固体 | **92%** |
| **导赤散**（生地黄/甘草/木通） | 甘寒补心体 + 苦寒泄心用 + 利水通用 | **95%** |
| **泻白散**（地骨皮/桑白皮/生甘草） | 甘寒泄肺用（不伤肺体） + 甘平固肺体 | **95%** |
| **益黄散**（丁香/陈皮/青皮/诃子/炙甘草） | 辛香温脾用 + 酸收固体 + 甘平固中 | **90%** |
| **泻黄散**（藿香/栀子/石膏/防风/甘草） | 辛散泄脾用 + 甘寒清火用 | **88%** |
| **阿胶散**（阿胶/牛蒡子/甘草/马兜铃/杏仁/糯米） | 甘平补肺体 + 辛平泄肺用 | **90%** |
| **地黄丸**（熟地/山药/山萸/茯苓/丹皮/泽泻） | 甘温补肾体（三补）+ 苦泄浊用（三泻） | **95%** |

### 4.2 六味地黄丸的体用原理解析

六味地黄丸（原名地黄丸）是钱乙最妙的方—它完美体现了**三补三泻·体用双调**：

| 药味 | 体用定位 | 补/泻 |
|:----|:---------|:-----:|
| 熟地黄 | 水体甘温—**补肾体** | 补 |
| 山茱萸 | 木体酸温—**补肝体** | 补 |
| 山药 | 土体甘平—**补脾体** | 补 |
| 泽泻 | 水用甘淡—**泄肾浊用** | 泻 |
| 牡丹皮 | 木用辛苦—**泄肝火用** | 泻 |
| 茯苓 | 土用甘淡—**泄脾湿用** | 泻 |

**体用意义**：三补（补体）+ 三泻（泄用）= 体用双调。体不补则肾精不充，用不泄则浊邪不去。这是钱乙对儿科"体未全用未固"的精准应对。

## 五、儿科六经·体用对接

儿科体用与六经体用的对接，重点在三经：

| 六经 | 儿科对应 | 体用特征 |
|:----|:---------|:---------|
| **太阴** | 脾疳/泄泻 | 脾体虚为主 |
| **少阴** | 肾疳/慢惊 | 肾体虚+心用乱 |
| **厥阴** | 肝疳/急惊 | 肝用亢+肝体虚 |

### 5.1 儿科六经体用辨证表

| 症状 | 六经归属 | 体用病机 | 治则 |
|:-----|:---------|:---------|:-----|
| 吐泻不止 | 太阴 | 脾体衰→运化用绝 | 补脾体（理中/益黄） |
| 手足厥冷 | 少阴 | 肾体衰→温煦用绝 | 温肾体（四逆/通脉） |
| 惊风抽搐 | 厥阴 | 肝用亢→阴体不制 | 泻肝用（泻青/凉惊） |
| 喘息汗出 | 太阳/少阴 | 卫用不固+肾体不纳 | 固体（桂枝+肾气） |
| 发热无汗 | 太阳 | 卫用闭+体不化 | 通用（麻黄/桂枝） |

## 八、体用总判

### 8.1 儿科体用总公式

> **小儿者，纯阳之体，五脏未全。**
> **体未充则用易亢，体一虚则用即衰。**
> **体用皆弱故变化极速，朝病暮变，不可不慎。**

### 8.2 与成人内科的关键区别

| 维度 | 成人内科体用 | 儿科体用 |
|:----|:------------|:---------|
| 体 | 五脏已全，精血有源 | **五脏未全，精血薄嫩** |
| 用 | 升降有序，功能力强 | **用不稳固，极易失衡** |
| 治体 | 可峻补 | **不可峻补—恐碍用** |
| 调用 | 可猛攻 | **不可猛攻—恐伤体** |
| 体用变化 | 相对缓慢 | **极速—朝暮不同** |
| 核心治则 | 补体为主调用为辅 | **保体为先，轻用为要** |
