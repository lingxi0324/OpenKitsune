# 病因病机概论·河洛九宫视角

> 本概论以河洛数理为底层逻辑，以五脏九宫矩阵为框架，
> 重新梳理中医病因病机体系。
>
> 核心观点：**病机的本质，是河图生成数的失衡 + 洛书九宫位的偏移**。

---

## 一、病因总纲——河图五类因

### 1.1 五类病因的河图分类

| 河图数 | 五行 | 病因类别 | 具体内容 |
|:------|:----|:---------|:---------|
| **1水** | 寒 | **外感六淫之首** | 风寒暑湿燥火——天之六气失常 |
| **2火** | 热 | **内伤七情之源** | 喜怒忧思悲恐惊——情志过极 |
| **3木** | 风 | **饮食劳倦** | 饮食不节、劳逸失度 |
| **4金** | 燥 | **痰饮瘀血** | 病理产物导致的继发病因 |
| **5土** | 湿 | **内外合邪** | 外感+内伤复合病因 |

### 1.2 三因归类（传统框架 × 河图视角）

```
外因（天）← 1水·寒 — 六淫从外而入
内因（人）← 2火·热 — 七情从内而生
不内外因 ← 3木·风 — 饮食劳倦、金刃虫兽

→ 三类病因最终都会影响中宫5（脾胃），
  故"内伤脾胃，百病由生"（李东垣）
```

| **火（热）** | 火 | **坤2**（西南） | 炎上燔灼，动血 |

### 2.2 六淫的河图生克规律

```
风（木3）→ 克 → 湿（土5）→   "风能胜湿"
湿（土5）→ 克 → 寒（水1）→   "燥湿可祛寒"
寒（水1）→ 克 → 火/暑（2/9）→ "寒能清热"
暑（火2）→ 克 → 燥（金4）→   "火能灼金"
燥（金4）→ 克 → 风（木3）→   "金能制木"

→ 六淫的传变遵循河图相克序
→ 临床常见"风寒湿合邪"（1水+5土+3木，三才同宫）
```

## 三、内伤七情——九宫藏神模型

### 3.1 七情与五脏九宫的对应

| 七情 | 五脏 | 九宫 | 河图数 | 过则伤 | 九宫位置影响 |
|:----|:----|:----|:------|:-------|:------------|
| **怒** | 肝 | 震3 | 3木 | 伤肝，气上 | 左关脉独亢 |
| **喜** | 心 | 坤2 | 2火 | 伤心，气缓 | 左寸脉浮大 |
| **思** | 脾 | 中5 | 5土 | 伤脾，气结 | 右关脉涩滞 |
| **悲** | 肺 | 巽4 | 4金 | 伤肺，气消 | 右寸脉虚细 |
| **恐** | 肾 | 坎1 | 1水 | 伤肾，气下 | 双尺脉沉弱 |
| **惊** | 心/胆 | 坤2/艮8 | 2/8 | 气乱，心神不宁 | 乍疏乍数 |
| **忧** | 肺/脾 | 巽4/中5 | 4/5 | 气聚不散 | 右寸关间郁脉 |

### 3.2 七情致病的九宫传变

```
怒（震3）→ 纵向克脾（中5）→ "肝木乘脾"
  ↓ 横向传心（坤2）→ "木生火，怒极笑"
喜（坤2）→ 纵向克肺（巽4）→ "喜伤心→火克金"
  ↓ 横向传脾（中5）→ "火生土，喜极思"
思（中5）→ 纵向克肾（坎1）→ "思伤脾→土克水"
  ↓ 横向传肺（巽4）→ "土生金，思极悲"
悲（巽4）→ 纵向克肝（震3）→ "悲伤肺→金克木"
  ↓ 横向传肾（坎1）→ "金生水，悲极恐"
恐（坎1）→ 纵向克心（坤2）→ "恐伤肾→水克火"
  ↓ 横向传肝（震3）→ "水生木，恐极怒"
```

> **核心规律**：七情的九宫传变 = **纵向相克 + 横向相生**，形成完整的情绪致病闭环。
> 此即"五脏藏神辩证"的数理基础。

## 四、病理产物——河图"杂质"理论

### 4.1 三大病理产物的河图生成

```
正常气血运行中，由于各种原因产生的"杂质"：

① 痰饮 ← 5土（脾虚运化失常，水湿停聚）
② 瘀血 ← 2火（心气不足或寒凝，血脉不通）
③ 结石 ← 4金（湿热煎熬，津液凝结）

↓

这些"杂质"一旦生成，
就会阻塞河图的气血通道，
导致九宫之间的能量传递受阻。
```

### 5.2 病机的升降出入失常——九宫轴心理论

```
人体气机三大轴：

①  左升轴：坎1（肾）→ 震3（肝）→ 巽4（肺）
    病机：升发不及 → 阳陷、气郁

②  右降轴：离9（心）→ 坤2（胃）→ 兑7（大肠）
    病机：肃降失常 → 气逆、火升

③  中轴：中5（脾升胃降）
    病机：中轴不转 → 四维皆病

→ "气有一息不运，血有一息不行"——中轴是核心
```

## 六、双轨辩证视角下的病因病机

### 6.1 外感线（六经传变）

```
太阳（表）→ 阳明（里）→ 少阳（半表半里）
  ↕              ↕              ↕
太阴（脾虚）→ 少阴（肾虚）→ 厥阴（寒热错杂）

六经传变的河图逻辑：
  三阳 = 河图生数（1/2/3），病进
  三阴 = 河图成数（6/7/8），病深
```

### 6.2 内伤线（五脏传变）

```
五脏相生传：肾→肝→心→脾→肺→肾（母病及子）
五脏相克传：肝→脾→肾→心→肺→肝（乘侮传变）

与归经的关系：
  相生传 = 河图生数序（1→3→2→5→4→1）
  相克传 = 洛书对阵传（3→5→1→2→4→3）
```

### 6.3 合病与并病

| 类型 | 定义 | 九宫表现 | 临床特点 |
|:-----|:------|:---------|:---------|
| **合病** | 两经同时发病 | 两宫同时异常 | 起病即见，传变快 |
| **并病** | 一经未罢，另一经又起 | 一宫为主，牵涉他宫 | 层次递进 |
| **两感** | 表里同病 | 生数+成数同宫失常 | 病情较重 |

## 七、总结——病因病机的河洛核心

```
病因 = 河图五类因（1-5生数失衡）
病位 = 洛书九宫位（哪一宫异常）
病性 = 五行生克序（相生为虚、相克为实）
病势 = 九宫传变（纵向克、横向生、对角线越经传）

临证八步：
① 辨病因 → 外感/内伤/不内外
② 定病位 → 九宫哪一宫
③ 察病机 → 河图生成数偏盛偏衰
④ 审病势 → 传变方向（按九宫路径）
⑤ 合时气 → 当前节气/五运六气
⑥ 归双轨 → 六经线（外感）+ 五脏线（内伤）
⑦ 出方案 → 针对性立法
⑧ 预测预后 → 按洛书平衡判断好转/加重
```
