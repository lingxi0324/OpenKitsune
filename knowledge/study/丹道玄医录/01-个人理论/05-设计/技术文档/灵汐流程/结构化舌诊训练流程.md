## 二、阶段一：理论学习

### 2.1 学习资源

| 资源 | 路径 | 用途 |
|:-----|:-----|:------|
| **《杨春虎中药舌诊讲记》** | （待获取PDF） | 主教材，系统舌诊理论 |
| **《舌鉴辨正》** | 医藏/06辩证诊治-20本/ | 28种白苔、黄苔分型，图谱最丰富 |
| **《临症验舌法》** | 同上一 | 虚实阴阳+脏腑配主方，最系统 |
| **《察舌辨症新法》** | 同上 | 看舌八法+苔色诊断，最简明 |
| **《伤寒舌鉴》** | 医藏/09伤寒-49本/ | 伤寒专病舌诊 |
| **《形色外诊简摩》** | 同上一 | 综合望诊参考 |

### 2.2 学习步骤

**第一步：建立舌象分类认知（1-3天）**

1. 通读本规范「舌象分类体系」一遍，了解全貌
2. 对照《察舌辨症新法》的"看舌八法"——先掌握"怎么观察"
3. 对照《临症验舌法》的"虚实阴阳"——再掌握"怎么辨证"

**学习输出：**
```
□ 能说出舌质三大分类（舌色/舌形/舌态）及各自子类
□ 能说出舌苔两大分类（苔色/苔质）及各自子类
□ 能说出舌下络脉的5个观察维度
□ 能区分正常舌与病理舌
```

**第二步：逐类精读（每类1-2天，持续3-4周）**

按以下顺序，每类先读《杨春虎中药舌诊讲记》，再对照古籍印证：

| 周次 | 专题 | 对照古籍 |
|:----:|:-----|:---------|
| 第1周 | 淡白舌/淡红舌/红舌 | 《舌鉴辨正》白舌类+红舌类 |
| 第2周 | 绛舌/紫舌/青舌 | 《舌鉴辨正》紫舌类+《伤寒舌鉴》绛舌 |
| 第3周 | 白苔/黄苔/灰黑苔 | 《舌鉴辨正》苔色篇 |
| 第4周 | 腻苔/剥苔/燥滑/复合 | 《察舌辨症新法》苔质篇+《形色外诊简摩》 |

**第三步：鉴别训练（持续进行）**

```
同一类舌象中找2-3种亚型的区别：
  例：淡白胖嫩 vs 淡白瘦薄——同一色不同形的辨证差异
  例：红绛舌 with 黄腻苔 vs 红绛舌 with 无苔——同一质不同苔的病机差异
```

## 三、阶段二：图片采集

### 3.1 采集渠道

| 渠道 | 工具/方法 | 优先级 |
|:-----|:----------|:------:|
| **① PDF古籍提取** | `extract_pdf_tongue_images.py` | ⭐⭐⭐ |
| **② 临床拍摄** | 手机/相机按质量标准拍摄 | ⭐⭐⭐ |
| **③ 网络搜集** | 舌诊图谱网站、医学教材扫描版 | ⭐⭐ |
| **④ 书籍拍照** | 纸质舌诊图谱拍照 | ⭐ |

### 3.2 PDF提取流程

```bash
# 完整提取（推荐）
python extract_pdf_tongue_images.py "杨春虎中药舌诊讲记.pdf" -o 舌诊图片数据库 --dpi 300 --min-size 50

# 提取后操作
1. 浏览 raw/ 目录，删除非舌诊图片（如封面、目录、空白页）
2. 查看 extraction_meta.json 中的质量标记
3. 将合格图片按分类移动到对应子目录
```

### 3.3 临床拍摄流程

```
拍摄前准备：
  □ 自然散射光（或医用LED 5000K）
  □ 患者空腹（餐前或餐后1小时）
  □ 未食染色食物/饮品
  □ 未吸烟

拍摄步骤：
  1. 患者端坐，张口伸舌
  2. 舌自然放松（不紧张、不卷缩）
  3. 相机/手机与舌面平行，距离15-20cm
  4. 拍摄正位舌面（1张）
  5. 如需，拍舌下络脉（1张，舌尖抵上颚）
  6. 检查：舌体完整、对焦清晰、无过曝

保存规范：
  文件名：{分类编码}_{日期}_{序号}.jpg
  例：t01_20260508_001.jpg
```

### 3.4 图片质量标准速查

| 指标 | 合格线 | 检查方法 |
|:-----|:------:|:---------|
| 分辨率 | ≥720×540 | 属性查看 |
| 对焦 | 舌乳头清晰 | 肉眼 |
| 色偏 | 无明显色偏 | 对比标准色卡/自然光 |
| 反光 | ≤15%舌面 | 肉眼 |
| 舌体完整 | 舌根可见 | 肉眼 |
| 格式 | JPG≥质量90 | 属性 |

## 四、阶段三：标注入库

### 4.1 标注流程

```
打开图片 → 观察 → 判断三级分类 → 填标注 → 填写病机 → 关联古籍 → 入库
   ①      ②          ③            ④          ⑤          ⑥       ⑦
```

### 4.2 标注工具

当前使用**JSON手动标注**，后续开发图形化标注工具。

**标注文件结构：**
```
舌诊图片数据库/
├── metadata/
│   └── tongue_meta.json        ← 全库标注总表
│   └── extraction_meta.json    ← 提取元数据
```

**标注模板（每张图一条）：**
```json
{
  "image_id": "T01-20260508-001",
  "filename": "p0015_杨春虎中药舌诊讲记.jpg",
  "source_name": "杨春虎中药舌诊讲记",
  "source_ref": "第三章/淡白舌",
  "tongue_category_l1": "舌质",
  "tongue_category_l2": "舌色",
  "tongue_category_l3": "淡白舌",
  "tongue_category_tags": ["淡白", "胖嫩", "齿痕"],
  "color_desc": "舌色淡白，略偏苍白，无血色",
  "texture_desc": "舌体胖嫩，边有齿痕，舌面水滑",
  "coating_desc": "苔白滑腻",
  "shape_desc": "胖大，明显齿痕",
  "syndrome_type": "脾阳虚证",
  "pathogenesis": "脾阳不足，水湿内停，气血不荣于舌",
  "book_ref": "《舌鉴辨正》白舌第六条",
  "quality_score": 4,
  "verified": false
}
```

### 4.3 标注优先级

```
第一批：基础单类（淡白舌、红舌、薄白苔、黄腻苔等）—— 先建立基础库
第二批：复合证（红绛黄腻、淡白水滑等）—— 再积累复杂证
第三批：临床病例（含完整诊断信息）—— 最后补充真实病例
```

### 4.4 标注质量要求

| 要求 | 标准 |
|:-----|:------|
| 三级分类 | 必须填写完整的L1/L2/L3 |
| 多标签 | 一幅图多个特征时使用 tags 记录 |
| 病机分析 | 至少一句话，与经典理论一致 |
| 来源 | book_ref 必须可追溯（古籍/书籍） |
| 质量评分 | 3分以上才用于训练 |
| 校验 | 标注后人工复核 |

## 五、阶段四：算法训练

### 5.1 训练资源

现有 `tongue_algorithm` 技能已包含：

| 组件 | 状态 | 路径 |
|:-----|:-----|:------|
| 预处理+分割 | ✅ 已就绪 | tongue_algorithm/ |
| 32维特征提取 | ✅ 已就绪 | BGR/HSV/LAB/LBP/Canny/熵 |
| XGBoost辨证 | ✅ 已训练 | tongue_xgb_model.pkl |
| FAISS极速检索 | ✅ 已建立 | tongue_faiss.index |
| 病例库 | ✅ 已有3例 | tongue_meta.json |

### 5.2 训练流程

```
步骤1：积累标注数据
  └─ 图片数量：每类≥10张，总库≥100张

步骤2：预处理
  └─ 运行预处理脚本 → 舌体分割 → 统一尺寸

步骤3：特征提取
  └─ 提取32维特征（BGR/HSV/LAB均值+LBP纹理+Canny边缘+熵）

步骤4：训练/更新XGBoost模型
  └─ tongue_algorithm/scripts/train_xgb.py
  └─ 输入：标注数据 → 输出：tongue_xgb_model.pkl

步骤5：更新FAISS索引
  └─ 运行 index_builder.py
  └─ 输入：新特征向量 → 输出：tongue_faiss.index

步骤6：验证
  └─ 交叉验证：分类准确率
  └─ 人工抽查：对比模型诊断 vs 人工诊断
```

### 5.3 训练数据量建议

| 阶段 | 图片数 | 证型数 | 操作 |
|:----|:------:|:------:|:-----|
| **起步** | 30-50张 | 5-8种 | 基础分类训练 |
| **可用** | 100-200张 | 10-15种 | 常规辨证可用 |
| **可靠** | 500+张 | 20+种 | 临床辅助参考 |
| **成熟** | 1000+张 | 全分类 | 鉴别训练工具 |

### 5.4 每日训练计划

**日常20分钟训练（建议）：**

```
5 分钟   → 随机抽取5张图，快速判断三级分类
5 分钟   → 打开标注对比，看自己判断是否准确
5 分钟   → 读一条古籍对应条文，印证特征描述
5 分钟   → 新增1-2张图入库标注
```

**每周2小时专题训练（建议）：**

```
30分钟 → 精读一个舌象专题（如"黄腻苔的6种鉴别"）
30分钟 → 找出对应分类的所有图片，逐张分析
30分钟 → 用FAISS检索相似舌象，验证鉴别能力
30分钟 → 整理笔记、更新统计、规划下周专题
```

## 六、验证与迭代

### 6.1 训练效果验证

| 验证项目 | 方法 | 通过标准 |
|:---------|:-----|:---------|
| 分类准确率 | 10张图盲测 | 三级分类正确率≥80% |
| 病机判断准确 | 5张图+病历分析 | 病机分析准确≥60% |
| FAISS检索精度 | 输入新图看Top5 | 同类检索≥3/5 |
| 鉴别训练 | 相似证型双盲对比 | 能区分80%的相似证 |

### 6.2 循环迭代

```
训练 → 验证 → 发现不足 → 补充资料 → 重新标注 → 再训练
 ①     ②        ③          ④          ⑤         ⑥
```

**迭代重点：**
- 分类错误的图片 → 检查是否标注有误 → 修正后重训
- 检索不准的图片 → 检查特征提取参数 → 调整后重训
- 识别不了的证型 → 检查该证型图片数量 → 补充后重训
