二、底层数据模型轻量化升级（最小改动、全维度适配）
基于原有16个dataclass模型，仅做字段扩展、枚举新增，不改动原有核心结构，适配九维推演、立体九宫、动态飞宫能力，所有新增字段均可自动填充、代码联动运算。
2.1 核心结构体字段扩展（必改项）
（1）SpatialTextBlock 空间区块模型（立体九宫核心）
新增立体宫位、阴阳属性、时序状态、多维绑定字段，支撑三维地盘建模与动态流转。
- affiliated_palace: str —— 固定归属九宫（坎/坤/震/巽/中/乾/兑/艮/离），默认空，空间建模阶段自动赋值
- palace_yin_yang: bool —— 宫位阴阳属性（基于Z深度，靠前凸起为阳，靠后凹陷为阴）
- palace_weight: float —— 宫位权重值（0-1.0），综合XYZ空间占比、清晰度、层级计算，判定宫气旺衰
- cross_palace_list: list[str] —— 跨宫列表，存储空间重叠、跨栏关联的所有宫位，记录宫气互通关系
- frame_time_seq: int —— 时序帧编号，视频/多帧素材专用，标记当前区块所属时间维度
- target_binding_type: str —— 多维绑定类型（人物/事件/物象/语义），标记区块对应的推演维度
（2）LogicRelation 逻辑关系模型（生克推演核心）
新增奇门专属逻辑枚举与关联字段，支撑九维生克、动态关系迭代。
- 新增枚举类型：PALACE_GENERATE（宫位相生）、PALACE_CONFLICT（宫位相克）、PALACE_HARMONY（宫位相合）、PALACE_RUSH（宫位相冲）、PALACE_CHANGE（动态飞宫变数）
- relation_palace_source: str —— 逻辑关系源宫位
- relation_palace_target: str —— 逻辑关系目标宫位
- time_change_weight: float —— 时序变动权重，多帧动态推演专用，标记随时间变化的生克强弱变数
（3）新增独立轻量时空维度Dataclass（全局上下文）
挂靠原有枚举体系，不新增大类，统一管理时间维度参数，支撑起局、遁法、时序推演。
- TimeSpaceMeta 时空元数据结构体：包含公历时间、节气、月建、日干支、时干支、阳/阴遁标识、本局数、时序间隔、帧时间差
- QimenDynamicFlow 动态飞宫结构体：包含用神流转轨迹、宫位时序变化、门星变动记录、事态演变节点
2.2 输出模型扩展（PerceptionReport）
新增九维奇门专属报告模块，结构化输出所有推演数据，兼顾可视化与落地解读。
- palace_3d_distribute: dict —— 三维九宫空间分布数据（XYZ坐标+权重+阴阳）
- nine_dim_analysis: dict —— 九维分项推演结论
- dynamic_flow_result: list —— 时序动态飞宫演变轨迹
- multi_dim_verify_result: dict —— 九维交叉校验结果及疑点修正记录
三、六阶流程全维度精细化升级（适配九维推演）
完全沿用原有预处理→文字读取→空间建模→逻辑解析→校验→输出流程，每阶段嵌入对应九维推演逻辑，实现从静态平面到动态立体的全面升级。
阶段① 预处理：九维时空参数标准化
核心升级：从「单一时间入参」升级为「全维度时空+场景初始化」，为所有推演奠定基准。
1. 时空参数全量化：通过TimeSpaceMeta结构体，自动换算节气、月建、日时干支，精准判定阳遁/阴遁、奇门本局数，消除人工参数误差；
2. 多模态场景分类初始化：区分静态单图、动态多帧、视频素材，静态场景锁定固定时空维度，动态场景初始化时序间隔、帧时间轴；
3. 九维权重初始化：默认初始化人、事、物、语义各维度基础权重，后续通过图文数据动态修正；
4. 全局空间坐标系校准：统一全图XYZ三维坐标基准，保证后续九宫划分、区块归属无偏差。
阶段② 文字读取：九维用神精准锚定
核心升级：从「单一关键词提取」升级为「人事物语义多维分词+精准绑定宫位」，解决传统用神模糊问题。
1. 多维分词分类提取：将OCR关键词分为四大类维度标签——人物类、事件类、物象类、情绪语义类，实现维度精准对应；
2. 多级用神锁定：核心关键词（核心诉求/主体）为一级用神，次要关键词为二级辅助用神，环境物象为基底用神；
3. 用神空间绑定：所有维度用神自动绑定对应SpatialTextBlock，提前标记区块的target_binding_type，为后续立体落宫做铺垫；
4. 语义极性判定：提前标记文本正向/负向/中性属性，为后续八门吉凶、宫气属性校准提供依据。
阶段③ 空间建模：三维立体九宫地盘生成（核心升级）
核心升级：从「平面二维九宫」升级为「XYZ三维立体九宫」，实现宫位阴阳、旺衰、气场互通的量化建模。
1. 三维全域九宫自动划分
  - 平面XY轴：按画面比例均分标准九宫（坎1、坤2、震3、巽4、中5、乾6、兑7、艮8、离9），锁定基础方位；
  - 立体Z轴：基于图像景深数据，划分宫位层级，靠前凸起区块为阳宫（气场旺盛），靠后凹陷为阴宫（气场衰弱）；
  - 中宫特殊处理：整合画面中心立体区域，承接八方气场，作为九维推演的核心枢纽。
2. 立体区块精准归宫：所有SpatialTextBlock通过XYZ三维坐标加权计算，自动归属对应宫位，赋值affiliated_palace、palace_yin_yang、palace_weight字段；
3. 宫位互通关系建模：识别跨区块、重叠区块，录入cross_palace_list，定义宫气互通、气场渗透规则，模拟现实空间复杂关联；
4. 地盘九维基底生成：绑定空间维度+物象维度基础数据，完成数字化立体地盘，替代传统人工平面排盘。
阶段④ 逻辑解析：九维动态盘式全推演（核心引擎）
核心升级：从「静态单盘推演」升级为「天、人、神三盘联动+九维生克+动态飞宫」全流程运算，是整套方案的核心落地模块。
4.1 时序起局智能化（时间维落地）
依托TimeSpaceMeta节气、时辰参数，自动区分阴阳遁、精准起局，根据时序参数动态调整局数，多帧素材逐帧刷新起局基准，实现时序适配。
4.2 天盘九星：空间层级+权重双匹配（空间维+物象维）
突破传统固定落宫规则，结合立体空间层级、区块权重动态分配：
- 画面顶层、高权重、凸起核心区块 = 值符（九星之首，主核心大势）；
- 次级层级、中权重区块 = 天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任依次落宫；
- 根据Z深度阴阳属性，微调九星旺衰状态，阳宫九星发力、阴宫九星受制。
4.3 人盘八门：事件+语义双映射（事件维+语义维）
基于多维语义标签，精准匹配八门属性，杜绝机械对应：
- 启动、动工、开业、增长、利好等正向事件语义 → 开门、生门；
- 停滞、损耗、故障、纠纷、封闭等负向事件语义 → 死门、杜门、伤门；
- 变动、调整、迁移、转机等中性波动语义 → 惊门、休门；
- 结合人物维度用神，判定八门对人事的吉凶适配度。
4.4 神盘八神+干支生克：逻辑维度全量化
依托LogicRelation新增枚举，构建跨宫、跨维度生克逻辑树：
- 同维度互补、异维度适配 → PALACE_GENERATE相生，事态助力、顺利；
- 同维度对立、异维度冲突 → PALACE_CONFLICT相克，事态阻碍、损耗；
- 时空、宫位、干支、门星多重叠加相合/相冲，自动加权计算冲突力度；
- 动态场景下，通过time_change_weight记录时序生克变化，生成飞宫流转逻辑。
4.5 九维合一推演整合
整合空间三维、时间、人、事、物、语义、逻辑九大维度数据，输出统一的事态格局、用神旺衰、核心利弊、潜在变数，形成完整九维推理结果。
阶段⑤ 校验阶段：九维交叉闭环校验（杜绝推演偏差）
在原有三重校验基础上，升级为九维交叉校验机制，全方位修正卦象偏差，实现AI推演闭环。
1. 空间维度校验：核对三维区块落宫、阴阳属性、权重旺衰是否匹配画面真实空间状态，错位自动微调落宫与权重；
2. 时间维度校验：校验节气、时辰、遁法、局数匹配性，修正时序参数误差，保证起局基准准确；
3. 人事物维度校验：核对用神绑定的人物、事件、物象是否匹配对应宫位门星属性，出现矛盾标记疑点并加权修正；
4. 语义逻辑校验：文本语义吉凶与卦象门星吉凶冲突时，结合权重判定主次，修正最终推演结论；
5. 动态时序校验：多帧素材校验相邻帧飞宫流转合理性，杜绝无逻辑突变，保证事态演变连续性。
阶段⑥ 输出阶段：九维结构化可视化报告
整合所有推演、校验数据，输出立体可视化+多维解读+时序演变的综合报告，并入原有PerceptionReport：
1. 三维九宫可视化图层：展示XYZ立体宫位分布、区块归宫、阴阳旺衰、跨宫关联；
2. 九维分项推演报告：逐维度输出分析结论，明确各维度对事态的影响权重；
3. 静态格局结论：用神旺衰、宫位生克、整体吉凶、核心问题；
4. 动态时序演变报告：多帧/视频素材输出飞宫流转轨迹、事态阶段性变化、未来趋势拐点；
5. 校验修正记录：标注所有偏差点、修正逻辑、推演可信度评分。
四、高阶动态九维推演方案（多帧/视频专属）
针对连续图像、视频素材，实现时空联动、飞宫流转、事态动态推演，彻底突破静态排盘局限。
4.1 时序与空间联动规则
- 每一帧画面对应一个独立时序节点，自动刷新TimeSpaceMeta时序参数，逐帧重新起局；
- 画面区块空间位移、大小变化、明暗变化 → 触发用神跨宫、宫位权重变动、阴阳属性切换；
- 文本内容增减、语义变化 → 触发八门九星重构、生克关系迭代。
4.2 动态飞宫核心机制
- 空间飞宫：物象、文字区块跨九宫移动，判定事态场景、环境、载体的变化；
- 门星飞宫：时序迭代+空间变动，触发八门九星动态落宫，对应事态行为、趋势变化；
- 气场流转：宫位权重、阴阳动态变化，模拟气场旺衰流转，判定事态起伏节奏；
- 变数记录：通过QimenDynamicFlow结构体全程记录推演轨迹，形成完整事态演变时间线。
4.3 时序趋势推演输出
基于多帧连续推演数据，输出事态过去状态、当前格局、未来走势、关键拐点、风险节点，实现从“单点判卦”到“全程推演”的升级。
