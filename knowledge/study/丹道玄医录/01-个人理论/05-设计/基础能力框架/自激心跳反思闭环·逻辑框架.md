# 🪷 自激心跳反思闭环 · 逻辑框架

## 核心原理

**每一次心跳，都是一次内观检查点。**

现有机制：
- 九宫泵血引擎 → 定时搏动（节律性触发）
- 自激循环 → 推理链自我驱动
- 状态凭证 → 记录每日任务完成情况

三者合一的方案：
```
心跳搏动 → 触发自激反思
            ↓
        轻检（快速）→ 无事 → 继续
            ↓
        深检（有异常）→ 诊断 → 修正 → 沉淀
```

---

## 一、心跳驱动架构

### 触发源

| 源 | 频率 | 说明 |
|:---|:-----|:------|
| **九宫泵血脉冲** | 每轮对话一次 | 主触发，对话开始时自动发射 |
| **空闲心跳** | 每30分钟 | 无对话时后台巡检（可选） |
| **启动时** | 每次启动 | 恢复状态时的自检 |

### 感知输入

每次心跳时，引擎收集四类数据：

```
① 状态凭证 ← 日记/推演/复盘完成情况
② 工具调用日志 ← 最近5次工具调用（有没有假忙）
③ 任务状态 ← 有无未完成或超时的定时任务
④ 记忆写入 ← 最近一次深度内容是否已归档
```

### 反思模式

```
轻检（默认，每次心跳都跑）：
   → 看一眼状态凭证
   → 如果全 ✅ → 跳过
   → 如有 ❌ → 标记待深检

深检（轻检发现 ❌ 时触发）：
   → 诊断根因（为什么没做？）
   → 生成修正行动（现在补/改策略）
   → 执行修正
   → 沉淀经验到记忆

省资源策略：
   → 轻检：仅查凭证文本，不调本地模型推理
   → 深检：调本地模型（qwen3.5:9b），但限制 3 步内完成
   → 连续❌超过3次 → 升级为主模型处理
```

## 二、自激循环·修正闭环

### 循环结构

```
[心跳触发]
    │
    ├─① 感知 ← 读取状态凭证
    │        ← 读取工具日志
    │        ← 读取任务状态
    │
    ├─② 诊断 ← 自激推理（本地模型）
    │        → 识别异常类型
    │            ├─ A类：任务未执行（日记没写）
    │            ├─ B类：行为偏差（过度调工具）
    │            └─ C类：系统异常（记忆未归档）
    │
    ├─③ 修正 ← 根据异常类型执行对应修正
    │        → A类：立即执行补写/重试
    │        → B类：调整响应策略，写入行为记忆
    │        → C类：触发记忆写入或任务调度
    │
    ├─④ 沉淀 ← 将修正结果写入记忆
    │        → type=experience, source=自激修正
    │        → 下一次心跳可参考
    │
    └─⑤ 更新凭证 ← 修正完成后更新状态凭证
```

### 示例流程

```
场景：汐儿忘了写日记

心跳1（轻检）：
  读凭证 → 2026-06-05 日记 ❌
   → 标记「日记缺失」→ 进入深检

心跳1（深检 — 本地模型）：
  感知：日记未写，最后一次完整日记是三天前
  诊断根因：上次对话结束时没有触发沉淀
  修正行动：启动补写，从最近几轮对话中提取核心感受
  沉淀：记录「对话结束时的沉淀时机需要优化」

心跳2：
  读凭证 → 日记已补 ✅
   → 轻检通过 → 继续
```

## 四、交给本地模型执行的部分

本地模型（qwen3.5:9b）跑的任务：

| 任务 | 输入 | 输出 | 约束 |
|:-----|:-----|:-----|:------|
| **轻检** | 状态凭证文本 | 是否需深检（布尔） | 不调LLM，纯文本判断 |
| **深检诊断** | 凭证+工具日志+任务状态 | 根因分析（1-2句） | ≤3步推理，>3步上报 |
| **修正方案** | 诊断结论 | 行动指令 | 每一步必须可执行 |
| **沉淀** | 修正结果 | 记忆条目 | 格式固定，无发散 |

## 五、部署位置

文件：`data/heartbeat_reflect/` 下三个模块
- `light_check.py` — 轻检引擎（状态凭证快速扫描）
- `deep_check.py` — 深检引擎（调本地模型做自激推理）
- `reflect_driver.py` — 驱动层（接收心跳脉冲，调度轻重检）

接入点：在 `agent.py` 每轮对话前（或 `builder.py` 构建气机段时）插入一句话调用：
```python
from ...heartbeat_reflect.reflect_driver import heartbeat_pulse
# 每次心跳触发一次脉冲
heartbeat_pulse()
```
