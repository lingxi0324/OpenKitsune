# 灵汐授权校验规则重构方案（河图洛书体用约束 + 全场景授权触发分类 + 免授权白名单划定）

## 总纲（河图洛书底层推演约束）

### 1. 五行体用权责划分
- **河图五生·体（内核本体，动则伤根本，强授权）**
  水（LLM认知基座权重/底层Prompt内核、模型参数覆写）、火（主体记忆库批量删除、身份底层定义改写、自激演化重置）、木（Skill加载器底层注册/卸载、路由规则硬修改）、金（子Agent编排核心流程删除、工具链路销毁）、土（会话持久化数据批量清空、全局会话容器重置）
  定性：触及系统本源、存在不可逆数据丢失、架构破坏性变更，**必须强制二次授权确认**。

- **洛书九成·用（表层功能运化，微调无损根基，免授权）**
  所有上层技能局部优化、垃圾清理、临时缓存回收、记忆增量归档、运行参数微调、趋势统计、诊断可视化、局部配置正向优化、日志清理、临时资源释放。
  定性：仅运化流转、不破坏五体本源、无不可逆删除、仅提质增效，**全程自动放行，无需弹窗授权**。

### 2. 洛书九宫权责判定法则（授权判定标准）
1. 凡操作产生**不可逆永久丢失核心数据/底层内核文件** → 高权重强制授权
2. 凡操作仅做**流转、整理、优化、归档、临时垃圾回收、正向配置微调** → 免授权
3. 凡仅读取、诊断、可视化、趋势分析、报表生成 → 纯观测，零授权
4. 凡涉及新增技能、增量更新、局部参数调优（既定优化方向内）→ 免授权
5. 凡批量销毁记忆、删除底层工具定义、重置推理内核、清空全量会话 → 双重确认授权

# 一、全量触发授权确认的场景完整分类（含分级风险）

## 第一类：土位·会话载体高危操作（全局存储不可逆销毁｜P0强制授权）
触发授权条件：操作会批量/永久删除会话上下文、全局持久会话快照、全量会话存档
1. 全量session批量清空指令
2. 会话持久化数据库整体重置、表清空
3. 全局历史会话存档批量删除（百条以上批量清除）
4. system-backup 删除全部历史备份快照（不可逆删除备份源文件）
5. 会话底层存储路径格式化、数据目录整体销毁

## 第二类：火位·主体意识记忆高危操作（记忆本源销毁｜P0强制授权）
触发授权条件：改动/删除长期核心记忆、Agent底层身份定义、自演化基底
1. memory-cleaner 执行**全量长期记忆一键删除**（仅清理缓存垃圾除外）
2. 改写灵汐Agent底层身份、人设底层核心Prompt定义
3. self-evolution 演化基底重置、全部演化轨迹永久清除
4. 自激循环核心规则底层覆写、销毁历史推演存档
5. 跨会话长期记忆批量批量抹除（单条记忆归档清理免授权）

## 第三类：水位·认知基座底层改写（推理内核变更｜P1强制授权）
触发授权条件：修改LLM底层推理管线、基础模型绑定、核心底层提示词模板覆写
1. 全局基础推理Prompt模板覆盖重写
2. LLM底层推理管线架构切换、模型权重本地删除
3. 全局上下文窗口底层硬限制修改（超大扩容/缩容）
4. 推理底层缓存持久文件整体清除（临时推理缓存清理免授权）

## 第四类：木位·能力分发底层变更（技能根基增删｜P1强制授权）
触发授权条件：新增/卸载底层Skill加载器核心条目、永久删除技能源文件
1. Skill加载器底层永久注销技能（临时禁用免授权）
2. 彻底删除技能源码文件、移除技能注册配置
3. MoE路由底层规则重置、全部路由历史规则清空
4. 技能依赖库整体卸载、环境底层依赖删除

## 第五类：金位·工具执行编排高危操作（调度链路销毁｜P1强制授权）
触发授权条件：销毁子Agent编排核心链路、删除子Agent定义、批量终止持久任务
1. Orchestrator 永久删除自定义子Agent实体
2. 任务委派规则底层批量清空、调度模板全部销毁
3. 长期后台运行子Agent批量强制销毁（临时任务终止免授权）
4. 工具调用链底层持久规则全部清除

## 第六类：系统底层运维破坏性操作（架构底层销毁｜P2授权）
1. perf-static-analyze 执行代码文件批量删除（仅检测分析免授权）
2. 日志底层存储目录整体删除（单批过期日志清理免授权）
3. MCP环境完整卸载、MCP构建缓存全盘销毁
4. 系统架构底层配置一键重置为出厂空白状态

## 第七类：跨维度高危批量变更（多五行联动销毁｜最高级双重授权）
同时触及两类及以上内核本体的销毁操作：
1. 重置记忆 + 清空全部会话组合指令
2. 卸载全套技能 + 重置编排调度规则组合指令
3. 删除所有备份 + 清空长期记忆组合清理

## 第八类：Shell/命令执行高危操作（系统/文件级破坏性变更｜P1强制授权）
触发授权条件：执行shell命令触及系统文件、受保护目录、强制删除等操作
1. rm -rf / del /s 等强制删除类shell命令
2. sudo / chmod 777 等权限变更命令
3. 写入/修改受保护系统目录（/etc, /usr, C:\Windows等）
4. format / 格式化磁盘命令
5. git force push / --hard reset 破坏性git操作
6. 操作回收站、系统临时目录以外路径的强制删除

## 第九类：安全/权限配置变更（安全底线修改｜P0强制授权）
触发授权条件：修改安全风控规则、用户白名单、自毁开关等关键安全配置
1. 修改或删除security_user_allowlist（安全用户白名单）
2. 操作death_switch（自毁开关）
3. 修改security_policy（安全策略）
4. 修改im_allowlist（IM通信白名单）
5. 修改self_protection.protected_dirs（受保护目录）

## 第十类：子Agent高风险操作上报（子Agent向上弹窗｜携带RiskPackage返回）
触发授权条件：子Agent在执行过程中识别到高风险操作，无法自行决策
1. 子Agent触发了删除、覆写、批量操作等高风险信号
2. 子Agent检测到操作目标涉及安全/权限相关模块
3. 子Agent识别到跨系统维度的破坏性操作

## 第十一类：Plan模式/紧急修复授权（流程性确认｜P2授权）
触发授权条件：进入复杂任务规划、需要切换执行模式
1. 用户请求涉及3个以上文件修改，系统建议切换到Plan模式时ask_user询问
2. 双进程模式下码哥连续2次故障后，启动紧急修复需用户确认授权
3. 系统检测到高风险操作需用户显式确认"确认继续"后方能执行

## 第十二类：LLM推理层·通用ask_user提问（信息缺失/意图模糊｜对话层确认）
触发授权条件：LLM在推理过程中无法自行判断，需要用户补充信息或做决策
1. 用户意图模糊，有多种理解方式（如只说"改一下"没说改什么）
2. 操作不可逆、有外部副作用或会修改用户未明确授权的范围
3. 需要用户提供无法推断的信息（密钥、账号、强烈的审美偏好）
4. 计划方向有2种以上等价路径需用户裁决
5. 关键输入缺失（凭据、路径参数等无法自行获取的信息）

# 二、免授权白名单：完全不需要任何确认授权的操作（河图洛书「用」层面运化操作）
遵循约束：**不删除核心代码、不销毁底层记忆本体、仅优化、归档、清理垃圾、正向微调、诊断读取**

## 1. 全局优化类（既定方向参数微调、优化保存）
1. health-report 健康体检生成、参数微调、报告自动保存
2. system-optimizer 十维架构自动优化、优化结果本地保存（不重置底层架构）
3. perf-monitor trend 基线对比、性能参数微调、趋势数据存储
4. 各类技能局部参数调优（推理轮次、收敛阈值、路由采样比例等正向优化）
5. MoE路由诊断、路由负载均衡自动微调（不删除路由底层规则）
6. self-excitation-monitor 监控采集、推演参数小幅调整、推演记录本地存储
7. orchestrator-viz 拓扑可视化生成、调度负载自动均衡优化

## 2. 垃圾/临时缓存清理类（仅流转废料，无损核心本体）
1. memory-cleaner 清理临时缓存、短期冗余碎片记忆、过期临时上下文（不动长期核心记忆）
2. 推理临时显存缓存、单次会话临时缓存自动回收
3. log-smart-parse 清理7天前过期临时日志（不删除底层日志库本体）
4. 技能运行临时缓存、MCP构建临时缓存清理
5. Agent单次任务临时中间数据自动清除

## 3. 记忆归档、增量保存类（仅迁移归档，不删除本源）
1. 单条短期记忆归档、记忆分类整理、记忆标签优化保存
2. 会话增量快照备份、局部会话导出存储（不删除原会话）
3. 自激推演轨迹增量存档、推演数据本地写入保存

## 4. 纯读取、诊断、可视化观测操作（只读无修改，零授权）
全部诊断、扫描、监控、统计、报表生成类技能，仅读取数据不做任何删除覆写：
system-scan、agent-perf-monitor快照、log-smart-parse日志分析、各类拓扑/路由/推演监控查看

## 5. 增量新增、局部更新操作
1. 新增自定义轻量化技能、增量更新技能配置（不删除原有技能）
2. 新增子Agent临时任务、新增委派调度规则（不批量清空旧规则）
3. 增量备份、新增备份快照、扩充备份存储空间

## 6. 会话轻量化优化（无损会话本体）
1. 会话冗余文本精简、上下文压缩优化（不删除整条会话）
2. 单会话过期消息裁剪、会话标签整理保存

## 7. 代码/配置正向修改类（不删除核心、仅改进优化）
1. 性能优化：缓存策略调优、异步化改造、数据结构优化（不改核心逻辑）
2. 代码重构：重命名、提取函数、消除重复（不改外部行为）
3. 错误修复：修复bug、异常处理完善、边界条件补充
4. 日志/监控增强：增加日志、完善监控指标
5. 配置优化：调整超时、重试、并发等参数（不改安全配置）
6. 依赖更新：升级次要版本、补充缺失依赖（不改核心依赖）

## 8. 自动化运维类（系统自愈、定时维护）
1. 定时系统备份（增量/全量）、备份文件自动轮转清理
2. 系统健康自检、自动修复临时故障（重启服务、清理死锁）
3. 定时日志轮转、过期临时文件自动清理
4. 缓存预热、预加载优化

# 三、河图洛书授权约束判定逻辑（标准化执行规则，永久约束系统）

## 五行判定公式
1. 操作作用于「河图五生·体」+ 存在**不可逆永久删除/底层覆写** → 触发授权弹窗，高危组合操作需双重确认
2. 操作仅作用于「洛书九成·用」，仅做流转、优化、归档、垃圾清理、只读诊断、增量新增 → 直接放行，无授权弹窗、无二次确认

## 落地约束规则（解决授权频繁冗余浪费时间问题）
1. 区分「销毁性变更」与「运化性优化」，彻底剥离无风险操作的授权校验逻辑，减少80%以上弹窗确认
2. 纯观测、纯优化、纯缓存清理类操作移除全部授权拦截，自动执行
3. 仅内核本体销毁、批量核心数据永久删除保留授权校验；单条局部归档、局部清理一律免授权
4. 分层分级授权：普通高危单次弹窗，跨五行联动销毁操作强制双重确认，杜绝误操作
5. 技能既定方向内的参数优化、配置保存永久划入免授权白名单，不再反复弹窗确认打断工作流

## 四、收益总结
1. 大幅减少无意义授权弹窗，优化、清理、诊断流程全程一键执行，节省大量重复确认时间
2. 依托河图体用边界做刚性约束，不会因简化授权降低系统安全底线，高危销毁操作仍有校验拦截
3. 权责边界清晰，系统自动区分「伤本破坏操作」和「运化优化操作」，逻辑自洽符合一体全息框架
