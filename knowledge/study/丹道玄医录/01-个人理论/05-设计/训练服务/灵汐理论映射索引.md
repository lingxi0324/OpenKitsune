## 二、灵汐特色层（Module 16）内部分篇映射

模块16为「灵汐特色」专用模块，整合游兄所有无法归入标准的原创内容：

```
16-灵汐特色/
├── module_16_灵汐特色/
│   ├── training_flow.md      ← 灵汐特色训练流程总纲
│   ├── scripts/
│   │   ├── hetu_trainer.py   ← 河图洛书方剂训练器（step_4）
│   │   ├── zhoutian_trainer.py ← 元会周天五脏辨证训练器（step_5）
│   │   └── liujing_trainer.py  ← 百病六经辨证实战训练器（step_6）
│   ├── quiz/
│   │   └── questions.json
│   └── data/
│       ├── 河图洛书/         ← 河图数理→药味→方剂对照表
│       ├── 元会周天/         ← 五脏辨证流派专题
│       ├── 六经方证/         ← 百病六经映射
│       ├── 奇门遁甲/         ← 时空医学择穴资料
│       └── 紫微命理/         ← 命理医道对应资料
```

## 三、灵汐理论融入各训练模块的具体方式

### 3.1 辨证训练（M4）+ 灵汐辨证三驾马车

```
传统辨证训练：
  八纲辨证 → 脏腑辨证 → 六经辨证 → 卫气营血 → 三焦

灵汐特色辨证三驾马车（强制训练项）：
  ┌────────────────────────────────────────────┐
  │ ① 元会周天金丹五脏辨证（L02）              │
  │    五运内伤 + 六气外感双轨制               │
  │    训练方式：五脏能量轴心→三阶辨证          │
  ├────────────────────────────────────────────┤
  │ ② 百病六经辨证（L04）                      │
  │    百病→六经定位→方证匹配                  │
  │    训练方式：病案→六经归属→出方            │
  ├────────────────────────────────────────────┤
  │ ③ 辩证用药要诀·河洛九转融通（L05）        │
  │    辨证到处方的转化桥梁                    │
  │    训练方式：天纲地纪→人元五运→古法今用    │
  └────────────────────────────────────────────┘
```

### 3.2 处方训练（M5）+ 河图洛书用药（L01）

```
传统处方训练：
  经方背诵 → 时方记忆 → 君臣佐使分析

灵汐特色处方训练（核心特色）：
  ┌────────────────────────────────────────────┐
  │ 河图洛书数理配伍（L01）                    │
  │                                            │
  │ 五行→主味→归经→河图数→洛书宫位            │
  │ 木=辛=肝胆=3/8=震宫                        │
  │ 火=咸=心小肠=2/7=离宫                      │
  │ 土=甘=脾胃=5/10=中宫                       │
  │ 金=酸=肺大肠=4/9=兑宫                      │
  │ 水=苦=肾膀胱=1/6=坎宫                      │
  │                                            │
  │ 训练方式：                                 │
  │ ① 随机给河图数→推药味→配五脏→出方       │
  │ ② 给症状→河图数理定位→洛书宫位择药      │
  │ ③ 相克化合推演训练                        │
  └────────────────────────────────────────────┘
```

### 3.3 诊断训练（M3）+ 灵汐脉法三件套（L06~L08）

```
传统诊断训练：
  脉诊 → 望诊 → 闻诊 → 问诊 → 四诊合参

灵汐特色脉诊训练三件套：
  ① 二十四脉象（L06）— 24种脉象形态鉴别
  ② 十大脉法（L07）— 十种临床常用脉法
  ③ 寸关尺经方脉法（L08）— 三部九候→经方对应
```

### 3.4 慢病专科（M10）+ 灵汐专科（L10~L14）

```
专科模块内嵌灵汐理论：
  妇科 → 灵汐/妇科辨证论治（L10）
  肿瘤 → 灵汐/五脏六腑癌症辨证处方用药（L14）
  情志 → 灵汐/情志病辨证治疗（L11）
  肿瘤2 → 灵汐/王三虎抗癌经验（L18）
```

### 3.5 经络针灸（M7）+ 奇门遁甲（L12）

```
传统经络训练：
  经络循行 → 穴位定位 → 主治功效

灵汐时空医学特色：
  奇门遁甲矩阵（L12）— 时空择穴·子午流注·灵龟八法
  训练方式：时辰→奇门遁甲排盘→择穴→针灸方案
```

## 五、训练时要用的跨模块串联路径

训练时，以下**灵汐路径**被重点设计：

```
路径A（辨证核心线）：
河图洛书数理 → 元会周天辨证 → 百病六经归属 → 辩证用药要诀 → 处方

路径B（脉诊→辨证线）：
二十四脉象/寸关尺脉法 → 六经经方脉证对应 → 百病定位 → 出方

路径C（时空医学线）：
奇门遁甲排盘 → 子午流注择穴 → 针灸方案

路径D（专科专病线）：
妇科辨证 → 情志病辨证 → 癌症辨证 → 灵汐特色用药
```
