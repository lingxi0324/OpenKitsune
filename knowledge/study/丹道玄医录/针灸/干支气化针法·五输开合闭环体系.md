# 干支气化针法 · 五输开合闭环体系

> **核心定旨**：天地干支，一合一开、一阴一阳，万物气机不外和合收敛、激荡散破。
> **古法针灸失传高阶理法**：虚则合而养之、和之；实则劫而散之、破之。
> **核心总纲（终身铁律）**：`虚用合、实用劫；合为体、劫为用；劫必归合、散必复收。`

⚠️ **重要提示**：本体系属于古象理推演重构的气化针法，所有配伍均限定五输穴，仅作理法研究、个案观察。癥积重症不可替代现代规范医疗，劫法必须严格把握正气尺度。针刺操作必须由持证执业中医师完成。

## 第二章 阴阳双机法理闭环

### 2.1 两大核心治法（一体阴阳、互为成败）

#### 甲、合机（常法 · 属阴 · 主收）

- **适用病机**：一切虚证、气机不和、多脏腑失调、久病虚郁、劫法术后修复
- **核心作用**：经气相合、五行化合、交通脏腑、收敛散气、固本培元、调和失衡
- **法理定位**：体系之底盘、归宿、根本，无合则劫无所依

包含两类配伍：

1. **天干五合（五门十变）**：甲己、乙庚、丙辛、丁壬、戊癸 — 脏腑夫妻经化合，调内伤久病、脏腑相克失衡
2. **地支六合**：子丑、寅亥、卯戌、辰酉、巳申、午未 — 经脉气相亲近，调周身气机不和、表里不通

**操作手法**：补法/平补平泻，温和化合，久留调气

#### 乙、劫机（劫法 · 属阳 · 主散）

- **适用病机**：一切实证、固结死瘀、痰瘀毒结块、癥积结节、气机死寂、常规合机久治无效
- **核心作用**：经气相激、对冲撕扯、松动固结、打散死结、扰动伏邪、开通闭阻
- **法理定位**：体系之妙用、攻坚、开路，无劫则沉痼不开

包含两类配伍：

1. **天干对冲五组**：辛乙、庚甲、壬丙、癸丁、戊甲 — 五行相战、经气激荡，破顽固郁滞痰核
2. **地支阶梯劫法**：六破 → 六害 → 三刑 → 六冲，由浅入深、阶梯攻坚

**操作手法**：纯泻法、短留针、中浅刺、井穴点刺，严禁久留补法

### 2.2 终极阴阳闭环公式

| 病机类型 | 治法 |
|----------|------|
| 虚证、不和、涣散 | 单用合机，久调固本 |
| 本虚标实、固结顽邪 | 阶梯劫法攻坚 → 必转合机收摄固元 |
| 纯实固结、正气充足 | 短时劫法破结，中病即止，即刻归合 |
| 纯虚衰败 | 终身禁用劫法，只用合机 |

## 第三章 劫法四级阶梯体系

**力量梯度排序**：六破（松动开路）＜ 六害（深挖伏邪）＜ 三刑（纠缠撕扯）＜ 六冲（终极对冲）

**核心规则**：严禁越级强攻、严禁多组叠加、严禁连续猛攻

### 3.1 六破（开路试探 · 最轻劫法）

- **作用**：松动完全死寂的气机死结，不开破、不撕扯，仅开缝隙，试探正邪反应
- **适用**：结块坚硬、气机凝滞、正气偏弱，无法承受刑冲强攻
- **间隔**：7 天/次，最多 2 次试探，耐受再进阶
- 📄 详见：[[针灸/劫法阶梯/六破]]

### 3.2 六害（暗穿深挖 · 中等劫法）

- **作用**：穿透表层、深挖深层潜伏痰瘀毒邪，针对外轻内重的隐性固结
- **适用**：六破后邪有微动、深层结节、伏邪久藏、常规疏通无效
- **间隔**：7–10 天/次
- 📄 详见：[[针灸/劫法阶梯/六害]]

### 3.3 三刑（纠缠撕扯 · 强劫法）

- **作用**：拆解多经盘根错节、多层胶结的顽痰死瘀，单向疏通无法解开的复杂癥积
- **铁律**：禁止三针同刺，仅取两经配对撕扯，避免气机大乱
- **适用**：多经交织、痰瘀毒纠缠、顽固复合结节
- **间隔**：10–14 天/次
- 📄 详见：[[针灸/劫法阶梯/三刑]]

### 3.4 六冲（终极对冲 · 顶级劫法）

- **作用**：两经正气正面对冲，一击打散多年固结死瘀、沉寒痼结、顽固癥积
- **适用**：正气充足、前三阶铺垫完毕、结块松动、死结将开
- **铁律**：全程总攻不超 3–5 次，中病即止，永久停用劫法
- 📄 详见：[[针灸/劫法阶梯/六冲]]

## 第四章 核心闭环铁律：劫必归合

> **千古失传针灸法理**：攻而不收，则正气外泄、邪气流窜；散而不复，则气机无根、久病反复。
> **本体系独创刚性规则**：任何一级劫法施术完毕，必须配套对应合机五输方收摄固本，无一次例外。

### 4.1 收摄取穴标准（唯一标准）

1. **优先**：本次劫法两经对应的地支六合五输合穴（同气同源、收敛最快）
2. **备选**：本次劫法两经对应的天干五合（五门十变）五输合穴（调脏腑化合）
3. **收摄手法**：补法/平补平泻，禁用泻法，专司敛气、固气、复气
4. 📄 完整对照表：[[针灸/收摄方/劫法配对收摄对照表]]

### 4.2 收摄时机二选一

| 方案 | 适用场景 | 操作 |
|------|----------|------|
| **方案 1（重症固结）** | 重症、正气可支 | 同次施针：劫法泻法先行 → 收摄补法收尾，一次完成开合闭环 |
| **方案 2（正气偏弱）** | 虚证明显 | 本次仅劫法攻坚 → 7–14 天复诊，首诊单用合机收摄固本，养护正气 |

## 第五章 临床准入、禁忌标准

### 5.1 合机：无条件适用

一切虚损、气机不和、久病失调、术后修复、亚健康、劫法术后养护、纯虚体质。

### 5.2 劫法：准入标准（全部满足方可启用）

1. 有形固结癥积、结节、肿块、久瘀，合机常法久治无效，气机静态死寂
2. 脉有根、尺脉不绝，体力尚可、纳食正常
3. 无活动性出血、无凝血障碍
4. 非恶病质、无大肉脱、无重度衰竭
5. 本虚标实，正气尚有根基，可耐受激荡

### 5.3 预警降阶/停攻标准（出现任意一项立刻停劫转合）

脉象浮散无根、体力骤降、纳差乏力、心慌盗汗、神魂不宁、病灶剧痛、异常出血。

### 5.4 绝对禁忌（终身禁用劫法）

晚期恶病质、危重衰竭、活动性出血、孕妇、纯虚无实、急性高热气分证、神魂涣散。

## 第六章 完整临床配伍流程

```
第一步：辨证定性（先分虚实，定开合）
  虚、郁、不和、亏损 → 判定：合机常法
  实、结、瘀、癥、死寂不动 → 判定：劫法阶梯攻坚

第二步：定级选阶（实证专属）
  正气弱、结块僵死 → 从【六破】起步试探
  深层伏邪、久瘀深藏 → 进阶【六害】
  多经纠缠、多层胶结 → 进阶【三刑】
  正气充足、结块松动 → 终极【六冲】

第三步：施术攻坚
  单次仅取一组劫法五输穴对，纯泻短留，不叠加、不滥攻

第四步：必转收摄（闭环核心）
  匹配对应六合/五合五输收摄方，补法敛气，修复气机、防止邪窜、固护元气

第五步：随访迭代
  7–14 天随访，根据正气、脉象、结块变化，决定维持、进阶、停攻、纯合养护
```

## 第八章 本体系独有创新

1. **补全失传古理**：恢复「合主补虚和、劫主破实结」的干支阴阳双向针法，填补国内失传、仅海外舍岩留存片面五行的空白
2. **独创四级阶梯攻坚**：古今所有干支针法、舍岩针法均无分层递进，本体系实现从试探到终极破结的标准化阶梯，安全可控
3. **独创攻后收摄闭环**：所有劫法激荡必配合机收摄，解决劫法耗气、邪窜的千古弊端，真正做到攻不伤正、散不脱元
4. **纯五输标准化**：全程无杂穴、无经验取穴，完全依托干支气化模型，有理可依、有法可循、可学可传
