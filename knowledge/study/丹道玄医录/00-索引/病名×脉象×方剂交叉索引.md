> 按二十四脉象分组，每组列出此脉象常见于哪些病证、对应何方

| 脉象 | 常见病证 | 对应方剂 |

| **浮脉** | 表证（风寒/风热）、虚阳外越 | [[../../01-中医基础/06-四诊心法/二十四脉象\|详见脉象]] → 麻黄汤、桂枝汤、银翘散 |
| **沉脉** | 里证（寒实/虚寒）、阴盛格阳 | → 四逆汤、大黄附子汤 |

| **迟脉** | 寒凝痛证、阳虚 | → 四逆汤、温经汤、麻黄附子细辛汤 |
| **滑脉** | 痰饮、食积、妊娠 | → 温胆汤、保和丸、橘皮竹茹汤 |
| **涩脉** | 血虚、瘀血、精亏 | → 血府逐瘀汤、生化汤、桃红四物汤 |
| **长脉** | 肝阳上亢、气逆 | → 镇肝熄风汤、天麻钩藤饮 |
| **短脉** | 肺气虚、气陷 | → 补中益气汤、补肺汤 |
| **缓脉** | 湿困脾、胃气衰 | → 参苓白术散、平胃散 |
| **紧脉** | 寒实证、痛证 | → 麻黄汤、大黄附子汤、天台乌药散 |
| **石脉** | 肾阳虚衰、阴盛格阳 | → 四逆汤、真武汤、右归丸 |
| **芤脉** | 大失血、津脱 | → 独参汤、黄土汤、生脉散 |
| **大脉** | 阳明热盛、虚阳外浮 | → 白虎汤、黄连阿胶汤 |
| **小脉** | 阳虚、气血两亏 | → 右归丸、补中益气汤 |
| **弦脉** | 肝郁、痛证、痰饮 | → 逍遥散、柴胡疏肝散、小柴胡汤 |
| **牢脉** | 癥瘕积聚、寒疝 | → 大黄䗪虫丸、暖肝煎 |
| **濡脉** | 表虚自汗、湿困 | → 玉屏风散、防己黄芪汤 |
| **弱脉** | 气血两虚 | → 八珍汤、归脾汤 |
| **散脉** | 元气大脱、亡阳 | → 参附汤、独参汤 |
| **伏脉** | 邪气深伏、闭厥 | → 紫雪丹、四逆汤 |
| **动脉** | 惊风、痰热扰心 | → 羚角钩藤汤、生铁落饮、安宫牛黄丸 |
| **代脉** | 脏气虚衰 | → 复脉汤、参附汤、炙甘草汤 |
| **促脉** | 实热瘀滞、痰热扰心 | → 千金苇茎汤、清营汤 |
| **结脉** | 阴寒凝滞、胸痹 | → 阳和汤、瓜蒌薤白白酒汤、当归四逆汤 |
