# 棘轮进化日志 · Ratchet Evolution Log

## 迭代 R5 · 胜复校正+资本行为集成

**日期**: 2026-06-19
**目标**: 将方向精度从 36.8% 提升到 77.8%

### 关键突破

| 版本 | 引擎 | 方向精度 | 提升 |
|------|------|---------|------|
| v4.2 (旧) | 简单生克 | 36.8% | - |
| R5 基线 | 胜复校正 (corrected_scoring) | 71.4% | +34.6% |
| R5 最优 | 胜复校正+资本行为 (深度比例型) | **77.8%** | **+41.0%** |

### 架构

```
胜复校正评分引擎 (corrected_scoring.py)
├── 岁运太过/不及判定 → 复气/郁发影响
├── 司天在泉加入
├── 郁气积累 → 爆发窗口
└── → 71.4%基线方向精度

资本行为集成 (深度比例型, ratchet_v5.py)
├── 历史序列追踪 (回看12个月)
├── 深度比例抄底 (force = abs(raw) × depth_factor)
├── 深度比例收割 (cut = abs(raw) × depth_factor)
└── → 77.8% (14/18)
```

### 最优参数 (棘轮锁定)

| 参数 | 值 | 说明 |
|------|----|------|
| depth_factor | 0.7 | 修正力度 = 评分深度的70% |
| max_boost | 0.2 | 最大修正幅度0.2 |
| min_streak | 2 | 至少2月连续同向才触发 |
| up_th | 0.05 | 评分>0.05判涨, <-0.05判跌 |
| streak_boost | 0 | 不按连续月数递增 |

### 剩余4个错误分析

| 错误 | 原因 | 能否修复 |
|------|------|---------|
| 1月木 +0.150 act=-12% | 冬季木天然弱，模型给分过高 | 需修订胜复校正的冬季规则 |
| 1月土 +0.610 act=-8% | 雪球敲入事件(市场结构,不可预测) | 不能，超出五运六气范围 |
| 2月火 -0.250 act=+15% | ms=2:历史仅1个月,资本不触发 | 结构性问题(首月无历史) |
| 3月火 -0.075 act=+8% | boost=0.175 < 翻正所需0.300 | 若加大力度会破坏5-8月正确判跌 |
