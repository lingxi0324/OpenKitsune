# 五运六气市场推演（五毂历）

## 核心理念

以五运六气为天地节律之骨，以五行生克为万物循环之血，以资本行为为市场动能之筋，构建从年度基调到时辰精度的七层全链路市场推演体系。

**根本公设：** 市场不是随机波动的，而是在天地气运的节律框架内、资本行为驱动下的五行生克博弈。五运六气提供势能（天地之气偏向），资本提供动能（人如何利用势能获利）。

**一体全息公理：** 天人合一不是比喻——人和天共用同一套底层五行生克规则。诊断一个市场的气机，和诊断一个人的病机，用的是同一套方法论在不同尺度上的投影。

## 第四章：第3层·特殊格局（修正系数）

### 4.1 岁会

年干与年支五行相同。能量共振放大，该年份对应板块全年偏强。

### 4.2 天符

岁运与司天之气五行相同。全年受单一力量主导，波动剧烈但方向明确，涨跌幅极端化。

### 4.3 同天符

太过之年 + 岁运与在泉之气五行相同。下半年能量极度放大。

### 4.4 不和

司天克岁运。气运割裂，板块分化严重，多空分歧加大。

## 第五章：第4层·日层（三层干支叠加）

### 5.1 基础框架

将年干支、月干支、日干支三层叠加，逐层判断生克：

```
年干对日干 → 年生/年克/年比
月干对日干 → 月生/月克/月比
日干对日支 → 日坐吉/坐杀/坐败
```

### 5.2 六档分级

| 层级 | 评分区间 | 判读 |
|:---:|:---:|:---|
| 强开穴 | 80-100 | 三重生助，最佳窗口 |
| 偏开穴 | 60-79 | 两重生助，偏顺 |
| 震荡偏强 | 40-59 | 有生有克，偏震荡向上 |
| 震荡偏弱 | 20-39 | 有源有压，偏震荡向下 |
| 偏闭穴 | 10-19 | 两重压制，宜守 |
| 强闭穴 | 0-9 | 三重压制，绝对警戒 |

### 5.3 增强因子

- **纳音五行**：年份、月份、日份纳音自成一套五行能量场，与正五行形成对冲/加持
- **十二长生**：天干在地支的十二长生状态（临官/帝旺/墓/绝），修正力量系数
- **辰戌丑未藏干**：四库藏本气60%+余气25%+墓气15%，解释同一日干支不同年份的力度差异

## 第六章：第5层·时层（时辰干支叠加）← 新增 v3.6.0

### 6.1 核心原理

将子午流注的"按时开穴"逻辑平移至金融市场。中医子午流注认为，特定时辰某条经络气血最旺——对应到市场，**特定时辰某类五行属性的板块气机最通顺**。

### 6.2 五鼠遁法（时干计算）

```
时支根据实际时辰确定：
  子时 23:00-00:59  丑时 01:00-02:59  寅时 03:00-04:59
  卯时 05:00-06:59  辰时 07:00-08:59  巳时 09:00-10:59
  午时 11:00-12:59  未时 13:00-14:59  申时 15:00-16:59
  酉时 17:00-18:59  戌时 19:00-20:59  亥时 21:00-22:59

时干根据日干用五鼠遁法推算：
  甲己日 → 甲子时起  乙庚日 → 丙子时起
  丙辛日 → 戊子时起  丁壬日 → 庚子时起
  戊癸日 → 壬子时起
```

### 6.3 四柱综合评分

```
四柱评分 = w_year × 年柱分 + w_month × 月柱分 + w_day × 日柱分 + w_hour × 时柱分

推荐权重（基于2024年回测校准）：
  w_year  = 0.35（年度基调，最可靠）
  w_month = 0.25（气运节奏）
  w_day   = 0.25（当日气机）
  w_hour  = 0.15（时辰细节，精度最低但补充微观信息）
```

### 6.4 三层生克 × 时辰补充

```
年干对时干 → 年生时/年克时/年比时
月干对时干 → 月生时/月克时/月比时
日干对时支 → 时支对日干的十二长生状态（最直接的影响）
日干对时干 → 日时同柱生克
```

### 6.5 时辰八档分级

| 层级 | 评分区间 | 判读 |
|:---:|:---:|:---|
| 强开时 | 85-100 | 四柱全顺，最佳切入窗口 |
| 偏开时 | 65-84 | 三柱顺，一柱平，正向窗口 |
| 微开时 | 50-64 | 两柱顺，有支撑 |
| 震荡偏上 | 35-49 | 有生有克，趋势向上不强烈 |
| 震荡偏下 | 15-34 | 有压有源，向下偏弱 |
| 微闭时 | 5-14 | 两柱压制，不宜动作 |
| 偏闭时 | -15~4 | 三柱压制，减仓防险 |

## 第七章：第6层·动态循环（胜复郁发）

### 7.1 四大气运动态

| 动态 | 定义 | 市场表现 |
|:---|---|:---|
| **胜气** | 太过则恃强凌弱 | 强势板块过度扩张 |
| **复气** | 被克之子来救母 | 被压制板块获支撑反转 |
| **郁气** | 不及则被克太甚 | 弱势板块持续被压制，积累反弹势能 |
| **郁发** | 郁极必发，暴力反转 | 极端行情爆发（如924行情） |

### 7.2 积累周期

郁气积累速度与气段长度正相关。被天刑/不和持续压制时，积累速度×1.5~2.0。

### 7.3 前置铺垫规律

郁发前7-14天会出现前置铺垫信号（小型震荡/试探性反弹），这是资本行为对郁气释放的预演。

### 7.4 释放期

郁发爆发后，有15-30天释放期，力度逐渐衰减。

## 第八章：第7层·资本行为（动能修正 · 棘轮进化版）

### 8.1 核心公设

资本是五行气运在金融市场的**具身执行者**。五运六气提供势能，资本提供动能。

### 8.2 资本三阶段 × 五行映射

| 阶段 | 五行 | 行为 | 市场信号 |
|:---|:---:|:---|---|
| **抄底潜伏** | 水 | 在郁气积累最甚的板块底部建仓 | 连跌数月的停滞性横盘 |
| **推升扩散** | 火 | 推动反弹，吸引跟风盘 | 放量上涨，情绪升温 |
| **收割离场** | 金 | 在郁发高潮时逐步减仓 | 高位震荡，量价背离 |

### 8.3 资本来源假设

资本永远在寻找被低估（郁气最甚）和高估（郁发最盛）的标的。资本的行为方向与五运六气的势能方向**整体一致**，但在精确的时机把握上有独立节奏。

### 8.4 资本行为判定阈值（棘轮进化校准）

| 信号 | 条件 | 判定 | 校准来源 |
|:---|---|:---|---|
| 抄底 | 板块连跌≥5个月 + 郁气积累≥0.7 | 积极抄底 | 2024年1-8月火板块积累期 |
| 推升 | 板块连涨≥2个月 + 胜复校正评分>0 | 推升中 | 2024年2月V反 |
| 收割 | 板块连涨≥5个月 + 郁发释放≥0.6 | 准备收割 | 2024年10月高位震荡 |
| **深度抄底** | 连跌7个月+评分<−0.6 | **强力抄底（×1.5）** | 棘轮R5新增 |
| **深度收割** | 连涨7个月+评分>0.6 | **强力收割（×0.5）** | 棘轮R5新增 |

**棘轮校准的关键修正：** 资本行为的介入/退出不是二值开关，而是**深度比例函数**——积累越深、力度越强，而不是简单的"触发→实施"。

### 8.5 资本行为集成（CapitalIntegration）

```
最终评分 = 胜复校正评分 × (1 − capital_weight)
         + 胜复校正评分 × capital_weight × 阶段调制系数

阶段调制系数：
  抄底: ×1.3   推升: ×1.2   收割: ×0.6   离场: ×0.8   观望: ×1.0

最优参数（棘轮锁定）:
  capital_weight = 0.20   (权重)
  active_level   = 1.0    (活跃度)
```

## 第十二章：四柱联合判读（八层流程）

## 八层联合判读流程

```
Step 1: 运层 → 年度基调（五运太过不及 → 板块偏强/偏弱列表）
Step 2: 气层 → 季度节奏（司天在泉 + 主客气加临 → 每气段格局）
Step 3: 特殊格局 → 修正系数（岁会/天符 → 能量共振核验）
Step 4: 日层 → 逐日干支评分（三层 + 纳音 + 长生 + 藏干 → 6档分级）
Step 5: 时层 → 时辰干支评分（五鼠遁 + 时干生克 + 四柱加权 → 8档分级）
Step 6: 动态循环 → 胜复郁发修正（积累系数 → 爆发窗口 → 前置铺垫）
Step 7: 资本行为 → 动能修正（抄底/推升/收割信号 → 加减速）
Step 8: 个股五行图谱 → 偏差四规则（偏高/太高/偏弱/太弱 → 生克判读）
```

### 四柱加权评分公式

```
最终评分 = 0.35 × 年柱评分
         + 0.25 × 月柱评分
         + 0.25 × 日柱评分
         + 0.15 × 时柱评分
```

**方向判定规则（棘轮二分法）：**
```
评分 > 0.0 → 看涨  评分 ≤ 0.0 → 看跌
无"震荡"档——强迫框架做出确定性判断
```

## 第八章：第4层·九宫奇门（微观时空精确定位）← 新增 v3.7.0

### 8.1 核心原理

九宫飞星是天地气运在微观时空中的精确坐标定位。
五运六气提供年度大势（宏观），九宫飞星提供月份/日期的能量聚焦点（微观精调）。

**核心公设：** 飞星九宫是每一个时空坐标的"精确坐标格"。年飞星设全年基调，月飞星调月节奏，
日飞星判日级强弱。三者叠加形成完整的微观时空定位。

### 8.2 九星五行映射

| 星数 | 名称 | 五行 | 吉凶 | 能量系数 | 对五行板块的核心影响 |
|:---:|:---:|::---:|:---:|:---:|:---|
| 1 | 一白贪狼 | 水 | 吉(财) | +0.8 | 水板块受益最甚 |
| 2 | 二黑巨门 | 土 | 凶(病符) | -0.6 | 土板块受压，但火板块借凶转吉→反获小利 |
| 3 | 三碧禄存 | 木 | 凶(蚩尤) | -0.3 | 木板块竞争加剧，动荡但非全凶 |
| 4 | 四绿文曲 | 木 | 吉(文昌) | +0.5 | 木板块温和平和，偏多 |
| 5 | 五黄廉贞 | 土 | 大凶(正关) | -1.0 | 所有板块普受影响，土板块最甚→绝对警戒 |
| 6 | 六白武曲 | 金 | 吉(武曲) | +0.7 | 金板块强势偏多，水板块次之 |
| 7 | 七赤破军 | 金 | 凶(破军) | -0.4 | 金板块竞争激烈，火板块受克严重 |
| 8 | 八白左辅 | 土 | 大吉(当旺) | +1.0 | 所有板块普涨，土板块最甚→最吉入中 |
| 9 | 九紫右弼 | 火 | 吉(喜庆) | +0.9 | 火板块高潮偏多，科技板块受益 |

### 8.3 年飞星计算

```
公式：入中星 = (2022 - year) % 9，0→9
示例：
  2024年 → (2022-2024)%9 = 7 → 七赤破军(金)入中
  2025年 → (2022-2025)%9 = 6 → 六白武曲(金)入中
  2026年 → (2022-2026)%9 = 5 → 五黄廉贞(土)入中
```

年入中星决定全年的飞星基调。以2024七赤破军(金)为例：
- 入中为金→全年竞争激烈基调吻合
- 七赤为破军，偏凶→市场波动加剧
- 金克木→木板块（新能源）全年受压（吻合宁德时代走势）
- 火克金→火板块（科技）虽受压制但有反制之力

### 8.4 月飞星计算

```
月序 = (月份 - 2) % 12 + 1  （寅月=1, 卯月=2, ...）
月飞星 = (年入中星 - 月序) % 9，0→9
```

### 8.5 年+月叠加评分矩阵

```
年飞星权重：0.3（年度基调）
月飞星权重：0.7（当月决定性影响）

各星对五行板块的满影响系数矩阵（STAR_TO_PLATE_IMPACT）：
  一白(水) → 水:+0.5, 火:-0.3, 木:+0.2, 金:+0.1, 土:-0.1
  二黑(土) → 水:-0.4, 土:-0.5, 火:+0.1, 金:+0.1, 木:+0.2
  三碧(木) → 木:+0.3, 土:-0.4, 金:-0.2, 水:+0.1, 火:+0.1
  四绿(木) → 木:+0.4, 火:+0.2, 土:+0.1, 金:-0.1, 水:+0.05
  五黄(土) → 土:-0.8, 水:-0.5, 火:-0.3, 木:-0.2, 金:-0.1
  六白(金) → 金:+0.5, 水:+0.3, 土:+0.2, 木:-0.2, 火:-0.3
  七赤(金) → 金:+0.3, 火:-0.4, 木:-0.2, 水:+0.2, 土:+0.1
  八白(土) → 土:+0.7, 火:+0.4, 金:+0.3, 木:+0.1, 水:-0.1
  九紫(火) → 火:+0.6, 木:+0.3, 土:+0.2, 金:-0.2, 水:-0.4
```

### 8.6 九宫飞星×五运六气·协同判读

九宫奇门不是独立于五运六气的系统，而是同一套天地气运的**不同分辨率投影**：

| 场景 | 五运六气判读 | 九宫飞星判读 | 综合结论 |
|:---|:---|:---|:---|
| 2024年三气(太阴湿土/天刑) | 天刑→剧烈波动，土当令 | 月飞星二黑(土)→土板块受压 | 土板块受主客气天刑+飞星病符双重压制 |
| 2024年四气→五气(郁发反弹) | 郁发释放→反弹窗口 | 月飞星八白(土)→当旺，火板块受益+0.4 | 在郁发基础上叠加八白吉星，放大反弹力度 |
| 2024年9月(924反弹) | 郁发释放第3月，蓄势已足 | 八白左辅(土)入中→全年最吉月 | 气运释放+当旺吉星→历史级反弹窗口 |

### 8.7 四层叠加评分公式（v3.7.0）

```
最终评分 = 胜复校正评分 × (1 - 资本权重 - 奇门权重)
          + 资本行为信号 × 资本权重
          + 九宫奇门信号 × 奇门权重

推荐权重（基于棘轮进化 v6.0 校准）：
  胜复校正：0.65（基底）
  资本行为：0.20（独立信号源）
  九宫奇门：0.15（微观精调）
```

## 第九章：四层框架总览（游兄框架）

### 9.1 四层定义

游兄定义的"四层框架"是从**市场推演维度**出发的横切组织方式：

| 层序 | 名称 | 精度单元 | 对应七层中的纵向模块 | 准确率基线 |
|:---:|:---|:---:|:---|:---:|
| **第1层** | 五运六气 | 年/气段/73日 | 运·气·格 | ~93% |
| **第2层** | 五行图谱 | 月/节气/15日 | 日·时（四柱部分） | ~90% |
| **第3层** | 三层干支 | 日/时辰 | 日·时（时辰分类部分） | ~77% |
| **第4层** | **九宫奇门** | 时/日/月 | 奇门飞星 | 新增·待校准 |

### 9.2 四层框架的正确用法

```
第1层(五运六气) → 定全年基调，锁定哪几个板块全年偏强/偏弱
第2层(五行图谱) → 定月度节奏，判断板块轮动时间点
第3层(三层干支) → 定日级风控，判断开穴/闭穴窗口
第4层(九宫奇门) → 微观精调，在关键转换月份提供额外判断依据
```

### 9.3 四层回测须知

2024年回测关键发现（基于四层框架 v3.7.0 逐板块逐月验证）：
- **板块级严格方向精度：72.7%** — 胜复校正引擎提供稳定基线
- **个股级综合精度：50.4%** — 五行权重映射法在2024年火板块表现好(73%)，木板块差(20%)
- **资本行为层成效有限** — 当前集成方式（乘性调制 vs 独立信号源）导致方向切换力不足
- **九宫奇门层：方向确认价值 > 方向翻转力** — 在关键转换月提供额外+0.1~+0.4的调整，适合辅助判断而非主导

**四层框架最适合：给出方向性判断的概率分布，而非单一涨跌判定。**
建议使用者：先看第1/2层确定大方向，再用第3/4层做风控精调。
