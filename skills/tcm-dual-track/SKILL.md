# 中医双轨辨证与一站式处方引擎

一条命令走完：**输入归一化 → 体用检测 → 六经加权评分 → 三观四证 → 双规次序 → 处方 → 五运六气 → 火候 → 北斗七星针法**。

> 双轨公式：以六经调阴阳，以五脏补气血；先通后补，双规并重。

## 何时使用

- 用户给出主诉/舌/脉，要求「辨证、开方、出针法、看医案」
- 症状复杂、虚实难辨，需要先定表里寒热虚实津血气机
- 需要判断「见虚能不能直接补」，或要一份可交付的处方与针法
- 需要脉舌验证、药证映射与配伍禁忌校验

单纯穴位查询、中药知识问答、理论概念解释，不必跑完整流程。

## 直接调用

```text
run_skill_script(

  args=["大便粘滞 腹胀", "--pulse", "沉紧", "--tongue", "淡胖", "--coat", "白腻", "--year", "2026"]
)
```

## 用法

```bash
# 一站式病案推演（推荐）
python scripts/tcm_case.py "大便粘滞 腹胀" --pulse 沉紧 --tongue 淡胖 --coat 白腻

# JSON 输出（结构化交付/二次加工）
python scripts/tcm_case.py "口苦 咽干 目眩" --pulse 弦 --json

# 只看三观四证与双规（轻量，无处方）
python scripts/tcm_dual_track.py "口苦 胸胁满 纳差 乏力" --pulse 脉弦
```

口语词条会自动归一：`不士气/纳差/食欲不振 → 纳呆`、`流鼻涕 → 流涕 鼻塞`、`睡不好 → 失眠`、`沉细 → 脉沉细`。

## 输出契约

| 字段 | 内容 |
|:----|:-----|
| `输入归一化` | 主诉原文、归一化症状、脉象补全、舌象舌苔 |
| `体用检测` | 体用三型（一致/偏颇/相悖）、体分用分、相悖模式、代表方、治法原则 |
| `六经辨证` | 各经加权评分、主经与置信度、亚型、合病、推荐方、六经传变、证据链 |
| `三观四证` | 津液观/表里观/正邪观 + 病机约分五步 + 水火气血四证亚型 |
| `双规次序` | 六经开路 → 五脏填补 → 水火收功（六经以加权结果为准） |
| `处方` | **主方 + 组成剂量 + 君臣佐使 + 加味 + 减味 + 药证映射 + 配伍校验 + 用法** |
| `五运六气` | 岁运、司天、在泉、主气客气（传 `--year` 时） |
| `火候次第` | 火候策略、疗程、火候序列 |
| `北斗七星针法` | 七星主穴、针序、配穴加减、艾灸、疗程、七言要诀 |
| `综合结论` | 总纲、核心病机、治法方向、处方方向 |
| `禁忌` | 误补、过汗、开路过久、配伍冲突、急危重症提示 |

## 处方层规则

1. **主方**取自六经加权评分后的推荐方首方；方剂库共 285 首 = 51 首精析方（含君臣佐使与体用）+ 234 首经方备选（《经方常用处方》方证对应表）。
2. **备选方**只补方名、组成、症候与推断六经，不参与六经主方排序；未标注君臣佐使时药证映射显示「—」。
3. **别名可查**：`肾气丸→八味丸`、`理中丸→理中汤`、`肾着汤→甘草干姜茯苓白术汤` 等自动归一。
4. **自动加味**：按兼症追加药味（如咳嗽→杏仁、纳呆→神曲麦芽、腹胀→厚朴、失眠→酸枣仁），已含药味不重复添加。
5. **自动减味**：出血减辛温动血、妊娠减破血峻下、阴虚减大热、便溏减峻下，逐条写明依据；减掉君药时提示方义不成立。
6. **药证映射**：每味药标注君臣佐使、功效、归经、针对的症状或主方主治，来源标明「主方/加味」。
7. **配伍校验**：内置十八反/十九畏药对检查，冲突时 `通过=false` 并在禁忌中告警。
8. 剂量为参考量（备选方按原表转录，枚/片/杯等非克单位保留原文），**必须由执业中医师按个体核定**。

## 针法层

- 天枢膻中 / 天璇神门 / 天玑期门 / 天权关元 / 玉衡（太白或太溪）/ 开阳（足三里或太冲）/ 摇光三阴交
- 针序：开气门 → 泻实 → 安神 → 补虚 → 灸法
- 配穴按症状加减，附艾灸壮数、三阶段疗程与七言要诀
- 更细的命宫/九宫飞星/四时变阵，转 `zhenfa-jiugong`

## 边界

- 本引擎是传统辨证知识的结构化辅助，不替代执业中医师的四诊合参与处方权。
- 方药剂量、煎服法与加减必须由医师根据个体情况决定；孕妇、儿童、肝肾功能不全者需单独评估。
- 急危重症、出血、意识障碍、持续高热等应优先现代医学处置。
