## 三、立体度·空间剖面六层法（L1-L6）

### 3.1 六层剖面定义

| 层级 | 名称 | 对应盘面 | 解读要点 |
|:---:|:----|:---------|:--------|
| L1 | **天盘层** | 天盘九星+天干 | 外部能量、天时大势、不可抗力 |
| L2 | **人盘层** | 八门+八神 | 人间事态、人际关系、执行过程 |
| L3 | **地盘层** | 地盘九宫+地支 | 地理位置、底层根基、地气环境 |
| L4 | **格局层** | 天干组合格局 | 特定"化学配方"（混合百神60组） |
| L5 | **年命层** | 问事人年命落宫 | 个人命运底色与当前事的交集 |
| L6 | **时令层** | 节气+四时旺衰 | 当下天时对盘面的强弱影响 |

### 3.2 六层读取规则

每一层的读取顺序：**从L1到L6逐层穿透，每层取一个核心关键词**。

```
L1天盘 → 外部大势（是什么力量在推动这个事）
→ L2人盘 → 事态性质（这个事是什么性质的）
→ L3地盘 → 根基状态（这事扎不扎实）
→ L4格局 → 化学反应（天干组合给了什么特殊配方）
→ L5年命 → 个人交集（问事人与此事的命运连接）
→ L6时令 → 天时加持（季节气机对盘面的强弱影响）
```

### 3.3 ⚠️ 古籍验证标记

**九星配经脉、八门配经脉 ⚠️ 推演所得，非经典原文**
九星配经脉是基于"九星五行→卦宫→经络"的间接推论，在《秘笈大全》《符应经》等古籍中无直接出处。使用时需标注"推演所得"。

## 四、因果穿透·三层法

### 4.1 三层因果定义

| 层 | 名称 | 定义 | 对应宫气 |
|:--:|:----|:----|:--------|
| ① | **表象（文件层）** | 对外公开的说法、写在文件上的理由 | 时干+八门 |
| ② | **实因（推动层）** | 真正主导推进的力量 | 值符+值使+生门 |
| ③ | **底色（战略层）** | 藏在最深处的根本动因 | 值符+年干+天蓬/天心 |

### 4.2 实战路径

```
① 表象 → 查时干落宫+八门
   时干宫的天干组合（如己+杜门→"信息不透明"）

② 实因 → 查值符+值使+生门
   值符落坎1+死门→高层已决策终结旧局
   生门在中宫→有资金方在推动

③ 底色 → 查年干+天蓬/天心
   年干丙在巽宫+天蓬→国家战略级规划调整
```

## 五、时间维度·六阶推进法 + 三维时间判断

### 5.1 六阶推进时间轴

| 阶 | 阶段名称 | 时间范围 | 推演内容 |
|:-:|:--------|:--------|:--------|

| P6 | **收官·长期** | 事发后6-12个月 | 最终格局、余波震荡 |

### 5.2 三维时间判断（时量·时质·时势）

| 维度 | 判断方法 | 古籍来源 |
|:----|:--------|:---------|
| **时量**（多久） | 神应时之初·星应时之中·门应时之末 | 《法窍》 |

### 5.3 应期三大法则（《奇门法窍》融合）

| 法则 | 内容 | 用法 |
|:----|:----|:----|
| 📐 神星门三应 | "神应时之初，星应时之中，门应时之末" | 八神定快慢（神速），九星定中段，八门定收尾 |
| 📐 符使先后应 | "符应在先，使应在后" | 值符所在的宫位先应，值使所在宫位后应 |
| 📐 空亡出旬 | "直符落在旬空，必以出旬断之" | 值符或年命落空亡，必等出旬才能定应期 |

## 六、符号优先级·四层嵌套规则

### 6.1 为什么需要这个规则

当同一个宫位同时出现多个符号方向时，按权重降序选择，避免解读打架。

### 6.2 优先级四层

| 层级 | 判据 | 作用 | 优先级 |
|:---:|:----|:----|:----:|
| ① | **值符所在宫位+混合百神组合** | 最高决策层信息 | 最高 |
| ② | **值使门+八门主事** | 事态性质 | 次高 |
| ③ | **九星休旺+天时趋势** | 能量强弱 | 中 |
| ④ | **八神+格局辅助信息** | 补充/修饰 | 参考 |

### 6.3 混合百神冲突解法

当混合百神组合与八门/九星解读方向冲突时：

```
混合百神吉 ＋ 八门凶 → 以八门为事实方向，混合百神为底色
混合百神凶 ＋ 八门吉 → 以八门为事实方向，混合百神为风险提示
混合百神凶 ＋ 八门凶 → 双重确认，此宫不利
```

## 八、四层奇门融合·时空滚动推演

### 8.1 四层奇门定义

| 层 | 名称 | 定局方式 | 周期 | 用途 |
|:-:|:----|:---------|:---:|:----|
| 🏛️ | **年家奇门** | 年干支定局 | 60年 | 宏观国运、行业大势、大地气 |

| 🌤️ | **日家奇门** | 日干支定局 | 3日 | 事件步骤、出行择日 |
| ⌛ | **时家奇门** | 时辰定局 | 5日 | 当下时空、即时盘面（九维核心） |

### 8.2 四层穿透读取法

```
年干落宫 → "大运底色"（这事的整体基调）
月干落宫 → "当年重点"（这件事在今年的核心位置）
日干落宫 → "当下事件"（问事者与这件事情的汇集点）
时干落宫 → "事体本身"（这件事的真实状态）
```

### 8.3 12节气滚动推演法

以当前节气为P3（引爆点），向前翻6个节气推前因，向后翻6个节气推后果。

```
P1（前12·惊蛰） → P2（前6·清明） → P3（当前·芒种）
→ P4（后6·夏至） → P5（后12·立秋） → P6（后24·白露）
```
