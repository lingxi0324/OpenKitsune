# 科室分类判断规则

## 立极点宫位→科室对照表

| 立极点宫位 | 主要症状 | 科室 | 说明 |
|:----------:|:---------|:----|:------|
| 离9/艮8 | 头痛/鼻塞/面瘫 | 内科 | 排除外伤 |
| 艮8/兑7 | 颈项/肩背痛 | 外科/骨伤科 | 常见误归精神科 |
| 坎1/乾6 | 腰/腹/膝 | 内科/妇科 | 需区分内伤与外伤 |
| 坤2/离9 | 胸/心/不寐 | 内科/精神科 | 八神+离宫双重验证 |
| 震3/巽4 | 胁/乳/风 | 内科 | 肝郁为主 |
| 中5/艮8 | 胃/腹痛 | 内科 | 脾胃为本 |
| 兑7/巽4 | 皮肤/疮疡 | 皮肤科 | 肺主皮毛 |
| 坎1/乾6 | 腰酸/带下/崩漏 | 妇科 | 重点看坎坤宫 |
| 巽4/震3 | 惊风/麻疹/食积 | 儿科 | 重点看艮巽宫 |
| 离9+腾蛇/玄武 | 幻觉/妄见/抑郁 | 精神科 | 八神主导 |

## 科室判定优先级

1. 立极点宫位 → 确定大致科室方向
2. 症状性质 → 外伤/内伤二选一
3. 八门+八神 → 情志病因判定（精神科专用）
4. 患者年龄 → 儿科/妇科/内科分流
