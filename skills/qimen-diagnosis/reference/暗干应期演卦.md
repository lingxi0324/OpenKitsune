# 暗干穿透 + 应期三法 + 奇门演卦

## 暗干穿透

法窍卷六：「凶中有吉，则有暗奇；吉中有凶，则有暗庚。」

### 定位规则

值符加时干定天盘暗干起始 → 阴阳遁顺逆排布各宫

| 宫位状态 | 含义 |
|:---------|:-----|
| 凶格+暗奇（乙丙丁入凶宫） | 表面凶险但暗中有生机 |
| 吉格+暗庚（庚入吉宫） | 表面顺利但暗藏杀机 |
| 暗干生宫位天干 | 暗中助力 |
| 暗干克宫位天干 | 暗中有阻 |

### 找法
1. 值符加时干定天盘暗干起始
2. 阴阳遁顺逆排布到各宫
3. 暗干遇乙丙丁为暗奇——凶中有救
4. 暗干遇庚为暗庚——吉中藏凶

## 应期三法

### 第一法·神应（值符落宫断大势）

| 值符落宫状态 | 应期判定 |
|:------------|:---------|
| 逢冲（对冲宫见值符之六合） | 以六合干/支断——合日前后见分晓 |
| 逢刑（自刑/互刑） | 以合解刑——刑日后的第一个合日 |
| 逢空亡 | 出旬断——空亡填实之日 |
| 不冲不刑不空 | 以星门生克断——生旺之日 |

### 第二法·星应（值使星蒙十二次）

| 状态 | 节奏 |
|:-----|:-----|
| 旺相之气 | 加速（3~7日） |
| 休囚之气 | 减速（15~30日） |
| 刑合 | 僵持后突然变化 |
| 冲 | 立即变化（当日内） |

### 第三法·门应（八门旺相休囚）

| 状态 | 应期 |
|:-----|:-----|
| 旺（月令当季） | 3日内 |
| 相（月令次季） | 7~15日 |
| 休（季末） | 30日左右 |
| 囚（对冲月令） | 3个月以上 |

三应合并：神应定大局时间窗口 → 星应定进展节奏 → 门应定具体落点。

## 奇门演卦（旨归·符使演卦法）

### 演卦规则

| 元素 | 转换逻辑 |
|:----|:---------|
| 值符天盘干 | → 上卦（后天八卦数） |
| 值使地盘干 | → 下卦（后天八卦数） |
| 值使落宫地支 | → 动爻（子1~亥12） |

### 占断要诀

- 世爻：上卦天干对应宫位，代表问事主体
- 应爻：下卦天干对应宫位，代表外部环境
- 六亲：生世为父母、克世为官鬼等
- 用神：根据所问之事取对应六亲
