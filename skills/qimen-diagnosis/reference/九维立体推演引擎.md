# 九维立体动态推演引擎

> 脚本：`scripts/nine_dim_engine.py`

## 九维分项定义

| 维度 | 符号 | 作用 |
|:----|:----|:-----|
| X横向 | X | 判定九宫左右方位、气场横向流转 |
| Y纵向 | Y | 判定九宫高低层级、主次格局 |
| Z深度 | Z | 宫位阴阳虚实、旺衰（阳遁/阴遁核心依据） |
| T时序 | T | 节气/月建/日时干支/多帧时序变化 |
| 人物 | P | 问事人、关联人角色属性 |
| 事件 | E | 核心诉求、事态类型、进程 |
| 物象 | O | 标的物、环境物象 |
| 语义 | S | 情绪正负、属性、场景语义 |
| 逻辑 | L | 跨宫生克、时序生克变数 |

## 核心升级对照

| 维度 | 原有 | 九维升级 |
|:----|:-----|:---------|
| 空间 | 平面九宫 (2D) | 三维立体九宫 (XYZ) |
| 时间 | 单一时辰 | 时序动态飞宫 (多帧/连续) |
| 维度 | 单一医疗 | 人/事/物/语义/逻辑 五维绑定 |
| 校验 | 三重校验 | 九维交叉闭环校验 |
| 输出 | 静态结论 | 动态演变报告 |

## 快速使用

```python
from nine_dim_engine import NineDimEngine
engine = NineDimEngine()

# 静态九维推演（通用场景）
result = engine.deduce_3d(year=2026, month=6, day=2, hour=13,
    multi_dim_bind={"person": "问事人", "event": "求职面试"},
    spatial_hints={"person_zone": "震宫", "event_zone": "离宫"})

# 多帧动态推演
frames = [{"time": "2026-06-02 13:00", "data": {}},
          {"time": "2026-06-03 09:00", "data": {}}]
result = engine.deduce_dynamic(frames)
```

## 各方法使用场景

| 推演需求 | 调用方法 | 输出 |
|:--------|:--------|:-----|
| 剖开盘面逐层看 | `calc_spatial_profile(meta)` | L1→L2→L3→L4→L5→L6 |
| 看表面→实因→底色 | `calc_causal_penetration(meta)` | 三层递进 |
| 看时间趋势 | `calc_time_rolling(meta, direction, steps)` | 三判+六阶+12节气 |
| 看宫位关系网 | `calc_network_analysis(meta)` | 回路/冲击/平衡 |
| 择时判断 | `_eval_time_quality(meta)` | 宝义制伐+五阳五阴+三甲开阖 |
| 出处溯源 | `_add_provenance_report(meta)` | 古籍出处三级标记 |
| 全都要一步出 | `deduce_full_penetration(meta)` | 以上全部集成 |
