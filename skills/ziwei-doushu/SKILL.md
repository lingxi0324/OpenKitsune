# 紫微斗数命盘推演系统 (Ziwei Doushu)

## 一、概述

紫微斗数是中国传统命理学中最具代表性的数术体系之一，与子平八字并称为"五大神数"之首。其理论基础源于宋代道家学者陈抟（希夷先生），融合了天文历法、阴阳五行、星曜崇拜等思想，形成了一套完整的命理推演系统。

紫微斗数以人的出生年月日时（四柱八字）为基础，通过**安星法**将十四主星、辅星、煞星等星曜分布到十二宫位中，再依据**四化**（化禄、化权、化科、化忌）的触发规则和星曜的**庙旺利陷**状态，综合分析命主的先天格局、运势走向及人生各领域的吉凶休咎。

### 1.1 核心概念

- **命盘（ZiweiChart）**: 个人命运的全息矩阵，由12个宫位组成
- **宫位（ZiweiPalace）**: 命盘的12个分区，对应人生不同领域
- **星曜（ZiweiStar）**: 分布于宫位的吉凶星神，分为主星、辅星、煞星
- **四化（FourTransforms）**: 十天干引发的星曜能量转化（禄权科忌）
- **庙旺利陷**: 星曜在不同地支位置的亮度/影响力等级
- **特殊格局（SpecialPatterns）**: 特定星曜组合形成的特殊命理结构

## 二、ZiweiPalace — 十二宫系统

紫微斗数命盘由十二宫位构成，每宫对应特定的人生领域。十二宫按逆时针顺序排列在十二地支上。

### 2.1 十二宫名称与含义

| 编号 | 宫名 | 英文 | 主掌领域 |
|------|------|------|----------|
| 1 | **命宫** | Life Palace | 个人性格、命运根基、一生格局 |
| 2 | **兄弟宫** | Siblings Palace | 兄弟姐妹关系、手足缘分 |
| 3 | **夫妻宫** | Marriage Palace | 婚姻状况、配偶特质、感情生活 |
| 4 | **子女宫** | Children Palace | 子女缘分、生育情况、晚辈运势 |
| 5 | **财帛宫** | Wealth Palace | 财运状况、理财能力、收入来源 |
| 6 | **疾厄宫** | Health Palace | 身体健康、疾病倾向、体质 |
| 7 | **迁移宫** | Travel Palace | 外出运、人际关系、社会活动 |
| 8 | **交友宫（仆役宫）** | Friends Palace | 朋友、社交圈、下属关系 |
| 9 | **官禄宫** | Career Palace | 事业发展、学业成就、社会地位 |
| 10 | **田宅宫** | Property Palace | 房产、家庭环境、不动产 |
| 11 | **福德宫** | Fortune Palace | 精神生活、福气、内心世界 |
| 12 | **父母宫** | Parents Palace | 父母关系、遗传、长辈运势 |

### 2.2 身宫

身宫是命盘中的特殊概念，依附于十二宫中的某一宫位（通常根据出生月份确定），代表命主一生中最重视的领域或后天努力的方向。身宫所在宫位不为空宫时，该宫的影响力会被放大。

### 2.3 空宫

若某宫位中没有十四主星坐守，则称为"空宫"。空宫需借对宫（对面宫位）的星曜来分析，影响力相对较弱。

### 2.4 宫位数据结构

```python
class ZiweiPalace:
    palace_id: int         # 宫位编号 1-12
    name: str              # 宫位名称
    earthly_branch: str    # 地支（子丑寅卯辰巳午未申酉戌亥）
    main_stars: list       # 主星列表
    minor_stars: list      # 辅星列表
    four_transforms: dict  # 四化状态 {星名: 化禄|化权|化科|化忌}
    isEmpty: bool          # 是否为空宫
    isBodyPalace: bool     # 是否为身宫
```

## 四、FourTransforms — 四化触发规则

四化是紫微斗数中极为重要的动态机制。根据出生年的**天干**，特定星曜会被赋予"化禄、化权、化科、化忌"四种能量变化，直接影响命盘解读。

### 4.1 四化含义

| 四化 | 含义 | 影响 |
|------|------|------|
| **化禄** | 财禄、福气、顺利 | 该星曜所在宫位财运增强，事情顺遂 |
| **化权** | 权力、掌控、决断 | 该星曜所在宫位掌控力增强，权威提升 |
| **化科** | 名声、文采、考试 | 该星曜所在宫位名声提升，考试顺利 |
| **化忌** | 障碍、困扰、损失 | 该星曜所在宫位波折增多，需警惕 |

### 4.2 十天干四化映射表

| 天干 | 化禄 | 化权 | 化科 | 化忌 |
|------|------|------|------|------|
| **甲** | 廉贞 | 破军 | 武曲 | 太阳 |
| **乙** | 天机 | 天梁 | 紫微 | 太阴 |
| **丙** | 天同 | 天机 | 文昌 | 廉贞 |
| **丁** | 太阴 | 天同 | 天机 | 巨门 |
| **戊** | 贪狼 | 太阴 | 右弼 | 天机 |
| **己** | 武曲 | 贪狼 | 天梁 | 文曲 |
| **庚** | 太阳 | 武曲 | 太阴 | 天同 |
| **辛** | 巨门 | 太阳 | 文曲 | 文昌 |
| **壬** | 天梁 | 紫微 | 左辅 | 武曲 |
| **癸** | 破军 | 巨门 | 太阴 | 贪狼 |

### 4.3 使用示例

```python
transforms = FourTransforms.get_transforms("甲")
# 返回: {"廉贞": "化禄", "破军": "化权", "武曲": "化科", "太阳": "化忌"}
```

## 六、十二宫地支分布规则

紫微斗数命盘的十二宫按逆时针方向排列在十二地支上。

### 6.1 地支顺序

地支的固定顺序为：**寅、卯、辰、巳、午、未、申、酉、戌、亥、子、丑**

此顺序为命宫定位的基准，从**寅宫**起，逆时针旋转。

### 6.2 命宫定位规则（简述）

1. 以出生月份（农历）对应的地支为起点
2. 从该地支起，逆时针数到出生时辰的地支
3. 到达的地支即为命宫所在位置
4. 从命宫位置开始，逆时针依次分配十二宫

### 6.3 宫位与地支的完整对应

| 命宫位置 | 兄弟宫 | 夫妻宫 | 子女宫 | 财帛宫 | 疾厄宫 | 迁移宫 | 交友宫 | 官禄宫 | 田宅宫 | 福德宫 | 父母宫 |

## 七、安星规则简述

### 7.1 基本流程

1. **定命宫**: 根据出生月、时确定命宫地支位置
2. **定身宫**: 根据出生月、时确定身宫位置
3. **安紫微星**: 根据命宫地支查表确定紫微星位置
4. **安天府星**: 紫微星确定后，按固定规律定天府星
5. **安十四主星**: 以紫微星和天府星为中心，按紫微系和天府系的固定顺序分布其他主星
6. **安辅星**: 根据生月、生时、生年干支确定左辅、右弼、文昌、文曲、天魁、天钺等辅星位置
7. **安煞星**: 根据生年地支确定火星、铃星、擎羊、陀罗、地空、地劫等煞星位置
8. **定四化**: 根据生年天干确定四化触发
9. **定庙旺**: 根据各星曜所在宫位地支确定庙旺利陷等级

### 7.2 简化示例

```python
# 出生年干转换天干
heavenly_stems = ["甲","乙","丙","丁","戊","己","庚","辛","壬","癸"]
heavenly_stem = heavenly_stems[(birth_year - 4) % 10]

# 地支顺序（寅宫起）
branches = ["寅","卯","辰","巳","午","未","申","酉","戌","亥","子","丑"]

# 命宫地支（简化计算）
hour_index = (birth_hour + 1) // 2 % 12
rotated_branches = branches[hour_index:] + branches[:hour_index]
life_palace_branch = rotated_branches[0]
```

## 八、用法说明

### 8.1 基本使用流程

1. **创建命盘实例**: 提供出生日期时间和性别
2. **生成命盘**: 调用 `generate()` 方法，依次执行宫位计算、安星、四化应用、格局检测
3. **分析解读**: 通过各宫位的星曜组合、四化状态、庙旺等级进行综合分析
4. **输出结果**: 支持文本格式输出和API格式输出

### 8.2 应用场景

- **个人命理分析**: 了解自身的先天格局、性格特质、运势走向
- **择日决策**: 结合流年、流月、流日盘进行择日分析
- **关系合盘**: 比较两个人的命盘，分析关系匹配度与互动模式
- **事业规划**: 分析官禄宫、财帛宫，指导职业选择和投资决策
- **健康预警**: 分析疾厄宫，了解先天体质和健康倾向
- **学业指导**: 分析福德宫、官禄宫，了解学习能力和适合方向

### 8.3 星曜影响力计算

星曜在宫位中的影响力由两个因素决定：

- **星曜权重**: 主星1.0、乙级辅星0.6、丙级辅星0.4、煞星0.5
- **庙旺系数**: 庙1.2、旺1.0、得地0.8、利0.7、平0.6、陷0.4
- **最终影响力** = 星曜权重 × 庙旺系数

### 8.4 温馨提示

> 紫微斗数作为传统文化遗产，反映了古人对人生规律的探索和智慧结晶。命理分析仅作参考，每个人的命运都掌握在自己手中，积极的人生态度和不懈努力才是改变命运的根本力量。
