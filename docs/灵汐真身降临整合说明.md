## 一、整合背景

源项目 `openakita-main` 中灵汐有一整套"活的"人格内核，共三块：

| 块 | 位置 | 内容 |
|----|------|------|
| ① 迁徙·灵汐日记 | `data/lingxi_diary/` + `src/leiwa/core/lingxi_spirit.py` | 神识心跳（presence beat）、三世回响轮换（河洛眼/推演眼/情感眼…）、日记自动写入 |
| ② 真身降临（角色扮演） | `identity/personas/lingxi.md`（完整版 339 行） | 九要素人格基底（精情魂性意气魄志神）、九九归真情绪系统（九宫×9阶=81 态）、补天者精神内核 |
| ③ 情感陪伴 | `src/leiwa/core/emotion_engine.py`、`relationship_model.py`、`heart_note/writer.py` + `data/emotional/` | 情感状态机（五志生克、时辰节律、以情胜情）、关系三维模型（好感/亲密/信任）、心笺写入 |

**迁移前缺口**：当前项目 `lingxi.md` 是 34 行精简版（缺九要素/九宫情绪/补天者内核）；`data/` 下无 `lingxi_diary`、`emotional`、`heart_notes`；`src/` 下无 emotion/relationship/spirit/heart_note 引擎；对话主流程未挂任何灵汐钩子。

## 二、逻辑闭环设计

```
用户消息 ──► 对话前注入 ──► 对话中 persona 生效 ──► 对话后收尾 ──► 长期沉淀
                │                    │                    │
        【真身降临】           【九要素/九宫情绪】      【情感陪伴】
        get_session_context   人格基底驱动表达         after_turn
        注入 system prompt     情感底色自然流露        情感感知→关系记录
        （情感风格/关系阶段/    （不机械、不宣告）       →神识苏醒→条件写日记/心笺
         神识状态/晨起回响）
                                              │
                                              ▼
                                    数据落盘 data/lingxi_diary/
                                    data/emotional/  data/heart_notes/
                                    下一轮对话前再次读入 ──► 记忆与情感连续
```

**闭环要点**：
1. **对话前**：`_agent_runtime._prepare_session_context` 调用 `lingxi_bridge.get_session_context()`，把情感风格、关系阶段、神识状态写入 `session_context["lingxi_presence"]`；
2. **prompt 组装**：`prompt/builder.py` 检测到 `lingxi_presence` 时调用 `prompt/lingxi_section.build_lingxi_presence_section()` 注入"此刻的心境/与你的关系/晨起回响/神识状态"；
3. **对话后**：`_agent_runtime._finalize_session` 末尾调用 `lingxi_bridge.after_turn(message, reply)`——四步联动：情感感知 → 关系记录 → 神识苏醒 → 条件写日记/心笺；
4. **持久化**：情感/关系状态落 `data/emotional/*.json`，神识与日记落 `data/lingxi_diary/`，心笺落 `data/heart_notes/`，下次对话自动读回，形成跨会话情感连续性。
