Agent 系统河洛映射技术整改规范

2026-10-17 · 将河图洛书·干支·九宫约束体系转译为可实现的工程规范；实现层不含任何玄学术语，干支词仅出现在第 10 章溯源核对表中。

1. 目的与边界

本规范把「天干主时、地支主节、洛书主位」的约束骨架，转译为三层工程结构：L1 生命周期状态机（何时做什么）、L2 校验门（每步查什么）、L3 运行角色（各处守什么），并以「复合状态编码 + 五类横切策略」贯穿。整改目标是逻辑闭环、状态唯一、节奏同步——既不残缺（无未校验环节）也不重复（无冗余状态）。

边界：本规范描述系统应具备的约束能力与接口契约，不绑定具体语言与实现；实现层标识符即本章及后文给出的英文标识，禁止把干支/九宫名词写入配置或代码。

2. 术语与标识符约定

术语含义
Stage / 阶段任务生命周期的推进位置，共 10 态，编号 S0–S9
Gate / 校验门任务周期内的强制校验点，共 12 门，编号 G0–G11
Role / 角色运行时职责单元，共 9 个，见第 6 章
TaskState复合状态码 = (stage_idx, gate_idx)，合法组合恰 60 个
策略标签五类横切语义：GROWTH / CLARITY / STABILITY / RIGOR / LEARNING

3. 架构总览

S0 意图获取→S1 规格解析→S2 方案设计→S3 草稿生成→S4 执行→S5 过程审计→S6 结果验证→S7 优化→S8 交付→S9 复盘沉淀↺

12 道校验门分布于入口、各阶段转换、收尾与闭环回程上（见第 5 章）；9 个角色按星型拓扑围绕编排器运转（见第 6 章）。三层叠加构成完整约束空间。

4.1 转移规则

  • 主链：S0→S1→…→S9→S0，顺序推进，每步须通过绑定门。
  • 回退（制衡触发）：S6→S3（生成-验证分离：验证发现草稿缺陷，回退重生成）；S6→S1（越界：产物超出意图边界，回退重解析）；S4→S2（执行不可行：连续失败且方案失效，回退重规划）；S9 仅消费 S5 审计日志（复盘数据可追溯）。
  • 心跳：S4 执行期间须有心跳检测，超时挂起而非空转。

5.1 接口契约

interface Gate {
  id: G0..G11;
  bound_stage: Stage;          // 绑定的状态或转换
  condition: () => boolean;     // 可判定的通过条件

6.1 拓扑与架构级制衡

所有角色经 ORCHESTRATOR 调度（星型/中介模式），不直接互相调用；读路径可加缓存降级（见第 12 章）。四组对角对位制衡：

对位技术语义
REASONER ↔ GUARD推理产出的每条内容须经守卫判定（生成即审核，自由与底线互为张力）
EXECUTOR ↔ PRESENTER执行与交付分离，执行结果不得自我宣称交付成功
COLLECTOR ↔ TOOL_REGISTRY采集须登记来源，工具须有调用契约
CONTEXT_POOL ↔ MEMORY_STORE短期上下文与长期记忆物理隔离、语义分流

7. 复合状态编码

任务状态由两个维度构成：推进序号 i（stage_idx，0–9）与 校验序号 j（gate_idx，0–11）。合法组合要求两序号同奇偶，恰生成 60 个合法态；30 个异奇偶组合是「推进与校验节奏脱节」的失衡态，状态机在进入前拦截。

// 合法性：推进节奏与校验节奏同频（奇阳偶阴相配的技术化）
bool is_valid(int i, int j) { return (i % 2) == (j % 2); }

// 转移：阶段与门同步推进，保持同频
State advance(State s)  { return (s.i+1, s.j+1); }   // 先过当前门再推进
State rollback(State s) { return (s.i-1, s.j-1); }
State audit(State s)    { return s; }               // 门内复核不改变状态码
  • 完整：任何合法时刻存在唯一状态码；唯一：(i,j) 组合互异、可追溯；可推演：依 advance/rollback 可预测下一态。
  • 示例：(0,0)＝任务入口·目标校验中；(4,4)＝执行中·数据已汇聚；(8,10)＝交付中·收束在即；(9,11)＝复盘归藏·经验入册。

8.2 依赖方向（相生 → 前置条件）

规格完备(CLARITY 产物)是方案设计前置；草案就绪是执行前置；审计记录完整是验证前置；定稿合规是交付前置；复盘经验是下任务意图获取的前置——五段依赖构成主链推进力，任一前置缺失则后继状态不可进入。

8.3 制衡触发（相克 → 回退/分离规则）

制衡技术语义触发条件

验证-意图边界验证须约束越界行动产物超出意图边界 → 回退 S1 重解析
执行-规划纠偏执行不得僵化盲从连续失败且方案不可行 → 回退 S2 重规划
