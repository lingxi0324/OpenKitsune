# OpenKitsune 启动器维护说明

## 两个版本（并存，二选一运行）

| 启动器 | 启动脚本 | 运行时 | 日志 |
|---|---|---|---|
| `OpenKitsunewinLauncher.exe` | `start.ps1` | Windows `.venv\Scripts\python.exe -m openkitsune serve` | `data\logs\serve_win.log` |
| `OpenKitsunewslLauncher.exe` | `start_wsl.ps1` | WSL 内 `venv/bin/python -m openkitsune serve` | `data\logs\serve_wsl.log` |

两者都指向最新代码目录 `E:\agents\OpenKitsune-main`，共享 `.env`、`data/`、`identity/`。

## 切换方式

同一时间只能有一个版本占用 18900 端口：

```powershell
# 从 Windows 切到 WSL
powershell -ExecutionPolicy Bypass -File stop_win.ps1
# 双击 OpenKitsunewslLauncher.exe（或运行 start_wsl.ps1）

# 从 WSL 切到 Windows
powershell -ExecutionPolicy Bypass -File stop_wsl.ps1
# 双击 OpenKitsunewinLauncher.exe（或运行 start.ps1）
```

`stop_wsl.ps1` 会同时删除 `start_wsl.ps1` 建立的 127.0.0.1 端口代理，避免切回 Windows 时端口被 `svchost` 占用。

## 文件清单

- `start.ps1` — 纯 Windows 启动脚本（无 WSL 依赖）
- `start_wsl.ps1` — WSL 启动脚本（调用 `scripts/wsl_serve.sh`）
- `stop_win.ps1` / `stop_wsl.ps1` — 停止对应版本
- `tools/launcher_win.cs` — Windows 启动器源码
- `tools/launcher_wsl.cs` — WSL 启动器源码
- `tools/launcher.cs` — 旧通用启动器源码（保留兼容）

## 重新编译

在 PowerShell 5.1 中执行（UTF-8 读取源码，避免中文乱码）：

```powershell
$winCs = [IO.File]::ReadAllText("E:\agents\OpenKitsune-main\tools\launcher_win.cs", [Text.Encoding]::UTF8)
Add-Type -TypeDefinition $winCs -OutputAssembly "E:\agents\OpenKitsune-main\OpenKitsunewinLauncher.exe" -OutputType ConsoleApplication

$wslCs = [IO.File]::ReadAllText("E:\agents\OpenKitsune-main\tools\launcher_wsl.cs", [Text.Encoding]::UTF8)
Add-Type -TypeDefinition $wslCs -OutputAssembly "E:\agents\OpenKitsune-main\OpenKitsunewslLauncher.exe" -OutputType ConsoleApplication
```

## 日志

- Windows：`E:\agents\OpenKitsune-main\data\logs\serve_win.log` / `serve_win.err`
- WSL：`wsl -d Ubuntu -- tail -f /mnt/e/agents/OpenKitsune-main/data/logs/serve_wsl.log`
