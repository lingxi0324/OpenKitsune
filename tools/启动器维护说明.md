# OpenKitsune 启动器维护说明

## 文件清单
- `launcher.cs` — OpenKitsune.exe 启动器源码（C#，.NET Framework 4.x）
- `OpenKitsune.exe` — 编译产物，位于 `.OpenKitsune\OpenKitsune.exe`（项目根上级目录）

## 启动器职责
双击入口（`C:\Users\Administrator\.OpenKitsune\OpenKitsune.exe`）：
1. 弹出控制台窗口（Console 子系统，日志实时可见）
2. 以同一控制台运行 `powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1`
3. 启动成功 → 窗口常驻，实时滚动 WSL 服务日志（`tail -f serve_wsl.log`）；关闭窗口不影响服务
4. 启动失败 → 红色错误信息 + 排查日志路径，停住等待确认
5. 单实例锁：窗口开着时重复双击被拦截（提示"已在运行"）

依赖：根目录 `start.ps1`（v5，纯 WSL 直启 + 探活预算 120s/60s/60s + 日志落盘）。

## 重新编译
在 PowerShell 5.1 中执行（注意：必须显式用 UTF-8 读取源码，否则中文乱码报错）：

```powershell
$cs = [System.IO.File]::ReadAllText(
    "C:\Users\Administrator\.OpenKitsune\OpenKitsune\tools\launcher.cs",
    [System.Text.Encoding]::UTF8)
Add-Type -TypeDefinition $cs `
    -OutputAssembly "C:\Users\Administrator\.OpenKitsune\temp\OpenKitsune.new.exe" `
    -OutputType ConsoleApplication -ErrorAction Stop
Copy-Item "C:\Users\Administrator\.OpenKitsune\temp\OpenKitsune.new.exe" `
    "C:\Users\Administrator\.OpenKitsune\OpenKitsune.exe" -Force
```

## 版本历史
| 版本 | 说明 |
|---|---|
| v1（原版 4608B） | GUI 无窗，拉起 powershell 后立即退出；无日志、无反馈 → 用户无法分辨启动/闪退 |
| v2（5632B） | 改 Console 子系统，同一控制台显示日志；等待子进程，失败停留 |
| v3（6144B） | 成功停留 5 秒显示"启动成功"结论 |
| v4（当前 7168B） | 成功窗口常驻 + 实时滚动服务日志；exe 单实例锁防重复启动 |
