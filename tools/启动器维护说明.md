# OpenKitsune 启动器维护说明

## 运行版本

当前仅保留 **Windows 原生版**（WSL 版已删除，2026-10-18）。

| 入口 | 启动脚本 | 运行时 | 日志 |
|---|---|---|---|
| **`manage.ps1`（推荐，纯 PowerShell）** | `start.ps1` / `stop_win.ps1` | Windows `.venv\Scripts\python.exe -m openkitsune serve` | `data\logs\serve_win.log` |
| `OpenKitsunewinLauncher.exe`（兼容遗留） | 内部弹 PowerShell 窗口跑 `manage.ps1 start -ShowLog` | 同上 | 同上 |

桌面快捷方式「OpenKitsune 启动」→ `powershell -NoProfile -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 start`。

> `OpenKitsunewinLauncher.exe` 双击行为：exe 为 GUI 子系统（无黑色控制台），拉起一个独立 PowerShell 窗口
> （彩色启动检查 + 实时日志常驻，等效 `manage.ps1 start -ShowLog`），exe 立即退出；
> 关闭 PowerShell 窗口不影响后台 serve。

## 启停方式（推荐）

```powershell
# 一键启动（已在运行则只开浏览器；默认不阻塞，服务为隐藏独立进程）
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 start

# 启动并前台跟随日志（Ctrl+C 退出日志，不影响服务）——等效旧 exe 的"运行中"窗口
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 start -ShowLog

# 启动后驻留守护（health 探活，serve 崩溃自动重启；Ctrl+C 退出守护）
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 start -Watchdog

# 停止 / 状态 / 重启 / 日志跟随
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 stop
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 status
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 restart
powershell -ExecutionPolicy Bypass -File D:\ai\OpenKitsune-main\manage.ps1 log
```

服务以隐藏窗口、脱离终端的方式运行在 `127.0.0.1:18900`，关闭任何窗口不影响服务。

## 文件清单

- `manage.ps1` — 纯 PowerShell 管理脚本（start/stop/status/restart/log/watchdog）
- `start.ps1` — Windows 启动脚本（支持 -NoBrowser / -ShowLog）
- `stop_win.ps1` — 停止 Windows 服务并释放 18900 端口
- `tools/launcher_win.cs` — 启动器源码（GUI 子系统：双击弹 PowerShell 窗口跑 `manage.ps1 start -ShowLog`；ProjectRoot 指向 D:\ai\OpenKitsune-main）
- `tools/launcher.cs` — 旧通用启动器源码（保留兼容）

> 编码约定：所有 .ps1 必须带 **UTF-8 BOM**，否则 Windows PowerShell 5.1 按 ANSI/GBK 读取中文注释会解析失败。

## 重新编译（修改源码后需要重建 exe 时）

使用 .NET Framework 的 csc.exe 编译为 GUI 子系统（winexe，无黑色控制台窗口）：

```powershell
$csc = "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
& $csc /nologo /target:winexe /codepage:65001 `
    /out:"D:\ai\OpenKitsune-main\OpenKitsunewinLauncher.exe" `
    /r:System.Windows.Forms.dll `
    "D:\ai\OpenKitsune-main\tools\launcher_win.cs"
```

> `/codepage:65001`：源码为无 BOM 的 UTF-8，必须按 UTF-8 读取，否则中文提示会乱码。
> 注意：`launcher_win.cs` 中 `ProjectRoot` 为硬编码常量，仓库迁移后必须同步修改并重新编译，
> 否则启动器会去旧路径找 `manage.ps1`（弹窗报「未找到管理脚本」）。

## 日志

- 启动/运行日志：`D:\ai\OpenKitsune-main\data\logs\serve_win.log`
- 错误日志：`D:\ai\OpenKitsune-main\data\logs\serve_win.err`
